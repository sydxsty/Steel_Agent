# 高强度建筑用钢的焊接技术

屈朝霞， 夏立乾， 郑乔（宝山钢铁股份有限公司， 上海 201999）

摘 要：高强度建筑用钢的应用推广符合我国可持续发展战略， 不仅可有效减少建筑结构的用钢量， 实现建筑结构轻量化，还能创造更大建筑使用空间。 宝钢股份开发了系列高强度建筑用钢， 产品涉及 Q390、 Q420、 Q460、 Q550、 Q690 等强度级别， 采用 TMCP 状态交货， 板厚范围可覆盖 10mm 到 150mm。 它具有优良的综合力学性能， 钢板均匀性好， 板形好，碳当量低，具有良好的焊接性能。为了更好的服务用户及助推高强度建筑用钢应用，宝钢开展了其焊接技术方案研究。以 Q550 和 Q690 为研究对象，系统研究了两个钢种不同焊接方法的匹配焊接材料、 焊接方法及工艺、 焊后处理措施、 不同板厚所需的预热温度及环境温度要求等内容。（1）不同焊接方法匹配的焊接材料。屈服强度为 550 和 690 高强厚焊接材料应分别选用 70kg 和 80kg 焊接材料。气体保护焊时， 建议采用富氩气体， 通常推荐采用 82%Ar+18%CO2。 埋弧焊时，焊剂应按照要求进行烘干、保温和使用，烘干次数不宜超过两次。 通常烧结焊剂的烘干温度为 350～400℃，烘干时间 1-2h，保温温度 150℃。 出烘箱 2 小时后必须重新烘干后方可使用。（2） 预热及焊接环境要求。基于碳当量、 钢材强度级别与板厚等多重因素确定预热温度。 现场安装焊接， 由于安装的构件刚度更大， 需要严格按要求执行。（3）焊后处理举措。 由于高强厚板需要采用多层多道焊接方式进行。多层多道会使得焊缝金属中的扩散氢累积在一起。为了减少焊缝金属中的扩散氢含量，需要创造条件帮助氢逃逸，为此采用缓冷加焊后消氢处理措施， 降低结构的开裂风险。  
基于以上研究结果，宝钢股份有信心和能力支撑业主和施工方完成高强建筑用厚板焊接。
