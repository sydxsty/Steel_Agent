# 热镀锌汽车钢“一贯制”生产工艺流程与技术特点

Production Process and Technical Characteristics of "Consistent System" of Hot-dip Galvanized Automobile Steel

供稿|康华伟， 尹翠兰， 高兴昌 / KANG Huawei, YIN Cuilan, GAO Xingchang

在汽车工业的高速发展下，2022 年中国汽车产量超过 2700 万辆，产销总量已经连续 14 年稳居全球第一。在汽车产量快速增长的同时，主机厂对汽车用钢材料的质量提出了更高的要求，包括表面质量、成形性能、焊接性能、涂镀质量、尺寸精度等，以满足汽车制造行业的多方面需求。通过汽车钢“一贯制”生产管控，提高钢铁企业全流程生产效率与产品质量，降低全生命周期碳排放，为汽车钢的高质量可持续绿色发展做出贡献。

随着经济的快速发展，我国在汽车品种和技术水平方面，已经和发达国家同步，用户对优质汽车用钢的要求越来越高，需求也越来越大[1]。在中国汽车需求量日益增加的同时，伴随着生态环保的加强，汽车轻量化成为汽车工业发展的大趋势[2]。对汽车主机厂而言，希望汽车钢产品的成形性能好、表面质量高、耐蚀性能优、尺寸精度高，确保汽车从生产到应用全过程的质量稳定性；而对于钢铁厂企业，汽车钢生产特点为工艺流程长，包括冶炼、热轧、酸轧、热镀锌、精整等工序，汽车钢产品质量需要高洁净度冶炼，高表面质量、板形质量、尺寸精度和性能均匀的全流程控制工艺。通过智能化关键技术实现多工序、全流程板带产品质量提升和生产过程优化，解决由于工序界面和工况复杂性导致的产品质量和生产效率问题，是板带轧制智能化的未来发展方向[3]。殷瑞钰等[4] 指出当代冶金学的战略目标除了制造新一代产品以外，已经聚焦于冶金工厂的绿色化（绿色、低碳、循环发展）和智能化发展（智能化设计、智能化生产、智能化服务、智能化管理等）。本文着重介绍了汽车钢“一贯制”工艺流程、技术特点及相关设备，基于国内某大型钢铁企业，采用国际先进装备与工艺技术，通过全流程质量分析（PQA）系统进行大数据采集、质量分析及工艺优化，进行“一贯制”全流程质量跟踪与控制，实现热镀锌汽车钢高质量的工业化生产，其生产工艺及管理流程对大型钢铁企业具有较好的借鉴作用。

# “一贯制”概述

所谓的“一贯制”， 就是指横向将相关性强的业务管理职能合并归属于同一个职能部门，强调前后工序的有机衔接。企业从接到合同开始到完成合同为止的管理业务，从原料进厂到成品出厂为止的所有工序，统一由一个管理部门实行一以贯之的管理。质量一贯制管理是以满足用户需求为前提，从产品质量先期策划着手，以规程和质量控制系统为依据，按产品系列从原料进厂直至用户满意，进行以“客户”为中心的全过程的最优化控制（包括效率、成本和进度），并借助 PDCA（计划 Plan、执行 Do、检查 Check、处理 Act）方法来获得最佳的企业经济效益和社会效益，真正实现质量稳定、成本最优、提升效率的目的。

钢铁工业是典型的流程工业，钢铁企业的生产过程错综复杂，主要生产工序包括炼铁、炼钢、热轧、冷轧及热处理等。由于各种汽车钢产品特性不同，其生产工艺亦有所区别， 目前大部分钢企尚未形成全流程的一体化控制与各层次的协调优化，面临着产品外形尺寸与内部性能控制稳定性差、高端供给能力不足、劳动生产率低等问题，大规模、连续化生产条件下的个性化定制亟待全方位推进[5−6]。为了更好地控制热镀锌汽车板的力学性能和表面质量等，需要从冶炼到成品的整个冶金流程进行“一贯制”管理[7]，实现高效率高质量工业化稳定生产。

钢铁最终产品质量的优劣，是由全流程的各个环节共同决定的，要想获得稳定、优良的材料质量，必须针对每一个工艺环节，进行全流程、一体化控制[8]。

冷基热镀锌汽车钢的生产工艺包括炼铁、炼钢、热轧、酸洗、冷轧、热镀锌、精整等。为了提高生产效率，减少头尾切除量，提升钢卷通条力学性能的均匀性与尺寸精度的窄范围控制，炼铁采用大容量高炉生产，炼钢采用连续浇注与连续铸造，连铸后的钢坯通过热送或冷送至热轧加热炉，加热后的钢坯经过热轧精轧与连续精轧轧制后卷取为热轧钢卷，钢卷再开卷通过连续酸洗+冷轧组成的酸轧联合机组后轧制卷取为冷轧钢卷，钢卷再开卷通过连续热镀锌机组进行退火、镀锌以及精整后，获得最终的热镀锌汽车钢产品。对于热基热镀锌钢带，可免冷轧工序，热轧后直接酸洗与热镀锌，但其尺寸精度与表面质量相对较低。热镀锌汽车钢典型全流程生产工艺如图1 所示。

# 生产装备及技术特点

由于汽车钢质量要求高，对产线设备与工艺技术的要求高，否则很难保证汽车钢品质。目前，国内大多数钢铁企业都建设专用的汽车钢生产线，其装备水平与工艺技术均达到国际先进水平，通过炼钢至冷轧全流程“一贯制”管控，可获得理想的组织与性能，满足汽车主机厂的使用要求。

采用转炉双联冶炼技术，有利于提高转炉脱磷率，降低转炉钢水磷含量，提高钢水洁净度，冶炼低磷要求的汽车钢，且能降低原辅料消耗，提高金属收得率。

采用“恒温恒速恒液面”连续浇注控制技术，通过全程高效连铸保护浇注控制，减少钢水温降与二次氧化，降低转炉出钢温度或精炼升温量，改善钢水可浇性。

# 炼钢

采用铁水汽车运输一罐制工艺技术，将炼铁出铁与炼钢装铁所用的铁水罐统一起来，改变了铁–钢界面传统模式，流程更加简洁紧凑，一包到底运行费用低，且降低了过程中夹杂的风险。

采用技术成熟的全机械搅拌（KR）脱硫工艺，利用先进的脱硫冶金专家系统，可准确预测脱硫剂消耗并有效降低脱硫剂使用量。并在 KR 加料处设计带伸缩功能的加料溜管，如图 3(a) 所示。 可最大限度地保证脱硫剂的加入效果，提高了脱硫效率。

连铸通过连续弯曲和矫直工艺，使铸坯曲率均匀变化，避免铸坯表面和固液两相区由于弯曲或矫直引起裂纹。图 3(b) 所示为采用动态轻压下与动态二冷技术，通过扇形段的夹紧液压缸控制压力，在铸坯的凝固末端实施动态轻压下，避免中心偏析、疏松，改善铸坯内部质量。

采用铸坯在线火焰清理技术，可对铸坯表面进行扒皮清理，降低夹杂缺陷， 可满足 FD 高表面汽车钢的要求。

# 热轧

加热炉采用蓄热式燃烧技术，将助燃空气和煤气预热到约 1000 ℃， 使烟气温度降到 150 ℃左右排放，高效回收烟气余热，降低氮氧化物，提高加热质量与设备使用寿命。

粗轧高压水除磷采用 25 MPa 的高压水除鳞系统，提高了除鳞打击力和除鳞效果，同时小流量可节能并减少温降，满足汽车板的高表面质量要求。

采用大压下量的定宽机， 如图 4(a) 所示。最大侧压能力达到 350 mm， 有效地改进板坯的边部质量，且有利于不同宽度规格的订单排产组织，解决轧机与连铸坯料匹配和作业率问题。与传统立辊轧机相比，还可改善板坯的头尾形状，提高金属成材率。

中间坯采用边部加热器+保温罩的保温装置，如图 4(b) 所示。可有效减少中间坯的头尾温差和边部温降，提高横断面、纵向和横向温度的均匀性，保证带钢表面质量以及薄规格汽车板的生产稳定性。

精轧机组均设有长行程全液压自动厚度控制系统（AGC）、工作辊弯辊系统及窜辊系统、连续变化辊凸度（CVC）板形控制技术、工艺润滑系统，采用镰刀弯控制和差分活套的功能，能有效地提高产品的板形、尺寸精度，表面质量和生产稳定性。

轧后冷却模式有层流模式和前+后双超快冷却模式 2 种，带有边部遮挡技术，满足超高强钢生产的工艺要求，降低了合金元素的用量，可实现低成本工业化生产。

采用在线组织性能预报系统，通过理论计算，利用实际数据对模型进行自学习，提高带钢性能预报的准确性。

# 酸轧

采用激光焊机，该设备焊接质量好且适应钢种范围宽，适合汽车高强钢产品生产及新产品开发。

酸洗工艺段采用浅槽紊流技术，在入口设置两弯一矫大张力拉伸破鳞机，改善板形并碎裂带钢表面氧化铁皮，加快化学反应，提高酸洗速度和质量。

酸洗后设置在线表检仪，可有效监控酸洗后钢带表面质量，发现缺陷及时管控，避免冷轧高速轧制断带、辊印等缺陷。

轧机段采用高性能六辊轧机连续轧制， 板形调

控手段丰富，厚度和板形控制能力强，适合薄规格、高强度汽车钢生产，产品精度高，成材率高。

出口设置在线表面检查台， 可实现单与双面的有或无张力检查。

# 热镀锌

入口清洗段采用多级强化清洗工艺， 包括碱喷淋、碱刷洗、电解清洗、热水刷洗、热水漂洗及热风干燥，清洗强度大且效果好，有效去除油污和铁屑，利于提高镀层附着力。在碱洗、电解循环系统中设置高效磁过滤器及碱液浓度自动控制装置，降低碱液中杂质含量。

退火炉采用立式、全辐射管加热和快速冷却技术，加热能力大、冷却速度高、温度控制精度高、炉辊辊形控制优良。适当的炉内纠偏系统及监视系统，保证了退火产品的高质量及通板的稳定性，适合汽车板等高档产品的生产要求。全辐射加热管如图 5(a) 所示。

采用加大加深的熔沟式感应加热陶瓷锌锅，可防止锌渣对镀层产生影响。吹扫气刀带有边部档板、快速离线装置和高精度定位调整系统，可满足高速下镀层质量要求；通过电磁稳定系统降低带钢的摆动幅度，获得厚度均匀的镀层。

采用四辊光整机与二弯一矫拉矫系统，并配有工作辊正负弯辊系统、湿光整和高压水清洁系统，保证带钢表面质量与板形质量，适应多品种生产。

采用多供液箱的辊涂式钝化设备， 如图 5(b) 所示。可实现三价铬钝化、无铬钝化、耐指纹钝化等多种环保钝化模式。

出口段设置立式与水平检查站供停机对带钢表面进行磨石检查与板型检查，另外装有自动表面缺陷检查装置、机械性能检测装置和粗糙度检测装置等自动质检设备。

考虑汽车板生产对周边环境洁净度要求，退火炉后均设置机组封闭及必要的防蚊设施。

# 结束语

我国钢铁企业应及时掌握国内外先进高强度汽车钢板的发展动向，不断地进行产品开发及应用技术研究的对标提升，使我国汽车用钢达到世界先进水平。汽车钢的“一贯制”生产绿色工艺已成为当前汽车发展的主导方向，需要钢厂自主创新、产销研一体化、与用户互动研发，并充分展现良好的用户应用技术与供应商的先期介入（EVI）工作模式，让材料制造商介入下游用户的早期研发阶段，充分了解用户对原材料性能的要求，从而为用户提供更高性能的材料和个性化服务，实现热镀锌汽车钢全生命周期的高质量发展。
