# 厚规格海工钢组织调控与力学性能研究

宋继强1，2，3，白学飞1，2，3，马 林1，2，3，王彦龙1，2，3，张小宇1，2，3，徐 鑫1，2，3（1．日钢营口中板有限公司，辽宁 营口 1500；2 ．辽宁省中厚板专业技术创新中心，辽宁 营口 1500；

3．辽宁省企业技术中心，辽宁 营口 1500）

摘　要：为提高厚规格海工钢低温冲击韧性，使其获得良好的强韧性匹配，对某钢厂生产的80mm厚EH36钢板的轧制与水冷工艺进行研究，实现对钢板组织的调控，达到优化厚规格海工钢强韧性匹配，提升低温冲击韧性的目的。试验采用了7种不同轧制与水冷工艺，并对试制钢板进行了拉伸性能试验、冲击性能试验以及金相组织观察。结果表明：在低碳微合金化的化学成分体系下，粗轧阶段至少2道次压下率大于10％、中间坯厚度为2h以上（h为成品钢板厚度），控制精轧终轧温度小于80 ℃、终冷温度小于30 ℃，可获得细化的针状铁素体、贝氏体组织，钢板强韧性匹配良好。进一步，将钢板在冷却前进行弛豫处理，再水冷至30 ℃以下，析出一定比例的先共析铁素体，并使组织得到进一步均匀与细化，使钢板冲击韧性得到了进一步提升。

# Research on microstructural control and mechanical properties of thick gauge ofshore stel

海洋资源是除陆地资源以外，人类赖以生存与发展的最重要的资源领域之一。特别是海洋强国战略的提出，进一步吹响了我国向海洋进军的号角。随着海洋资源开发不断向远海、深海拓展，海工装备也将不断向大型化、智能化与绿色化方向发展［1］。由于装备大型化以及结构安全性要求的不断提高，对钢板的等级要求也不断提高，除要求较高的强度以外，还需要优异的低温冲击韧性以及良好的焊接性能［2］，以适应未来海工装备的发展需求。

# 3 分析与讨论

# 3．1 轧制工艺对 EH36 钢板组织性能的影响

3．1．1 粗轧大压下对 EH36 钢板组织性能的影响

钢板厚度方向变形渗透不足，是其厚度方向组织 均 匀 性 不 佳、晶 粒 度 粗 大 的 主 要 原 因 之一［9］。在粗轧再结晶轧制阶段，采用大压下轧制策略，即单道次压下率不小于10％，使轧制力充分向芯部渗透，使厚度方向不同位置能够充分发生再结晶，以达到组织细化与均匀化的目的［10］。对比1号与2号钢板，1号钢板粗轧末2道次压下率在10％以上，2号钢板粗轧道次压下率均小于10％，相对应的2号钢板组织粗大且极不均匀，冲击韧性较差。

# 3．1．2 中间坯厚度与精轧终轧温度对 EH36 钢板组织性能的影响

精轧阶段，在奥氏体非再结晶区温度范围内，将钢板组织进一步拉长与细化，以形成大量位错、亚晶、变形带等晶体缺陷，为接下来的相变准备足够的铁素体形核核心，从而实现细晶强化，改善钢板的强韧性。因此，在精轧阶段需保证累计压下率在50％［11］以上，即中间坯厚度需在2　h（h为成品钢板厚度）以上。但由于中间坯厚度的提升，使钢板表面与芯部的温差进一步加大，根据经验公式［12］可得表面与芯部的温差约为0．45　t（t为中间坯厚度）。当精轧终轧温度过高时，钢板厚度方向芯部温度高于奥氏体再结晶临界温度，轧制变形结束后钢板内部将继续发生再结晶，并在高温下晶粒快速长大，最终将导致出现晶粒粗大及混晶组织［13］。对比1号、3号及4号钢板，3号钢板精轧终轧温度841℃，钢板轧后发生再结晶且在高温条件下晶粒快速长大，4号钢板中间坯厚度141 mm（1．73　h），精轧累计压下率不足，均导致3号、4号钢板组织粗大且不均匀，冲击性能稳定性较差。

# 3．2 水冷工艺对 EH36 钢板组织性能的影响

# 3．2．1 终冷温度对 EH36 钢板组织性能的影响

较低的终冷温度，一方面可以使更多的位错、空位等缺陷保留在基体中，提升晶内形核率，有效细化组织；另一方面，可以改善钢板厚度方向温差导致的组织差异，最大限度在厚度方向获得细小且高位错密度组织，从而改善钢板的强韧性［14］。对比1号、5号钢板，通过增加冷却水流量，使5号钢板终冷温度降至30 ℃以下，使组织由不均匀的多边形铁素体转变为以针状铁素体、贝氏体为主的细小且相对均匀的多相组织，钢板1／4厚度位置冲击功由终冷温度457℃时的149J提升到终冷温度30 ℃时的251J，如图6所示。

# 5 结论

（1）粗轧阶段大压下率轧制，并提高精轧阶段的奥氏体非再结晶区累计压下率，能够显著改善EH36钢板厚度方向变形渗透不足的问题，并在精轧阶段形成大量位错、亚晶、变形带等晶体缺陷，实现细晶强化，改善钢板的强韧性；

（2）较低的精轧终轧温度，可确保钢板厚度方向不同位置温度均低于奥氏体再结晶临界温度，避免轧制变形后再结晶现象的发生，从而提高钢板组织的均匀性；

（3）在低温控轧工艺条件下，当终冷温度小于30 ℃时，获得了细化的针状铁素体、贝氏体组织，钢板强韧性匹配改善明显；

（4）降低冷速、提高水冷时间，能够有效促进钢板内部热量的释放，从而更充分地完成组织细化并改善厚度方向组织的均匀性；

（5）钢板入水前进行弛豫处理，使钢板组织先发生先共析转变，析出一定比例的先共析铁素体；同时，在Nb元素的析出强化与钉扎铁素体晶界共同作用下，进一步实现了组织的均匀与细化，可实现冲击韧性的进一步改善；

（6）按照上述工艺生产的80 mm 厚规格海工钢，1／4 厚度位置及芯部冲击韧性稳定并满足－40℃低温冲击标准要求。
