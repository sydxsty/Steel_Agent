# Nb对高性能汽车钢的作用及影响机理

康 华 伟

（山东钢铁集团日照有限公司 钢铁研究院，山东 日照 276800）

摘 要：对微合金铌（Nb）的影响机理以及Nb在现代汽车用钢中的作用进行了分析，分析结果表明，Nb发挥作用明显，对金属的组织、性能、加工和工程应用起到了潜在的影响，能够提高汽车安全性，实现汽车的减重轻量化。

# 1 前 言

我国正处于汽车发展的普及期，汽车市场在未来的很长时间内仍将呈持续增长态势，但因汽车引起的环境污染与安全事故也将带来巨大的压力，因此，汽车的轻量化、安全性和低成本要求汽车用钢向高强度、高韧性和更易于加工方向发展。含Nb汽车钢的发展应用，大幅提升钢的强度与韧性，Nb微合金是目前汽车用钢中添加最广的微合金元素之一。

20世纪80年代是汽车用含Nb钢高涨的年代，我国虽然发展较慢，但对含Nb 汽车钢的使用也越来越广泛。目前欧洲典型的汽车含Nb 量约100 g/辆，如此微量的Nb 就能在汽车安全和轻量化方面达到非凡的效果。据统计，目前世界平均吨钢的Nb消耗量为50 g左右，而中国仅约为23 g。随着含Nb 合金钢的良好组织结构与突出性能表现，目前许多钢铁厂都在加大对微合金Nb 钢的研究与应用，以适应高强高韧钢的发展趋势。

# 2 微合金Nb对钢的影响机理

在钢的各种微合金化元素中，Nb是最有效的微合金化元素，104个铁原子中有1个铌原子就能达到改善钢性能的目的，实际上钢中加入0.001%～0.1%的Nb就足以改变钢的力学性能。Nb作为微合金化元素加入钢中并不改变其结构，而是与钢中的C、N、S结合改变钢的显微结构。Nb对钢的强化作用主要为细晶强化和弥散强化，Nb能和钢中的C、B生成稳定的碳化物和碳氮化物，还可以使碳化物分散并形成具有细晶化的钢［1］，因此，晶粒细化和沉淀强化是微合金钢最重要的两种强化方式。

生产汽车用钢的微合金化元素一般有Nb、V、Ti、Zr 和B 等。其中Nb、V、Ti 等微合金元素的加入，既能阻止奥氏体晶粒长大，又能阻止奥氏体再结晶，从而细化了铁素体晶粒，其结果如图1 所示［2］。从图1 中可看出，Nb 的细化晶粒效果最明显，因此本研究主要是针对Nb 微合金对汽车钢的影响作用。

微合金元素主要是以细化晶粒为目的而添加到钢中，同时也伴随着沉淀强化以及改善夹杂物形状等作用。微合金元素Nb、V、Ti 在钢中与C、N 强烈反应形成相应的碳化物、氮化物或碳氮化物，统称为微合金碳氮化物M（CN）。此化合物加热到高温时溶解，而在低温时又弥散析出，对钢材的强韧性产生重大影响。同时，此化合物在冷轧后的退火过程中阻碍再结晶及晶粒长大，从而改善冷轧钢的机械性能［3］。Nb 钢在加热过程中，加热到1 200 ℃时保温10 min，钢中的Nb大部分都溶于奥氏体中，析出的Nb 质点非常小；在轧制过程中，高温变形（再结晶区域，如1 050 ℃）时，Nb（C，N）化物颗粒是沿奥氏体晶界析出，而在晶内析出量很少；低温变形（未再结晶区域，如800～900 ℃）时，由于奥氏体未发生再结晶，具有较高的畸变能，位错密度高，因而加速了C和Nb的扩散速度，在晶界上、晶内和亚晶界上均有Nb（C，N）化物颗粒析出，故析出的颗粒较小。控制轧制就是应用微细的Nb（C，N）化物析出质点固定在亚晶界而阻止奥氏体晶粒再结晶，达到细化晶粒的目的［4］。对Nb 在钢中奥氏体与铁素体的作用机理，进行了归纳总结，如图2所示。

# 3 微合金Nb对汽车钢的作用

通过对微合金Nb 对钢的机理研究分析，可得出Nb 对汽车钢的主要作用有：1）提高汽车钢的强度。2）提高汽车钢的韧性。3）提高汽车钢及构件的疲劳性能。4）提高汽车钢的扩孔性能。5）提高汽车钢的弯曲性能。6）降低带状组织以及偏析。7）减缓汽车构件的氢致脆裂。8）提高汽车镀锌钢板的锌层附着力。 9）提高汽车镀锌钢板的工艺可行性。

含Nb 高性能钢在乘用汽车的车身覆盖件、结构件、保安件等大量使用，如目前大量使用的IF钢、HSLA 钢、DP 钢、BH 钢、TRIP 钢以及超高强度热冲压成型PH钢等汽车用钢，微合金Nb在其中发挥了明显的作用，如表1所示。

# 4 结 语

微合金Nb 的应用，对金属的组织、性能、加工和工程应用都起到了潜在的影响，微合金化钢的工艺技术将因人类对能源需要的不断增长而受到巨大影响。在当今国内汽车发展迅速期，Nb 在汽车钢的应用中起到了突出的作用，如何低成本高效地发挥Nb 在汽车钢中的最大贡献，仍需技术人员不懈地研究。
