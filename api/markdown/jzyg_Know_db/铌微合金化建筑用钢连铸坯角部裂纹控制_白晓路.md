# 铌微合金化建筑用钢连铸坯角部裂纹控制

白晓路1， 张小伟1， 李梦飞2， 张立强2（1 永钢集团炼钢厂， 江苏 张家港 215628； 2 安徽工业大学冶金工程学院， 安徽 马鞍山 243032）

摘　要：为了研究含铌建筑用钢轧制产生开裂的问题，对多组铸坯低倍样进行检测分析，并结合生产过程数据对化学成分、中间包过热度、拉速及二冷各区比水量进行了统计分析。结果表明，角部裂纹是缺陷根源，含铌钢铸坯的断面收缩率低于75％的温度范围为750～960℃。通过降低二冷一区的比水量，适当提高三区、四区的比水量、调整矫直温度使其避开断面收缩率小于75％的温度区间和控制硫、磷、铬含量等一系列优化措施，有效解决铸坯表面的角部裂纹缺陷，保证了含铌建筑用钢的产品质量。

关键词： 铌微合金化建筑用钢； 连铸坯； 角部裂纹； 二冷； 残余元素文献标志码：A 文章编号： 105－406（202 ）02－ 061－05

随着钢铁市场竞争的日益剧烈和钒铁合金价格居高不下，各公司均在研究摸索以铌代钒的工艺，通过实施部分或全部替代来降低建筑用钢生产成本［1－3］。但是永钢炼钢三厂7号连铸机生产的含铌建筑用钢共发生6次轧制开裂，为了消除裂纹提高产品的质量，永钢对连铸坯角部裂纹的形成进行了分析研究，发现含铌钢裂纹敏感性较高［4］，含铌钢因凝固过程中铌的氮化物或碳化物析出造成钢的热塑性降低，容易在连铸坯上产生较为严重的裂纹，在轧制过程中开裂、冒料，对生产顺行和产品质量带来不利的影响［5－11］。本文通过采取相应的控制措施，使含铌建筑用钢表面的裂纹得到了有效的控

制，取得了良好的效果。

# 3 角部裂纹影响因素分析与探讨

根据角部裂纹检测结果，结合生产过程数据对化学成分、保护渣、中间包过热度、拉速、结晶器水量及二冷各区比水量进行了统计分析。在现有工艺参数条件下，以下因素与低倍角部裂纹有较为显著的对应关系。

# 3．1 铌对铸坯热塑性的影响

铌元素属于过度族元素，具有未充满内层的电子排列，可置换铁原子形成置换固溶体，其表现出很强的碳、氮化物的形成倾向。铌在体心立方结构中的扩散系数比在面心立方结构中要高，所以在奥氏体向铁素体转变过程中铌的碳、氮化物在晶界大量析出［12－15］。这是其热塑性降低的主要原因。断面收缩率表示钢材断裂前经受塑性变形的能力，断面收缩率越高说明钢材塑性越大。 铌对钢热塑性的影响如图2所示。

![](images/86c8930c138741a8af225681d9ebc42ad53c3963a067432af0a0f1d6c304919b.jpg)  
图2 铌对钢热塑性的影响

由图2可知，对于不含钢铸坯在温度低于950℃时，热塑性随温度的下降而下降，当温度下降到约为815℃的时候，不含钢铸坯的断面收缩率最低约为68％，对于不含钢铸坯在温度低于815℃时，热塑性随温度的下降而上升。为了降低铸坯裂纹发生的概率，矫直温度应避开断面收缩率低于75％的温度区间，所以设定临界断面收缩率为75％。由图2可知，不含铌钢铸坯低于临界断面收缩率的温度范围为780～870 ℃

含铌钢铸坯的断面收缩率在低于1　10 ℃时就开始下降，在825℃左右时达到最低，约为53％，当温度降低到825℃以下时，断面收缩率再次上升。由图2可知，含铌钢铸坯低于临界断面收缩率的温度范围为750～960℃。

# 3．2 残余元素对角部裂纹的影响分析

尽管铌的加入确实引起了钢的热塑性变化，但是有些钢厂通过对残余元素及其他冶炼工艺的合理控制使铸坯裂纹控制在合理的范围，使其不影响铸坯质量。因此，铸坯裂纹和其他缺陷被错误的归因于铌对热塑性的影响，而忽略了残余元素的影响，如在某些情况下造成热塑性降低的根本原因是硫含量造成的硫化物夹杂。有资料表明［16－17］，如果硫过高，会使铌的碳、氮化物与奥氏体的晶界之间产生大量的空位，扩大裂纹的产生。又比如［18－21］，磷含量过高，则发生磷偏析的概率增加，在凝固过程中，低于固相线温度将出现枝晶间液体，在奥氏体晶界上出现的这种液体将严重影响铸坯的热塑性，使铸坯在连铸结晶器内或二冷早期产生裂纹。

# 3．3 拉速对角部裂纹的影响分析

确定浇注拉速应该首先考虑钢水过热度的影响，在合适的过热度下选择适合的拉速有利于保证铸坯的质量和提高的生产效率。在同一钢水过热度下，浇注拉速越高，在结晶器内生成的坯壳越薄，铸坯的不均匀性越严重；浇注拉速越低，铸坯在冷却区所受的冷却强度越大，铸坯越易发生凹陷引起内裂［2 ］。

角部裂纹与拉速的关系如图5所示，统计数据来源于了184炉的含铌建筑用钢低倍样本（样本量：54块低倍试样），从图5可以看出，在7号连铸机目前的生产节奏、中间包温度控制水平及二冷强度条件下，随着拉速的增加，低倍角部裂纹不低于3．0级的比例呈下降趋势，尤其是拉速为2．80～3．0m／min时，角部裂纹不低于3．0级的比例显著降低。

# 3．4 二冷强度对角部裂纹的影响分析

含铌钢由于铌元素会使钢的共析转变推迟，造成第三脆性温度区向低温区域延伸并扩大。如果方坯在二冷区采取冷却强度较大的喷水冷却时，坯温过低则易导致Nb（C，N）在奥氏体晶界上析出，从而使方坯的塑性降低，产生晶界裂纹，尤其角部冷却速度比中间快，更易产生角部裂纹。因此，二冷区需要适当降低水量，并调整水量在各区的水量配比，实现矫直前段相对较弱的冷却［23］。

# 4 工艺改进及优化效果

# 4．1 工艺优化

（1）建筑用钢在不增加工序、不影响生产效率且不增加成本的前提下，尽量采取控制钢种冶炼磷、硫成分，该钢种要求磷、硫的质量分数都不高于0．045％，为防止因角裂出现问题，在生产过程中对磷、硫的含量进行控制，一般控制 w（P）≤0．038％、w（S）≤0．030％、避免含铬钢水回炉冶炼等措施。

（2）中间包过热度按照不低于30℃控制，适当提高拉速，典型工作拉速控制在2．80～3．0m／min。

（3）优化连铸二冷工艺，在确保不漏钢的前提下，降低二冷一区的比水量，适当增加三区、四区的比水量，使铸坯在二冷室的温度波动控制在合理范围之内，且保证矫直温度不低于950 ℃

# 4．2 效果

通过相关工艺优化措施，角部裂纹得到明显改 善。工艺优化前后角部裂纹对比如图7所示。

# 5 结论

（3）微量元素对含铌钢的影响同样不可忽视，应尽量控制硫、磷、铬含量，使其不至于过高。
