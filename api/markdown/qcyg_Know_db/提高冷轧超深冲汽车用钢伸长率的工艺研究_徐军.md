# 现状与分析

某汽车用户针对 A钢厂0．7mm厚的DC06钢种产品，提出了断后伸长率A ≥43％的性能要求。而历史数据显示，A钢厂 DC06产品的断后伸长率稳定达到40％，可以满足一般用户的需求。

根据客户订单厚度要求，收集了 A、B两个钢厂0．7 mm 厚 DC06 带钢的伸长率历史数据，使用minitab 工具对数据做Xbar－R控制图，如图1所示。

由图1可知，A、B两个钢厂生产的 DC06带钢伸长率均值基本相同。 但是 A 钢厂的数据整体波动较大，当用户提出更高要求时，合格率无法达到10 ％，部分钢卷会降级销售，导致利润下降；而 B钢厂的数据波动相对稳定，所有数据均在 43％以上。

为使 A钢厂 DC06 带钢伸长率稳定达到客户要求水平，首先要确认带钢伸长率的影响因素，主要从生产工艺和化学成分两个方面进行分析。

（1）工艺方面。热轧工序的卷取温度［5－6］、连续退火工序的退火温度等工艺参数对冷轧退火后带钢的晶粒尺寸大小有直接影响。热轧工序精轧终轧温度对晶粒尺寸及均匀性有重要影响，提高精轧终轧温度，有助于形成尺寸较大而均匀的等轴铁素体晶粒［7］；在一定范围内，较低退火温度条件下细小的第二相粒子呈条带状偏聚，随退火温度的升高，晶粒长大，第二相粒子溶解聚集长大，第二相粒子数量减少，没有明显偏聚，分布更均匀，可避免局部塑韧性差，使冷轧退火后带钢伸长率增加［5］。另外，有研究［8］指出，提高平整机延伸率将导致冷轧带钢伸长率的降低。

（2）化学成分方面。随钢中 C含量的增加，其塑韧性下降；微量元素Nb、Ti为强碳化物形成元素，易与C形成稳定碳化物，使钢中的C、N间隙原子得以消除，得到纯净的铁素体基体，从而使钢具有高的塑韧性。钢中的 Al主要用作脱氧剂，另外，炼钢工序水口结瘤物的脱落会导致 AlO 类夹杂物的产生［9］；钢中S、P元素的偏析，会显著降低钢的塑性和韧性，随钢中S、P含量的增加，其伸长率呈下降趋势［10］。文献［1 ］指出，Si、Mn、P的加入，会危害钢材的延伸性能，但钢水中Si含量太低，会使脱S能力变弱［12］。为此，初步确定了对 DC06带钢伸长率产生影响的因素有：精轧终轧温度、卷取温度、退火温度、平整机延伸率、钢中C、Si、S、P、Mn、酸溶铝（Als）、Ti、N、Nb等含量。

凭借 minitab工具，采用逐步回归法，确定了影响DC06带钢伸长率的关键因素为退火温度、平整机延伸率、精轧终轧温度、及钢中Si、S、P含量，如表1所示。

# 结论

（1）提高退火温度，DC06钢中晶粒长大的同时，第二相粒子发生了溶解聚集长大，使带钢伸长率随之增加。

（2）与平整机延伸率为0．6％的工艺相比，平整机延伸率为0．5％时，DC06 带钢具有较高的断后伸长率。

（3）S含量偏高时，易生成 MnS夹杂，带钢厚度断面夹存在 MnS夹杂物，对改善带钢断后伸长率是不利的。

（4）针对0．7 mm厚超深冲级别DC06带钢，在其他工艺参数不变的情况条件下，通过提升退火温度、降低平整机延伸率、降低钢中S含量的措施，使DC06带钢伸长率稳定达到43％以上。
