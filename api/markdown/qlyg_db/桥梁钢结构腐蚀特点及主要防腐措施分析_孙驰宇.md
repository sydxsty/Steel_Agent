# 桥梁钢结构腐蚀特点及主要防腐措施分析

孙驰宇

（大庆油田工程建设有限公司路桥公司 黑龙江大庆 163000）

[摘  要] 针对某海洋环境大桥钢结构的腐蚀问题， 通过检测钢箱梁、 钢桁梁等关键构件，分析其腐蚀特点与影响因素。结果表明，该钢结构腐蚀具有分布不均衡性和类型多样性，受环境、材料及结构设计因素共同作用， 钢箱梁底板腐蚀速率最快。采用涂层防腐与阴极保护联合技术，显著降低腐蚀速率，延长结构使用寿命。

[关键词] 桥梁钢结构； 腐蚀特点； 防腐措施； 涂层防腐

# 前言

某大桥钢结构用量1.2万t， 主要涵盖钢箱梁、钢桁梁及钢支座等关键构件。该桥梁常年受高湿度、高盐雾、强紫外线及周期性潮汐作用影响，钢结构腐蚀问题突出。运营5年后，检测发现部分钢桁梁节点出现点蚀现象，钢箱梁底板局部锈蚀厚度达0.3mm， 直接影响结构承载能力和使用寿命。桥梁钢结构腐蚀不仅会增加维护成本，还可能引发结构安全隐患，因此，系统分析其腐蚀特点，探究针对性防腐措施，对保障桥梁运营安全、延长使用寿命具有重要工程意义。

# 桥梁钢结构腐蚀特点

# 1.1 腐蚀分布不均衡性

该大桥钢结构腐蚀呈现明显的部位差异性，不同结构构件及同一构件不同区域的腐蚀程度差异显著。其中，钢箱梁底板、腹板及钢桁梁节点区域腐蚀最为严重，钢支座及钢护栏腐蚀相对较轻。这一现象主要与各部位所处环境条件、受力状态及防护情况密切相关。钢箱梁底板长期处于密闭空间，内部易积聚水汽，且通风条件较差，同时承受车辆荷载带来的振动作用，导致涂层易破损，进而引发锈蚀；钢桁梁节点多为焊接或螺栓连接部位，存在缝隙结构，易形成缝隙腐蚀，加速局部锈蚀进程；钢支座表面有防腐涂层保护，且处于相对干燥的环境中，腐蚀速率较低[1]。

为精准掌握该桥梁钢结构腐蚀分布情况，对其关键构件进行全面检测，检测范围涵盖钢箱梁、钢桁梁、钢支座等主要钢结构部位，检测结果如表1所示。由表1可知，钢箱梁底板腐蚀速率最快，年平均腐蚀速率达0.12mm，钢桁梁节点次之，年平均腐蚀速率为0.09mm，钢支座腐蚀速率最慢，年平均腐蚀速率仅为0.02mm。腐蚀分布的不均衡性导致钢结构局部承载能力下降，若不及时处理，可能引发局部结构失效，进而影响整个桥梁的安全运营。

# 1.2 腐蚀类型多样性

该大桥钢结构腐蚀类型多样，主要包括大气腐蚀、海洋腐蚀、缝隙腐蚀及应力腐蚀开裂等多种类型，不同腐蚀类型相互叠加，加速了钢结构的损坏进程[2]。其中，大气腐蚀主要由空气中的氧气、水汽及二氧化碳等物质引发，属于电化学腐蚀范畴，在桥梁钢结构表面形成一层薄液膜，构成腐蚀电池，导致钢材逐渐锈蚀。海洋腐蚀是该桥梁钢结构面临的主要腐蚀类型，所处海洋环境中含有大量Cl-，Cl-具有强腐蚀性，能够穿透钢结构表面的氧化膜，破坏涂层防护效果，导致钢材发生严重锈蚀。缝隙腐蚀主要发生在钢结构的连接部位及缝隙处，这些部位易积聚电解质溶液，形成局部腐蚀电池，导致缝隙内部钢材快速锈蚀。应力腐蚀开裂是在腐蚀介质和拉应力共同作用下产生的一种严重腐蚀形式，该桥梁钢结构在车辆荷载、风力及温度变化等作用下产生持续拉应力，在海洋腐蚀介质的侵蚀下，部分高强度钢构件出现应力腐蚀裂纹，严重威胁结构安全[3]。不同腐蚀类型的协同作用，使得该桥梁钢结构腐蚀问题更为复杂，给防腐工作带来较大挑战[4]。

# 2 桥梁钢结构腐蚀影响因素分析

# 2.1 环境因素

环境因素是影响该大桥钢结构腐蚀的主要外部因素，主要包括湿度、温度及紫外线照射等。湿度是腐蚀发生的必要条件，空气中的水汽在钢结构表面形成薄液膜，为电化学腐蚀提供了介质环境[5]。该桥梁所处区域年平均相对湿度达82%，高湿度环境使得钢结构表面长期处于湿润状态，加速了腐蚀反应的进行。温度变化会影响腐蚀反应速率，该区域昼夜温差较大，导致钢结构表面液膜浓度发生波动，同时引发构件热胀冷缩，产生微小裂纹，为腐蚀介质侵入提供通道。紫外线照射会加速防腐涂层的老化分解，并且破坏涂层的化学结构，导致涂层出现开裂、粉化、脱落等现象，降低涂层防护效果。

# 2.2 材料因素

材料自身因素对该桥梁钢结构腐蚀具有重要影响，主要包括钢材化学成分、组织性能及表面状态等。钢材化学成分中的碳、铬、镍等元素会影响其耐腐蚀性，碳含量过高会导致钢材组织中珠光体含量增加，降低钢材的耐蚀性；铬、镍等合金元素能够提高钢材的耐蚀性，形成稳定的氧化膜，阻碍腐蚀介质的侵入。该桥梁钢结构采用Q345qD钢材，该钢材含铬量为0.5%，含镍量为0.3%， 耐蚀性一般，在海洋环境中易发生锈蚀。

钢材组织性能也会影响腐蚀速率，均匀细小的晶粒结构能够提高钢材的耐蚀性，而晶粒粗大、组织不均匀会导致钢材内部电位差增大，加速电化学腐蚀。该桥梁部分钢结构构件在焊接过程中，因焊接工艺不当，导致焊缝区域晶粒粗大，组织不均匀，成为腐蚀敏感区域。钢材表面状态对腐蚀也有重要影响，表面光滑、无缺陷的钢材耐蚀性较好，而表面存在氧化皮、锈蚀、划痕等缺陷的钢材，易成为腐蚀起始点。该桥梁部分钢结构在加工过程中，表面未进行充分清理，残留氧化皮和划痕，加速了腐蚀进程。

# 2.3 结构设计因素

结构设计合理性直接影响钢结构的腐蚀程度，主要包括排水设计、通风设计及连接设计等。排水设计不合理会导致钢结构表面积水，积水会积聚腐蚀介质，延长钢结构与腐蚀介质的接触时间，加速腐蚀。该桥梁钢箱梁内部排水孔设置数量不足，且部分排水孔被堵塞，导致雨天过后，钢箱梁内部积水无法及时排出，长期积聚在底板和腹板部位，引发严重锈蚀。通风设计不佳会导致钢结构所处环境湿度升高，加速涂层老化和钢材锈蚀，该桥梁钢箱梁内部通风口设置不合理，通风效果差，内部湿气无法及时排出，形成高湿环境。

连接设计不当会导致钢结构出现缝隙，形成缝隙腐蚀，该桥梁钢桁梁节点采用螺栓连接，连接部位存在较多缝隙，雨水、盐雾等腐蚀介质易积聚在缝隙内部，形成局部腐蚀电池，导致缝隙内部钢材快速锈蚀。此外，结构设计中未充分考虑腐蚀裕量，部分构件设计厚度不足，在长期腐蚀作用下，截面厚度快速减薄，提前出现失效现象。

# 3 桥梁钢结构主要防腐措施

# 3.1 涂层防腐技术

涂层防腐是该桥梁钢结构采用的主要防腐措施之一，通过在钢结构表面涂刷防腐涂层，形成防护屏障，阻碍腐蚀介质与钢材接触，达到防腐目的。结合该桥梁所处环境特点，选用氟碳涂料作为防腐涂层，氟碳涂料具有优异的耐候性、耐腐蚀性和耐紫外线性能，能够有效抵抗海洋环境中盐雾、湿度、紫外线等因素的侵蚀。涂层施工采用喷涂工艺，施工前对钢结构表面进行彻底清理，去除氧化皮、锈蚀、油污等缺陷，然后进行喷砂处理，使表面粗糙度达到Sa2.5级，提高涂层与钢材表面的附着力。

涂层体系采用底涂、中涂、面涂三层结构，底涂采用环氧富锌底漆，厚度为80um， 主要起到阴极保护作用； 中涂采用环氧云铁中间漆，厚度为120um， 主要起到增加涂层厚度、提高防护性能的作用；面涂采用氟碳面漆，厚度为60um，主要起到耐候、耐腐蚀作用。为验证该涂层体系的防腐效果，对施工后的钢结构进行长期监测，监测结果如表2所示。由表2可知，采用该涂层体系后，钢结构腐蚀速率大幅降低，涂层完好率在运营5年后仍达85%，防腐效果显著。

# 3.2 阴极保护技术

针对该桥梁钢结构海洋腐蚀严重的问题，在涂层防腐的基础上增设阴极保护技术，采用牺牲阳极阴极保护法，通过在钢结构表面安装牺牲阳极，使阳极材料优先腐蚀，从而保护钢结构免受腐蚀。选用锌铝镉合金作为牺牲阳极，该阳极材料具有牺牲效率高、使用寿命长等优点，适用于该桥梁所处的海洋环境。牺牲阳极安装在钢箱梁底板、腹板及钢桁梁节点等腐蚀严重部位，安装密度为2个/m2，确保阳极能够均匀保护钢结构表面。

# 4 结论

某大桥钢结构腐蚀存在明显部位差异， 钢箱梁底板年平均腐蚀速率达0.12mm，钢支座仅0.02mm/a。腐蚀受高湿度、钢材成分及排水通风设计等因素影响，多种腐蚀类型叠加加剧损坏。采用环氧富锌底漆+氟碳面漆涂层与锌铝镉阳极阴极保护联合方案，5年涂层完好率85%，钢材年腐蚀速率降至0.01-0.03mm， 防腐效果显著。

牺牲阳极安装前，对钢结构表面进行清理，确保安装部位表面干净、干燥，然后采用焊接方式将阳极固定在钢结构表面。安装完成后，对牺牲阳极的电化学性能进行检测，确保其能够正常发挥保护作用。阴极保护技术与涂层防腐技术联合使用，能够形成双重防护体系，涂层起到主要防护作用， 当涂层破损时，牺牲阳极能够及时提供阴极保护， 防止钢材发生锈蚀，有效提高钢结构的防腐效果，延长使用寿命。
