# 高强超厚桥梁钢结构焊接应力与变形仿真研究

常志军1，陈虎成1，牛　丽2（1 中交公路规划设计院有限公司 北京市 10010； 2 邹平市交通运输局 邹平市 25620 ）

摘　要：桥梁拱肋具有支撑桥梁重量和传递载荷的作用，是桥梁的重要结构之一。桥梁拱肋在焊接时通常会发生残余应力和变形，对桥梁结构的使役性能造成不利影响。采用热弹塑性有限元仿真方法，在横隔板约束条件下，对Q620qD钢桥拱肋结构的典型外框肋板和外框过渡段进行了焊接数值模拟分析。研究发现横隔板可以有效减少焊接变形，但其附近会出现应力水平较大的区域，并且横隔板的厚度对焊接变形的影响较小。 本研究成果为 Q620qD钢在桥梁拱肋上的焊接提供了一定的技术参考。

关键词： 桥梁工程； 焊接应力与变形； Q620qD钢； 有限元仿真

# 研究背景

目前，在国内桥梁钢结构中，采用的主流钢种为Q345、Q370、Q420级别的低合金结构钢、桥梁钢或耐候钢［1－3］，高强钢的应用较少。随着各种桥型主梁跨度的不断增加，景观要求的不断提升以及各种特殊结构的不断出现，高强钢、超高强钢的应用有了更大的需求。国内已经有 Q690qE（江汉七桥）和Q690q（澳氹四桥）的应用案例，但都是用在受压区。本项目研究的 Q620qD钢是一种专门为桥梁建设设计的结构钢板，具有强度高、韧性高、焊接性能优异和低温冲击韧性良好等特点，可用在结构的全断面上。为保证 Q620qD钢板在桥梁应用时顺利进行焊接，需要对其进行相关的焊接变形和残余应力研究。

对于大型桥梁钢结构构件进行的焊接应力和变形分析，如果采用试验的方法进行相关的研究，将耗费大量的人力、物力及研究周期。随着计算机性能的飞速提升和数值分析理论的不断成熟，越来越多的行业已经使用数值模拟仿真软件对其产品进行仿真，通过仿真分析和实物试验的对比，对仿真分析不断地修正。目前，数值模拟焊接接头应力和变形的可靠性得到了业内的广泛认可。

本研究采用热弹塑性有限元模拟方法，分析某桥梁拱肋方案的典型外框肋板和外框过渡段在横隔板约束条件下的焊接应力与变形的分布规律，为后期该类结构的焊接提供重要的技术参考。

# 3 热弹塑性有限元法

本研究采用热弹塑性有限元法对焊接过程进行仿真分析。使用热弹塑性有限元法时，先将焊接过程每一时刻工件温度场的温度数据输入热弹塑性有限元分析程序，然后进行焊接变形和残余应力场的计算。

# + 横隔板约束对典型外框肋板的焊接应力和变形的影响分析

本研究分析了无横隔板及横隔板厚度为20mm和40mm等3种状态下，典型外框肋板和外框过渡段的应力与变形分布情况。根据实际工况，对模型的位移进行约束。典型外框肋板仿真结果焊接残余应力（等效应力）分布的情况如图3所示。

结果表明，横隔板的存在在一定程度上缓解了焊缝应力总体偏高的问题，应力在焊接起始点、横隔板存在处具有一定的集中，同时横隔板的厚度对于应力分布的影响不大。焊后残余应力的峰值为580MPa，接近屈服强度，且主要集中在横隔板处等附近，这说明约束越大的位置其焊后的残余应力水平越大。

# 6 结语

（1）横隔板能缓解焊缝整体应力水平偏高的情况，但在横隔板处会出现焊接应力集中，焊接残余应力在典型外框肋板最大可达到580MPa。 同时，研究发现横隔板的厚度对焊接变形的影响较小。

（2）对于典型外框肋板，横隔板可有效减小肋板前边下沿厚度方向的变形，同时会使肋板左边下沿厚度方向的变形增大，某些部位的变形量可达到无横隔板时变形量的两倍。

![](images/62b863a30fe4990b55bf36e413a2d3a8c106a47e89fc73cceaa1c18df06632a5.jpg)  
图8 外框过渡段焊后变形情况曲线

（3）对于外框过渡段，横隔板能够很好地减小过渡段处前边外沿厚度方向的变形和过渡段处上边外沿厚度方向的变形，尤其是对后者的变形减小效果更为显著。（4）焊前预热、焊接时保温、焊后缓冷能有效改善焊缝残余应力。（5）焊后应采取降低残余应力的措施，超声冲击可以在一定范围内将拉伸残余应力逆转为压缩残余应力，能有效改善焊缝的疲劳性能。
