# Nb－V－Mo－N 微合金钢奥氏体中 MX 碳氮化物析出动力学

郑　易1，2，3，　童　炀1，2，3，　张　婧1，2，3， 辛文彬1，2，3，　彭　军1，2，3， 侯蹬云1，2，3

（1．内蒙古科技大学稀土产业学院（稀土工程技术学院），内蒙古 包头014010；2．内蒙古科技大学轻稀土资源全周期绿色高效开发利用教育部重点实验室，内蒙古 包头014010；3．内蒙古科技大学冶金未来技术学院，内蒙古 包头014010）

摘　要：为了探明 Nb－V－Mo－N微合金钢奥氏体中MX（M＝Nb，V，Mo；X＝C，N）碳氮化物的析出动力学，利用第二相理论计算与应力松弛试验对其沉淀析出的形核率－温度（NrT）曲线和析出－温度－时间（PTT）曲线等进行研究，并借助透射电镜分析碳氮化物的析出特征。结果表明，0Mo、0．26Mo和0．50Mo钢 NrT曲线均呈反“C”形曲线，而PTT曲线均为“C”形曲线，随着形变储能从0增大至3　820J／mol，试验钢的NrT曲线右移，最大形核率温度分别为920～950℃、970℃和950℃，PTT曲线向左上方移动，最快析出温度分别为960～980 ℃、960～980℃和940～950℃。相同形变储能条件下，0Mo和0．50Mo钢 NrT曲线和PTT曲线十分接近甚至部分重合，但0．26Mo钢NrT曲线较两者明显向右上方移动，PTT曲线左移，这与试验所得0．26Mo钢PTT曲线最靠左、孕育期最短结果基本一致。此外，变形温度固定为960℃时，当钢中 Mo元素的质量分数由0增加到0．26％和0．50％时，MX碳氮化物均以富 Nb相为主，平均尺寸和数密度先增大后减小；固定 Mo的质量分数为0．26％，随着变形温度从90 ℃升高至960和1　00℃，主要碳氮化物种类由富 Nb相＋富V相转变为富Nb相，对应的平均尺寸增大、数密度减小。关键词：Nb－V－Mo－N微合金钢； 奥氏体；MX碳氮化物； 析出动力学；应力松弛试验

工程结构用钢是桥梁、建筑、能源输送等领域的重要物质基础，提高结构用钢的综合性能尤其是强韧性能够在保障钢结构安全性的同时发展轻量化［1－3］。微合金钢中常添加 Nb、V、Ti、Mo等元素，通过与C、N结合形成微合金碳氮化物，在调控钢的微观组织和力学性能方面起着关键作用［4－8］。如在奥氏体区轧制过程中，形变诱导析出的碳氮化物一方面能够钉扎晶界，使奥氏体回复与再结晶受到阻碍，另一方面可为后续相变提供更多的形核位置，细化显微组织，提高细晶强化效果，显著改善钢的性能［9－12］。因此，探明奥氏体中微合金碳氮化物的析出规律，明确其沉淀析出热力学和动力学，对于获得具有良好强度－韧性配合的微合金钢进而应用于复杂工程结构领域具有重要的指导意义。

多元复合微合金碳氮化物沉淀析出主要采用经典形核长大动力学理论研究，通过建立相应的固溶度积公式，对析出相的热力学和动力学进行理论计算［13－18］。有关Ti－V－Mo微合金钢奥氏体中（Ti，V，Mo）C沉淀析出动力学的研究显示，随着形变储能由0增加到1　360和3　820J／mol时，（Ti，V，Mo）C析出－温度－时间（PTT）曲线向左上方移动，形核率－温度（NrT）曲线向右上方移动，即促进第二相粒子析出［19－20］。此外，HUANG　H　H 等［21］在研究Nb对Ti－Mo微合金化高强度铁素体钢的组织和性能的影响时发现，添加 Nb可以增加 Mo在基体中的过饱和度，提高沉淀析出驱动力，使得PTT曲线向左上方移动。为验证理论计算的准确性，ZHANG　Z　Y等［22］采用应力松弛法研究了 Nb－Mo低碳钢奥氏体中碳化物的析出，结果表明Nb钢和Nb－Mo钢PTT曲线鼻子点温度分别为90 和950℃，最快析出时间为28和17s，即添加 Mo促进了碳化物的析出，与透射电镜下观察到的结果一致。目前，有关（M ，

M ）C和（M ，M ，M ）C类型碳化物以及单一微合金元素的碳氮化物如 Nb（C，N）或 V（C，N），其析出动力学模型已被提出并得到试验验证，而针对（M ，M ，M ）（C，N）类型碳氮化物析出动力学规律的研究较少，尤其是围绕 Nb－V－Mo－N微合金体系开展第二相析出动力学分析与析出特征研究相结合的报道较为缺乏。事实上，随着服役条件的日益严苛，为保证工程结构用钢的综合性能，材料设计时所采用的合金体系趋向多元化发展，旨在通过充分发挥各合金元素的协同效应达到降本增效的目的。例如，含 V 钢中添加适量的廉价 N 元素能够大幅促进V（C，N）析出，且在改善其强韧性的同时可降低昂贵合金元素用量［23－26］。然而，各微合金元素与钢中C、N元素的亲和力不同，强碳氮化物形成元素相互作用又十分复杂，故需研究（M ，M ，M ）（C，N）复合碳氮化物的析出动力学，以促进其大量沉淀析出，进而显著提升材料性能。

因此，本工作以 Nb－V－Mo－N微合金钢为研究对象，基于多元复合析出相的固溶析出理论和经典形核长大动力学理论，建立（M ，M ，M ）（C，N）五元复合析出相模型，将理论计算与应力松弛试验相结合，研究形变储能和合金元素对奥氏体中 MX碳氮化物（M＝Nb，V，Mo；X＝C，N）沉淀析出PTT和 NrT曲线的影响规律，明确奥氏体中第二相最快析出温度和最大形核率温度，并结合透射电镜分析MX碳氮化物的析出特征，进而指导高性能微（TEM，FEI TecnaiG2F30）合金化结构用钢控轧控冷工艺参数的设计。

# 1．3 MX碳氮化物析出动力学理论计算模型

根据多元复合微合金碳氮化物固溶析出理论和经典形核长大动力学理论，对（M ，M ，M ）（C，N）型五元MX碳氮化物进行以下假设：

1）基于合金元素在奥氏体中的固溶规律，钢中N元素在奥氏体区与 Nb、V 结合并消耗完全，Mo以碳化物的形式存在，（M ，M ，M ）（C，N）为（Nb，V，Mo）（C，N）。

2）基体中分布着大量的晶体缺陷，MX碳氮化物以非均相晶界和位错形核为主。由于晶界形核位置有限，其附近相关溶质原子耗尽后晶界形核停止，故碳氮化物集中在位错线上形核；同时，刃位错比螺位错更适合于析出相形核，因此只考虑MX碳氮化物在刃位错上形核且形核率迅速衰减为零［27－28］。

3）奥氏体中设定 MX碳氮化物的核胚形状为球形，当计算单个核胚自由能变化时不考虑弹性应变能的影响；此外，采用微区位错能量方法进行估算［19，29］，假定微区尺寸为0、1和2nm，对应的形变储能为0、3　820和1　360J／mol。

# 3 结论

1）在（M1，M2）C和（M1，M2，M3）C类型碳化物析出动力学研究的基础上，针对 Nb－V－Mo－N 试验钢奥氏体中 MX碳氮化物的沉淀析出，建立（M ，M2，M3）（C，N）五元复合析出相模型，理论计算结果表明 NrT曲线呈反“C”形曲线，而 PTT曲线为“C”形曲线。

2）当形变储能由0增加到3　820J／mol时，0Mo、0．26Mo和0．50Mo钢奥氏体中MX碳氮化物沉淀析出 NrT 曲线右移，最大形核率温度分别为920～950℃、970 ℃和950℃，PTT曲线向左上方移动，最快析出温度分别为960～980、960～980和940～950℃；在形变储能一定的条件下，0Mo和0．50Mo钢 NrT曲线和PTT曲线非常接近甚至部分重合，但0．26Mo钢 NrT曲线较0Mo和0．50Mo明显向右上方移动，PTT曲线左移；应力松弛试验结果显示0．26Mo钢PTT曲线最靠左，孕育期最短，与理论计算结果基本一致。

3）当变形温度为 960 ℃时，随着 Mo元素的质量分数由0增加到0．26％和0．50％，奥氏体中MX碳氮化物以富 Nb相为主，平均尺寸和数密度分别从（18．4±3．65）nm和（6．6±0．9 ）×1013　m－2先增大至（20．8±4．26）nm 和（7．8±1．23×1013）m－2，后减小至（17．0±3．56）nm 和（2．1±0．35）×1013m－2；当 Mo元素的质量分数为0．26％时，随着变形温度从90 ℃升高到1 00 ℃，主要MX碳氮化物种类由富 Nb相和富 V 相转变为富 Nb相，析出相平均尺寸由（9．4±2．07）nm 增大至（24．2±4．60）nm，数密度从（3．3±0．68）×1014　m－2减小至（1．7±0．3 ）×1013　m－2。

4）通过理论分析与试验研究，探明Nb－V－Mo－N多元微合金钢奥氏体中 MX碳氮化物析出动力学规律及析出特征，对后续高性能结构用钢多元微合金化体系设计与控轧控冷工艺制定具有指导意义；未来研究将进一步聚焦铁素体中 MX碳氮化物的析出动力学，尤其是不同 Mo含量的影响规律。
