# 单次淬火对大厚度 FH790 海工钢微观组织和性能的影响

赵喜伟，龙 杰，庞辉勇，王九清（河钢集团舞钢公司，河南舞钢 46250 ）

摘　要：利用力学检测设备、光学显微镜（OM）、扫描电子显微镜（SEM）和透射电子显微镜（TEM）等先进手段研究分析了大厚度FH790海工钢单次淬火＋回火热处理后不同厚度位置的力学性能和微观组织。结果表明：大厚度FH790海工钢仅进行一次淬火＋回火热处理后，不同厚度位置的屈服强度和抗拉强度差别不大，都能满足船级社规范要求，但是离钢板表面1／4厚度（T／4）位置冲击功均值为58J，距离钢板表面1／2厚度（T／2）芯部位置冲击功均值为26J，很难达到船级社规范的要求，主要原因是大厚度FH790海工钢厚度T／2芯部位置存在大量的回火粒状贝氏体组织，这种微观组织的有效晶粒尺寸相对较大，导致了冲击韧性相对较差。

关键词：大厚度FH790海工钢；微观组织；冲击韧性；马氏体组织；贝氏体组织中图分类号：TF03 1：TG15；TG142 文献标志码：A 文章编号：100－7571（2024）08－034－07

随着我国科技水平和经济实力的逐渐增强，国家对深海及极地的开发也越来越重视，而急需建造的海上大型设备离不开大厚度超低温韧性的高强度海洋工程结构用钢［1－2］，国外企业用于自升式海洋平台桩腿齿条钢，厚度规格多为127、14 、178、210mm，屈服强度不低于690MPa，距离钢板表面1／4厚度（T／4）和距离钢板表面1／2厚度（T／2）芯部位置的－60℃纵向冲击功不低于69J。外国一直对此类产品进行技术封锁，因生产技术难度大，目前国内能够批量供货的大厚度海工钢是 CCS／EH690，而对于强度级别更高，冲击韧性更低级别的钢种，国内一些高校、研究所和钢厂也对这类海工钢板进行了系统性研究［3］，但是大部分仍处于科研实验开发阶段，还不能进行批量生产［4］。在对大厚度超低温韧性 FH790 海 工 钢 研 究 过 程 中 发 现，大 厚 度FH790海工钢仅经过一次淬火＋回火热处理后，不同厚度位置屈服强度和抗拉强度差别不大，都能满足船级社规范要求，但是－60℃超低温冲击韧性较低，特别是厚度T／2芯部位置的冲击韧性，很难达到船级社规范中冲击功均值69J以上的标准要求［5］。钢板经过两次淬火不仅增加生产成本，提高生产工序难度，而且二次淬火改善性能效果有限［6］，因此本文针对单次淬火这种情况下的科研试板进行了分析研究，以期找出造成大厚度 FH790海工钢－60℃超低温冲击韧性较低的原因，用于再次生产试验时进行参考改进。

# 试验材料

试验材料为电炉冶炼＋LF炉精炼＋VOD炉真空精炼＋模铸生产的扁形钢锭，然后经过宽厚板轧机轧制成厚度180 mm的大厚度钢板。钢板仅经过一次80℃淬火＋630℃回火热处理后，试验钢板的拉伸性能良好，钢板的－60 ℃低温冲击韧性较差，达不到船级社规范中冲击功均值69J以上的标准要求。对这种情况的大厚度FH790海工钢试样进行了常规力学性能检测和采用先进显微镜设备进行了微观组织观察，其中厚度位置0T、T／4和T／2分别代表180mm 大厚度FH790海工钢的钢板表面、厚度1／4位置即距离钢板表面45 mm 和厚度1／2芯部位置即距离钢板表面90 mm。

# 2 试验仪器

CK40M 型光学金相显微镜（日本奥林巴斯）；QUANTA40 型扫描电子显微镜（荷兰FEI公司）；

CMT5605型拉力试验机（三思泰捷）；JB－W50CYZ型摆锤冲击试验机（济南恒大汇峰）；JEM－2010HR型发射透射电镜（日本电子株式会社）；MERLINCompact型发射扫描电镜（德国蔡司）。

# 3 试验过程和方法

在试验钢板表面0T、T／4和T／2位置切割出10 mm×10 mm×10 mm大小的金相试样，依次在20 、40 、80 、1 000 目的砂纸上磨平，然后用抛光机抛光，抛光后在金相显微下观察夹杂物情况。将磨平抛光后的金相试样用4％的硝酸酒精溶液腐蚀后在金相显微镜和扫描电子显微镜下观察微观组织。为了观察实验试样的原始奥氏体晶粒晶界和晶粒尺寸，将磨平抛光后的金相试样用过饱和的苦味酸溶液热腐蚀，然后在光学金相显微镜上进行观察，并随机选择5个不同的视场，利用截线法并参照GB／T　6394—2017《金属平均晶粒度测定方法》对原始奥晶粒的晶粒尺寸进行统计。拉伸和冲击试验的取样和制备按照GB／T　2975—2018《钢及钢产品 力学性能试验 取样位置及试样制备》，拉伸试验采用GB／T　28．1—2021《金属材料 拉伸试验 第1部分：室温试验方法》，在电子万能试验机上进行室温拉伸；冲击试验采用GB／T　29—2020《金属材料 夏比摆锤冲击试验方法》，纵向试样 V型缺口，实验温度为－60℃，在全自动冲击试验机上进行，试验结果取3个数值的算术平均值；透射电镜试样用线切割机切取0．5 mm 的薄片，利用水磨砂纸研磨到50m以下，然后用双喷电解减薄到试验要求的尺寸，再采用透射电镜进行形貌观察和分析。电子背散射衍射样品是利用水磨砂纸磨平和金刚石抛光膏抛光后再采用电解抛光的方法制备，电解液为10％的高氯酸酒精溶液，然后采用场发射电镜进行表征分析，扫描步长为0．5μm，在 Aztec Crystal数据处理软件上对背向散射电子衍射（EBSD）数据进行处理。

# 试验结果与分析

# 4．1 力学性能分析

对单次淬火＋回火热处理后的大厚度 FH790海工钢进行了拉伸性能和冲击韧性的检测，具体结果见表1。由表1可见，大厚度FH790海工钢经过一次淬火＋回火热处理后，不同厚度位置的拉伸性能良好，从表面到厚度T／2，屈服强度（R0．2）分别为837、862、851MPa，抗拉强度（Rm）分别为948、975、935MPa，延伸率（A）分别为18、17、17，均满足船级社规范对FH790海工钢的标准要求；但是－60℃超低温冲击韧性较差，仅表面0T位置的冲击功均值87J大于船级社规范中69J的标准要求，T／4位置的冲击功均值为58J，T／2芯部位置的冲击功均值仅26J，都低于船规69J以上的标准要求［7］，试验钢板的冲击韧性由表面至T／2芯部位置逐渐降低［8］。

# 4．4 微观组织观察

对大厚度FH790海工钢不同厚度位置的微观组织进行了光学显微镜和电子扫描电镜观察，其观察结果如图 3 所示。从图 3 可以看出，大厚度FH790海工钢热处理后的表面显微组织为回火马氏体LMT 组织，厚度T／4位置的显微组织为回火马氏体 LMT 和回火条状贝氏体 LBT 的混合组织，厚度T／2芯部的显微组织为回火条状贝氏体 LBT和回火粒状贝氏体GB 的混合组织，有相关文献报道回火粒状贝氏组织的冲击韧性特别差［12－13］，厚度T／2芯部位置的显微组织大约为15％的回火条状贝氏体LB ＋85％的回火粒状贝氏体 GB ，这样的微观组织正好与冲击韧性宏观检测值较差相对应。

# 5 结语

（1）单次淬火 ＋ 回火热处理生产的大厚度FH790海工钢，力学性能检测结果表明，不同厚度位置的拉伸性能都较好，屈服强度和抗拉强度值差别不大，都能满足船级社规范要求；但是－60℃的低温冲击韧性较差，仅表面0T位置的冲击功能达到船级社规范标准要求，厚度T／4和T／2芯部位置冲击韧性都较差，很难满足冲击功均值69J以上的要求。

（2）单次淬火 ＋ 回火热处理生产的大厚度FH790海工钢，表面0T和厚度T／4有相对较高的冲击韧性主要是因为该厚度位置热处理后生成的显微组织为回火马氏体和回火板条状贝氏体混合组织，同时这些位置的微观组织具有相对较小的有效晶粒尺寸。

（3）单次淬火 ＋ 回火热处理生产的大厚度FH790海工钢，厚度T／2芯部位置冲击韧性较低的主要原因是该位置生成的微观组织为回火粒状贝氏体较多，同时有效晶粒尺寸相对较大。
