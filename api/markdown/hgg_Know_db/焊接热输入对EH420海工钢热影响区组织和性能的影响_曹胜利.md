# 焊接热输入对 EH420 海工钢热影响区组织和性能的影响

曹胜利1,2,3, 张庆军2,3, 张彩军1,2(1.华北理工大学冶金与能源学院,河北 唐山063210; 河北省高品质钢连铸工程技术研究中心,河北 唐山 063210; 3.华北理工大学综合测试分析中心,河北 唐山 063210)

摘 要:为了研究焊接热输入对EH420海工钢热影响区组织和性能的影响及其影响机制,采用 Gleble350 热模拟机对EH420海工钢进行了焊接热输入分别为50、10 、20 、30 kJ/cm 的模拟焊接。利用扫描电子显微镜、金相显微镜、冲击试验机等设备对热模拟后得到的热影响区进行-40 ℃冲击试验、金相组织分析、断口形貌检测。研究发现,焊接热输入为50kJ/cm 时,奥氏体晶粒细小,组织以板条贝氏体为主。随着焊接热输入的升高,贝氏体组织面积分数减小,铁素体组织面积分数明显增大。在钢中夹杂物对相变组织影响的研究中,发现在分散性较好的MgO 上形成的Ti氧化物或者与其他元素复合而成的夹杂物具有促进晶内铁素体形成的作用。诱发形成的晶内铁素体以大角度晶界分割原奥氏体晶界,在裂纹扩展时,晶内铁素体可以阻碍裂纹扩展,提高钢材韧性。随着焊接热输入的提高,冲击韧性下降,断口纤维区宽度减小,裂纹扩展时改变方向的次数降低,组织中大角度晶界所占比例变小,断口从以韧性断口为主逐渐演变成以准解理断口为主。

关键词:大线能量焊接;热影响区;海工钢;晶内铁素体; EBSD 文献标志码:A 文章编号: 1006-9356（2025)04-0058-09

随着更大吨位现代化船舶制造的发展,高性能中厚板易焊接结构钢的需求逐渐增多。在船体建造中,目前采用的常规焊接技术需要进行多道次焊接成型,存在焊接效率低下、焊接成本高等问题。高效的大线能量焊接技术具有焊接效率高、速度快、成本低、一次成型等优点[1-6],逐步取代传统的厚板多道次焊接技术。

与常规焊接相比,大线能量焊接技术线能量有明显的提高,焊缝附近金属所经历的热循环更加强烈。焊接热影响区(HAZ)温度可达到140 ℃,部分区域甚至能达到液相线温度以上,并且高温停留时间延长,导致传统钢材经历焊接后,晶粒严重粗化[7-11]。同时,在随后冷却过程中的固相转变阶段,由于冷却速度较慢,HAZ更容易形成魏氏体组织、粗大的晶界铁素体等低温韧性较差的显微组织[12-16]。

氧化物冶金技术是利用钢中析出的第二相粒子在焊接热循环过程中有效钉扎 奥氏体晶粒,阻碍晶粒过度长大。利用在钢中形成的适合的夹杂物,在 随 后 的 固 固 相 变 过 程 中 诱 发 晶 内 铁 素体[17-22],细化 HAZ 晶粒的同时形成交织互锁的组织结构,提高 的低温冲击韧性[23-27]。但目前研究者一般只针对1种或者2种合金元素的作用进行研究,多因素的协同及交互作用对阻碍晶粒长大并诱导晶内铁素体优先竞争析出研究很少。

本研究以 Nb-Mo-Ti-M 微合金体系氧化物冶金型试验钢为样本,利用热模拟焊接试验机对海工钢进行了不同焊接热输入的焊接。借助场发射扫描电子显微镜、金相显微镜、冲击试验机等设备,研究了不同热输入条件下对 的组织和性能的影响规律,并对其影响机制进行了探讨。

# 3 试验结果分析

# 3.1 夹杂物诱发晶内铁素体

在 HAZ中存在如图9所示的夹杂物诱发的晶内铁素体组织( ),诱发形成的铁素体向四周以细长条状生长,存在二次铁素体在一次铁素体上进行诱发(如图中实线所示),分割原奥氏体晶粒,晶内铁素体之间相互交叉互锁。对夹杂物进行能谱分析,发现主要含有Fe、Mn、Ti、S、Mg、O 等元素。由形貌图可知该夹杂物明暗程度不同,为复合夹杂物。研究表明,Mg在钢液中极易与氧结合,且 MgO 夹杂分散性好,在炼钢过程中,控制 Mg的加入时机,可以使钢中形成以 M O 为核心的均匀分散的夹杂物,随后 的氧化物和 的硫化物等其他夹杂物附着析出,可以使得到的复合夹杂物更加细小、分布更加均匀,从而增加IGF[30]所占比例。

![](images/cb738629f4fc16a73e2566a0f3342c3e43a0502d31728bed489f7a783104bf93.jpg)

当裂纹扩展经过存在IGF 的钢材时,会频繁、多次改变扩展方向,而在 内时,扩展方向改变较小。裂纹扩展方向的改变,势必会消耗更多的能量,因此IGF具有良好的裂纹扩展阻碍作用,可提高钢材韧性[31]。

# 3.2 断口截面

图 所示为断口组织形貌,可以看出,当焊接热输入为50kJ/cm 时,裂纹扩展多次改变方向,断口波折较多。随着焊接热输入的提高,裂纹扩展改变方向的次数较少,当焊接热输入提高到10 kJ/cm时,出现了较大的平直段。随着焊接热输入的进一步提高,裂纹扩展方向改变的次数更少。当焊接热输入提高到30 kJ/cm 时,断口处较平整,有很大的平直段。裂纹扩展方向的改变需要消耗一定的能量,裂纹扩展方向的增多,需要更多的能量,进而可以阻碍裂纹扩展,增强钢材的韧性。这也进一步说明了随着焊接热输入的提高钢材韧性下降的原因。

# 4 结论

)焊接热输入为 kJ/cm 时,奥氏体晶粒细小,组织以板条贝氏体为主,还有部分铁素体和侧板条铁素体组织。随着焊接热输入的提高,铁素体面积分数增加,贝氏体组织面积分数下降。当焊接热输入为30 kJ/cm 时,存在大量的铁素体组织。

2)含有 Mn、Ti、S、Mg、O 的夹杂物可以诱发晶内晶内铁素体的生长,晶内铁素体相互交叉互锁,以大角度晶界隔开,可以增加大角度晶界所占比例,在裂纹扩展时改变扩展方向,阻碍作用增加,从而提高HAZ韧性。

)随着焊接热输入的增加,低温冲击功 由50kJ/cm 时的 183.0J 下降到 30 kJ/cm 时的75.9J。在裂纹扩展时,随着焊接热输入的提高,扩展方向改变次数减少,大角度晶界所占比例下降,对裂纹阻碍作用减弱。
