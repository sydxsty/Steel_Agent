# Nb 含量对抗酸管线钢 X70MS 组织及抗氢脆行为的影响

李中平1，李慧杰2，巨银军1，张 阳2，杜 江1，王　斌2

（1．湖南华菱湘潭钢铁有限公司，湖南 湘潭 41101；2．东北大学数字钢铁全国重点实验室，辽宁 沈阳 10819）

摘　要：海底管线钢的服役条件复杂，除需要具有更大管径和壁厚、承受更高压力及优异的低温落锤韧性外，还要求具备抗酸性能。本文以抗酸管线钢X70MS为研究材料，基于低碳抗酸钢化学成分，通过添加 Nb的合金设计思路，采用 TMCP工艺调控钢的显微组织，实现了抗酸管线钢X70MS高强度与优异低温韧性的匹配。 在此基础上，研究了不同 Nb含量对其显微组织的影响，并通过氢渗透实验、充氢慢应变速率拉伸实验作为表征手段，分析了 Nb含量对管线钢氢脆敏感性的影响。结果表明，随着 Nb含量的增加，实验钢组织得到细化，位错密度增加，并促进了（Nb，Ti）（C，N）的析出，因此强度升高。在 A 溶液条件下，Nb碳氮化物的氢捕集和引起裂纹萌生的能力低于氧化物和硫化物，不同 Nb含量实验钢均具有良好的抗氢致开裂性能，试样表面没有氢致鼓泡出现。实验钢经浸泡处理后，氢致裂纹附近均伴随有含氧和硫的夹杂物产生。随着 Nb含量的增加，实验钢的氢脆敏感性升高。 当充氢时间为5h和10h时，实验钢的伸长率明显降低，但对强度影响较小，充氢时间为20h时，因捕获氢和游离氢的含量显著增加，实验钢的伸长率和抗拉强度急剧下降。

与常规陆上管线钢相比，海底管线钢的服役条件更加复杂，除需要具有更大管径和壁厚、承受更高压力及优异的低温落锤韧性外，还要求具备抗酸性能［1－4］。高强度管线钢在酸性环境下连续使用的关键挑战之一是氢致损伤，氢致损伤的两种典型形式为氢致开裂（Hydrogen－Induced Cracking，HIC）和 氢 致 起 泡 （Hydrogen－Induced Blistering，HIB）［5－7］。海底管道输送油气中常含有酸性气体，随着 H2S含量较高的油气田的开发，集输管线的H2S会引起氢脆（Hydrogen Embritlement，HE）现象［8－9］。当管道内部暴露于高压氢气中或暴露于含有大量硫化氢（H2S）的酸性气体中时易引起氢脆，H2S会通过钢的酸性腐蚀产生氢原子。当管道外部暴露于阴极保护产生的电化学氢气中时，氢气吸附在钢的表面并渗透到钢中，会导致管线钢力学性能的退化并引发微结构缺陷中的氢致裂纹［10－12］。

管线钢的抗氢致开裂性能与钢的化学成分和显微组织密切相关，Nb是高强钢中常用合金元素，其对高强钢力学性能和显微组织的影响已被广泛研究。通过 Nb微合金化产生析出相，弥散分布的析出相通过细晶强化和析出强化提升了钢基体的耐蚀性能，同时，还可以形成大量氢陷阱，阻碍氢的扩散 与 聚 集，降 低 了 显 微 组 织 对 氢 脆 的 敏 感性［13－18］。 ZHANG　S　Q等［19］利用不同Nb含量管线钢研究了 Nb对氢致鼓泡的影响，认为纳米级的NbC析出改善了微观结构，阻碍了氢鼓泡的形成，但较大尺寸的析出相又会促进氢鼓泡的形成；但该研究未关注 Nb含量对于氢致开裂的影响。

本文以不同 Nb含量的 X70MS管线钢为实验材料，研究了 Nb含量对实验钢显微组织的影响，并通过氢渗透实验、充氢慢应变速率拉伸实验作为表征手段，分析了 Nb含量对管线钢氢脆敏感性的影响。

# 实验材料和实验方法

根据X70MS抗酸管线钢强度、低温韧性、屈强比和焊接性能等技术条件要求，设计了低C、低 Mn、高Nb的合金成分，并添加适量 Cu、Cr和 Ni等元素。实 验 钢 Nb 质 量 分 数 分 别 为 0．045％ 和0．075％，分别命名为 45－350 钢、75－350 钢，化学成分如表1所示。热轧实验在φ450 mm 二辊可逆轧机上进行，将10 mm厚度的坯料加热至1　20 ℃，保温2h进行均匀化处理，然后进行两阶段控制轧制，将钢板轧至13mm 厚，然后进行水冷，冷速为20～25℃／s，终冷温度为350 ℃。

采用 BX53MRF 型光学显微镜（Optical Micro－scope，OM）、ULTRA　5 型扫描电子显微镜（Scan－ning Electron Microscope，SEM）以及电子背散射衍射（Electron Backscater Difraction，EBSD）分析了实验钢显微组织特征，在 Tecnai G2 F20 透射电子显微镜（Transmision Electron Microscope，TEM）下观察样品的位错及析出情况。 横向圆棒拉伸试样（平 行 段 直 径 d ＝5 mm，平 行 段 长 度 L ＝25mm） 以 及 纵 向 低 温 冲 击 试 样 （试 样 尺 寸：10mm×10 mm×5 mm）均符合标准 GB／T　28—208 和 GB／T 29—207 中 规 定 尺 寸，分 别 在CTM 5105型万能拉伸实验机和Instron Dynatup9250 型冲击实验机上进行了室温拉伸（拉伸速率：2 mm／min）和－40℃低温冲击实验。在JL－500落锤冲击实验机进行 －27 ℃ 的落锤撕裂实验（Drop－Weight　Tear Test，DWTT），落锤撕裂实验的试样采用标准压制缺口型冲击试样（试样尺寸：305 mm×76．2mm×13 mm）。

# 2．2 氢致腐蚀开裂行为

图9为实验钢氢致开裂实验后试样表面形貌以及抗氢致开裂性能。不同 Nb含量的 X70MS实验钢试样氢致裂纹缺陷平均比率均满足美国石油协会 API　SPEC　5L—2018的标准要求，具有良好的抗氢致开裂性能要求。

实验钢内部的氢致裂纹是由于气态氢在各种缺陷（微孔隙或夹杂物）处的积聚而形成。当氢原子的浓度超过临界水平，即材料的溶解度极限时，晶格中的原子氢就会以气态氢的形式析出。裂纹形成后，气态氢会继续聚集，裂纹由于积聚压力而发生扩展。如果没有足够的氢气进入材料以保持裂缝中的足够压力，裂缝的扩展就会停止。如果裂纹扩展到实验钢表面，氢气就会逸出形成氢致气泡。由图9（a）可 以 看出，试样表面没有氢致鼓泡出现。实验钢经浸泡后出现的氢致裂纹如图10所示，裂纹附近伴随有夹杂物的存在。

氢在实验钢中会被空位、置换原子、位错、MnS、微孔洞和第二相等微结构缺陷所捕获，如果这些缺陷所捕获的氢浓度超过临界氢浓度，则很可能成为裂纹的起始位置。Nb作为高强钢的重要微合金强化元素之一，由于其具有可明显细化晶粒尺寸的作用而被广泛应用。其形成的 NbC颗粒可以通过钉扎晶界来减小晶粒尺寸，增加晶界有效面积，使得氢陷阱在实验钢基体中更均匀的分布，进而抑制氢原子向裂纹尖端扩散。两种实验钢的组织均以贝氏体铁素体为主，由于75－350钢添加的Nb含量更高，其组织晶粒更细，晶界有效面积、位错密度及 NbC析出相的含量更高，这些都可以作为氢陷阱，捕获大量的氢原子使其无法移动，反而恶化了板条界面处的力学性能。由于氢捕获，沿贝氏体板条边界的氢气聚集最终会导致贝氏体板条边界的分离，裂纹也更容易通过这些边界传播，而不是穿过铁素体晶粒。因此，当这些区域的氢浓度变高时，会出现大量微裂纹，游离的氢可以迅速定位到裂纹起源位置，促进裂纹扩展。

# 3 结论

（1）随着 Nb含量的增加，实验钢组织得到细化，组织类型由多边形铁素体、珠光体以及 M／A组元转变为准多边形铁素体、贝氏体以及 M／A组元，位错密度增加。较高的位错密度和较细的基体组织促进了（Nb，Ti）（C，N）的析出，使得75－350钢具有更高的强度。

（2）在A溶液条件下，不同Nb含量实验钢均具有良好的抗氢致开裂性能，试样表面没有氢致鼓泡出现。Nb碳氮化物的氢捕集和引起裂纹萌生的能力低于氧化物和硫化物，实验钢经浸泡后出现的氢致裂纹附近伴随有含氧和硫的夹杂物存在。

（3）随着 Nb含量的增加，75－350钢的氢脆敏感性高于45－350钢。 当充氢时间为5h和10h时，实验钢的伸长率明显降低，而对强度的影响较小，此时实验钢断口开始出现沿晶断裂形貌。充氢时间为20h时，因捕获氢和游离氢的含量显著增加，实验钢的伸长率和抗拉强度急剧下降，实验钢断口出现了较大尺寸的穿晶裂纹。
