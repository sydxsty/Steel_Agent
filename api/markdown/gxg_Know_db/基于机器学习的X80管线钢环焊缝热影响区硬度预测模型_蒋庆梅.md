# Machine Learning based Hardness Prediction Model for Girth Weld Heat Affected Zone of X80 Pipeline Steel

JIANG Qingmei1, DENG Liyang2, 3, ZHANG Xiaoqiang1, GONG Yu2, ZHANG Dong2, ZHEN Ying4, LIU Xiaoben2   
(1. PipeChina Engineering Technology Innovation Co., Ltd., Tianjin 300450, China; 2. College of Mechanical and   
Transportation Engineering, China University of Petroleum (Beijing), Beijing 102249, China; 3. PipeChina South China Pipeline Co., Ltd., Guangzhou 510623, China; 4. China University of Petroleum (East China), Qingdao 266580, Shandong, China)

Abstract: To investigate the characteristics of the heat⁃affected zone (HAZ) in X80 pipeline steel girth weld joints, and obtain the nonlinear relationship between thermal cycle data and HAZ hardness, precise predictions of HAZ hardness were conducted. Using X80 pipeline steel as the research subject, thermal simulation tests were performed. Microhardness tests were conducted on the thermal simulation specimens to determine the hardness values and the hardness distribution of the HAZ in full scale girth weld joints. Based on the hardness database of thermal simulation specimens, a multi index comprehensive evaluation was carried out to optimize the support vector regression algorithm using particle swarm optimization, thereby constructing a hardness prediction model. Furthermore, characteristic data of the thermal cycle were acquired through finite element modeling of the girth weld. Input the hardness prediction model to predict the actual hardness distribution in the heat⁃affected zone. Results showed that the relative errors in the predicted mean hardness for fully automatic welding and combined automatic welding were 4.70% and 6.01%, respectively. The model demonstrated high accuracy and could provide guidance for optimizing welding processes, ensuring the inherent safety of high⁃grade pipelines.

Key words: X80 pipeline steel; girth weld heat ⁃ affected zone; thermal simulation experiment; hardness prediction; machine learning

# 0　前 言

X80高强管线钢广泛应用于管道工程[1-2]，因其具有优异的强度、韧性及良好的焊接性能[3-4]，适用于海洋、高原等极端环境下的长距离输送。然而，焊接过程中的热循环易导致焊接热影响区内的强度和韧性发生潜在退化，因此选择合适的焊接工艺对调控该区域性能至关重要。

热影响区硬度是评价钢材可焊性的重要指标之一[5]，通常与热影响区抗拉强度、冷裂风险[6]正相关，且硬度测试较为简便，使其预测成为研究热点。近年来，多种机器学习方法被应用于该领域。李继红、李琳等[7-9]选用反向传播（backpropagation， BP）神经网络探究连续油管焊接工艺与热影响区硬度的非线性关系。 Pouraliakbar等[10]使用具有前馈拓扑结构和反向传播算法的神经网络来预测化学成分和拉伸试验参数对X70管线钢埋弧焊 （submerged arc welding， SAW） 热影响区硬度的影响。 Ajith等[11]结合响应面法与遗传算法优化双相不锈钢摩擦焊接头硬度。郭永环等[12]采用 BP 与径向函数 （radial basis function，RBF）神经网络，以稀土元素含量和焊接速度为输入，预测了包括热影响区平均硬度在内的多项力学性能，基于该样本数据库，RBF网络在预测精度和效率上均优于BP 网络。Yu 等[13-14]应用

RBF神经网络，不仅构建了经有限元模拟验证的激光回火焊硬度预测模型，还进一步建立了基于峰值温度与冷却速率的多道焊硬度预测模型，预测值与实测结果吻合良好。上述研究表明，基于机器学习的硬度预测方法可为焊接工艺选择提供有效依据。

针对X80管线钢展开研究，开展热模拟试验和硬度试验，获取不同热循环参数条件下热模拟试样硬度和全尺寸环焊接头热影响区的硬度分布，同时开发了一种基于机器学习的硬度预测模型，并将该模型应用于实际焊接接头热影响区的硬度分布预测。经实测数据验证，该模型能够实现管道焊缝热影响区硬度均值的准确预测，为优化焊接工艺参数提供指导，保障高钢级管道运行安全。

# 1.2 硬度试验

显微硬度测试使用HV-1000 型显微硬度计，测试负荷为0.3 kg。 测试对象包括热模拟试样和全尺寸焊接接头试样（全自动焊和组合自动焊两种焊接工艺[15]焊接的 X80钢级 Φ1 219 mm×22 mm管线钢）。

热模拟试样经打磨、抛光、浸蚀后，通过金相观察确定等温区，并在该区域进行5 次硬度测试，以减少局部微观组织差异对硬度值的影响，并将所获得的硬度取平均值。全尺寸焊接接头试样经相同处理后，在其热影响区内以网格状覆盖进行硬度测试。由于热影响区宽度通常为2\~3 mm， 因此设置测试点间距为0.3 mm， 以保证沿每层热影响区宽度方向有5个以上的测试点。

# 3 热影响区硬度预测模型

试验采用支持向量回归[19-20] （support vectorregression， SVR）、粒子群优化的支持向量回归[21]（particle swarm optimization support vector regression， PSO-SVR）、 随 机 森 林[22] （random forest，RF）、 极端随机树[23] （extremely randomized trees，ET）、 稀疏高斯过程回归[24] （sparse gaussian pro⁃cess regression， SGPR） 5种算法，基于热模拟试样硬度数据库，将一次峰值温度T 、二次峰值温度T 以及对应的降温速率CR作为模型输入，显微硬度 （HV0.3） 作为输出。

# 3.3 热影响区硬度预测模型应用

利用训练的PSO-SVR 热影响区硬度预测模型，对实际焊接接头热影响区的硬度进行预测。焊接接头各区域温度历程由3.2节有限元模型计算获得，仍以一次、二次峰值温度及其对应的降温速率作为机器学习模型输入参数，经模型计算后得出对应的硬度预测值，并与试验数据进行对比。

图9所示为热影响区硬度模型预测值和试验测试值的具体分布情况。从结果分析可以看出，全自动焊、组合自动焊的硬度预测值与硬度测试值的均值相对误差分别为4.70%和6.01%，预测结果与测试结果吻合。然而，模型计算得到的硬度预测值分布较为集中，对于局部强化或软化效应所导致的硬度极值波动与分布预测存在较大误差。这一现象一方面可能源于预测数据所用的温度历程与实际焊接过程之间的差异，另一方面则是由于硬度预测模型是基于热模拟试验数据库构建的，而热模拟试样无法精准复现实际焊接过程中由于元素扩散及析出物导致的局部硬化效应。

# 4　结 论

（1） 以X80管线钢为研究对象，通过热模拟试验和硬度测试，获取了在不同热循环条件下热模拟试样的硬度数据以及全尺寸环焊接头热影响区的硬度数据。基于这些数据，开发了一种基于机器学习的硬度预测模型，该模型能够较准确地预测管道焊缝热影响区的硬度均值。

（2） 由于热模拟试验数量限制， 以及环焊缝热影响区存在局部强化或软化现象的复杂性，导致模型虽然在预测全尺寸接头热影响区硬度均值方面表现较好， 但在硬度极值波动和分布预测方面仍存在较大误差。因此，针对X80管道环焊接头热影响区性能的预测模型仍需进行更加深入的研究。
