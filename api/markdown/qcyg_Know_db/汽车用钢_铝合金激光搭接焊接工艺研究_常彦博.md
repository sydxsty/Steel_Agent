# 汽车用钢／铝合金激光搭接焊接工艺研究

常彦博1， 郭亮1，2＊ ， 张庆茂1，2， 张鑫1， 吕启涛2， 左涵宇1（1华南师范大学广东省微纳光子功能材料器件重点实验室，广东 广州 5106；2广东省工业超短脉冲激光技术企业重点实验室，广东 深圳51805 ）

摘要　汽车制造时将钢／铝合金结合起来使用，能够实现车身强度不降低的前提下，极大地减轻车身的质量，以实现节能减排的目的。选取10 mm×50mm×1．5mm的 DC01冷轧钢板和相同尺寸的6010铝合金进行光纤激光搭接焊接试验。试验发现，当激光功率P＝1　90 W，焊接速度v＝45mm／s，离焦量f＝－3mm时获得的焊接接头剪切强度达到最大值10 ．21MPa。随后在搭接面添加0．2mm 的 Cu中间层后，实验结果表明，添加 Cu中间层后接头强度提升到14 ．91MPa，焊缝中心硬度显著提高。金相显微镜观察表明，添加 Cu中间层可以增大焊缝深宽比，同时细化晶粒。XRD结果表明，添加中间层后有新物相生成，主要为 Al－Cu系化合物。EDS线扫描结果发现，添加中间层后金属间化合物层由40μm降低至20μm。

0 引言

目前，全球各大汽车厂商都在大力发展新能源汽车，轻量化技术可以有效提高新能源汽车的续航能力。铝合金具有比强度高、耐腐蚀、吸能效果好的特点，非常适合应用于车身轻量化，但其相对较低的强度不适用于车身的重要结构件［1－3］。传统钢材具有极高的强度，车身内的一些影响碰撞安全的重要结构仍会使用高强度或超高强度钢［4］。因此，将两种材料结合起来使用，可以在保证车身安全的前提下，最大程度地实现车身的轻量化。然而，钢和铝的物理、化学性能差别较大，Fe、Al的固溶度低，热输入过大时容易形成脆性的金属间化合物。激光焊接能精确控制热输入，有效减小金属间化合物的厚度［5－7］。

本文采用2　00W 光纤激光来实现钢／铝合金异种金属焊接，为了进一步提高焊缝的力学性能，在搭接间隙添加0．2mm厚的Cu中间层。添加中间层后焊缝形貌和组织均有变化，可以观察到新物相的产生，从而抑制金属间化合物的生成。脆性化合物混合区厚度显著降低，有效提高了焊缝的剪切强度。

# 2．1 激光焊接参数对钢／铝合金焊缝成形的影响

# 2．1．1 激光功率对焊缝成形的影响

根据激光功率密度公式 ＝P／d，焊接时保持光斑直径d一定时，激光功率P的大小与激光功率密度ρ 成正比。当辐照在材料上的激光功率密度大于临界阈值（106　W／cm2）时，激光焊接形式为深熔焊，即产生“匙孔效应”；如果小于临界阈值，激光焊为热导焊，此 时 母 材 温 度 升 高 到 熔 点 之 上 而 低 于沸点［8－10］。

由焊接热输入公式E＝P／（vd）可知，当光斑直径d不变时，激光功率P和焊接速度v是影响焊接热输入值的重要参数，焊接热输入E的大小决定焊缝的熔宽和熔深［11］。由图2可知，当焊接速度v为45mm／s，离焦量f为－3mm 时，随着激光功率P的增加，热输入E增加，材料的流动性增强，因此焊缝熔宽由图2（a）到（e）逐渐增加，热影响区的宽度也随之增加。功率为1　90 W 时焊缝表面鱼鳞纹细密均匀，焊缝边缘过渡连续、圆滑，焊缝背面未焊透，热影响区窄，焊缝成形质量比较理想，剪切强度达到最高，为10 ．21MPa。 当功率增加到2　00W，焊接热输入继续增加，熔宽和热影响区变大，焊接时有明显飞溅产生，导致熔池金属量减小，焊缝表面凹凸起伏，边缘有焊瘤产生，成形质量较差。此外，焊缝背面焊穿，导致背面气体保护性能不良，有开裂现象，剪切强度降低，仅为21．3 MPa。

# 2．1．3 离焦量对焊缝成形的影响

离焦量指激光焦点和作用材料的间距。在焊接过程中，离焦量对接头质量有显著的影响。激光焊接过程离焦量不能为0，因为激光焦点处光斑的功率密度很高，焊接过程中熔池金属容易蒸发成孔，而非激光焦点的平面上，功率密度分布更加均匀，焊接效果良好［12］。以钢板上表面为基准，规定激光焦点位于钢板表面上方时为正离焦量。从光学的角度看，正负离焦量相等时，对应基准点功率密度相同，但焊缝形状有所区别。采用正离焦量时，穿透能力相对较弱，在焊接薄板时采用正离焦比较合适［13］；而采用负离焦量时，激光能够向材料的更深处穿透，因此焊接熔深更大。本试验钢板和铝板的厚度达到3mm，因此采用负离焦的方式以实现良好的穿透能力。图4 是激光 功 率 为 1　90 W，焊 接 速 度 为45mm／s时，不同离焦量下钢／铝合金焊缝表面形貌。当离焦量为0mm时，焦点作用在冷轧钢表面，此时光斑直径最小，能量密度最大，焊接时有飞溅产生，焊缝宽度较小，存在咬边缺欠，表面粗糙，没有形成鱼鳞纹，焊缝背面烧穿，成形不良，抗拉强度只有13．27MPa；将离焦量增加到－2mm以上时无明显飞溅产生，激光束对焊缝的铺展性提高，焊接过程熔池平稳。当离焦量为－3mm 时抗拉强度最大，为10 ．21MPa。当离焦量为－5mm 时，焊缝表面光滑，无鱼鳞纹产生，拉伸强度降低，因为此时的能量密度降低，激光穿透能力下降，无法形成较大的熔深，导致承载面积不足。

# 2．2．2 显微硬度的影响

硬度的变化趋势是焊接接头组织和力学性能的一个评判标准。图6是钢／铝合金焊接接头添加中间层前后铝侧显微硬度分布，可以看出，两种焊接接头的硬度分布大致为两端高、中间低，从母材到焊缝区显微硬度呈先增大后减小的变化趋势。激光焊接接头主要由母材、热影响区、熔合区和焊缝组成。硬度分布呈现该趋势主要是由于熔池内液态金属的温度梯度（G）、过冷度、晶体生长速度（R）和合金元素含量造成的。激光深熔焊时熔池内液态金属具有较大的过冷度，这往往有利于枝状晶的生长。焊缝中心与边缘晶粒差别主要与G∶R比值有关。在熔合线附近温度梯度较大，G∶R比值较大，有利于枝状晶的形成；焊缝中心区域温度梯度小、晶体生长速度快，G∶R比值较小，有利于等轴晶的形成［14］。焊缝的硬度与焊缝组织和合金元素的含量有关。焊缝的晶粒比母材的晶粒小，焊缝硬度受细晶强化的影响而高于母材。由于熔合区的合金元素含量高于焊缝中心区，焊接接头熔合区的硬度大于焊缝中心区等轴晶的硬度。

# 2．2．3 焊缝组织的影响

图7为添加中间层前后钢／铝合金焊接接头的微观组织。未添加中间层时，熔池上宽下窄，形成“匙孔”，实现深熔焊。熔池到达6010铝合金层而未熔透。添加Cu层后焊缝中部宽度显著减小，与未添加中间层相比，熔深有明显提高。其原因在于Cu的热导率高，在20℃时，铜的热导率是397W／（m·K），远远大于DC01冷轧钢（6 ．7W／（m·K）和6010铝合金（206．9W／（m·K）。当熔池温度升高时，Cu的导热系数仍大于这两种母材。在焊接两金属板时，铝合金吸收的能量主要来源于光束和金属的热传导，熔融状态下，Cu层可以改善上层冷轧钢对下层铝合金的热传导效率，使得激光能量更快传递到下层铝合金，从而“匙孔”效应更加显著，焊缝截面形状更近似于“钉型”。

# 2．2．5 XRD 物相分析

金属间脆性化合物是影响钢／铝焊接头性能的重要因素之一，本研究使用 X射线衍射仪确定添加中间层前后焊缝区域的物相组成差异，并用能谱仪（EDS）测定元素比例变化。图10（a）为未添加中间层试样XRD检测结果，从图中可以看出焊缝区产生了FeAl、FeAl2、Fe4Al13金属间化合物。EDS线扫描结果表明在未添加中间层时，Fe－Al金属间化合物层厚约40 m，易于检测，与 XRD检测结果一致；图10（b）为添加Cu中间层后试样 XRD检测结果，由于新物相 AlCu 的产生，Fe－Al系金属间化合物的厚度降低至20μm 左右，焊接接头表现出更好的韧性。

# 3 结论

（1）当激光功率P＝1 90 W，焊接速度v＝45 mm／s，离焦量f＝－3 mm 时，焊缝剪切强度达到最大，为10 ．21 MPa。 添加 Cu中间层时，剪切强度比未添加中间层提 高 4 ．61％，达 到14 ．91MPa。

（2）未添加中间层时剪切试样断口形貌表现为 脆性断裂特征；添加Cu中间层后，剪切试样微观断 口形貌表现为塑性断裂特征，焊缝呈“钉”型，晶粒尺 寸减小，硬度有明显提升。

（3）未添加中间层时，金属间化合物厚度约为40μm；添加 Cu中间层后，混合区宽度显著减小，约为20 μm。 XRD检测结果表明，添加 Cu中间层后有新物相 Al－Cu系化合物生成。
