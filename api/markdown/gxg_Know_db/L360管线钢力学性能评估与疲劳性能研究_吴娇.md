# L360 管线钢力学性能评估与疲劳性能研究

吴 娇1, 万力华2, 汪 波1, 龙俨丽1, 马代强3, 贾丹彬2, 龙木军2(1.中国石油西南油气田分公司重庆气矿,重庆40147; 2.重庆大学材料科学与工程学院,重庆4004 ;3.重庆天然气储运有限公司,重庆 401147)

摘 要:注采管道的力学性能和疲劳性能对于地下储气库的长期安全运行和服役寿命至关重要。对L360管线钢母材与焊缝进行了力学性能测试与显微组织表征,针对注采管道高周疲劳难以实际测试的问题,基于材料实测力学性能,建立了母材与焊缝高周疲劳仿真模型,并通过高载荷疲劳试验验证了模型的准确性,探究了不同加载条件下疲劳寿命演变规律,并对比母材与焊缝试样疲劳性能的差异。结果表明:L360焊缝塑性相较于母材下降明显,母材与焊缝断后伸长率分别为26.1%和21.6%,断裂类型分别为塑性断裂与准解理断裂。母材与焊缝试样疲劳寿命均随着平均拉伸载荷与载荷谱幅值的增大而减小,在相同的加载条件下,母材的疲劳性能优于焊缝。当拉伸载荷为6.5kN,幅值大于0.075时,焊缝试样疲劳循环次数为母材试样的4.7%。研究结果可为储气库管材选择与管道失效防护提供数据与理论支持。

Mechanical performance tests and microstructural analysis on L360pipeline steel basemetal (L360-BM) and welds(L360-WM) were conducted. 地下储气库是将异地油气田产出的天然气加压重新注入、储存、采出的一体化系统,是解决天然气季节性、地区性供需不平衡矛盾的最佳选择[1-4]。注采管道母材及焊缝的基本力学性能(强度、塑性、疲劳性能等)是直接影响地下储气库安全可靠性和服役寿命的主要因素之一。与常规天然气运输管道相比,地下储气库注采管道设计压力更大,且承受注气-采气周期过程中气压波动、管体振动等交变载荷,存在材料疲劳失效风险[5-6]。因此,对储气库所用管材及焊缝疲劳性能、强度、塑性等基本力学性能进行评估是储气库建设满足安全性高、服役年限长等基本要求的重要前提。

目前,地下储气库注采管道多以低级别管线钢为主,常 用 材 料 包 括 L245、L360、L415 等 管 线钢[7-8]。许多学者对其进行了管材应用的安全性评估,但主要集中在管材腐蚀[9-11]、氢脆[12-15]行为上。管道的疲劳失效在管道运输领域中是一种普遍存在且难以发现的问题,需要在管材选择与评估时予以特别考虑。ZHANG 等[16]研究发现储气库复合管道内衬出现裂纹的原因是管内气压波动产生的交变载荷导致了管道弯曲疲劳失效。LUO 等[17]对一条天然气泄露管线进行失效分析,发现管道凹坑泄漏是由材料疲劳失效导致的。现有的研究表明,管道焊接接头可能是疲劳裂纹萌生和扩展的主要位置。A ZAM 等[18]对X42海底管道疲劳失效分析,发现疲劳裂纹起源于热影响区并沿着焊缝区扩展。王超逸等[19]研究发现高强度船舶用钢焊缝的疲劳性能都低于母材,热影响区可能成为裂纹萌生和扩展的潜在区域。可见,注采管道焊接接头可能成为地下储气库注采管网安全运行的薄弱环节。大量研究表明材料的微观结构状态对其力学性能有显著影响[20-22],而材料的疲劳性能与其力学性能密切相关。因此,对L360管线钢母材与焊缝力学性能与疲劳性能进行评估对储气库安全运行有重大的意义。

材料疲劳性能的评估方法主要分为疲劳试验与疲劳仿真。在地震、滑坡等极端情况下,管道受到大应变幅的循环荷载作用,可能发生极低周应变疲劳失效[23]。但管道在正常服役时产生的最大应力是低于材料屈服强度,且疲劳寿命一般较长,疲劳失效类型通常为高周应力疲劳。传统的高周疲劳试验虽然能够直接测量材料在交变加载下的疲劳寿命,但试验周期极长、成本高。相比之下,有限元疲劳仿真能够快速评估材料和结构在不同加载条件下的疲劳寿命,更 加 经 济 高 效[24-25]。 BAGNI 等[26] 采 用nCode Designlife软件对混合接头进行了高周疲劳寿命评估。MIAO 等[27]利用 Ansys Workbench与nCodeDesinlife软件建立了带腐蚀坑钢丝的有限元模型,模拟发现,随着坑深宽比的增加,钢丝的疲劳寿命由高周疲劳转向低周疲劳。然而,目前关于对L360管线钢母材及焊缝力学性能上的评估数据十分有限,尤其缺乏对其疲劳性能的评估。因此,研究不同加载条件下 管线钢母材和焊缝的疲劳寿命演变规律对于提升储气库系统的可靠性和耐久性是极其有必要的。

综上所述,本文选用 L360 管线钢母材及焊缝为研究对象,对其进行力学性能测试与显微组织表征;通过 AnsysWorkbench与nCodeDesignlife有限元软件,基于实测材料性能参数,建立高周疲劳仿真模型;通过高载荷疲劳试验验证模型预测材料疲劳寿命的准确性,最后仿真分析不同加载条件下母材与焊缝疲劳试样的疲劳寿命演变规律。研究结果可为储气库管材选择、提高管道运行的安全性和耐久性提供科学依据。

# 2 结果与讨论

# 2.1 力学性能及组织差异分析

# 2.1.1 显微组织观测

图7所示为 L360母材、热影响区、焊根、焊缝在光学显微镜下放大 倍的显微组织。母材的显微组织为准多边形铁素体( )、粒状贝氏体( )、上贝氏体(UB)的混合组织,铁素体为软韧相,具有良好的塑性与韧性,但其强度、硬度较低。粒状贝氏体的组织特征是铁素体中分布一些颗粒状的小岛,这些小岛可起第二相强化作用,对基体的强度有一定的提升[30]。相较于母材,热影响区出现了部分较为粗大的晶粒,且铁素体中析出较为弥散分布的碳化物,形成铁素体与碳化物的机械混合物,向贝氏体发生转变。焊根与焊缝中心组织均以准多边形铁素体、珠光体(P)为主,珠光体在焊根基体中沿铁素体晶界呈条状分布,而在焊缝中心基体中呈均匀块状分布。由于,焊缝中心焊条成分中有微量的 Mo、V元素,起到了细化晶粒的作用,焊缝中心的晶粒尺寸相较于焊根基体晶粒尺寸更小[31]。
