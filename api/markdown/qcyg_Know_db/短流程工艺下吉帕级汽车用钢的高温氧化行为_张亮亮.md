# 短流程工艺下吉帕级汽车用钢的高温氧化行为

张亮亮1,2, 杨 永1, 黄贞益1, 王 畅2, 于 洋2, 缪成亮3( 安徽工业大学冶金工程学院,安徽 马鞍山 24302; 2.首钢集团有限公司技术研究院,北京 10043;3.首钢京唐钢铁联合有限责任公司制造部,河北 唐山 063200)

摘 要:为解决短流程硅锰系吉帕级汽车用钢在工业生产中出现的红锈缺陷问题,以取自实际 MC R(多模式全连续铸轧)产线板坯的0.2C-1.5Si-2.3Mn体系汽车用钢为研究对象,对其在90 \~1250 ℃高温条件下的氧化行为进行系统研究,重点探讨 、 合金元素对氧化铁皮结构、界面形貌及元素迁移的影响机制。 研究结果表明,氧化行为呈现明显的温度依赖性。在100 ℃以下,氧化皮主要由FeO 和FeO 构成,氧化层/基体界面处形成SiO与FeSiO 颗粒富集层,基体内氧化程度较低;温度升至1150 ℃时,界面FeSiO 发生部分液化,内氧化层中出现弥散分布的SiO-MnO 复合氧化物;当温度达到120 ℃以上时,Mn 元素向外扩散显著,形成致密且脆性的(Fe,Mn)O 尖晶石固溶体,同时界面橄榄石相转变为(Fe,Mn)SiO ,并与SiO 形成网状共晶结构,该共晶相沿FeO 晶界渗透至氧化皮内侧并钉扎于钢基体,与脆性尖晶石共同作用,加剧除鳞残留与轧制碎裂风险。通过提高连铸坯拉速、优化隧道炉出炉温度及改进除鳞喷嘴结构,有效抑制了有害氧化物相的形成,红锈缺陷发生率显著降低。本研究为短流程高硅高锰钢表面质量控制提供了理论依据。

为应对汽车普及带来的安全、节能与环保挑战,发展高强轻量化材料已成为汽车产业的重要方向。在此背景下,薄板坯连铸连轧等短流程工艺因其流程紧凑、节能高效、产品性能稳定等特点,为轻量化高强钢的生产提供了理想的技术途径[1-5]。

为实现优异的强塑性组合,以 、 、等为代表的吉帕( )级高强钢普遍采用“中高碳、高硅、高锰”的合金设计路线,并辅以少量 Al、Cr、Nb、Ti等微合金元素进行组织细化与性能调控[6-8]。为实现极致的成本与效益目标,首钢京唐(多模式全连续铸轧)产线在吉帕级高强钢的开发与生产中,仍延续“中高碳、高硅、高锰”的合金设计。然而,高Si、Mn等合金元素在高温下倾向于在界面强烈偏聚并形成复合氧化物,该成分体系在实际生产中易诱发严重的表面红锈缺陷,产品降级率显著升高,直接影响了成材率与经济效益。目前大量研究聚焦于传统热连轧工艺下高温 等合金元素的氧化行为[9-13],短流程采用连铸坯直接轧制或仅经隧道炉短时均热,相比于传统热连轧工艺,板坯在隧道炉停留时间大幅缩短,但由于受连铸拉速限制,板坯温降大,粗轧后需要增加感应加热装置对板坯进行快速补热,控制高的精轧入口温度从而满足后续轧制工艺要求[14-15],另外传统热连轧工艺在粗轧往复轧制过程中投入多次除鳞道次,而短流程工艺为保持轧制连续性,除鳞窗口更少、时序更严格,在有限的除鳞条件下极易去除不净,其效果高度依赖于氧化铁皮结构、氧化铁皮/基体界面的结合状态,因此,针对短流程特有的快速热历程,深入研究此类高敏感成分体系的氧化动力学、界面反应路径及缺陷形成机制,尤为重要与紧迫。本文以首钢 MCCR 短流程产线实际生产的中碳硅锰系吉帕级汽车钢为研究对象,通过系统的高温氧化试验,揭示合金元素、 在短流程快速热历程下对氧化动力学、界面结构演变的作用机制,阐明其诱发红锈缺陷的关键演化规律,以期为该产线表面质量的精准控制提供理论依据与工艺指导。

# 3 分析与讨论

# 3.1 高温氧化行为分析

上述试验结果表明,试验钢的高温氧化行为同时受温度与合金元素( 、 )的耦合作用控制。通过热力学与动力学分析,可系统揭示其内在机理。在Fe-Si-Mn-O 体系中,元素与氧的亲和力强弱决定了氧化反应的优先顺序。其标准生成自由能(ΔG0)关系为:ΔG0SiO <ΔG0MnO<ΔG0FeO,表明在热力学上Si将优先于 Mn和Fe被氧化。然而,在实际氧化过程中, 的扩散行为受其较大原子半径及较高扩散激活能的限制,使其成为氧化反应的速率控制步骤。在 范围内,温度通过调节元素的扩散速率与相关相的稳定性,驱动氧化行为呈现阶段性演变,最终在界面处形成特征各异的形貌。

在100 ℃及以下的氧化初期,由于Si扩散缓慢但氧化倾向极强,其富集于钢基体/氧化皮界面处,形成一层连续或半连续的SiO 薄膜及富硅颗粒层。该层结构致密,可有效阻隔氧与金属离子的相互扩散,从而显著抑制钢的进一步氧化[16-19]。典型的界面形貌如图4(a)所示。

当温度升至1 150 ℃以上时,合金元素的扩散速率普遍加大,其中 的扩散速率显著高于 。此阶段的关键过程是 的向外扩散以及尖晶石(Fe,Mn)O 固溶体的形成。在1150 ℃时,钢基体/氧化皮界面的SiO 薄膜与富Si颗粒层仍较为致密,对 Mn的扩散具有一定阻碍作用。同时,部分Mn与SiO 反应生成SiO-MnO 复合内氧化核壳颗粒,因此该温度下生成的(Fe,Mn)O 固尖晶石相数量较少。

温度达到1 及以上时,氧化皮/基体界面处因FeSiO 液化而形成熔融层,为 Mn的迁移提供了快速扩散通道。Mn元素得以大量向外迁移进入氧化层,促使(Fe,Mn)O 尖晶石相大量形成,该现象与XRD 物相分析(图4、表2)以及扫描电镜(图5(c)观察到的微观形貌特征相互印证。

综上所述,中碳硅锰系吉帕级汽车钢轧制后残留在钢基体界面的(Fe,Mn)SiO 与内部充满微裂纹的(Fe,Mn)O 共同作用,是导致表面产生红铁皮缺陷的根本原因。在高Si成分下,Mn的添加提高了(Fe,Mn)SiO 的稳定性,加剧了高温下界面液相的形成,其与SiO (FeO)形成的共晶液相显著增加了除鳞难度。同时,共晶液相加剧 Mn的外扩散促使脆性(Fe,Mn)O 尖晶石在精轧过程中大量生成,进一步恶化氧化铁皮的塑性变形能力,提高热轧板表面氧化铁皮破碎形成红锈缺陷风险。

基于上述氧化机理的研究结论,对 MC R 产线关键工艺参数进行了系统性优化。具体措施包括:将连铸坯拉速从 / 提升至 / ,隧道炉保温温度控制在1 150\~1 20 ℃、保温时间缩短至20min,以抑制(Fe,Mn)SiO 铁橄榄石相的形成;同时,改进除鳞喷嘴结构,并将除鳞压力由25MPa提高至35MPa,从而显著减少粗轧过程中残留的(Fe,Mn)SiO 。拉速提高也有助于降低精轧温降,将精轧入口温度控制在1120\~1170 ℃后,可有效抑制脆性(Fe,Mn)O 尖晶石相的生成与破碎。通过采用上述措施,MC R 短流程工艺生产高强钢时红锈缺陷发生率得到显著降低。

从长远发展角度,钢种成分体系的优化仍具有进一步探索的空间。例如,可在现有硅锰系成分基础上,尝试引入 、 等元素进行替代或复合添加[39-40]。Al可促进形成热力学更稳定的 AlO ,避免低熔点硅酸盐共晶相的产生; 则可能通过形成( ) 等磷酸盐化合物,降低氧化铁皮与基体的界面结合强度。然而,需严格控制其添加量,以避免对材料成形性与焊接性造成不利影响。总而言之,通过成分与工艺的协同优化来实现高性能与高表面质量,是短流程生产高强钢的重要发展方向。

# 4 结论

)中碳硅锰系吉帕级汽车钢高温氧化行为具有明显的温度依赖性:温度低于 时氧化平缓;超过1150 ℃后氧化加剧;温度高于120 ℃后,界面生成并熔融的(Fe,Mn)SiO 是氧化增重急剧上升的主要原因。

) 元素扩散对高温氧化铁皮结构、界面形貌影响显著。在120 ℃以上,Mn元素促进界面形成液相(Fe,Mn)SiO ,大幅提高氧化皮黏附性,同时 Mn元素外扩散生成大量脆性(Fe,Mn)O 尖晶石,严重恶化氧化皮轧制变形能力,导致其破碎。

3)通过开展系统工艺优化,如连铸拉速、精准控制隧道炉的保温温度与时间,并改进除鳞系统的结构与压力参数,MC R 产线吉帕级高强钢的红锈缺陷发生率得到显著降低。

)成分优化是控制红锈缺陷的根本途径,如微量 元素添加可抑制连续硅酸盐膜形成,降低氧化皮黏附性;适量 Al元素添加可形成高熔点 AlO ,抑制有害低熔点共晶生成。未来应注重多元素协同设计,推动成分与工艺的协同优化。
