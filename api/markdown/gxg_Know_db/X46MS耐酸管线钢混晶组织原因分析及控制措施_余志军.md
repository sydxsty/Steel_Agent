# X46MS 耐酸管线钢混晶组织原因分析及控制措施

余志军1，李 显2，周明科1，唐文洋1

（1．广西钢铁集团有限公司，广西 防城港 53802；2．广西柳州钢铁集团有限公司，广西 柳州 54502）

摘 要：针对X46MS耐酸管线钢产生混晶组织的问题，对其显微组织、生产工艺进行了分析，结合其化学成分设计及轧线实际控制情况，研究了混晶组织的产生原因，并提出了控制措施。结果表明：X46MS耐酸管线钢再结晶温度较低，而精轧入口温度较高时钢卷在精轧前机架处于部分再结晶区轧制是导致其产生混晶组织的主要原因。 通过采取针对性措施，包括加热工序适当降低板坯加热温度、缩短加热时间，以降低整体工艺温度、减少原始奥氏体晶粒长大；粗轧工序优化除鳞喷水模式及温度控制，确保粗轧末道次温度命中率，并缩短中间坯待温时间；精轧工序将精轧空过机架及压下量后移，有效消除了X46MS耐酸管线钢混晶组织现象。关键词：X46MS耐酸管线钢；混晶组织；粗轧末道次温度；精轧入口温度；部分再结晶区；生产工艺；改进措施

石油天然气的管道输送具有高效、经济、安全等特点，是长距离输送石油天然气的主要形式［1－2］。随着易开采资源的减少，管道的服役条件和输送介质越来越苛刻复杂，许多管道必须穿越人口稠密地区或沙漠、严寒等地带，这就对管线钢的性能尤其是耐腐蚀性能提出了更高的要求。李鹤林院士［3］曾指出抗氢致开裂（HIC）管线钢及钢管是高性能油气输送钢管的发展方向之一。当管线钢在富含 HS的油气环境中处于无应力或非拉应力状态下受腐蚀产生的氢进入钢内造成的开裂称为氢致开裂（HIC），一般指氢致鼓泡（表面裂纹）和氢致台阶式开裂（内部裂纹）［4］。HIC可使管线钢在没有任何明显预兆的情况下突然开裂，其破坏性和危害性极大。影响管线钢抗HIC性能的因素较多，就钢材本身特性而言，包括化学成分、显微组织、夹杂物控制等，其中热力学平衡且稳定的细晶组织是抗 HIC的理想组织［5］。而混晶组织对抗 HIC性能的危害较大［6－8］。本文结合X46MS耐候管线钢生产过程中存在混晶组织的情况，分析了混晶组织的产生原因，并结合轧线工艺特性提出了针对性措施，有效地消除了混晶组织缺陷。

# 1．2 工艺控制

# 1．2．1 炼钢工艺

试验材料的炼钢工艺路线：铁水预处理→转炉冶炼→炉后吹氩→LF精炼→RH精炼→板坯连铸。采用铁水预处理脱硫，保证入炉铁水S质量分数不大于0．02％；所有铁水均需扒渣，保证扒渣后亮面面积在95％以上，要求入炉铁水P质量分数在0．135％以下。转炉冶炼脱碳后采用挡渣出钢，出钢前3min至出钢过程严禁添加任何造渣料，底吹采用全程吹氩模式；

LF精炼全过程顶渣必须发泡良好，最后一次合金化后必须保证3min 以上的中等强度吹氩或强吹氩时间；RH 真空精炼保证真空总循 环 时 间 在 15～20min，极限真空保持时间在15 min 以上。

# 1．2．2 轧钢工艺

试验材料采用 230mm×1 50 mm 断面的连铸坯生产15．8 mm 厚的耐酸管线钢带钢。控制板坯炉内最高加热温度为1　260℃，出炉温度为1　230℃，加热时间在 150 min 以上；轧制工艺采用两阶段控制轧制，设定粗轧温度目标值1　00℃，中间坯厚度设定为50mm，精轧入口温度为950℃，终轧温度为（810±10）℃，轧后带钢通过层流冷却至510℃进行卷取。粗轧轧制及中间坯待温期间根据钢卷实际温度进行摆荡。 此外因钢卷较厚，为保证精轧各机架压下率，将精轧机F～F机架中的F机架设为空过。

# 2．2 控轧工艺分析

带钢在生产中出现混晶组织的直接原因是由于带钢在奥氏体部分再结晶区进行变形，而导致带钢在奥氏体部分再结晶区发生混晶的主要原因包括原始奥氏体晶粒尺寸、变形条件、微合金元素的影响等。奥氏体部分再结晶区对应到轧线温度则为粗轧末道次温度及精轧入口温度。由于板坯加热温度为1　260 ℃，板坯温度整体较高，也导致原始奥氏体晶粒较为粗大；实际生产中，由于来料温度较高，为提高生产节奏，粗轧末道次轧制温度往往偏高，较设定的 1　00 ℃高约30～50℃，并导致精轧入口温度也较高，基本在970～90℃，实际生产粗轧末道次轧制温度及精轧入口温度如图2所示，其中横坐标标识钢卷长度位置。 而精轧终轧温度810 ℃及层流冷却温度510℃则均命中较好。

# 3 分析与讨论

通常，可将控制轧制分为3个阶段：（1）奥氏体再结晶区轧制阶段（温度1　00℃以上）。在该温度范围内，奥氏体变形和再结晶同时进行，因再结晶而获得的细小奥氏体晶粒将导致相变后的铁素体晶粒细 化。（2）奥 氏 体 非 再 结 晶 区 轧 制 阶 段（950℃～Ar3）。在该温度范围内，形变使奥氏体晶粒被拉长，在伸长而未再结晶的奥氏体内形成高密度变形孪晶和变形带，同时微合金碳、氮化物因应变诱导析出，增加了铁素体的形核位置，细化了相变后的铁素体晶粒。（3）γ＋α 两相区轧制阶段（Ar～Ar）。在该温度范围内，奥氏体和铁素体均发生变形，形成亚结构［9］。

X46MS耐酸管线钢仅加入了质量分数0．025％的Nb，再结晶温度较低。而根据设计工艺参数，板坯加热温度较高，必然导致原始奥氏体晶粒尺寸较大。当原始奥氏体晶粒尺寸较大时，会略微推迟动态再结晶过程的发生。这是因为晶粒比较粗大，变形时在晶内产生的位错密度较小，晶体内的形变储能也较小，奥氏体动态再结晶也越困难［11］。此外，实际生产中当来料温度较高时，出于提高轧制节奏、减少中间待温的目的，往往会尽量提高精轧入口温度，使得带钢在精轧前机架处于部分再结晶区轧制。在部分再结晶区轧制时，再结晶部分的晶粒细小，在其晶界上析出的铁素体往往较细小；而未再结晶部分的晶粒受到变形被拉长，晶粒没有细化，因此铁素体形核位置较少，容易形成粗大的铁素体晶粒，最终导致出现混晶组织现象。混晶组织对带钢强度的影响不太大，但对其韧性、抗 HIC性能等有较大影响［12－13］。

为避免出现混晶组织，需要尽量避免在部分再结晶区轧制或尽量减小在部分再结晶区轧制时的压下率。X46MS耐酸管线钢由于再结晶温度低，精轧入口温度完全高于再结晶温度的待温时间会较长，而如进一步增加 Nb含量以提高再结晶温度又会造成成本的增加。考虑到板坯加热温度较高、粗轧末道次温度较高、精轧空过F5机架的情况，降低工艺温度、调整精轧工艺则为主要的控制方向。

# 控制措施

# 4．1 降低工艺温度

结合 Nb的固溶情况，将板坯加热温度由1 260 ℃降低至1　230℃，出炉温度降至1　20 ℃，达到降低整体工艺温度的目的；另外，板坯加热时间由 150min 以上缩短至130min以上，以减小原始奥氏体晶粒长大。在粗轧轧制期间进行多道次高压水除鳞，以进一步降低轧件温度，缩短粗轧阶段待温时间，确保粗轧末道次轧制温度及精轧入口温度的命中率。

# 4．2 精轧工艺调整

将精轧空过F机架改为空过F机架，即精轧第1道轧制机架变为F机架轧制，延长了中间坯的待温时间。同时将F机架间除鳞水设为常开，达到进一步降低精轧首道次实际轧制温度的目的。此外，将F机架的压下率降低，可减少部分再结晶区轧制的影响。

优化措施实施后 X46MS耐酸管线钢混晶组织现象基本得到消除，实施后的金相组织如图3所示，抗HIC试验结果见表2。带钢组织均匀性大幅提高，拉长的粗大晶粒及偏析带得到有效改善。 其抗HIC试验裂纹率均为0，远优于 API SPEC 5L 46th—2018标准规定，表明带钢具有良好的抗 HIC性能。

# 5 结语

X46MS耐酸管线钢强度相对较低，仅添加质量分数0．025％的Nb，再结晶温度较低；另外，为提高轧制节奏、减少中间坯待温的目的，精轧入口温度较高。过高的精轧入口温度使带钢在精轧前机架处于部分再结晶区轧制，从而导致出现混晶组织现象。通过采取针对性措施，如适当降低板坯加热温度及粗轧末段次轧制温度，优化除鳞喷水模式，精轧空过机架及压下量后移等，优化后 X46MS耐酸管线钢的混晶组织现象基本得到消除，带钢组织均匀性大幅提高，其 HIC试验裂纹率均为0，远优于标准规定。
