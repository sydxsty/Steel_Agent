# CrMnMo 空冷耐磨钢调质处理的组织与性能的研究

刘金国1于淑政2龚建宇1王　 琦1

（1∙煤炭科学研究总院 测试中心 北京 100013; 2∙河北建筑科技学院 机械工程系 河北 邯郸 0　56038）

摘 要：为了实现以CrMnMo 空冷耐磨钢作为新型极硬岩石反井破岩滚刀刀体材料的设计对CrMnMo 空冷耐磨钢调质处理的组织与性能进行了研究．通过研究搞清了 CrMnMo 空冷耐磨钢在调质处理时的显微组织、断口形貌及淬火加热奥氏体化温度；从根本上解决了 CrMnMo 空冷耐磨钢的力学性能、耐磨性、硬度与回火温度的关系等关键技术问题．与中硬岩石破岩滚刀刀体材料ZG30GrMnSiTi 相比在硬度相当的条件下冲击韧性提高了50％耐磨性提高了10％较好地解决了新型极硬岩石反井破岩滚刀使用寿命低的技术难题

随　着反井钻井技术的不断发展和技术进步其服务领域也由煤炭行业逐步拓展到了水电和有色金属行业反井钻井施工所钻凿岩石的岩性也由沉积岩逐步拓展到了火成岩．该类岩石结构致密硬度、强度高单轴抗压强度一般为160～20 MPa属硬或极硬岩石．这样在沉积岩中使用且具有较高使用寿命的中硬岩破岩滚刀由于在刀体材料、主轴结构、刀齿布置等方面无法满足硬及极硬岩石的破岩工况要求因此在实际施工中破岩滚刀突出表现为刀体大量掉块、过度磨损、刀齿脱落使用寿命很低一般平均为40～60m／把．这不仅大大提高了工程成本加大了工程风险而且严重制约了反井钻井技术在火成岩地层中施工的进一步发展和推广．为了解决这一关键技术问题笔者提出并开发了与目前国产反井钻机相配套的硬及极硬岩石反井破岩滚刀．根据破岩滚刀在硬及极硬岩石条件下的失效形式与特点在借鉴中硬岩石反井镶齿滚刀结构的基础上提出了以CrMnMo 空冷耐磨钢作为新型滚刀壳体材料的设计思想并对CrMnMo 空冷耐磨钢的热处理工艺、显微组织与力学性能进行研究使其满足硬及极硬岩石条件下的破岩工况要求

# 1 CrMnMo 空冷耐磨钢调质处理的组织与性能的研究

新　型硬及极硬岩石反井镶齿盘型破岩滚刀刀体材料的组织与性能直接影响滚刀的使用寿命为了满足极硬岩石破岩工况的要求其刀体材料与中硬岩石滚刀刀体材料ZG30CrMnSiTi 相比在硬度相当的条件下冲击韧性、耐磨性应有大幅提高．为了实现这一目标对CrMnMo 空冷耐磨钢的热处理工艺、显微组织、断口形貌与力学性能进行了研究

# 1∙1 CrMnMo 空冷耐磨钢淬火加热奥氏体化温度的确定

由　文献 ［1］ 的研究成果可知： CrMnMo 空冷钢的临界点AC3为810℃在AC3以上选择840 86080 90 及920℃五个奥氏体化温度进行试验奥氏体化加热时间均为30min 采用空冷及油冷2种冷却方式进行淬火在 HRU－150型光学洛氏硬度计上测定不同温度加热淬火后钢的硬度．淬火加热温度对钢的硬度的影响如图1所示．由此可看出随淬火加热奥氏体化温度的提高钢的硬度逐渐增加 加热温度升至90 ℃ 钢的硬度已稳定在HRC53～54 在各种加热温度下空冷后的硬度比油冷的仅低HRC1\~2. 由上述试验结果可确定CrMnMo 空冷钢的最佳淬火加热区为870～910 ℃, 故本研究采用的淬火加热温度定为890℃

# 2 实际应用

根据对CrMnMo 空冷耐磨钢调质处理的组织与性能的研究结果将CrMnMo 空冷耐磨钢用于新型极硬岩石反井破岩滚刀刀体材料 在完善了其它相关各方面的设计后于199年5月试制出6把样刀．该样刀于199年6月～200年3月在云南大朝山水电站工地进行了工业性试验．在玄武岩地层中 （岩石单轴抗压强度平均170MPa） 先后钻凿直径为1∙4m 的各类井孔8个累计深度达960多米平均寿命160m／把从根本上解决了滚刀破岩过程中刀体大量掉块、过度磨损的技术难题大幅度地提高了反井破岩滚刀在硬及极硬岩层中的使用寿命

该　系列反井破岩滚刀在批量生产后 先后用于山西万家寨水利枢纽 甘肃金川有色金属公司等水电、有色金属行业 取得了明显的经济和社会效益

# 3 结 论

（1） 采用CrMnMo 空冷耐磨钢作为硬及极硬岩石反井破岩滚刀刀体材料 经调质工艺处理后的性能较好地满足了硬及极硬岩石的破岩要求

（2） 为了满足硬及极硬岩石的破岩要求 该镶齿破岩滚刀刀体材料－－CrMnMo 空冷钢具有 HRC37～42硬度要求相对应的CrMnMo 空冷钢调质处理的工艺应为 （890±10）℃油淬＋ （570±20）℃回火．

（3） 当CrMnMo 空冷钢的硬度为 HRC37～42时 与 ZG30CrMnSiTi 在相同温区回火后的性能相比CrMnMo 空冷钢的无缺口试样冲击韧性提高52％～213％ 耐磨性提高1∙1％～12∙3％

（4） CrMnMo 空冷钢调质处理后的金相组织为回火索氏体 由于该钢含有强碳化物形成元素 使回火转变速度减慢 在上述温区回火后回火索氏体中碳化物粒子尺寸细小且呈弥散分布 从而使 CrMnMo空冷钢具有高的强度韧性和耐磨性等综合性能
