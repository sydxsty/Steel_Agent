# 3 结论

活塞杆端部在磷化前存在淬火裂纹， 装配时在扭矩的作用下，裂纹扩展导致活塞杆脆性断裂。

# 2 原因分析

断裂活塞杆的化学成分和硬度均符合要求，显微组织为回火索氏体，为正常的调质组织。断口约95%的区域具有沿晶断裂特征，断口的棕黄色腐蚀产物富含 P，有磷酸盐结晶，说明在磷化前活塞杆端部已经存在裂纹，在磷化过程中，磷化液渗入裂纹使金属基体腐蚀［1］。断口暗灰色区域无高温氧化产物，结合活塞杆的加工工艺，可以断定裂纹为淬火裂纹［2-4］，装配时，在扭矩的作用下，裂纹扩展，导致活塞杆断裂［5］。

# 汽车用钢的强塑积

好的汽车一是安全， 二是质量轻， 要求汽车用钢兼具高强度和高塑性， 且抗压陷、防冲撞， 用强塑积衡量。强塑积( Pa·%) = 抗拉强度( TS) ×全部断后伸长率( EL) 。

第1 代汽车用钢， 如 DP 钢、CP 钢、TRIP 钢和热成形硼钢等 ，强塑积约 15 G·Pa%， 难以满足未来汽车的轻量化和安全性的需求。

第2 代汽车用钢， 如 TWIP( 孪生诱导塑性) 钢、奥氏体钢， 塑性较高， 强塑积达 60 GPa·%，但合金含量较高，生产工艺复杂 ，成本高。

第3 代汽车用钢， 以第 1 代汽车钢的成本获得接近第 2 代汽车钢的性能， 强塑积为 20～ 50 G·Pa%。

第1 代汽车用钢强塑积低的原因是其加工硬化主要受位错机制的控制， 强度提高时其位错密度也相应增大，导致加工硬化速率及塑性下降。

第2 代汽车用钢强塑积高的原因是其加工硬化机制除了位错增殖外 ，还有来自孪晶的贡献。

第3 代汽车用钢具有多加种工硬化机制及超高强度的基体组织。 有学者认为， 若使用第一代汽车钢钢板厚度 0．7 mm ，则用第三代汽车钢钢板厚度为 0．6 mm。
