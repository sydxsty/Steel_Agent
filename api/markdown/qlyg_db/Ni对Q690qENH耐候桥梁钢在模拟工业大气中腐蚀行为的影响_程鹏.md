# Ni对 Q690qENH 耐候桥梁钢在模拟工业大气中腐蚀行为的影响

程 鹏, 周庆军, 白会平, 黄先球, 庞 涛, 李江文(宝钢股份中央研究院(武钢有限技术中心),湖北 武汉 430081)

摘 要:为研发和推广应用新型耐候桥梁钢,采用周浸加速腐蚀实验和电化学测试方法,结合扫描电子显微镜(SEM)、X 射线衍射(XRD)、电子探针(EPMA)和X 射线光电子能谱(XPS),研究了 Ni对 Q690qENH 耐候桥梁钢在工业大气环境中腐蚀行为的影响。结果表明,Ni的添加可以提高 Q690ENH 钢在工业大气环境下的耐蚀性。添加 Ni可以提高 Q690qENH 钢的自腐蚀电位,增大锈层电阻。Ni在锈层中均匀分布,主要以 NiFeO 的形式存在。NiFeO 一方面提高了锈层的离子选择性,阻挡了 SO 向基体渗透;另一方面促进了锈层中γ-FeOOH 向α-FeOOH 的转化。随着 Ni质量分数从0.31% 增加到0.52%,锈层中 S 的富集量明显减少,Q690qENH 钢的锈层保护指数α/γ\* 值增大,腐蚀速率降低,耐蚀性提高。

Abstract: To develop and romote the aplication of new weathering bridge stel, the efect of Nion the corosion behavior of Q690qENH weathering bridge stel in industrial atmoshere was studied by using the acelerated corosion test and electrochemical test methods, combined with scaning electron microscopy (SEM), X-ray difraction (XRD), electron probe (EPMA) and X-ray photoelectron spectroscopy (XPS). On the other hand, it promotes thetransformation of γ-FeOOH toα-FeOOH in the rust layer. 随着基础设施建设的发展,桥梁钢在市政工程、山区道路、轨道交通等工程项目中得到越来越多的关注,高强、耐蚀、低成本已成为了桥梁钢的发展趋势。在实际应用中,桥梁钢的腐蚀是世界各国工程建设面临的共同难题,腐蚀会降低工程建筑物使用寿命,增加维护和运营成本,甚至会导致重大安全事故[1-3]。因此在关注桥梁钢高强减重的同时,也必须高度重视钢材本身的耐蚀性能。

通常可以通过向桥梁钢添加合金元素以形成稳定致密的锈层来提高其耐大气腐蚀性能。镍是一种常见的提高耐蚀性能的合金元素[4-6]。Nishimura等[7]指出在质量分数为0.5% 的 NaCl溶液中,Ni元素促进了铁锈中尖晶石氧化物的形成,从而在耐候钢上形成了更有保护作用的锈层。Kimura等[8]将3%Ni(质量分数)耐候钢在沿海环境中暴露9a后发现,钢中腐蚀介质 - 的平均穿透率比传统耐候钢低 倍, 2+ 能部分取代 2+ ,并稳定了铁锈中的FeNiO 相,形成一个密集堆积的细晶粒铁锈。文献[9-11]也表明在沿海大气中,含 Ni耐候钢与普通钢材相比能形成更坚韧、更致密的锈层。Chen等[12]的研究结果表明当Ni质量分数超过4%时,耐候钢具有较好的离子选择性,能够阻止 Cl- 进入锈层内部发生腐蚀,在海洋环境中有良好的耐蚀性。Díaz等[13]的研究表明当 Ni质量分数为3.0% 时,可显著提高耐蚀性。

桥梁钢在不同环境的腐蚀发展机制和变化规律差异较大,目前关于 元素对耐候钢耐蚀行为影响的研究主要集中在海洋大气环境,并且Ni元素的添加量必须达到一定程度(质量分数一般为 以上)才能取得较好的耐蚀效果。然而,在开发新型耐候桥梁钢时,不仅要注重其耐候性,还要综合考虑制造成本等因素。工业大气环境是耐候桥梁钢免涂装推广应用的主要市场[14],而目前关于 Ni元素对桥梁钢在工业大气环境下耐蚀性影响的研究较少。Q690ENH 是国内开发的最新一代高性能耐候桥梁钢,目前Ni对 Q690ENH 钢在工业大气中耐蚀性能的影响尚未见报道,有必要开展相关研究。

本文根据GB/T714-2015,从耐蚀性和成本综合考虑的角度设计了3种不同Ni含量的Q690qENH实验钢。采用周浸加速腐蚀实验和电化学测试方法,结合扫描电子显微镜(SEM)、X 射线衍射(XRD)、电子探针(EPMA)和X射线光电子能谱(XPS),研究了Ni对Q690qENH 耐候桥梁钢在工业大气环境中腐蚀行为的影响,以期对 Ni元素对桥梁钢在工业环境中腐蚀性能影响机制做出解释。

# 4 结论

3H O

3种实验钢锈层的 Ni元素的 XPS 光谱分析显示, 元素在锈层中主要以 和 NiFeO 形式存在(图7),随着 Ni含量增加,NiFeO 含量显著增加。文献[29]指出,NiFeO 主要是以 Ni2+ 代替FeO 中铁原子生成的尖晶石化合物,其具有较高的负电性,能细化晶粒,形成致密的离子选择性腐蚀产物膜,能提高锈层对腐蚀性阴离子的阻碍作用。从EPMA 扫描结果(图4)也可以看出,Ni在3种实验钢的锈层中都是均匀分布,S在锈层中的富集量随着 含量的增加而减少,在 钢的整个锈层中富集,在 钢锈层中的富集量减少,但是在0.52Ni钢的锈层中,S元素基本只在外锈层中富集。这说明, 元素的增加可以减少元素的富集,且可以提高锈层离子选择性,阻止HSO- 等腐蚀性介质进入基体,提高了实验钢的耐蚀性能[30]。

同 时,纳 米 级 的 NiFeO 还 可 以 促 进α-FeOOH 的形成[31-32]。由XRD 分析结果(图5,图6)可知,Ni含量的增加可以有效促进γ-FeOOH 向α-FeOOH 的转化,随着 Ni含量的增加,3种实验钢的α/γ\* 值逐渐增大,说明锈层中的α-FeOOH 在增加,而α-FeOOH 被认为是铁的腐蚀产物中最稳定的物质。

此外,标准电极电位越高的金属,其热力学稳定 性 越 高, 的 平 衡 电 极 电 位 比 要 高:Ni(-0.25V)>Fe(-0.4 V)[33],因此 Ni可以提高金属的自腐蚀电位。电化学实验结果表明,

()在工业大气环境中, 种实验钢的腐蚀速率均随腐蚀时间的增加而减小,其腐蚀动力学曲线符合幂函数W =Atn 的规律,随着 Ni含量的增加,A值和n 值均减小,Q690qENH 钢的腐蚀速率逐渐降低,耐蚀性提高。

(2)Ni的添加可以提高 Q690qENH 钢的自腐蚀电位,减缓阳极溶解,随着 Ni含量的增加,3种实验钢的锈层电阻增大,耐蚀性增强。

(3)Ni在锈层中均匀分布,主要以 NiFeO 的形式存在,随着 含质量分数从 增加到0.52%,锈层中S主要在外部富集,锈层其余部分S含量较低。NiFeO 一方面提高了锈层的离子选择性,使S在外锈层富集,阻止了SO 等向基体渗透,另一方面促进了γ-FeOOH 向α-FeOOH 的转化,3种实验钢的锈层保护系数α/γ\* 值随Ni含量的增加而增大,提高了锈层的致密性和保护性能。
