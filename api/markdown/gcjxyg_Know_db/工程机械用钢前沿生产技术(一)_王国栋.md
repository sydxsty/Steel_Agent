# 工程机械用钢前沿生产技术（一）

王国栋，田 勇，李海军，刘振宇，曹光明，王 斌，王丙兴（东北大学轧制技术及连轧自动化国家重点实验室，辽宁 沈阳 10819）

摘　要：工程机械行业近年来发展迅猛，带动了上游钢铁行业在工程机械用钢生产方面的技术进步。我国钢铁企业基于工程机械行业的迫切需求，与高校和科研院所联合，开发出系列关键共性技术：（1）针对特厚规格钢板生产中面临的压缩比不足问题，开发出液芯大压下技术和“温控－形变”耦合轧制工艺，促进变形向钢板中心渗透、改善了其心部缩孔、疏松缺陷；（2）开发出超快冷技术，实现了工程机械用钢组织和性能在线调控；（3）开发出极薄、特厚规格离线淬火装置，解决了厚板冷却能力不足、薄板板形不良等热处理瓶颈问题；（4）开发出薄与极薄规格钢板在线热处理工艺和装备，实现了工程机械用钢的绿色化生产；（5）运用数字化手段，基于热轧过程极为丰富的大数据，解决了工程机械用钢生产中稳定性不足的问题。介绍了以上关键共性技术及其应用，实现了高强、高韧、特厚、极薄等各类工程机械用钢的批量稳定生产。此外，还介绍了我国典型工程机械用钢产品的研发历程，分析了国内知名钢企在工程机械用钢开发和推广过程中的高性能化和品牌化战略路线，探讨了工程机械用钢全生命周期循环利用策略。通过“产、学、研、制、用”协同攻关合作，我国钢铁企业开发出满足工程机械关键原材料制造需求的各类钢铁材料，促进了相关行业发展，提升了我国工程机械行业的国际竞争力。

# 超厚板坯连铸技术

# 1．1 超厚板坯连铸关键技术

近年来随着重型机械行业的迅猛发展，对大规格、高性能钢板的需求愈发迫切。为保证厚规格钢板的轧制压缩比，对连铸板坯厚度规格提出了更高的要求。然而，随着板坯规格的加厚，凝固组织中柱状晶发达、枝晶搭桥严重，中心等轴晶粗大，导致板坯中心偏析、缩孔疏松等问题愈加严重［3］。为改善板坯内部缺陷，电磁搅拌技术、凝固末端轻压下技术已广泛应用于生产实践；近年来针对厚板坯，凝固末端重压下技术、单道次液芯大压下轧制技术也逐渐开始了工业化应用。

# （1）板坯连铸电磁搅拌技术［4－5］。

厚板坯电磁搅拌通常采用线性行波磁场，搅拌器安装在结晶器或二冷区，因磁场穿透能力有限，一般不采用凝固末端电磁搅拌。结晶器电磁搅拌（M－EMS）可均匀钢液内部温度、改善坯壳凝固均匀性，促进固液界面非金属夹杂和气泡的剥离，改善板坯表面和皮下质量，此外可促使凝固前沿不稳定的树枝晶断裂重熔，沉积到液相穴底部成为形核质点，提高中心等轴晶率，改善中心偏析。二冷区电磁搅拌（S－EMS）可消除柱状晶搭桥，增大中心等轴晶率，在改善中心偏析、缩孔疏松的同时，可减少中间裂纹。二冷区电磁搅拌易产生白亮带（负偏析）缺陷，可以通过降低搅拌强度或采用交替搅拌方式来解决。

（2）凝固末端轻压下技术［6］。

连铸板坯中心部位凝固收缩形成负压，产生抽吸作用是中心偏析形成的主要原因。凝固末端轻压下技术通过补偿心部凝固过程的体积收缩，抑制枝晶间浓化钢液向中心流动，来改善中心偏析及缩孔疏松，已然成为改善板坯内部质量的主要措施。目前行业对轻压下的理论压下区间已基本达成共识：区间起始位置所对应的中心固相率为0．2～0．3，终了位置所对应的中心固相率为0．7～0．9，对于枝晶搭桥现象严重的中高碳钢，其压下区间较低碳钢略靠前。轻压下的压下量需保证能够补偿凝固收缩，同时还要避免压下量过大产生内部裂纹。目前应用轻压下技术的难点在于，基于在线凝固传热计算模型难以精确预测凝固末端位置，导致轻压下的工艺效果难以有效发挥，甚至进一步恶化了板坯质量。

# （3）凝固末端重压下技术。

行业内习惯以压下量的大小来区分轻、重压下技术，然而这样区分并不恰当，实际上重压下与轻压下在消除缺陷的机理上有着本质区别：轻压下通过补偿凝固过程体积收缩、抑制枝晶间浓化钢液向中心流动来消除心部缺陷；而重压下技术则是通过压合内外弧坯壳强行中断凝固过程，促使中心部位浓化钢液逆拉坯方向回流来消除心部缺陷。韩国浦项所开发的PosHARP重压下技术［7］，为使中心浓化钢液易于逆向回流，其压下区间较轻压下更为靠前，一般在枝晶搭桥薄弱、中心固相率更低的区域进行大压下变形。国内开发的厚板坯凝固末端重压下技术（图1）却恰好相反，其在两相区的中后段进行连续两阶段压下［8］：第1阶段的压下用来改善中心偏析；第2阶段的压下用来改善缩孔、疏松缺陷。由此可见，目前行业内对于凝固末端重压下技术的核心工艺尚未达成共识。

（4）单道次液芯大压下轧制技术。

厚板坯凝固末端重压下技术多在连铸机扇形段采用多道次压下的方式，这种方式对于改善中心偏析是有利的，然而从促进变形向中心渗透、改善缩孔、疏松缺陷的角度考虑，单道次大压下变形通常更具优势。 日本住友金属所开发的PCCS（Poros－ity　Control　of　Casting　Slab）技术［9］，利用一对轧辊在中心固相率0．80～0．95的位置，对30 mm厚板坯施加约 10mm的压下量，显著改善了板坯的缩孔、疏松缺陷，以2∶1的压缩比制备出高强度150mm特厚板；中冶东方在国内率先开展了液芯大压下轧制工艺的探索，在江苏重工250mm板坯连铸机水平段中前部 安 装 了 1 架 二 辊 轧 机，最 大 压 下 量 高 达60mm［10］，相关工作为开发厚板坯大压下轧制技术积累了宝贵经验。首钢京唐在其40 mm厚板坯连铸机上水平段末端进行单道次液芯压下，最大压下量为20mm［11］，历经1年多的工艺探索调试，压下后板坯内部缩孔、疏松缺陷明显减轻，热轧钢板的Z向性能、冲击功及伸长率也有较大幅度的提高。

# 1．2 板坯铸后高温直轧技术

板坯液芯大压下轧制是在近凝固终点带液芯压下，而此处板坯芯部恰恰处于钢铁材料的第Ⅰ（凝固）脆性区，其最大压下量受内裂纹制约［12－13］。此外，液芯大压下轧制技术在实际应用时需要严格控制凝固终点位置，极大降低了连铸工艺的灵活性。鉴于此，东北大学 RAL提出充分利用板坯余热，进一步加大压下量进行单道次热芯大压下轧制工艺（简称HHR2工艺）［14－16］，如图2所示，以此取替粗轧第1道次，避免因总轧制道次（全流程）增加而削弱大压下技术对成品钢板内部质量的改善效果。热芯轧制时若压下量过大，板坯边角部存在开裂风险，可 通 过 轧 前 对 边 角 部 补 热 的 方 式 来 解 决。HHR2工艺与轻压下相配合，可有效消除板坯中心偏析、缩孔、疏松缺陷，全方面提升厚板坯内部质量。

# 2 中厚板热轧过程“形状－组织性能－表面”一体化调控

热轧作为钢铁生产的核心工序，是一个多工序集成的成形成性综合控制过程，产品显微组织随温度和压下量的变化而发生改变，组织变化直接影响轧制负荷等力能参数，从而对产品形状和尺寸的精确控制具有重要影响［14］。 与此同时，在“气氛、温度及轧制变形”综合作用下的氧化界面不仅决定了轧材的表面质量，同时界面状态的改变也会影响轧制力能参数，对产品尺寸精度产生影响［17－19］。因此，热轧流程是一个“牵一发而动全身”的集成化复杂非线性生产系统，产品组织性能、形状尺寸和表面氧化呈现强耦合的特点，属于典型的“黑箱”过程［20］。

# 2．1 传统组织、氧化、力能解析模型

长期以来，人们一直采用解析模型作为破解黑箱的工具。一个世纪以来，研究人员基于塑性力学理论提出以均匀变形为基础的轧制力计算模型，但该方法并未考虑显微组织演变对钢材软化及硬化行为的影响，制约了轧制力的计算精度［21－24］。20世纪70年代，众多研究者基于模拟实验建立了轧制过程显微组织演变模型，但由于实验条件与生产过程的流程性和连续性严重不符，导致模型计算结果与实际生产过程存在较大差距［25］。近70年，国内外学者基于大量的实验研究和高温氧化理论，开发了氧化铁皮厚度的经验模型，但由于热轧流程长、钢中合金元素间交 互氧化复杂，导致控制效果不佳［26－27］。综上所述，传统建模方法多为以实验为主的传统方法，且均为轧制负荷、组织性能和表面质量彼此独立进行，没能针对这些密切相关问题进行全局分析，因而降低了各相关参数的计算精度。

# 2．2 “形状－组织性能－表面”一体化、数字化调控

针对热轧生产，轧制力是可实时、精准检测的关键参数。轧制力的两大关键影响因素为轧件流变应力和界面摩擦因数。建立起热轧生产过程轧件再结晶、应变诱导析出等组织演变与流变应力、轧件表面氧化厚度与界面摩擦状态的耦合关系模型，并融合工业大数据，开发出集成机器学习方法，建立起综合反映热轧全流程组织演变、表面氧化及力能参数变化的“形－性－面”高保真动态数字孪生模型，可实现热轧生产过程“黑箱变透明”。在此基础上，结合多目标智能优化理论和算法，通过工艺参数全局寻优并在实际生产中迭代优化，可实现热轧过程氧化铁皮厚度与结构演变、显微组织演变及道次轧制力的精准计算，为热轧板带材生产过程组织性能优化、表面质量提升及板形与尺寸控制的全局一体化调控提供新的技术方案。热轧过程“形－性－面”耦合机器学习技术路线如图3所示。

（1）热轧全流程组织演变可视化。

考虑到轧件的显微组织演变直接影响其流变应力，因此轧制负荷是显微组织演变的宏观表现，热轧过程轧制力作为工业生产中可实时、精准检测的关键参数，能够准确反映显微组织变化。因此，以流变应力为桥梁，融合工业大数据驱动和机器学习算法，通过轧制负荷变化揭示轧制过程奥氏体再结晶及晶粒形态演变，提出了混合奥氏体组织形态的计算方法，实现了对混合组织中各类型晶粒的尺寸、形状与体积分数进行定量描述，并用 Laguere－Voronoi图实现显微组织的快速重构，可对轧制过程奥氏体形貌及析出形貌进行直观展示，如图4所示［28－29］。

（2）热轧全流程氧化行为动态演变。

氧化铁皮厚度及均匀性是影响热轧产品表面质量最主要的因素，此外，氧化铁皮可以充当轧辊与轧件界面的润滑介质，影响轧件与轧辊的接触状态［30－32］，进而影响轧制负荷［33］。为此，利用数据驱动算法解析了氧化速率、氧化铁皮变形率与轧制工艺及化学成分的关系。基于非等温氧化动力学模型建立了热轧全流程氧化铁皮厚度演变模型，通过工业大数据与遗传算法实现了热轧全流程氧化铁皮厚度演变的精准预测，并建立起氧化状态与界面摩擦因数的对应关系，如图5所示 ［34］，实现了轧制过程界面状态的精准描述。

# 3．1．1 轧后超快冷组织调控原理

以超快速冷却为核心的新一代 TMCP技术在高性能热轧钢铁材料的组织调控及生产制造方面突破了传统 TMCP技术冷却强度的局限以及大量添加微合金元素的强化理念，针对不同的组织性能要求，通过高冷却速率及轧后冷却路径的灵活、精准控制，实现“以水代金”的绿色强化，在 组 织 性 能 调 控 方 面 显 现 出 强 大 的 技 术优 势［35－37］。

新一代TMCP技术在细晶、析出和相变等方面形成了一整套组织调控机理［38－41］，如图8所示。在晶粒尺寸控制上，超快速冷却技术可突破晶粒细化对合金元素的过度依赖，针对合金元素含量较低的C－Mn钢，依托极高的冷却速率可避开粗晶区及细晶作用区，进入极限细晶区，从而获得稳定且细小的晶粒，实现产品力学性能的提升及稳定化或实现合金元素的减量化。在析出物的控制上，以超快速冷却为核心的新一代 TMCP技术可通过适当提高终轧温度及轧后冷却速率，抑制热轧过程中的应变诱导析出，使更多微合金元素保留到铁素体或贝氏体相变区，随后利用精准的冷却路径控制，并配合等温处理过程，可获得最佳的碳化物析出工艺窗口。在相变的控制上，超快速的冷却速率可抑制高温奥氏体相变，热轧后的钢板采用超快速冷却技术结合超快冷出口温度的控制，可将硬化的奥氏体保留至特定的相变区，实现钢板组织构成的调控。目前已

开发出 UFC－F、UFC－B及 UFC－M 等超快速冷却在 应用于成分节约型合金钢、高品质管线钢、高级别线热处理工艺，实现了对F、B、M 组织的精准控制， 工程机械用钢的开发生产。

# 3．2 厚板控制轧制技术

# 3．2．1 厚板心部组织调控机制

高品质特厚板产品对性能的要求较高，但其生产难度大，心部质量差，部分高端产品严重依赖进口。特厚钢板生产面临的主要技术难题是压缩比不足，产品心部质量无法保证。国内钢企试图通过大型模铸、超厚断面板坯连铸等方法改善特厚板产品心部质量，但随着板坯断面尺寸的增加，其内部的偏析、缩孔及疏松等缺陷趋于严重。这需要更大的变形压缩比来消除这些内部缺陷。

常规厚规格钢板轧制过程中尺寸效应显著，心部存在难变形区。难变形区内金属变形量严重不足，造成钢板内部缺陷消除困难，变形后侧表面也通常呈现双鼓形，厚规格钢板的心部质量无法保证，如图10（a）所示。针对特厚板心部缺陷难以消除这一关键难题，东北大学开发了“温控－形变”耦合控制的特厚钢板低压缩比高渗透性轧制技术［42－45］，创新性地提出协同控制轧制冷却工序，通过钢板厚向温度梯度和轧制复合分配的耦合调控，促进变形向钢板的心部渗透，细化钢板心部组织，改善钢板心部质量，如图10（b）所示。

# 3．3 中厚板产线温度控制

在热轧中厚板轧制冷却过程中，温度的控制精度直接决定产品最终性能及其稳定性，因此，在复杂多变的工况条件下如何提高温度控制精度至关重要。随着计算机和人工智能技术的快速发展，通过数据挖掘技术探究中厚板生产工艺数据之间的内在关联，建立高精度的终冷温度模型已成为当前研究的热点［46－49］。东北大学以热轧中厚板实际生产数据为依托，从数据预处理着手，通过选择合适的模型和优化算法，开发了高精度的终冷温度预测模型和冷却规程计算模型，并用以指导优化工业生产。

（1）热轧中厚板生产流程数据预处理方法研究。依据热轧中厚板生产数据进行采集和匹配，分析了热轧中厚板数据中存在的数据冗余、缺失值、异常值以及数据分布不均等问题。针对问题，结合轧制工艺和数据分析技术，给出完整的数据处理方法和流程，包括重复和缺失值处理、工艺参数过滤、基于LOF算法的异常值检测、数据标准化以及均衡化等。以预处理后的热轧中厚板数据为基础，采用Pearson和 MIC系数相结合的相关性分析方法，对终冷温度预测模型的输入进行筛选，计算结果如图13所示。结果表明，该数据预处理方法能够有效提升数据质量，并且在确保模型精度的条件下，采用筛选后的参数建模，能够简化模型的数据结构。
