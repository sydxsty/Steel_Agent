当前，国民经济持续高速发展，轻重工业携手并进，对石油、天然气等化石能源需求大幅提升，管道运输在保证运输安全、节约经济成本等方面具有显著优势，已经成为油气能源输送的首选方式，采用大口径、高压力和高强度管线钢已成为管道输送的发展方向［1］。截至2024年年底，我国油气长距离输送管网总长度已达19.5万公里，其中天然气管道里程达到12.8万公里， 已形成连通海外、覆盖全国、横跨东西、纵贯南北、区域管网紧密跟进的油气骨干管网布局， 天然气管网“全国一张网”格局基本形成［2］。然而，随着我国油气管网规模不断扩大，运行环境日趋复杂，给管网安全运行带来诸多挑战， 管道事故时有发生，从而导致油气泄漏、爆炸、人员伤亡等严重后果。我国油气管道大多采用埋地敷设，通常采用防腐涂层和阴极保护的联合防腐措施。 在油气管线服役过程中，由于受到土壤应力、腐蚀性离子等物理或化学因素的影响，导致防腐层老化、破坏、脱落，在复杂土壤环境和应力的协同作用下，在远低于材料屈服强度情况下发生应力腐蚀开裂现象，从而导致管线钢材料失效。 应力腐蚀开裂的发生往往是难以预测的，且其腐蚀破坏程度十分严重。 多年来油气管道的应力腐蚀开裂事故屡见不鲜，1965年美国出现第一例管线钢高pH-SCC（沿晶应力腐蚀开裂，IGSCC） 以及1985年加拿大首次出现近中性pH-SCC （穿晶应力腐蚀开裂，TGSCC）， 目前大多数国家均发生过此类事故，造成重大经济损失和人员伤亡。 通常认为，管线服役年限超过10年具有应力腐蚀开裂（Stress Corro-sion Cracking，SCC）风险，服役年限在20年左右处于SCC发生高峰期， 我国多数油气管线服役年限较短，近期SCC风险较小，但长此以往，SCC风险会有上升趋势［3］。 因此对管线钢SCC进行深度探究，提前制订科学防腐措施，对于降低管线SCC风险、保证我国油气管线安全运行具有重要意义。 笔者综述了高强度管线钢SCC在开裂机理、 影响因素（材料、力学、环境）等方面的最新研究成果，同时对后续研究进行展望，为管线钢科学防腐措施的制订提供理论支撑。

# 应力腐蚀开裂机理

我国管道运输地域跨度大，土壤环境复杂多变，导致各类腐蚀破坏现象频发。 管线发生应力腐蚀开裂现象通常具有不可预测性，在远低于材料屈服强度下发生腐蚀破坏，对油气管线安全运行构成严重威胁。 应力腐蚀开裂是应力与复杂土壤环境协同作用的结果，二者不是简单的叠加而是相互促进。根据管线钢SCC的介质特征，可将应力腐蚀开裂分为高pH 值SCC 和 近中性pH 值SCC［4］。

# 1.1 高pH值SCC

高pH值SCC通常发生在pH值为8.0\~10.5、温度为22\~99 ℃的高浓度碳酸盐/碳酸氢盐溶液中，腐蚀电位区间为-625\~-425 mV，腐蚀破坏形式多表现为沿晶应力腐蚀开裂 （Intergranular StressCorrosion Cracking，IGSCC）［5］。 目前，大量研究表明高pH值SCC机理为钝化膜破裂+阳极溶解机理（Anodic Dissolution，AD）。 在管线钢服役过程中，当处于合适的pH值、 温度和电位范围条件时，管线钢表面将形成一层保护管线钢基体的钝化膜。在一定应力条件作用下，裂纹尖端发生局部塑性变形导致钝化膜破裂，管线钢基体暴露于土壤腐蚀环境中， 裂纹尖端区域作为阳极发生氧化反应， 钝化膜未被破坏处作为阴极进行还原反应，形成大阴极小阳极的腐蚀电池结构，加速裂纹尖端的萌生、扩展过程。 在裂纹尖端阳极溶解过程中， 管线钢基体再次处于高pH值腐蚀环境中，钝化膜再次在裂纹尖端形成，在一定应力条件和腐蚀环境中再次破裂，发生膜破裂-阳极溶解-再钝化的连续腐蚀过程， 导致管线钢裂纹持续萌生、扩展，直至发生管线破裂。 PARKINS R N通过研究发现，管线钢发生高pH值SCC的过程可划分为4个阶段：孕育阶段、裂纹萌生阶段、裂纹扩展阶段和快速断裂阶段［6］。 图1所示为高pH-SCC裂纹萌生和扩展示意图。

# 1.2 近中性pH值SCC

近中性pH值SCC发生的pH值通常为5.5\~7.5，腐蚀破坏形式通常为穿晶应力腐蚀开裂（Trans-granular Stress Corrosion Cracking， TGSCC）。 近中性pH值SCC多在油气管线防腐涂层剥离处发生，其裂纹的扩展方向多沿管道轴向，腐蚀裂纹较宽且腐蚀明显，裂纹分叉较少。 目前，学术界关于近中性pH值SCC的发生机理尚未达成共识， 主要存

在以下3个观点：

a. 阳极溶解机制（AD）。 在土壤环境条件下，防腐涂层破损会导致腐蚀缺陷的形成，进而导致金属发生阳极溶解，Fe以Fe2+、Fe3+的状态进入土壤溶液，同时管线所受的拉应力会促进金属内部的位错运动，特别是在裂纹尖端，这种应力会导致钝化膜的破裂， 使得阳极溶解速率进一步加快，加剧裂纹萌生、扩展。

b. 氢脆断裂机制（HE）。 阴极反应过程中产生的氢原子是导致管线钢发生氢脆断裂的主要原因。 由于氢原子体积微小，易在金属内部扩散，且倾向于在裂纹尖端等应力集中区域富集，对裂纹尖端产生侵蚀进而逐渐对金属基体渗透，在持续拉应力作用下金属基体脆化，进而导致氢脆断裂［7］。

c. 阳极溶解+氢脆（AD+HE）。目前，众多科研人员认为近中性pH值SCC是AD和HE综合作用的结果，即应力腐蚀裂纹以AD机制形核，随后以HE为主导机制。 文献［8］指出，SCC是由于阳极溶解而发生的，然后以氢致开裂的机制传播。

# 2 应力腐蚀开裂影响因素

管线钢应力腐蚀开裂发生需要满足敏感金属材料、 一定水平的应力和特定的腐蚀环境这3个条件。 管线钢合金成分、显微组织等对高强度管线钢SCC敏感性具有一定影响；同时，根据断裂力学，当金属材料承载的局部拉应力超过临界值时会发生应力腐蚀开裂，即应力因素是诱发应力腐蚀的先决条件。 其次，在腐蚀介质不同的土壤环境中，管线钢受土壤pH值、腐蚀性离子、外加阴极保护电位、气体及温度等的影响不同。

# 2.1 材料因素

随着全球油气管线规模日益扩大以及埋地管线钢服役环境日趋复杂，对管线钢的性能提出更高要求。 研究表明，管线钢合金成分、显微组织等都会对管线钢SCC产生一定影响。

适宜的微量元素能够显著提高管线钢的抗腐蚀、抗疲劳性能。 CHUNG H M等研究在BWR中奥氏体不锈钢应力腐蚀开裂发现， 适量的Ni和Si能 够 抑 制 SCC，V 会 导 致 SCC 敏 感 性 增 大 ［9］。PARKINS R N等通过研究相关金属元素对铁素体钢应力腐蚀开裂的影响发现，Mn、S促进管线钢应力腐蚀开裂发生，Cr、Ti 则对SCC 有抑制作用［10］。目前，微合金化通常选择的合金元素有Mn、Nb、V、Ti、Ni及Cu等，采用微合金化技术能够有效提升管线钢性能、节约生产成本。 但合金元素对管线钢的作用并没有完善的研究结果，后续可进一步综合研究合金元素对管线钢SCC的影响，以期提高管线钢抗SCC性能。

管线钢的显微组织也是影响SCC敏感性的重要因素，通常情况下，铁素体抗SCC性能较强，马氏体抗SCC性能相对较弱， 贝氏体抗SCC性能则需进一步研究。 刘白发现下贝氏体比回火索氏体和回火屈氏体的应力腐蚀敏感性低［11］。 DONGC F等通过研究X70管线钢在发生氢致开裂时显微组织的作用发现，在电化学充氢条件下，微裂纹的形核扩展基本上沿铁素体界面［12］。 BULGERJ T等研究在近中性溶液中X70管线钢SCC发现，相比于铁素体+珠光体组织，细粒状贝氏体+铁素体的抗SCC能力更强［13］。

# 2.2 力学因素

# 2.2.1 应力

应力是引起应力腐蚀开裂的核心因素，在土壤环境中的管线钢所受应力通常来源于管线钢本身残余应力、温度热应力、外界土壤环境应力、运行工作应力等， 只有在一定的应力条件参与下，管线钢才会发生裂纹萌生、裂纹扩展现象，进而导致管线钢应力腐蚀开裂。 据研究报道，外加载荷能够显著提高管线钢的电化学活性，提高金属表面极化反应速率［14］。 REN R K等通过电化学测试技术研究在3.5%NaCl中低碳钢SCC发现，外加载荷与电化学腐蚀之间并非线性关系，应力会导致低碳钢腐蚀速率加快［15］。 张秋利等通过研究应力对X80管线钢电化学腐蚀行为影响得出，一定程度的外加载荷会导致交流阻抗谱出现第二段容抗弧， 并且外加载荷会使X80管线钢腐蚀速率加快［16］。 通过以上文献可以发现，在一定的外加载荷作用下， 电化学平衡会发生相应改变，管线钢腐蚀速率也会随之增大， 但机械-电化学效应对高强度管线钢应力腐蚀开裂的影响还需深入研究。

# 2.2.2 应变速率

在应力腐蚀开裂裂纹扩展进程中，应变速率扮演着关键的控制角色，相比外加应力，应变速率对裂纹扩展的影响更为显著。 SEREBRINSKY

S A等研究发现，当应变速率增大时，管线钢裂纹扩展速率随之增大， 且IGSCC裂纹扩展速率相比于TGSCC裂纹扩展速率更大［17］。 钟犁等通过研究在超临界水环境中应变速率对C-HRA-1镍基合金SCC影响发现，随着应变速率的减小，管线钢面临着更高的应力腐蚀开裂风险［18］。 在外加应力和腐蚀溶液的耦合作用下，裂纹尖端发生晶界氧化现象，裂尖结合力降低，裂纹持续扩展。 魏磊等通过研究应变速率和环境介质对2205双相不锈钢SCC行为的影响发现， 应变速率和SCC敏感性存在一定关系，当应变速率处于1×10-5\~2×10-5 s-1范围时，SCC敏感性最大［19］。 程远等采用SSRT实验研究X80管线钢SCC敏感性，发现当应变速率为1×10-6 s-1时，应力腐蚀敏感性达到峰值［20］。 低于此应变速率，敏感性略有降低；高于此应变速率，敏感性明显降低。 只有在一定应变速率范围下，腐蚀环境和 应 力 才 能 协 同 促 进 SCC 裂 纹 持 续 扩 展 。PARKINS R N和BEAVERS J A通过研究在近中性溶液中应变速率对管线钢TGSCC影响发现，应变速率与裂纹扩展有着一定的经验关系，并给出相应经验公式［21］。 综上所述，只有在一定应变速率范围内，即保持裂纹尖端新鲜金属的裸露速率大于裂纹基体的钝化速率， 管线钢SCC进程才会持续进行。 当应变速率较小时，裂纹尖端新鲜金属的裸露速率小于裂纹基体的钝化速率，裂纹尖端钝化程度不断加深， 抑制应力腐蚀裂纹萌生、扩展；当应变速率较大时，腐蚀溶液无法及时对裂纹尖端进行腐蚀老化，与应力的协同腐蚀作用无法及时显现，因此在较大应力条件下，管线钢发生韧性断裂现象。

# 2.3 环境因素

我国地域辽阔，油气管线跨越区域广，沿线土壤环境复杂，在复杂土壤环境和应力作用下管线钢应力腐蚀开裂风险较大。 管道所处土壤环境对于管道应力腐蚀开裂具有重要影响，土壤环境中影响管线钢应力腐蚀开裂的因素众多，主要包括pH值、腐蚀性离子、外加阴极保护电位、气体及温度等，这几种因素单独或者协同作用，对管线钢SCC具有重要影响。目前，针对环境因素导致的管线钢SCC相关研究仅局限于单一因素， 但管线钢SCC并非是单一因素作用的结果， 而是多种因素相互交织、共同作用的复杂过程。 因此，通过对pH值、腐蚀性离子、外加阴极保护电位、气体及温度等环境因素的介绍，为后续研究多种因素对管线钢SCC的耦合腐蚀作用奠定理论基础。材料、力学、环境因素之间的关系如图2所示。

# 2.3.1 pH值

土壤pH值是影响管线钢腐蚀与SCC敏感性的重要环境因素之一。 ANDRES C等通过SSRT和电化学阻抗谱对X70管线钢在不同pH值下的应力腐蚀开裂进行研究， 结果表明，SCC敏感性随pH值的降低而增加［22］。当pH值为3时，氢参与应力腐蚀进程，阳极溶解和氢致开裂共同导致管线钢发生SCC；当pH值为8或10时，腐蚀产物膜成分发生改变， 对管线钢SCC起到一定抑制作用。 GONGK等研究了X100管线钢在海洋干湿交替环境中不同pH值的SCC行为， 发现随着溶液pH值降低，腐蚀产物层即钝化膜对X100管线钢基体的保护性能在逐步降低，同时加速了阳极溶解和析氢现象的协同作用， 增大了X100管线钢SCC敏感性［23］。综上所述，当pH值从酸性向碱性变化时，腐蚀产物膜成分会发生改变，对管线钢基体起到保护作用，腐蚀速率减小，抑制管线钢尖端的阳极溶解过程和氢致开裂过程。

# 2.3.2 腐蚀性离子

我国油气管线服役环境复杂，土壤环境中含有Cl-、CO32-、HCO3-及S2-等多种腐蚀性离子， 都会造成埋地管线钢腐蚀，增大管线钢SCC敏感性。

Cl-作为土壤中的侵蚀性离子， 会对金属基体钝化膜产生侵蚀， 从而导致金属发生阳极溶解，加速管线钢腐蚀进程。 一般情况下，在一定浓度范围内，Cl-浓度增加能够加速管线钢SCC进程。 姚小飞等通过研究Cl-对超级13Cr油管钢SCC的影响发现，随着腐蚀溶液中Cl-浓度增大，超级13Cr油管钢应力腐蚀敏感性不断增加［24］。LV G C等通过研究Cl-富集对304奥氏体不锈钢SCC影响发现，由于Cl-的富集作用，Cl-在低浓度下也会导致SCC的发生［25］。 张亮等认为，Cl-会侵蚀管线钢钝化膜同时抑制管线钢钝化膜的再钝化过程，导致裂纹尖端阳极溶解，并伴随大量双空位的产生，这些空位使表面应变硬化层松弛，加速局部塑性变形并产生三向应力， 加速微裂纹在滑移面上形核，从而加速管线钢SCC进程［26］。

大量文献研究表明，HCO -对高强度管线钢腐蚀有显著影响，其阳极反应为基体溶解、表面成膜与氧化，阴极为氧去极化反应。 刘畅等研究发现相比于盐酸，碳酸对管线钢等油井管材具有更强的腐蚀性［27］。 付璇等研究发现CO2在水相中溶解所形成的HCO -和H CO 等物质使得管内流体对管线具有明显的腐蚀作用［28］。ELIYAN F F和ALFANTAZI A通过研究发现HCO3-离子浓度较高时，管线钢表面会形成具有保护管线钢基体作用的钝化膜，减缓管线钢的腐蚀［29］。 TORRES-ISLASA等通过研究X70管线钢在NaHCO 溶液中的SCC行为发现， 当NaHCO 溶液浓度不断变大时，X70管线钢的抗SCC性能也在逐步增强［30］。 宫克等通过研究在沈阳土壤模拟溶液中HCO3-对X90管线钢SCC影响发现，HCO3-浓度改变会使管线钢腐蚀产物改变，进而影响钝化膜对管线钢基体的保护性能，X90管线钢SCC敏感性随HCO -浓度先增大后减小，且当HCO3-离子浓度为7%时，X90管线钢SCC敏感性最强，其SCC机制为AD机制［31］。

由于油气管线服役环境复杂，腐蚀性离子种类较多，因此国内外学者开展多种腐蚀性离子的协同作用对管线钢SCC影响的研究。 李亮等通过研究在Cl-和CH3COOH环境中316L不锈钢的SCC敏感性发现， 随着Cl-浓度的增加，316L不锈钢的SCC敏感性迅速增大；加入CH3COOH后，在较低Cl-浓度下CH3COOH会促进SCC的发生，当Cl-浓度为 1 g/L 时 ，CH3COOH 会 抑 制 316L 不 锈 钢 的SCC［32］。 XIE F等通过正交实验探究溶解氧、HCO3-和Cl-对X70管线钢协同腐蚀作用发现，在这3种因素中，Cl-对X70管线钢的影响最小，HCO3-最大［33］。但目前相关研究成果较少，仅仅局限于单一离子对管线钢SCC影响， 后续应持续开展多种腐蚀性离子的协同作用对管线钢SCC的影响研究， 对于防止管线钢SCC具有重要意义。

# 2.3.3 外加阴极保护电位

作为埋地管线钢常见的防腐措施， 阴极保护能够向服役管道施加恒定阴极电位， 确保管线电位始终低于腐蚀电位，进而对管线钢SCC现象进行控制， 但过负的外加电位会使阴极反应产生的氢气量增多， 增大高强度管线钢应力腐蚀开裂敏感性。 鲜宁等认为，在裂纹萌生阶段，适度的阴极保护能够有效抑制X80和X100管线钢的裂纹萌生，但当在裂纹快速扩展阶段时，过负的阴极保护电位会使得管线钢SCC敏感性增强［34］。外加阴极保护主要通过影响SCC机制来对管线钢SCC行为产生影响。高强度管线钢存在最佳阴极保护电位，能够有效抑制管线钢腐蚀，但随着外加电位不断负向移动， 管线钢的阳极溶解过程受到抑制， 阴极析氢过程得到促进，SCC机制逐渐由AD向HE转变，SCC敏感性也在不断增强。

# 3 总结与展望

目前，有关高强度管线钢应力腐蚀开裂的研究已经取得了一定成果，揭示了管线钢在高pH值和近中性pH值两种典型环境中的应力腐蚀开裂机理，但近中性pH值开裂机理尚未形成共识。 笔者从材料、应力、应变速率、pH值、腐蚀性离子、外加阴极保护电位、气体及温度等方面综述高强度管线钢在土壤环境中应力腐蚀开裂研究进展，总结亟待解决的科学问题及研究展望如下：

a. 在管材方面，可从稀土元素微合金化和改善显微组织结构出发，微合金化作为提高管线钢性能的有效方式之一， 具有广阔的发展前景，通过微合金化技术开发新型耐SCC管线钢， 从根源上提高管线钢耐SCC性能。

b. 在力学方面， 机械-电化学效应对高强度管线钢应力腐蚀开裂的影响还需深入研究，要考虑不同应力类型，如循环应力、波动应力对腐蚀的影响， 同时要进一步探究高强度管线钢SCC裂纹萌生、扩展的应变速率范围。

c. 在环境方面， 不同地域土壤环境中pH值、气体含量、 盐含量和温度等因素的差异较大，目前单一因素对高强度管线钢SCC影响已有众多研究成果，但还需综合考虑多个腐蚀因素的耦合腐蚀作用。

应力腐蚀开裂是一种严重威胁管道安全运行的失效模式，各学科科研人员还需加强跨学科合作，综合应用材料力学、腐蚀科学、力学及化学工程等领域的最新研究成果，深入探究应力腐蚀开裂的本质，提前制定科学防腐措施，有效降低应力腐蚀开裂风险，确保我国油气管道安全可靠运行。
