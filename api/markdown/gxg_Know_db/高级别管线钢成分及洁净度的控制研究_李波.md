# 高级别管线钢成分及洁净度的控制研究

李  波 孟庆义 孟庆勇 张洪杰（河钢股份有限公司唐山分公司）

摘要 高级别管线钢具有高强韧性、高抗 HIC 等技术特征。 根据化学元素及夹杂物对管线钢的影响，结合理论与试验，得到了改进脱硫和控磷技术、调整转炉钢渣流动性、优化LF 精炼埋弧效果、精调RH 精炼合金加入量、改进钙处理工艺技术等方案，实现了对管线钢成品化学元素的精准控制，相关技术指标达到国内外先进水准，钢中夹杂物尤其是MnS、Al2O3、CaO- Al2O3 和CaO-CaS 等大尺寸夹杂物得到有效地控制，降低了钢水T.O 含量，解决了铸坯偏析的问题， 铸坯低倍等级为C0.5 级。

# 0 引言

随着社会的发展，能源需求的不断增加，对管线钢的性能要求也在不断提升，要求其具备较高的低温冲击韧性，较高的抗 HIC、抗 SSC、抗CO2 腐蚀性能，较高的强韧性以及较高的延塑性。S 元素对钢材的焊接性能和抗腐蚀性能有很大的影响，特别是对酸性气体输送管道用钢的抗 HIC 性能产生严重影响，管线钢对钢中 S 含量的要求不断提高 [1]。钢中的微合金元素（如 Nb、V、Ti 等）与碳氮化物的溶解、析出等存在非常紧密的关系，Mo 元素能够降低相变温度、促进针状铁素体的形成，上述元素波动对管线钢的组织、性能的影响至关重要。此外，高端管线钢对夹杂物要求严格，尤其是大尺寸夹杂物会导致管线钢在焊接过程中产生裂纹， 从而恶化管线钢焊接性能。

针对唐钢 2050 产线的管线钢 X80M 的生产，笔者根据管线钢的元素强化机理以及性能、组织要求，以热轧需求为导向，通过改进钢包顶渣流动性、完善双精炼（LF+RH）工艺、优化钙处理等工艺技术措施，实现了产品的窄成分控制，提升了钢水元素稳定性、纯净度以及铸坯质量，彻底解决了管线钢 X80M 热轧性能波动大、夹杂物尺寸大等质量问题。

# 管线钢性能影响因素

# 1.1 化学元素对高端管线钢影响

碳元素作为管线钢的基础强化元素，主要起到析出强化和固溶强化的作用，析出的碳化物能达到理想的强化效果，C 含量过高会造成钢的韧性大幅度下降，C 含量过低（小于 0.01%）会造成间隙原子数量降低以及含 Nb 碳氮化物沉淀析出减少，出现脆化问题，理想的碳元素含量对管线钢至关重要；锰元素在钢中起到固溶强化的作用，锰元素能扩大奥氏体温度区间，降低其转变温度，并延迟碳氮化铌的析出，Mn 含量过高会增加板坯中心偏析的程度，降低材料的组织和性能均匀性。

微合金元素 Nb 、V 、Ti 与碳氮化物的溶解、析出等存在非常紧密的关系，这些微合金元素在管线钢中可以细化晶粒，提升材料强韧性。但其沉淀强化对焊接性能和韧性有负面的影响，Nb、 Ti等的析出强化对于高强度管线钢而言不是占主导地位的强化方式 [2-3]。合金元素 Cr、Mo、Ni、Cu在管线钢中可以发挥很大作用，其中Mo 可以降低相变温度、促进针状铁素体形成， 但过高的Mo 含量会影响焊接指标且价格昂贵，因此高端管线钢可使用 Cr、Ni、Cu 来取代或部分取代 Mo，既有助于提高钢的淬透性，也有助于提升钢的抗酸性介质腐蚀效果和耐磨性 [4]。

S、P 元素作为常见的有害元素，高端管线钢对其含量要求较为严格，因为 S 会提高管线钢裂纹敏感率，P 会劣化钢的韧性，特别是在低温时的韧性，不利于管线钢的焊接。

# 1.2 夹杂物对高端管线钢影响

高端管线钢对夹杂物要求较高，尤其是大尺寸夹杂物的控制更为严格，主要是因为大尺寸夹杂物容易导致管线钢的探伤不合格，同时影响焊接性能，造成焊接过程中的裂纹，恶化管线钢的焊接性能；此外，大尺寸夹杂物还会影响管线钢板的 Z 向性能。因此，为了提高管线钢产品性能，在炼钢过程中要严格控制大尺寸夹杂物的数量。

# 2 工艺技术方案和效果

# 2.1 有害元素的控制及效果

钢中 S 含量较高时，会出现 S 偏析，导致晶界脆化，对钢材的延伸性和低温冲击韧性危害较大。S 与Mn 形成MnS 后，不利于后续轧制，在管材、板材等轧制过程中 MnS 变长容易引起裂纹。铁水预处理和炉外 LF 精炼双工序脱 S 是高级别管线钢深脱 S 的主要手段，唐钢铁水预处理采用 KR 脱硫法，控制入转炉铁水 S 含量≤ 0.002%，同时严格控制转炉辅料中的 S 含量，减少回 S 量，转炉炉后钢包内钢水 S 含量≤ 0.005%。结合 LF 精炼工艺技术定量制定不同批次造渣剂加入量、升温和底吹工艺要求，并明确深脱硫前渣氧化性和 Als的要求，有效控制LF 出站S 含量≤0.001 2%，使钢水中的 S 含量显著降低且稳定性增强，采用深脱硫模型后的脱硫效果如图1 所示。

# 2.2 主元素碳、锰、硅的优化及效果

# 2.3 合金、微合金元素的优化及效果

高级别管线钢通常要添加合金和微合金元素，以此改变管线钢的相变活动，从而提高管线钢的强度和韧性。依托高级别管线钢的强化机理，在X80 钢的生产工艺中添加了 Nb、Ti、Cr、Ni、Mo等元素，兼具了经济性和性能组织可控性。

根据合金元素氧化强弱顺序，转炉、LF 精炼、RH 精炼各工序分别配加，实现对合金及微合金元素的精准控制。

（1）Ni、Mo 元素：转炉兑铁水前，根据铁水量和废钢量，按照预测的出钢量配加镍板和钼铁，吸收率分别是 97%、99%，调整钢水中 Ni、Mo 元素至目标下限，后根据大包成分在 LF 精炼进行微调整至目标值。

（2）Cr、Nb、V 元素：转炉炉后在出钢过程中，根据预测的出钢量配加镍板、低碳铬铁、铌铁和钒铁，吸收率分别是95%、92%、95%，调整钢水中 Cr、Nb、V 元素至目标下限，后根据大包成分在LF 精炼进行微调整至目标值。

（3）Ti 元素：RH 精炼根据出钢量加入钛铁，吸收率90%，调整至目标值。

通过各生产工序对上述元素的严格控制，实现对中包钢水成分的稳定控制，各元素含量波动控 制 ：[Ni]±0.01%， [Mo]±0.01%， [Cr]±0.015%，[Nb]±0.003%， [V]±0.002%， [Ti]±0.002%。

# 2.4 夹杂物优化及效果

为了更好地解决夹杂物问题，满足高端管线钢对洁净度的需求，降低夹杂物尤其是大尺寸夹杂物对高端管线钢质量的影响至关重要，因此需要针对夹杂物的种类、分布、尺寸、数量等进行

深入研究。

通常，钢水中的大尺寸夹杂物主要有 MnS、Al2O3、CaO- Al2O3 和 CaO-CaS 等，其所产生的时间和工序不同，降低上述夹杂物的方案也有所不同。针对硫化物夹杂，通过铁水预处理预脱硫及LF 精炼深脱硫，最大限度降低钢水 S 含量，减少MnS 等硫化物的生成量及比例。为了更好降低钢水中的活度氧，采用的脱氧剂为铝，在钢中会生成 Al2O3 或者是 Al2O3 组成的混合夹杂物，去除该类夹杂物可以通过钢水循环、钢渣捕获等技术手段。研究表明，Al2O3 夹杂物容易聚集，含有其他成分的Al2O3 夹杂物聚集程度略差[5]。

高端管线钢通过双精炼 + 钙处理 + 软吹工艺流程，充分快速去除夹杂物，实现钢水纯净度的改善。

（1）优化转炉炉后合金加入顺序，由弱脱氧→强脱氧工艺调整为强脱氧→弱脱氧工艺，降低RH 顶渣SiO2 含量，顶渣的熔点由1 600 ℃以上降低到1 400～1 500 ℃，减少RH钢包顶渣结壳问题，降低钙处理难度。

（2）LF 精炼造白渣， 钢渣高碱度控制， 出站钢渣的 FeO+MnO 含量不超过 1.0%， 提升钢渣对夹杂物的吸附、去除能力。

（3）RH 精炼让钢水在采用真空状态循环，利用“气泡泵” 原理，在氩气泡的裹挟作用下，去除纯Al2O3 及含有其他成分的Al2O3 夹杂物。

（4） RH 精炼结束后进行钙处理， 当软吹流量为 30 ～ 70 NL/min 时，增加底吹流量有助于钙吸收率的提升，70 NL/min 软吹流量条件下钙吸收率为 35% ～ 40%，实验表明，中包钙含量为0.001 9%时夹杂物变性效果良好，Al O 夹杂物占比为 15%时有助于管线钢 B 类夹杂物的控制，唐钢与国内外典型企业中包夹杂物对比见表 1。钙处理时 Ca含量的最佳范围为 0.001 5% ～ 0.002 5%， 此时有利于改变夹杂物形态，提升钢水洁净度，对比国内外夹杂物控制状况，唐钢夹杂物控制水平较高，大于 10 μm 的夹杂物数量密度为 0.100 个 /mm2，夹杂物控制水平处于行业领先水平。

# 2.5 连铸工艺优化与效果

铸坯中心偏析会影响高端管线钢的铸坯质量。动态轻压下对高端管线钢连铸板坯中心偏析的改善效果十分明显 [6]。唐钢 X80 管线钢浇注期间，通过控制过程浇注因素，改善了铸坯洁净度和质量。

（1）控制连铸平台钢水静置时间， 静置 3 min后，铸坯夹杂物数量密度为 10.22 个 /mm2，最大夹杂物尺寸为 30 ～ 50 μm ；静置 5 min 钢中夹杂物数量密度为 4.42 个 /mm2，最大夹杂物尺寸为20 ～ 30 μm ；静置 8 min 铸坯夹杂物数量密度为4.15 个 /mm2，最大夹杂物尺寸为 20 ～ 30 μm。数据显示，随着时间的延长，铸坯夹杂物数量密度呈缓慢降低的趋势，因此连铸平台静置时间应大于 5 min。

（2）大包浇余 10 t 时，夹杂物数量密度为1.27 个 /mm2， 最大夹杂物尺寸为15 ～20 μm ；大包浇余7 t 时，钢中夹杂物数量密度为3.65 个/mm2，最大夹杂物尺寸为 50 ～ 100 μm。 随着大包浇余的减少，钢中夹杂物数量和最大尺寸增多。因此，生产过程中大包浇余 10 t 有助于钢水洁净度的提升。

（3）控制上水口及板间吹氩流量，长水口氩气流量控制在 150 NL/min， 中间包上水口氩气流量控制在 1 ～ 2 NL/min， 实心塞棒，板间吹氩流量控制在 3 ～ 5 NL/min。

（4） 中包过热度为15 ～35 ℃，拉速为 1.0 ～1.2 m/min， 同时采用动态轻压下，可提升铸坯质量，产出的铸坯低倍均为 C0.5 级，内部质量良好。

为评估铸坯不同厚度方向夹杂物的分布，采用 ASPEX 对比分析了不同厚度铸坯夹杂物的分布情况， X80M 管线钢铸坯不同厚度方向夹杂物数量密度为 3.67 ～ 4.70 个 /mm2。

良好的金相组织有利于后续热轧轧制，采用上述方案生产的 X80 管线钢，铸坯上下表面主要为马氏体组织，1/4 厚度和 3/4 厚度处主要为贝氏体组织 + 少量的铁素体，心部位置的金相组织主要为针状铁素体，有利于后续热轧性能组织控制。

# 3 结论

（1）高端管线钢 S 含量控制需要使用铁水预处理和炉外 LF 精炼双工序脱硫，控制转炉辅料中的 S 含量，减少回硫量，大包终点 [S] 不超过0.005%，LF 出站 [S] 不超过 0.001 2%

（2）采用单转炉双渣工艺，有利于控制高端管线钢的生产成本，单转炉双渣的成本优于双转炉工艺，成本降低约 100 元 /t，转炉终点 [P] 可控制在 0.010% 以内，综合脱磷率与双转炉工艺相当，达到了 92% ～ 93%。

（3）通过转炉辅料调整钢渣流动性，通过 LF精炼优化埋弧效果，通过 RH 精炼进行合金精调，以此实现对各元素目标值的精准控制。

（4）采用双精炼 + 钙处理 + 软吹工艺流程，通过转炉出钢脱氧工艺优化、LF 造渣工艺优化、RH 钙处理工艺与软吹工艺的优化、钢水静置时间优化、钢包剩余钢水量控制等措施，有效地去除了钢水中大尺寸夹杂物 MnS、Al2O3、CaO- Al2O3和 CaO-CaS 等，降低钢水 T.O 含量到 0.001 5% 以内，减少夹杂物尺寸及数量；合理轻压下能改善铸坯质量， 低倍等级为C0.5 级。
