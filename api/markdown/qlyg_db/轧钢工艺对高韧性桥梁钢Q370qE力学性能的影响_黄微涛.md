# 轧钢工艺对高韧性桥梁钢 Q370qE 力学性能的影响

黄微涛，唐志刚，戴  林，李宏伟， 赵永峰， 杜大松（重庆钢铁股份有限公司技术中心， 重庆 400084）

摘 要：新国标执行后， 高强桥梁钢Q370qE 低温冲击功由47J 提高至120J。沿用原有轧钢工艺生产厚规格Q370qE钢板时， 出现冲击性能不合的情况， 对此进行研究和工业试验。通过对不同轧钢工艺方案的比较， 得出采用 300mm断面铸坯， 并利用两阶段控轧+轧后控冷工艺， 可生产出合格的高韧性厚规格Q370qE 钢板。

关键词： 高韧性， 桥梁钢， Q370qE， 轧钢工艺， 优化， 力学性能

随着我国桥梁建设的高速发展， 桥梁跨径不断增大， 大跨度桥梁向更长、更大、更柔的方向发展， 同时桥梁结构不断向轻型化发展，这对桥梁用钢提出了更高的要求： 强度高、 塑韧性及焊接性好等。《中长期铁路网规划》提出，到2020 年，规划建设铁路新线1.6 万公里、铁路既有线增建二线1.3 万公里，同时国家“一带一路”和长江经济带战略以及西部地区基础设施建设，给重庆及周边地区的桥梁用钢市场带来巨大的需求空间， 这意味着桥梁用钢的需求将大大增加。

新版桥梁用结构钢国标执行后， 高强桥梁钢 Q370qE 低温冲击功由47J 提高至 120J。 沿用原有轧钢工艺生产厚规格Q370qE 钢板时， 会出现冲击韧性不满足标准要求的情况 ，因此有必要对轧钢生产工艺进行优化。

# 1 成分及工艺路线

# 1.1 化学成分的确定

结合生产实际情况， 成分确定的控制范围： C 含量在 0 11％～0 16％， Mn 含量为 1.40％～1.60％。采用Nb／Ti 和A1 复合微合金化，Al、Nb 和C、N 形成的化合物有细化晶粒作用， 可使钢的强韧性提高；同时采用微钛处理以改善钢材焊接热影响区的韧性。 由于采用转炉生产工艺，钢中氮含量较低，控制在20～40ppm。

# 1.2 生产工艺路线

生产工艺路线： 铁水预处理→210t 转炉冶炼→LF 精炼→RH 脱气处理→板坯连铸→步进式加热炉加热→高压水除鳞→初轧机轧制→四辊可逆式精轧机轧制→ACC 冷却→热矫直→精整→板材标识、取样/检验、堆垛、入库。

# 2 试验过程及结果

# 2.1 轧钢工艺方案及实际控制

在 210t 转炉冶炼经铸机浇注成 230mm×1530mm 和 300mm×2010mm 断面钢坯， 选择两断面各1 个炉号的板坯， 其实际成分控制水平接近， 按不同生产工艺方案进行试验， 钢板厚度均为40mm， 工艺方案及实际工艺见表1。

试验中尽量缩减轧制道次，增大单道次压下量，确保钢板在较低温度下完成较大的单道次及累计变形量，使晶粒尽可能破碎 （尤其是心部）， 从而得到尽可能细小的晶粒。

# 3.2 分析

试验钢板的轧制主要采用两阶段控轧工艺，第一阶段是在高温奥氏体再结晶区轧制， 是变形与再结晶同时进行的阶段，单道次变形量必须大于再结晶临界变形量的上限，以确保发生完全再结晶，通过多次变形再结晶，使粗大的原始奥氏体晶粒显著细化。随着累积变形量的增加，变形奥氏体晶粒尺寸逐渐减小，最终形成的铁素体晶粒越细小。第二阶段是在低温奥氏体未再结晶区轧制，是形变能累积阶段，在这个阶段，奥氏体晶粒被拉长，同时产生滑移带，可增加奥氏体晶粒中变形带和位错密度，增大有效晶界面积， 为铁素体形核提供有利条件，进而得到细晶粒铁素体。一般经验表明， 在奥氏体再结晶区每道次变形量为 10%， 总变形量为60%； 在非再结晶区大于45%～50%的总变形量有利于晶粒细化。

加入A1、Nb／Ti 等微合金元素的钢板， 经合理的控轧控冷工艺， 微合金元素Nb 在钢中以C 和N 化合物形式析出， 溶于固溶体或分布在基体中， 可阻止晶粒长大， 起细化晶粒作用。

晶粒的细化对提高钢材强度和低温韧性有较大作用，晶粒越细， 强度越高， 塑韧性越好， 韧脆性转变温度越低。混晶组织的生成对低温冲击性能存在巨大的危害。混晶形成的机理可能是铸坯的原始组织不均匀、加热温度不均、再结晶区轧制工艺异常或轧后层流冷却不均、终轧温度过低、压下量形变不够等。从本次试验来看，A 方案等混晶的形成与再结晶区域的轧制工艺和形变有关。

试验各方案执行过程中， 尽量缩减轧制道次， 增大单道次压下量， 方案 D 奥氏体再结晶区或非再结晶区的累计变形量大于其它工艺方案， 因此方案D 获得钢板的组织晶粒更均匀、 细小， 机械性能更佳。

# 4 结论

生产厚规格高强桥梁钢 Q370qE， 通过加入 Al、 Nb／Ti 等固定 C、N 的强碳化物形成元素和细化晶粒元素， 经控轧控冷工艺， -40℃低温V 型冲击达到标准要求， 且有较大富余量。

厚规格高强桥梁钢Q370qE 的主要生产工艺为：两阶段控轧工艺+轧后控冷工艺，同时尽可能采用300mm断面铸坯、 确保控轧厚度。
