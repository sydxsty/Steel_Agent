# 热轧高强汽车用钢生产实践

邯钢邯宝热轧厂 潘腾 康茂林 刘建文

摘 要：在对邯宝热轧厂高强汽车用钢生产过程中的瓶颈问题进行统计和分析的基础上，根据生产中存在的问题，采取新的板坯温度控制思路、改进轧机板形控制策略、优化层流冷却工艺等措施，提高了薄规格高强汽车钢合格率，改善了大梁钢板形问题。

关键词： 热轧;汽车用钢;生产

随着汽车工业的不断发展，轻量化、节能、环保已经成为汽车制造业的发展方向,世界各国钢铁公司都花费大量的人力、物力进行综合性能更优异的钢铁材料的研究。邯钢2250mm 热轧厂近年来在汽车用钢领域取得了优异的成绩，已经基本能够做到汽车用钢全覆盖，尤其是汽车结构钢方面已经开发并有批量供货能力的多个系列和牌号，如SAPH 系列汽车结构钢、QStE系列汽车结构钢；具有良好热加工性能的汽车结构钢SPFH系列：汽车大梁钢700L等。为了进一步提高高强汽车用钢生产过程稳定性，改善产品质量，邯钢2250mm热轧厂在对高强汽车用钢生产过程中的瓶颈问题进行统计和分析的基础上，根据不同问题采取针对措施，提高了生产稳定性和产品质量。

# 一、生产中存在的问题

# （一）板坯温度均匀性

邯钢2250mm 热轧厂有4 座加热炉，因炉况差异和板坯出炉后传输距离不同，板坯在粗轧轧制后的温差存在较大差异，造成板坯在精轧区域轧制时穿带不稳定、甩尾几率增加等问题。

# （二）粗轧板形及温降

高强钢在粗轧区域翘头问题相对较多，由此带来的问题是板坯头尾温降增大，严重时产生横裂。据统计，粗轧区域平均温降达到190℃，相对国内先进钢企的160℃差距较大，这势必会造成精轧入口温度偏低，以及加热炉能耗增加。

# （三）轧制稳定性

高强钢薄规格在轧制过程中稳定性较差，表现为穿带过程活套抖动、带钢跑偏、带钢头部厚度波动大等现象，严重时会造成精轧机堆钢。此外，抛钢过程也存在上述问题，轻则甩尾，重则尾部轧断。

# （四）产品板形问题

为满足汽车零件尺寸精度的要求,汽车大梁钢板尺寸公差一般要求较严,对板形和钢板残余应力也有特殊要求。板形问题主要集中在中厚规格700L，如7.8mm \*1500mm；根据用户的反映，700L 的板形问题主要为纵切后侧弯，焊缝不能对接。

# 二、生产工艺改进

# （一）加热温度均匀性提升

在二级自动加热控制的基础上，加热工根据轧线反馈的粗轧出口中间坯温度曲线来实时调整炉内板坯温度均匀性。

从以出钢温度为标准，转变为以粗轧出口中间坯温度为标准来判断板坯加热质量。

板坯加热温度控制指标：同板温差：≤30℃；炉间差：≤20℃；水梁黑印：≤15℃。以板坯加热为源头，为后续轧制提供保障。

# （二）粗轧区域工艺改进

根据数据统计，粗轧区域的板坯温降约为1℃/秒，为减少粗轧区域板坯温降，最主要的是缩短粗轧区域的运行时间，包括纯轧时间和间隔时间。

监控粗轧各道道次轧制力和扭矩，重新分配各道次压下量和轧制速度，优化原则为“前道次大压下，后道次高速”，优化后粗轧区域纯轧时间可缩短8秒以上。

提高粗轧各区域连接辊道速度，调整最短的抛钢距离，缩短每道次侧导板对中时的响应和动作速度，减少轧制等待间隔时间。

# （三）精轧区域工艺改进

# 1、精轧速度制度优化

轧制高强钢薄规格出现最大的问题就是带钢尾部轧破或甩尾，以及带钢表面的麻点问题；通过增加轧机加速度、提高穿带速度限幅、开启机架间冷却水、提高终轧温度目标值，最终达到缩短带钢在精轧机纯轧时间的目的，精轧纯轧时间可缩短20 秒，精轧入口温降可减少20℃。实现恒速、低速抛钢过程，即可以保持机架间秒流量均衡，又能便于及时对尾部跑偏进行调整。

# 2、精轧活套功能优化

在热连轧生产线中，活套功能的改进可以有效提高轧制稳定性，穿带过程和抛钢过程尤为重要；适当的活套张力可以改善带钢轧制过程中的对中性，减少跑偏轧破和甩尾。通过调整穿带过程活套驱动力，优化抛钢过程小套量控制时序，实现活套快速建立张力和快速恒张力落套。抛钢前先达到小角度位置（16 度），在活套下降到待钢角度之后的0.3s 之内，当前机架完成抛钢，整个过程活套张力不下降，以免引起抛钢前带钢失张跑偏。

4、精轧出口对中线识别和调整

带钢轧制过程中，后机架（F5-F7）带钢较薄，通过浪形能明显地反映出跑偏方向和程度，但前机架（F1-F4）由于厚度较厚（通常在7mm以上），就很难从浪形上判断机架跑偏的微小变化。往往前机架的微小跑偏，通过带钢的多道次延伸，成倍放大，最终造成精轧出口对中曲线跑偏。精轧出口对中曲线发生跑偏，造成的影响有：带头跑偏轧破；带尾跑偏造成甩尾；带钢磨损单侧侧导板，造成耐磨板粘钢；成品板形差，钢卷头尾错层等卷型缺陷增多。

通过分析精轧出口对中线各段的长度和程度，对小立辊横移、精轧入口侧导板短行程、精轧水平辊调平、卷取入口侧导板横移等条件针对性调整，将精轧出口对中线调整为一条水平的直线。

# 5、轧制润滑系统升级

研究结果表明:轧制过程中采用适合的轧制润滑技术,有利于轧制生产的进行和表面质量的提高。2250mm热轧厂升级改造了精轧F2-F5机架的辊缝润滑系统，涉及到液压阀台、管路及喷嘴、电气控制时序以及油水比例。改进后有以下优点：轧制时，辊缝润滑水阀处于常开状态，避免频繁启停造成管路压力变化和喷嘴堵塞；待轧时，管路内的润滑油在计量泵与机架旁的油水混合阀之间内循环，辊缝润滑投用后，润滑油可快速达到轧辊表面；使用大喷射扇面喷嘴，减少单个集管上喷嘴数量，减轻喷嘴堵塞情况；增加薄规格油水比例，提高润滑效果。

6、带钢凸度轮廓及CVC优化调整

轧制高强汽车结构钢薄规格，F1-F2的CVC位置长期处于正极限位置，此位置几乎消除了中间坯来料的凸度，只靠后面机架窜辊调整来达到目标值。当C40达到目标值后，二级模型不能很好的纠正这种“扁平状”断面轮廓。如下图2所示，C40已经达到了目标值45μm，C100 接近于0，其带钢存在潜在的不均匀变形。而良好的凸度轮廓如右图所示，呈现良好的圆弧型状，精轧机等比例凸度控制处于较高水平。

轧制高强汽车结构钢CVC控制方案：

以成品凸度轮廓为目标，调整精轧机CVC 位置，将凸度轮廓调整至圆弧状；

精轧机所有机架不得处于正负极限位置，并且不得长时间处于正负100mm以上；

使用PCFC中CVC限幅功能、F1-F7附加值修正功能和凸度手动控制功能来调整CVC分布。

# （四）层冷工艺优化

改造层流冷却集管为密集型冷却，优化层流冷却速率，减少带钢在层冷区域产生瓢曲等板形问题；生产高强汽车用钢前对层冷集管状态进行检查，处理好不能正常出水的集管，并清理堵塞的喷头；此外，通过调整流量阀调整层冷上下集管的水量和喷淋高度保持一致。

# （五）板形控制策略

由于热连轧带钢生产的特征使得钢板内部及上下表面残留着局部的残余应力，如果这种残余应力沿带钢宽度方向是呈不均匀分布的，这种不平衡的残余应力将会对钢板截面产生一个力矩,这样使钢板在分切后发生侧弯。残余应力的存在将影响板料的成形性能和产品质量,残余应力的松弛还影响带钢板料尺寸的稳定性。

轧制大梁钢中厚规格采用“微中浪”控制策略，即带钢头尾保持微中浪，中间部分保持平直。此策略可修改TARGITFLATNESS数值以及手动调整弯辊、窜辊来实现。

# 三、改进效果

通过提高精轧穿带速度和升速加速度、提高终轧温度目标值，开启精轧机架间冷却水，缩短纯轧时间20秒，尾部温降减小20℃，提高轧制稳定性并且改善表面质量；恒速轧制，实现精轧稳定抛钢。

通过优化精轧活套小套量控制，增加活套单位张力，分段识别和调整精轧出口对中线，提高穿带和抛钢稳定性。

对精轧F2-F5辊缝润滑系统进行优化改造，并提高薄规格油量配比，改善轧辊表面质量、降低电耗和轧辊消耗。

通过对带钢凸度轮廓识别和调整，建立良好的等比例凸度轧制，改善了高强汽车用钢板形。

通过分析高强度汽车用钢在热轧生产线存在的各种问题，制定出各个生产环节的工艺改进方案，实现了高强度汽车用钢产量和质量双提升。高强度汽车用钢的稳定生产为企业品结构升级做出了突出的贡献。
