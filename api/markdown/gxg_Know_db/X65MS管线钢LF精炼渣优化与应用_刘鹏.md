# X65MS 管线钢 LF精炼渣优化与应用

刘 鹏1,朱宏伟1,潘锡泉2,袁 渊2,包燕平1,顾 超1(1.北京科技大学 绿色低碳钢铁冶金全国重点实验室,北京 10083;2.湖南华菱湘潭钢铁有限公司,湖南 湘潭41101)

摘 要:为研究X65MS管线钢LF精炼过程的渣脱硫能力,对其精炼过程进行取样分析。结果表明,精炼渣中存在的高熔点固相CaO将使得渣系熔点升高,流动性及夹杂物吸收能力变差,需对渣系成分进行优化。利用Factsage软件进行活度、黏度计算,得出精炼渣中钙铝比控制范围1.5\~2,碱度控制范围5\~7.5,MgO质量分数4%左右可以保证高碱度渣的低熔点区域面积最大。基于上述分析,结合KTH 硫容量计算结果以及等温线三元相图得出合理的CaO-MgO-Al2O3-SiO2渣系成分范围:w(CaO)=49% \~59%、w(Al2O3)=29%\~37%、w(SiO2)=8%\~14%、w(MgO)=3%\~5%。优化渣系的工业应用结果表明,精炼渣熔点处于试验所要求低熔点区,钢中氧化物夹杂数量显著下降,钢中氧化物夹杂尺寸低于5 m 的数量占比增多,钢液中的S质量分数降低至10×10-6

随着全球经济的持续增长,世界各国对油气资源的需求量急剧上升[1]。同时,作为重要的能源矿产和战略资源,油气资源的勘探开发被列入我国“十四五”规划重大工程,海上油气田、极地 油 气 田 等 偏 远 地 区 油 气 田 得 到 大 力 开发[2]。由于所处极端环境以及所运输物质的特殊性,油气运输对管线钢的内部质量和性能提出了更高的要求,如组织、夹杂物、强度、抗腐蚀性能、抗氢致开裂(HIC)和抗硫化物应力腐蚀开裂(SC )等性能[3]。对于抗酸管线钢,钢液中的S对其影响不容忽视[4]。钢液中S偏析倾向大,使得晶界脆化,降低钢材延展性以及低温冲击韧性[5]。同时,钢液中的S与钢液中的 Mn形成 MnS塑性夹杂物,其具有较高的延展性,在连铸轧制过程中,较易沿轧制方向变成长条状夹杂[6]。这将导致钢材抗 HIC 以及抗SC 性能下降,在油气管道运输过程中较易产生氢致裂纹以及应力腐蚀裂纹[7]。

当前,国内外学者对于管线钢的研究主要针对硫和夹杂物的控制。兴澄特钢[8]通过严格控制转炉炉料结构、精炼 LF 下渣料(R 4.89),并做好防回硫工作,实现了X80M 管线钢的批量生产,其S质量分数低于0.01%。石鑫越等[9]在VD工序中,通过减少钙线喂入量并保证1.5≤w(Ca)/w(S)≤2,提高了夹杂物控制水平,夹杂物数量、尺寸明显降低。谢芳等[10]对 X65 管线钢冶炼工序中钢液中T.O、N和S的变化规律进行研究,通过工业化验证得到优化措施,有效降低钢液中T.O、N和S。杨勇等[11]采用转炉优质废钢、大渣量等方式使得脱硫率达到40%,LF精炼快速造渣并配合钙处理使得脱硫率达到90%以上,VD 炉进一步脱硫可将 X65MO 抗酸管线 钢 硫 质 量 分 数 控 制 在 15×10-6 以 下。Verhaeghe等[12]通过研究得出渣中夹杂物溶解时间公式,夹杂物溶解时间随着渣黏度的降低而缩短,渣的吸收效率升高。Zhang等[13]建立动力学模型研究钢水脱硫过程,综合计算钢中夹杂物的热力学演变过程,发现适当的钙处理可以将夹杂物转变为液态,Ca质量分数为(35\~45)×10-6。Liu等[14]构建了连铸板坯偏析模型,并 对 MnS 夹 杂 物 的 析 出 行 为 进 行 研 究。Shen等[15]在X80管线钢LF精炼出站时分别采用 Mg处理和Ca处理进行对比试验,研究 Mg处理对夹杂物的变性效果。

本研究对某钢厂X65MS管线钢的精炼生产工序进行取样分析,针对精炼渣系成分配比不当、渣碱度过高引起的高熔点低流动性等问题进行研究。通过Factsage软件计算碱度、钙铝比(w(CaO)/w(AlO )对精炼渣黏度的影响为进一步深脱硫提供动力学条件;分析渣碱度、钙铝比以及 MgO含量对渣系熔点的影响情况。基于以上研究,本文结合渣硫容量以及三元等温线对渣系成分进行优化,使其具备较好的脱硫能力以实现深脱硫,并对渣系成分优化结果进行工业试验。

# 研究方法

研究钢种为X65MS抗酸管线钢,采用“150t转炉→LF精炼→VD精炼→连铸”的工艺生产,由于未经过KR 工序对铁水预脱硫,导致入炉铁水中S含量较高。同时,转炉对硫脱除效果不佳,到达LF工序后,钢水中S质量分数较高,约为150×10-6。为研究 X65MS管线钢LF 精炼阶段的脱硫情况,在同一浇次下对三炉LF 精炼钢水的进站(L1)、白渣形成(L2)和喂钙线后(L3)工序分别取渣样以及钢样进行分析处理。对于渣样,将其研磨至20 目(约75 m)后,通过X 射线荧光光谱分析(XRF)检测渣系成分;并通过X 射线衍射仪(XRD)分析渣系物相组成。对于钢样,将其切割后进行打磨抛光,通过钨丝电镜和能谱分析其非金属夹杂物形貌、组成以及大小,并通过夹杂物扫描电镜对其夹杂物数量、组成进行定量分析,以衡量钢水洁净度水平。

# 2.2 CaO-MgO-Al2O3-SiO2渣系优化

# 2.2.1 渣系低熔点区控制

渣系优化首先应控制成分处于低熔点区。低熔点的渣系化渣速度快,可以保持较好的渣面流动性,对上浮夹杂物的吸收能力也更强[17]。高熔点的渣系局部难熔,所形成的固相氧化物使得渣的黏度上升,流动性变差,从而限制了夹杂物的传质扩散。通过优化精炼渣的成分,确保其液相线温度位于低熔点区域,加快化渣速度的同时,改善渣的流动性,为钢液中夹杂物的脱除提供良好的动力学条件。 X65MS管线钢精炼生产使用CaO-MgO-Al2O3-SiO2四元渣系,其低熔点区域的控制与w(CaO)/w(Al2O3)、w(CaO)/ w(SiO )以及渣系w(MgO)有关。

LF造 渣 配 料 过 程 中 通 常 加 入 一 定 量 的MgO,用于减弱渣钢界面处钢液对炉衬造成的侵蚀[18]。为探究不同 MgO含量对渣系低熔点区域面 积 大 小 的 影 响,利 用 Factsage 软 件 PhaseDiagram 模块计算CaO-MgO-Al2O3-SiO2高碱度渣系的等温相图。根据LF精炼温度,假定150 ℃以下为低熔点区;优化渣系需为高碱度渣,设定计算低熔点区 w(SiO2)<20%。渣中 MgO 质量分数为0%\~10%,Factsage 计算结果如图2所示。

随着 MgO含量的增加,低熔点区域面积比例呈现出先增大后减小的变化趋势,在 w(MgO)=4%时面积比例达到最大。因此,在最终渣系配料中应当控制 w(MgO)为3% 5%,下述渣系成分计算设定 w(MgO)=4%。

# 2.2.2 渣系活度及黏度控制

渣系优化选用的钢种为超低硫管线钢,其对钢液中O、S、非金属夹杂物有着严格的控制要求。采用铝块脱除钢液中的氧,产生大量氧化铝夹杂物,其脆性高且韧性差,在生产过程中易产生脆性断裂。精炼渣需要保持较好的流动性以取得更好的夹杂物脱除效果。黏度为传质扩散的主要影响因素[19],降低渣黏度有利于夹杂物在渣中的扩散。渣中Al2O3含量越高,渣黏度也越高,通过调整合适的钙铝比(w(CaO)/w(Al2O3)和碱度以控制 渣 中 Al2O3 含 量。 通 过 Factsage 软 件Viscosity模块对渣系黏度进行计算,定量分析钙铝比和碱度对其影响情况,计算结果如图3所示。图3a为碱度为7时钙铝比对精炼渣黏度的影响情况,图3b为钙铝比为2时碱度对精炼渣黏度的影响情况。结果表明,提高渣成分的钙铝比和碱度均有利于降低渣黏度,且钙铝比降低效果更佳。但过高的钙铝比和碱度均会使得精炼渣系液相线温度升高。

在150 ℃低熔点区域内,合理的渣系成分还应当从Al2O3活度、CaO活度两方面考虑。根据钢渣反应平衡,可以通过控制精炼渣成分达到控制钢液中夹杂物成分的目的[20]。在CaO-Al2O3-SiO2-4%MgO 四元渣系中,调控渣系成分偏向CaO一侧,使精炼渣保持较高的碱度。在高碱度渣系中,精炼渣碱度越高,相应的渣中Al2O3活度与渣黏度值越低,渣中CaO 活度越高。一方面,根据铝氧平衡反应,a(Al2O3)降低有利于反应的正向进行,抑制渣向钢液中传[O],提高渣的脱氧能力;同时,a(Al2O3)降低动力学上促进渣钢界面处钢液中 AlO 向精炼渣中传质。另一方面,精炼渣黏度下降,渣扩散能力增强,有利于提高精炼渣对Al2O3夹杂的脱除能力。此外,在渣系成分控制过程中精炼渣碱度不宜过高,碱度越高导致渣中a(SiO2)下降,由反应方程式(1)可知,降低渣中a(SiO2)或增加渣中a(Al2O3)均会使反应方程式正向进行,向钢液中传递更多的[Al],与[O]结合后造成钢液中 AlO 夹杂物数量上升。因此,X65MS管线钢渣系在保持低a(Al2O3)以及高a(CaO)的同时,还应将精炼渣碱度控制在合适的范围,利于钢液中Al2O3夹杂物的吸收。

通过 Factsage 的 Phase Diagram 模块,绘制出熔点1 50 ℃ 下 CaO-Al2O3-SiO2-4%MgO 四元渣系的 Al2O3和 CaO 的活度曲线,如图5 所示。

随着钙铝比和碱度的增加,Al2O3活度下降,CaO活度增大。为保持较低Al2O3活度以及较低渣黏度,钙铝比应当大于1.5;当钙铝比大于2时,液相线温度大部分超过150 ℃,渣的熔化温度升高,化渣速度降低,精炼周期拉长。因此,渣系钙铝比设计为1.5 2的窄区间为宜。与之相对应的碱度为5.0 10.7,为保证精炼渣成分具有一定的变化区域,将精炼渣碱度控制在5\~7.5为宜。此时渣中Al2O3的活度小于0.05,CaO 的活度大于0.2,精炼渣黏度下降,渣中Al2O3夹杂扩散能力增强,对钢液中Al2O3夹杂具有良好的吸收能力。

# 2.2.3 渣系硫容量控制

此外,精炼渣的硫容量是评判渣脱硫能力和效果的重要指标[21]。在渣系成分优化过程中,需保持较好的硫容纳水平以实现深脱硫。Factsage软件计算出CaO-Al2O3-SiO2-4%MgO四元渣系的等温度线三元相图,在此基础上通过 KTH 模型计算出等硫容量三元相图,如图6所示。计算结果表明,炉渣硫容量随着碱度和钙铝比的增加而增大,即渣系中 CaO 占比越高则渣脱硫能力越强,原因在于钢液中的S主要由渣中CaO 脱除。因此,渣系优化过程中,应保持较高的碱度和钙铝比以提高渣系脱硫能力。

# 2.2.4 渣系成分优化

基于上述讨论结果,在三元相图上根据渣成分w(MgO)=4%、钙铝比1.5\~2、碱度5\~7.5对CaO-Al2O3-SiO2-MgO 四元渣系成分优化位置进行确定,如图7所示。棕色圆点为优化后渣系所处位置,成分为:w(CaO)=49%\~59%、w(Al2O3)=29%\~37%、w(SiO2)=8%\~14%、w(MgO) =3%\~5%。

# 4 结 论

1)通过LF 精炼取样分析,碱度过高的精炼渣物相中存在高熔点CaO,导致精炼渣熔点升高,流动性变差,对夹杂物的吸收能力变差。

2)通过研究精炼渣成分的钙铝比和碱度对黏度和熔点的影响,得到适宜的钙铝比为1.5 2,碱度为5 7.5。在此基础上,提高炉渣钙铝比和碱度有利于提高渣硫容量。

3)综合对渣系钙铝比、碱度、硫容量和黏度的研究,得出 X65MS 管线钢 CaO-MgO-Al2O3-SiO2渣系的最佳成分区间为:w(CaO)=49% 59%、w(Al2O3)=29%\~37%、w(SiO2)=8%\~14%、w(MgO)=3%\~5%。

4)经工业应用,优化后的渣系完全熔化温度处于150 ℃以内的低熔点区,取得不错的优化效果;钢液中单位面积氧化物夹杂数量以及大尺寸氧化物夹杂数量大幅度下降。同时,精炼渣对S的吸收能力显著上升,可在LF精炼工序直接将钢液中的S质量分数脱除至10×10-6。
