肖　彪1，曾为民2，漆启松2，贾冬梅2，周焕能2（1．南昌大学材料科学与工程学院，江西　南昌 300 ；2．华菱安赛乐米塔尔汽车板有限公司技术中心，湖南 娄底 41700）

摘　要：从汽车的发展趋势出发，结合B柱的设计要求，分析了变强度钢（VAS ）在轿车的应用前景，研究了变强度钢的生产工艺和力学性能特征。 所设计的变强度钢高强度部分、低强度部分分别采用全奥氏体区淬火、临界区淬火。 根据生产实际情况，得到了Ac3 及与其相关的碳当量的计算公式。提供了含马氏体汽车用高强度钢的硬度和抗拉强度换算关系，方程的相关系数较高。在单位吸收能的计算中，提供了积分法和像素法两种方法，其中像素法可广泛用于计算复杂封闭曲线面积的工程问题。所设计的变强度钢高强度部分抗拉强度在80 MPa以上，低强度部分的单位吸收能接近高强度部分的1．5倍。

# 1 前言

汽车在给人类带来高效、便利出行的同时，安全问题也一直伴随其中，世界卫生组织发布的《2018年全球道路安全现状报告》［1］，2016年全球有135万人死于车祸，且该数字还在继续攀升。另外，根据世界气象组织发布的数据［2］，CO2 的全球平均表面摩尔分数在 2017年创下了新高，达到（405．5±0．1）×10－6，是1750年工业化之前的146％。汽车尾气的排放约占人类制造 CO2 的16％［3］，是全球气候变暖的主要原因之一。

汽车的设计一直致力于安全和减重，为了兼顾汽车的减重和安全性，安赛乐米塔尔研发了Usibor○R200和Ductibor○R100镀铝硅热成形钢，并推出了激光拼焊门环解决方案。变厚度板的应用成为汽车减重和提高安全性的方案之一［4－5］。铝合金在白车身的应用具有明显的减重、安全和环保作用［6］。复合材料在B柱的应用具有比钢材更为优秀的减重和吸能潜力［7］。变强度冲压热成形件在 B柱的应用也有广泛研究［8］。汽车侧面碰撞事故导致成员的重伤和死亡率高达25％，是造成成员死伤的主要事故类型［9］。因此，为了提高汽车的安全性能，以上所提到的大部分先进材料在汽车B柱均有应用。

相比变强度冲压热成形件、激光拼焊热成形件和变厚度板等，变强度钢（Variable Strength Stel，简称 VAS ）的优点：（1）冷成形工艺的模具互换性高，成形工艺简单；（2）强度分布范围可自由调节，设备利用率高；（3）批量连续、高效生产，能耗低；（4）热处理工艺容易控制，性能稳定；（5）避免激光拼焊，节约工序成本，不用考虑无焊缝热影响区的影响。

# 2．2 变强度钢生产工艺方案

HSLA钢的抗拉强度为 60 MPa，DP钢的抗拉强度为 605MPa，但双相钢具有更高的初始加工硬化值（图2），可有效延迟加工时产生的局部颈缩现象［10］。另外，采用相变强化是实现变强度分布行之有效的方案之一。因此，为了获得良好塑性、较高强度的变强度钢，本文所设计的变强度钢的低强度部分为双相钢，高强度部分的组织为具有较高比例的马氏体。

综上所述，变强度钢的设计具备以下特征：（1）在化学成分、厚度均匀的带钢上实现高、低强度的分布；（2）连续退火后变强度钢沿着带钢的宽度方向力学性能可变，非连续退火时其力学性能分布可自由调整；（3）主要采用相变强化实现强度的可变调整。

# 5 单位吸收能的计算

拉伸试样在拉伸过程中变形所吸收的能量，或变形能，在数值上等于设备对拉伸试样所做的功。

变形单元的变形能，或单位吸收能，反应了材料抵抗变形的能力和材料的韧性，也是评估材料变形发热的重要参数。在汽车安全件的设计中，材料单位吸收能越高，则越有利于将碰撞物传递的动能转化为零件变形、相变等所需的内能，从而降低碰撞物对车身其他部位的损伤。单位吸收能受材料成分、材料微观组织、变形速率、变形温度等的影响而不同［23］，设计零件时应根据具体服役状态计算单位吸收能。以单轴拉伸为例，式（4）说明了单位吸收能的计算过程：

# 6 结论

（1）相比变强度冲压热成形件、激光拼焊热成形件和变厚度板等，变强度钢的优点表现为冲压工艺简单，强度分布自由调节灵活，生产效率高，生产能耗低，力学性能稳定性高等优点。在汽车零部件的应用中，变强度钢具有一定的发展潜力。

（2）变强度钢在化学成分、厚度均匀的带钢上实现了高、低强度的分布。本文设计的高强度部分采用了较高的淬火温度，然后进行中温回火以提高屈服强度。低强度部分采用较低的临界区淬火温度，实现了提高低强度部分变形吸收能的目的。本文所设计的变强度钢高强度部分抗拉强度在80 MPa以上，而低强度部分的单位吸收能接近高强度部分的1．5倍。低强度部分的屈服强度加上烘烤硬化值低于高强度部分的屈服强度，同时抗拉强度低于高强度部分的屈服强度，能够有效避免变形、断裂优先发生在高强度部分，保护乘客的安全。

（3）本文根据膨胀法和金相法得到Ac3 结果，结合热处理工艺和化学成分设计的特点，得到了Ac 温度估算公式。

（4）本文根据实际情况，统计了含马氏体汽车用高强度钢的维氏硬度和抗拉强度换算关系，回归方程的相关系数达0．94　7，具备较高的精度。

（5）在单位吸收能的计算中，提供了积分法和像素法两种方法，两种计算方法得到的结果相差不到1％。相比积分法，像素法在确保高精度的同时，可高效率地用于其他复杂封闭曲线的面积计算问题。

另外，变强度钢也存在突出的缺点，比如零件设计时需平衡变强度钢的强度和成形难度的问题；冷成形用的变强度钢抗拉强度难以达到热成形钢的水平；变强度钢采用了不同程度的相变强化，导致带钢的板形控制难度加大；变强度钢的过渡区在热处理后、冷成形时需精确识别，以防零件强度分布的差错。因此在其实际生产应用中，仍需要做进一步深入的研究。
