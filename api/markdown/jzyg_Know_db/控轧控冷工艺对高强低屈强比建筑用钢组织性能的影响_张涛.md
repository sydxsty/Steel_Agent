# 控轧控冷工艺对高强低屈强比建筑用钢组织性能的影响

张 涛1,潘丽芳1,赵金华1,张红旭2,薛小飞1,刘光明1(1.太原科技大学材料科学与工程学院,山西 太原 03024;2.山西建邦集团有限公司,山西 临汾 04300)

摘 要:针对高强抗震建筑用钢如何实现高屈服强度及低屈强比耦合匹配的关键问题,基于自主设计的化学成分,采用控轧控冷工艺对试验钢组织性能进行了探究。结果表明:在“两阶段控轧+水冷(终冷温度60℃)”的工艺条件下,试验钢微观组织为铁素体、珠光体及贝氏体构成的复相组织,实现了强度、塑性及低屈强比的良好匹配,平均屈服强度约为60.0 MPa,平均抗拉强度达到约1196.7MPa,平均断后伸长率约为14.8%,平均屈强比低至0.5 。试验钢中 Mn、Si元素的固溶强化,以及贝氏体和珠光体组织产生的细晶强化及位错强化是获得高强度低屈强比的主要机制。

随着社会与科技的进步,建筑行业发展迅速,钢结构制造技术不断提高,建筑结构向高层化和大跨距发展,同时,高层建筑的安全和抗震问题引起了人们的广泛关注[1-2]。为提高钢结构的安全指数,保证高层建筑的抗震性能,建筑用钢不仅要能够承载苛刻的外力载荷,也要能承受严酷的变形负荷,因此推动了建筑用钢向着高强度与良好塑韧性匹配的方向发展[3-5]。

对于建筑用钢而言,除了强度指标外,屈强比是描述钢材抵抗塑性变形能力的重要指标[6-7]。钢材屈强比越低,意味着开始塑性变形至断裂所经历的形变容量越大,使用过程中的安全性越高[8]。特别是对于高强度建筑用钢而言,在要求高强度的同时,需要具有较低的屈强比[9-10]。在建筑用钢研发领域,特别是抗震用钢研发方面,有研究通过控制复相组织分布形态、数量、尺寸等指标,研发出具有一定强度及优异抵抗均匀塑性变形能力的钢材[11-15]。姚纪坛等[12]研发出屈服强度达到426.9MPa、屈强比为的耐候钢;宋国栋[13]通过研究轧后弛豫技术对试验钢组织及性能的影响,获得 了屈服 强度约为、屈强比约为 的钢板。然而,上述研究表明,对于抗震用钢而言,随着屈服强度的提高,屈强比也往往随之增加,存在屈服强度提升与屈强比降低无法兼得的难题,如何实现高屈服强度及低屈强比的耦合匹配,成为高强抗震用钢研发的关键。

基于上述背景,本研究基于复相组织诱导低屈强比控制的思想,研发了一种兼具高强度、高抗塑性变形能力的低屈强比建筑用钢,为我国建筑用低屈强比钢的研发奠定了理论及实践研究基础。

# 试验材料与方法

# 1.1 化学成分及组织设计

高强度、低屈强比钢的研发过程中,其微观组织设计在于获得“软硬”相兼具的复相组织[16-18]。在塑性变形过程中,硬度相对较软的相会率先发生塑性变形,变形临界条件往往与钢材屈服强度密切相关;而组织中相对较硬的相在塑性变形过程中,往往承担抵抗钢材发生塑性变形的最大能力,即与钢材抗拉强度相关[19]。因此,通过合理控制钢中软相的比例以及状态,综合利用典型强化机制,可以获得适中的抗拉强度;与此同时,在弱化硬相对钢材塑韧性影响的前提下,通过提高硬相抵抗塑性变形的能力,即可实现高强度及低屈强比的良好匹配。据此,本研究所设计的试验钢具体化学成分如表所示。采用较高的 含量,可通过固溶合金元素实现固溶强化效果,同时由于 Mn元素对奥氏体的稳定作用,又可适当提高试验钢的淬透性,获得强度及塑韧性匹配良好的贝氏体组织,有利于提高试验钢的抗拉强度;此外,添加少量的Nb、V 元素,可获得一定量的第二相粒子,从而可以细化试验钢组织。

# 2.3 复相组织实现低屈强比机制

钢材的力学性能由其微观组织决定。目前的研究表明:单一组织类型钢材的屈服强度和抗拉强度差值不大,导致屈强比相对较高,但如果组织中存在两种或者两种以上不同强度的相,通过控制软硬相的比例,即可实现高强度及良好的塑韧性匹配,实现低屈强比的控制[11,20-21]。本研究中,试验钢表现出较低的屈强比特征,其组织由具有良好塑韧性但强度和硬度偏低的软相组织铁素体和具有较高强度的硬相组织贝氏体与珠光体组成,在拉伸过程的塑性变形阶段,软相首先发生屈服,在进一步的变形过程中由硬相提供抗拉强度,确保了试验钢屈服强度与抗拉强度差值较大而实现了屈强比的降低。

结合本研究中试验钢化学成分、控轧控冷工艺及力学性能可知,经过控制轧制后,呈拉长纤维状的过冷奥氏体在空冷条件下会相对缓慢进入到铁素体与珠光体组成的高温相变区域而发生充分相变。由于试验钢中含有的一定量 Mn、C 元素,能够稳定过冷奥氏体,提高试验钢淬透性,相变过程中部分未发生转变的过冷奥氏体能够进入贝氏体相变区而形成贝氏体组织,使空冷工艺下试验钢获得铁素体、珠光体及贝氏体组成的复相组织。由于冷却过程中,试验钢芯部位置冷却速率相对较低,有利于以“扩散型相变机制”为特征的珠光体组织的形成,致使芯部位置形成了含量较多的纤维状珠光体。经过控制轧制后,在水冷工艺下呈拉长纤维状的过冷奥氏体会快速通过铁素体、珠光体高温相变区域,使得更多未来得及转变的残余奥氏体稳定至贝氏体相变区间而形成贝氏体,相较空冷工艺下试验钢,贝氏体含量更高。对于本研究试验钢,一旦组织中形成了以铁素体、珠光体及贝氏体组成的复相组织,组织中细小的铁素体、贝氏体组织可以通过细晶强化、位错强化等综合强化机制确保试验钢具有足够高的强度。另外,两种冷却工艺下的试验钢晶粒尺寸差别并不明显,因此,由细晶强化贡献的强度增量也近似相同。根据已有研究结果,不同冷却速率也会影响析出强化效果,随着冷却速率的增大,析出相的数量和尺寸都会变小[22],本研究中只在空冷工艺下的试验钢铁素体基体内观察到细小析出粒子,这也是空冷工艺下试验钢强度较高的原因。

为了进一步明确不同微观组织含量对试验钢力学性能的影响规律,对两种控轧控冷工艺下制备的试验钢微观组织进行着色处理并统计,结果如图8所示。结合力学性能测试结果可知,两种控轧控冷工艺下试验钢贝氏体组织含量发生改变,试验钢屈强比变化较小,保持在0.53\~0.5 的较低值范围区间,表明对于屈强比而言,贝氏体含量是不敏感影响因素;相对而言,空冷工艺下试验钢组织中存在的含量较多的纤维状珠光体易作为断裂过程裂纹萌生的裂纹源而恶化试验钢的塑性,导致试验钢塑性相对较低,但对屈强比影响较小。
