# 汽车用钢表面激光熔覆 AlCoCrFeNi 高熵合金涂层组织及耐磨性研究

郑军武1， 袁磊2

（1江苏省无锡交通高等职业技术学校，江苏 无锡 214151； 2中国建筑第四工程局有限公司，广东 广州5100 ）

摘要 为提升汽车用316不锈钢的耐磨性及硬度，在316不锈钢表面采用激光熔覆技术制备 AlCoCrFeNi共晶高熵合金熔覆层。采用金相显微镜（OM）、扫描电镜（SEM）、电子背散射衍射分析技术（EBSD）、显微硬度计、往复式摩擦磨损试验机分别对共晶高熵合金熔覆层的微观组织、相组成、晶体学特征、表面显微硬度、耐磨性及磨损机理进行分析。具体结论如下：AlCoCrFeNi共晶高熵合金涂层的相组成为FC 相和BC 相。EBSD结果表明涂层的晶粒尺寸约为15．34μm，涂层内部具有较高的位错密度。涂层的表面显微硬度为31 HV±10．2HV，约为316不锈钢基体的1．7倍。强化机制为固溶强化和位错强化。涂层的摩擦系数约为0．42 ，比磨损率为4．52×10－5　mm3／（N·m），均明显优于316不锈钢基体。磨损机理主要为磨粒磨损，并伴有轻微的黏着磨损。

# 0 引言

316不锈钢因其具有良好的可焊接性、耐蚀性和机械性能，被广泛应用于汽车核心部件等领域［1－3］。然而，316不锈钢的硬度较低、耐磨性能较差，在面临高磨损环境下，其使用寿命较短［4］。为提升316不锈钢在磨损环境下的使用寿命，采用表面强化技术可显著提升其耐磨性及使用寿命。

高熵合金是一种可用于制备涂层的新型材料，具有良好的耐磨性和抗腐蚀性［5－7］。目前高熵合金涂层的主要制备方法分别为电弧熔化沉积、磁控溅射、电化学沉积和激光熔覆等技术［8－10］。激光熔覆技术所制备的涂层可与基体间形成良好的冶金结合，并具有稀释率低、微观结构致密等优点，受到众多学者的广泛关注［11］。激光熔覆高熵合金的相组成多为面心立方（FCC）或体心立方（BCC）结构。具有FCC结构的高熵合金涂层具有优异的塑性和耐蚀性，而具有BCC结构的高熵合金则具有较高的硬度和优异的耐磨性［12］。然而，强度与韧性差异过大则会导致涂层综合性能降低，甚至会导致涂层产生开裂或失效。因此，开发一种具有高强度和高韧性的高熵合金涂层是现阶段抑制高熵合金涂层发展和应用的关键问题。

Lu等［13］在2014年提出了共晶高熵合金概念，并设计了具有 BCC相和FCC相组成的 AlCoCrFe－Ni共晶高熵合金。这种共晶高熵合金实现了高强度、高塑性相间的复合结构，使材料的强度与塑性形成良好匹配，成为金属结构材料领域的研究热点［14］。Ni等［15］采 用 激 光 熔 覆 技 术 制 备 了 Al0．5 Cu0．7FeNiCoCr高熵合金涂层。研究结果表明，当扫描速度为 630 mm／s时，熔覆层具有最高的显微硬度（750 HV），显微硬度约为 5083铝合金基体的8倍。Meng等［16］采用激光熔覆法在 AZ91D基体表面制备了 AlCoCrCuFeNi高熵合金涂层。结果表明，当Cu的原子分数达到30％时，Cu元素在熔体中的扩散系数显著降低，并形成CuMg2相。 这种CuMg2降低了涂层的磨损性能。

然而，现阶段对于在汽车用不锈钢表面制备AlCoCrFeNi共晶高熵合金涂层的研究相对较少。本文采用激光熔覆技术在316不锈钢表面制备AlCoCrFeNi共晶高熵合金涂层，分别对涂层的相组成、微观组织、晶体学特征、显微硬度及摩擦学特性进行研究。期望开发出适用于汽车用不锈钢表面强化的高强度、耐磨损共晶高熵合金涂层。

# 试验方法

# 1．1 试验材料

选用尺寸为 150 mm × 20 mm × 15mm 的316不锈钢作为基体材料，在激光熔覆前对基体材料进行打磨，去除表面氧化膜。随后采用丙酮对基体表面进行清洗去除污垢。采用纯度为9 ．9 ％，粉末粒度为53～105 μm 的 Al、Co、Cr、Fe、Ni粉末作为熔覆材料，各元素比例为等物质的量比。在氩气气氛保护下借助球磨机对混合金属粉末进行球磨2h。随后将粉末在氩气条件下烘干10h，烘干温度为50℃。

# 1．2 激光熔覆设备及工艺参数

本试验选用ZKZM－200 型激光熔覆设备，激光熔覆 试 验 参 数 为：功 率 1　50 W，扫 描 速 度1　00mm／s，重叠率为50％，氩气流量为15L／min，光斑直径为1．5 mm，离焦量为15mm。 本试验采用预制粉末法进行激光熔覆，粉末厚度约为1．2 mm。

# 1．3 微观组织及晶体学特征分析

激光熔覆后，使用线切割电火花加工（WEDM）机床垂直于扫描轨道切割金相样品。采用EMPY－GREAN　X射线衍射分析系统（XRD）在40kV 和30mA的Cu　Ka辐射下对共晶高熵合金涂层的相组成进行检测。扫描速度为4°／min，扫描角度为20°～10°。采用金相显微镜对AlCoCrFeNi共晶高熵合金涂层的微观组织进行观察，在进行金相观察前对 AlCoCrFeNi 共晶高熵合金涂层进行金相腐蚀，腐蚀剂为5g　CuCl2＋20mL　HCl＋10 mL　H2O，腐蚀时间为15s。采用电子背散射衍射分析技术（EBSD）对 AlCoCrFeNi共晶高熵合金涂层的晶体学特征进行检测，所选取的位置为涂层表面的中心位置，这一检测位置具有代表性。在检测 前 对AlCoCrFeNi共晶高熵合金涂层表面进行电解抛光，电解液选取10％高氯酸酒精溶液，电解过程中电压为20V，电解时间为35s。采用液氮对电解液降温，电解温度为－20℃。

# 1．4 硬度及摩擦磨损试验

采用 MH－60维氏硬度计测定 AlCoCrFeNi共晶高熵合金涂层表面的显微硬度，测试载荷为20 g，载荷持续时间为10s。为确保硬度测试的准确性，在不同位置分别进行10次测试，并取平均值，以确保结果的准确。采用 HT－60 往复式摩擦磨损测试机对 AlCoCrFeNi共晶高熵合金涂层和316不锈钢的耐磨性进行测试。摩擦副选用 GCr15轴承钢钢球，钢球直径为5mm，测试载荷为15N，测试速度为1　50 mm／min，磨损行程为6mm，磨损时间为30min。在磨损测试结束后，采用扫描电子显微镜对磨损形貌进行观察，并计算比磨损率。比磨损率计算方式如下［17］：

# 2．3 显微硬度及磨损行为

图5为 AlCoCrFeNi共晶高熵合金涂层和316不锈钢基体的表面平均显微硬度。其中 AlCoCrFe－Ni共晶高熵合金涂层的表面平均显微硬度为31 HV ± 10．2HV，而316不锈钢基体的硬度为184HV ± 9．3HV，AlCoCrFeNi共晶高熵合金涂层的平均显微硬度约为基体的1．7倍。表明在316不锈钢基体表面制备 AlCoCrFeNi共晶高熵合金涂层可显著提升其表面硬度。固溶强化和位错强化使AlCoCrFeNi共晶高熵合金涂层具有较高的显微硬度。首先，由于Al原子的半径显著小于Fe、Co、Cr、Ni的原子半径，因此，当 Al原子固溶在FCC相或BCC相时，会导致固溶体产生严重的晶格畸变，从而引起固溶体的固溶强化作用［22］。其次，由 EBSD结果表明，AlCoCrFeNi共晶高熵合金涂层内部存在大量位错，位错可以阻碍晶体的滑移和滑移带的扩展，从而提高材料的强度。这是通过增加阻碍位错运动的障碍或通过改变位错的类型和密度来实现的［23］。因此，由于固溶强化和位错强化使涂层的强度和硬度显著升高。

# 3 结论

本文通过激光熔覆技术在汽车用316不锈钢表面制备 AlCoCrFeNi共晶高熵合金涂层，分别对涂层的相组成、微观组织、晶体学特征、表面显微硬度及耐磨性进行研究，得出以下结论：

（1）AlCoCrFeNi 共晶高熵合金涂层的相组成为FCC相和BCC相，由于Al元素的固溶导致FCC相和BCC相均产生晶格畸变，从而引发了固溶强化作用。

（2）AlCoCrFeNi 共晶高熵合金涂层的表面显微硬度为31 HV ±10．2HV， 约为316不锈钢基体的1．7倍。AlCoCrFeNi共晶高熵合金涂层具有较高的显微硬度，可认为是固溶强化和位错强化的协同强化效果而引起的。

（3）AlCoCrFeNi共晶高熵合金涂层比316不锈钢基体具有更为优异的耐磨性，AlCoCrFeNi涂层在干滑动磨损 30 min 下的平均摩擦系 数 为0．42 ，磨损率为4．52×10－5 mm3／（N·m），均明显优于316不锈钢基体。AlCoCrFeNi共晶高熵合金涂层的磨损机理主要为磨粒磨损，并伴有轻微的黏着磨损。
