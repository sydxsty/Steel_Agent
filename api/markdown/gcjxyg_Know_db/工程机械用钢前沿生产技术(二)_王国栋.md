# 4 中厚板生产数字化转型

在第 次工业革命浪潮的推动下,钢铁行业正在经历数字化转型。热轧作为最典型的钢铁生产流程,各生产工序多为“黑箱”,且为多场、多相、多变巨系统,存在复杂的相关性和遗传效应等,这些不确定性给中厚板生产带来了巨大的挑战。但挑战和机遇并存,热轧过程极为丰富的大数据提供了挖掘其中蕴含客观规律的数据资源,现代的数据科学、智能技术为解决不确定性问题提供了强大的手段[51]。

# 4.1 原位分析系统与材料创新基础设施

在热轧生产线附近,设置一个基于数字孪生的原位分析系统,它能够以足够的精度给出描述材料化学成分、生产工艺与产品组织、性能、外形尺寸、表面质量、状态量等控制目标之间的关系,为后续的过程设定提供具有自学习、自适应、自组织能力的高保真度模型系统[52]。

以实验工具、数字数据、计算工具为支撑平台,建设钢铁企业的材料创新基础设施,提高研发效率,降低研发成本,将有力地支撑钢铁材料科学与技术的转型发展。实验工具平台除了传统实验室仪器装备和中试装备之外,实际的热轧生产线装备被作为最主要的实验工具。热轧过程的原位分析系统与材料创新基础设施如图17所示。

# 4.3.1 平面形状控制

平面形状控制技术是使中厚板产品矩形化,减少头尾和边部不规则形状切损,提高产品成材率非常有效的方法。东北大学经过多年的理论模拟、实验研究和现场应用实践,开发了可控点平面形状控制技术,并在国内大范围推广应用。该技术可实现平面形状控制过程楔形段的灵活调节,产品的矩形 度大幅提高[54-56]。

在平面形状控制应用过程中,单纯依靠模型预测很难进一步提高产品矩形度。因此,构建了基于图像识别检测反馈的平面形状控制 ,实现了对平面形状控制的自主优化控制。该技术在轧机下游安装机器视觉检测装置,利用数字图像技术对钢板图像进行识别,获得平面形状控制后的实际钢板形状,并作为闭环反馈控制的数据源,优化平面形状控制参数,改善钢板轧后矩形度[57-58]。

# 4.3.2 板形控制

板形是评价轧制板带产品的重要质量指标,其对产品的成材率和后续加工质量有极大影响。东北大学RAL在板带轧制的板形控制方面有深厚的理论基础,并开展了大量的应用研究工作。

在中厚板板形控制方面,深入研究了与板形控制密切相关的影响因素、板形理论和板形控制手段等。系统分析了各种工艺及设备参数对中厚板出口凸度的影响规律;建立了涵盖支撑辊直径、工作辊直径、单位宽轧制力、工作辊弯辊力、工作辊凸度、钢板入口凸度和负荷分布等因素对板形影响的板形控制模型[59-63]。

近年来,随着工程机械用钢等高等级钢板的开发,对TMCP生产工艺提出了更苛刻的要求,板形控制已经不能只靠轧机工艺区来完成,控制冷却以及后续的热处理工艺区都对最终成品的板形控制起到很大的作用。为此,开发了高精度的在线钢板板形检测系统,实现了钢板板形在线检测[64];采集控制冷却和热处理的全部工艺和设备控制数据,通过大数据学习方法获得最佳的板形控制策略,这些工作也是进一步提高最终产品板形质量的重要手段。

# 4.3.3 侧弯控制

中厚板轧制过程中,由于钢板宽度方向温度不均、坯料楔形、咬入偏差以及轧机两侧刚度不同等非对称轧制条件的影响,钢板两侧延伸不同,会使轧制后的钢板产生侧弯。现场使钢板产生侧弯的因素复杂多变,无法进行准确判断和快速响应控制[65]。目前国内外中厚板厂在钢板侧弯控制上还普遍采用手动控制,操作人员根据监控画面,通过经验调整两侧辊缝差来实现侧弯调整,由于反馈滞后,控制效果较差。

东北大学前期对中厚板侧弯的影响因素和规律进行了系统研究,获得了钢板侧弯的运动规律。在轧机前后安装工业摄像头,通过机器视觉技术检测轧制过程钢板的镰刀弯曲率,反馈给镰刀弯控制模型进行优化控制,可以实现对轧制过程中钢板镰刀弯的在线监控与智能化纠偏控制[66-68]。

# 4.3.4 翘扣头控制

中厚板轧制由于咬入时厚度方向的不对称变形使得轧件上下表面金属的延伸量不一致,使轧件产生翘扣头现象。影响轧件翘扣头的非对称因素较多,影响规律不一致,当轧件发生翘扣头时,如果调节不当,可能会导致严重的设备损伤事故[69]。

通过控制上下辊速差对轧件咬入瞬间头部弯曲进行控制是目前中厚板生产常见的控制方法。但由于头部弯曲控制对于轧件厚度、压下量等因素敏感,而这些因素对轧件头部弯曲的影响规律为非线性,所以当轧件出现头部弯曲后,难以准确地设定辊速差以消除头部弯曲。

东北大学通过有限元方法分析了不同轧制条件对于轧件翘扣头的影响规律,建立了翘扣头预测模型[70-72]。通过机器视觉技术,在线测量不同轧制条件下轧件头部的弯曲情况,建立了轧件头部弯曲与各影响因素之间的大数据库,开发了轧件翘扣头模型,通过自主机器学习,实现了轧制过程轧件翘扣头的在线监控与智能化诊断。

# 4.3.5 厚度高精度控制

厚度精度是中厚板产品最重要的质量指标。中厚板轧制过程中,头尾温度偏差,以及加热炉中“水印”等温度不均匀因素都会造成钢板纵向轧制力波动。这种波动的长度很短,基于厚度计工作模式下的 系统无法消除该类厚度偏差,从而影响产品厚度控制精度。

针对这类厚度控制问题,东北大学开发了非稳态过程的厚度自适应控制技术,对钢板轧制过程的加工历程信息进行跟踪,准确记录前一道次轧制过程中轧制力的波动情况,并在下一道次针对厚度波动点增加精确的前馈自适应控制,改善钢板同板厚度精度。

# 4.3.6 转钢自动控制

当前中厚板生产线自动化程度已经很高,只有转钢过程仍需要人工操作。实现自动转钢可使中厚板轧制过程实现真正意义的全自动控制,减少人工干预,提高生产效率,使轧制工艺控制具备更高的准确性和复现性。

目前国内外自动转钢技术仍处于研发阶段,国内有少数中厚板厂家开展了自动转钢的应用实践,但自动转钢的效率和对异常复杂工况的处理仍不够理想[73-74]。

东北大学基于机器视觉技术开发出适应复杂生产环境下的钢坯角度测量方法,实时检测钢坯转钢过程的位置、角度、速度等信息。其通过智能模型学习操作工转钢的控制过程,以最小转钢时间为约束条件进行模型训练,根据钢坯信息给出合理的转钢控制策略,通过高速数据通讯技术传递给基础自动化执行。东北大学研发了成套自动转钢系统并已成功应用于工业生产[75-76]。

# 4.3.7 动态组板

中厚板产品的订单具有多品种、多规格、小批量、个性化的特点,而中厚板厂的规模化生产要求钢板大单重、批量轧制生产。如何将中厚板大单重的母板与最终客户需要的合适尺寸子板匹配,是中厚板生产组板需要解决的问题[77]。

目前中厚板生产线一般在 MES 系统中完成坯料设计和组板工作,并主要针对长度方向一维母板设计优化问题展开[78]。在中厚板实际生产过程中,由于形状尺寸的偏差,以及镰刀弯等异常形状的影响,在精整剪切时可能无法按照计划的组板完成切割。在钢板进入精整线时通过机器视觉检测精确测量钢板的轮廓形状,根据实际形状判断,如果无法切割出计划产品,可进行动态调整,查找替代订单,从而减少非计划产品,降低生产和库存成本。

# 44 生产计划调度与管理

国内主要钢厂经过多年的建设与改造投入、技术和装备己经比较先进,许多企业虽然引进了一些关键生产设备,但由于缺乏科学、合理的整体生产计划组织,导致这些关键设备的潜能并没有全部释放出来。目前各大钢铁企业都在积极建立企业数字化平台,如何基于数字化平台整合的产销系统、资源计划系统、物流系统、设备管理系统等多系统信息,设计和开发融入可量化和可学习的专家知识的智能优化排程系统,将高度依赖专家经验的人工排产模式转化为由智能排产系统提供决策支持的数字化排产模式,从而实现生产调度环节的减人优化,是数字钢铁生产调度管理面临的关键难题之一。

# 4.4.1 生产计划制定与调度管理

现代的钢铁集团企业通常拥有制造能力平行的多个生产基地(制造实体单位),各生产基地又拥有工艺流程相近的多条生产线,这使其排产计划的编制问题变得更加复杂和困难。为了避免企业内部各生产基地之间的相互竞争,集团企业采用“对外集中销售、对内集中排产”的运作管理方式。目前钢铁企业多工序协同的生产调度系统多以信息化技术为基础,为调度员提供人工排程界面,依赖调度员的人工经验进行排程。

随着大数据和机器学习技术的进步,通过人工智能技术学习和提取人工排程中关键的专家知识构成生产调度知识库,并以此为基础,构建和开发以多工序协同的生产调度模型和算法为核心的一键式智能排程系统成为各企业生产计划制定和调度管理的发展目标,如图19所示。同时,高效的生产计划制定与管理还需考虑面向降本增效的多工序多目标协同,以及各生产线在线物流与设备状态情况,避免出现高能耗、能源不足、库存和物流不畅等情况发生。高效的生产计划制定也可以与企业库存备料相结合实现库存备料的最小化。

# 4.4.2 跟踪与物流管理

产线物料跟踪与物流管理是生产计划高效精准执行的关键。先进钢铁企业数字化管理需要全流程钢板跟踪与物流控制,该功能是每台设备及整条生产线与信息系统衔接的重要环节,实现各工序端到端的多源数据时空统一集成。跟踪系统(图)通过各种类型的传感器将各种物理量转变成模拟量信息物理系统,并且采集每台装备的生产工艺数据、加工过程质量参数和设备健康状态等数据和信息,且依照顶层生产工艺的工序指令实现生产计划排产制定的钢板生产流程自动控制。产线全流程钢板跟踪与控制实现了设备、生产订单、计划排程、过程质量管理等一系列环节的数据、信息的整合与优化。高效的钢板跟踪与物流管理可大幅提升生产过程应对个性化需求、柔性化制造、动态化决策等能力,为生产实现智能化制造提供必要和充分条件。传统跟踪数据采集量较少,数据丢失补入较为麻烦,造成数据质量不高,随着先进仪表的开发以及视觉识别等辅助技术的发展,产线物料跟踪和控制已经越来越精准和智能,先进的产线物料跟踪系统可以为大数据平台提供大量工艺大数据,为生产计划的优化和产品质量的分析提供基础[79]。

# 4.5.1 机器视觉检测系统的应用

# 4.5.2 板号识别和物料跟踪

板号是钢板的唯一编号,是重要的ID 信息。企业为了方便生产管理,所有的钢板都依靠板号来进行生产物料跟踪。目前随着自动化程度的提高,企业有自动喷码、激光打码等设备,但同时也还存在大量手写板号的企业。通过机器视觉技术实现板号的自动识别,是实现精确物料跟踪的前提条件。

准确的物料跟踪是实现工艺控制的基础。为了实现准确的物料跟踪,轧线必须配置大量的检测仪表。一旦轧线仪表出现故障将大大降低物料跟踪的精度。基于机器视觉的轧线板坯辨识跟踪可以有效地减少轧线检测仪表的数量,而且在轧线的热区和冷区均适用,特别是对缺少检测手段的冷床区的物料跟踪,更是一种有效的手段[81]。

# 4.5.3 钢板表面质量检测和修磨

修磨工艺是提升钢板产品质量和精度的方法之一,主要完成工件表面缺陷修磨、去毛刺等任务。随着用户对产品质量的要求越来越高,对产品表面质量提出了更高的要求。但国内很多企业大量的修磨工作仍靠人工完成,修磨产生的粉尘及噪音影响工人的身心健康,长时间重复劳动还易发生安全事故,以及修磨质量不稳定、精度不高等问题。开发缺陷自修磨机器人,通过自主识别钢板缺陷,判断缺陷大小并定位,优化修磨路径,调整合适姿态,可以实现钢板表面缺陷自动修磨[82-83]。

# 4.5.4 其他控制

基于机器视觉检测还可以实现其他常规控制方式无法实现自动控制的功能。例如加热炉钢坯的自动入炉和自动出炉,冷床的自动控制等功能。

常规加热炉的自动控制采用冷金属检测器或者热金属检测器对坯料位置进行检测。开发PLC与机器视觉系统相融合的加热炉自动控制系统,基于机器视觉检测实现坯料入炉和出炉位置的精确检测,辅助基础自动化修正钢坯坐标与尺寸,能够更精确地实现加热炉的自动控制功能[84-85]。

中厚板冷床区域由于物流复杂、上下游节奏控制变化频繁等,凭借传统冷热检信号控制冷床不能适应生产的需求。随着智能化技术的发展,基于机器视觉的智能感知技术,可以实现冷床上下料和钢板在冷床上运行位置的精确检测,实现冷床的自动控制和布料空间的优化。

# 极限厚度钢板热处理工艺、装备、技术与产品

# 5.1 超厚规格钢板热处理工艺、装备

目前,超厚规格钢板(钢板厚度h )生产节奏较慢,且淬火生产对热处理炉装备的运输装置要求较高,因此厚板生产时要综合考虑选择合适炉型。一般连续式辊底炉可生产厚度不超过230mm的钢板,更厚规格钢板一般采用室式炉进行生产。厚板生产过程中厚度方向温度分布较为关键,需要实现热处理全流程温度一体化控制,因此建立超厚规格钢板热处理温度一体化控制对于提升和控制厚板热处理质量有重要作用。

传统超厚规格钢板采用“台车炉 水槽”的方式进行热处理,钢板表面水 气换热效率低,厚向温度梯度小,钢板内部导热效率下降,导致心部冷速偏低、厚向截面效应明显。采用“变周期阵列射流辊式淬火”调控厚规格钢板断面温度梯度的方法,利用阵列射流辊式淬火实现钢板表面对流换热有序可控,利用变周期淬火实现断面淬火-返温热履历过程可控,解决了钢板高强度淬火问题;进而采用“温度梯度控制+ 反复相变/析出”方法,实现钢板近表面获得超细晶复合淬火/回火组织、近心部获得复合析出强化组织,提升了钢板断面性能均匀性。为此,开发出50\~350mm 厚规格钢板连续辊式淬火装备,建成了特厚钢板连续热处理产线(图24),结果表明:290mm厚钢板心部冷速为0.53℃/s,整板温度均匀性在±5℃范围内,淬火不平度不大于3\~6mm/m,钢板组织性能改善明显,满足了海工、能源化工、水电核电、装备制造等领域用钢需求。

# 5.3 薄与极薄规格钢板在线热处理工艺、装备

大型工程的建设离不开强有力的工程装备,在青藏铁路、大兴机场等国家重大工程建设中,大型的工程装备发挥着至关重要的作用。随着科技快速发展及工程机械装备向大型化、轻量化发展的需求,在提升钢板强度的同时,还要求钢板具有良好的韧塑性、优异的成型性和焊接性能。同时,随着工程装备的大型化和轻量化,要求使用的钢板规格更薄。然而,高强度薄规格钢板的内应力敏感性更高,控制难度加大,薄/极薄宽幅规格钢板在线热处理过程中易出现应力集中,造成板形不良的现象。如何实现薄/极薄规格钢板在线热处理的低应力和平直度控制,一直是行业难题。

采用超快速冷却技术,利用其高冷却速率、高冷却均匀性及冷却速率范围无极可调等特点,通过轧制 冷却一体化组织调控,充分利用细晶强化、析出强化以及相变强化等综合强韧化机制,实现了薄/极薄规格钢板的在线热处理。采用该技术,已经 批 量 化 生 产 薄 至 2.5 mm 厚 度 规 格、强 度级别的高强工程机械用钢,解决了大宽厚比超高强度钢板的低残余应力和高均匀性协同控制行业难题。另外,采用该技术,实现了薄规格(厚度薄至2mm)低合金NM350\~NM50 钢板的稳定生产,简化了工艺流程,解决了传统耐磨钢板淬火内应力大、切割和折弯易开裂、焊接性能差等问题,对推动钢铁行业产品转型升级和绿色制造具有重要意义。

6.1.1 超高强度系列结构用钢板协同研制开发与应用

超高强度结构钢板是大型工程机械制造的关键原材料,随着工程机械装备的不断大型化、轻量化和结构复杂化,要求所用的钢板具有高强度和高韧塑性、易焊接、高冷成型性和高平直度板形等综合性能。2010年前,我国仅个别企业能够生产中厚规格低级别工程机械用高强度结构钢板,2\~8mm极限薄规格和屈服强度 高级别工程机械用结构钢板,则完全被瑞典 S AB、芬兰RUUKKI和日本JFE 所垄断,致使该类钢板售价极高,交货周期长,严重影响了我国工程机械的发展。高端工程机械用钢板研发生产难度极大,主要因为该类钢板的级别高、综合性能极高,宽薄规格钢板厚度精度和高平直度板形等问题难以解决;该类钢板屈服强度级别最高达到130 MPa,同时要求具有高韧塑性、等强匹配焊接、抗疲劳、 冷成型和抗氢脆等性能,应用范围主要为2\~15mm 超薄或极薄规格,宽度最宽达 以上,由于钢板强度极高、宽厚比大,轧后冷却及淬火后内应力极大,致使钢板板形无法保证,部分钢板即使通过矫直得到良好的板形,但是在后续成型或切割后仍会存在变形,难以满足下游装备制造用户对高性能超高强度结构钢板的需求。

在上述背景下,东北大学协同华菱涟钢、南京钢铁等钢企以及三一重工、中联重科和徐工集团等上下游企业协同攻关合作,提出以碳含量和碳当量控制为基础、Ti-Nb/V-Mo微合金化的超高强钢合金设计体系,构建了超高强钢板轧制 冷却 热处理一体化组织调控方法,攻克了2\~12mm 超高强度结构钢板全流程内应力控制技术,研发成功Q890\~Q130 共12个牌号工程机械用高强调质钢产品,实现了钢板级别和规格国产化全覆盖[87-89]。同时,开发成功配套折弯成型、焊接、切割应用技术,使钢板切割不变型、焊后 折弯不开裂,并率先将国产钢板应用于超大型工程机械装备[90-92]。通过系列研究,解决了超高强度钢板强韧性矛盾和内应力难以控制两大世界难题,所研制钢板的级别和规格均达到同类级别的最高水平。系列钢板在国内徐工集团、中联重科、三一重工和柳工等大型工程机械上实现大批量应用,并出口到欧洲、南美、韩国等国际市场,满足了工程机械关键原材料的制造需求,大幅度降低了该类产品的价格,促进了相关行业发展,提升了我国工程机械的国际竞争力。

6.1.2 600\~900 薄规格低内应力高强度结构钢板协同研制开发与应用

工程机械中起重机和消防云车的伸缩吊臂、拉板、桁架梁及混凝土泵车的臂架等关键受力部件,要求其制造钢板不但具有极高的强度、硬度和韧塑性,还要具有优异的成型性、焊接性能和抗疲劳性能等,同时,该类部件在制造过程中一般需要折弯或切割成型,对钢板的内应力要求极高,不但要求钢板具有优异的板形,而且还要求钢板在切割和折弯成型后不能变形。传统薄规格高强度结构钢板采用TMCP或者TMCP+回火工艺生产,由于钢板强度较高,需要冷却至贝氏体或马氏体的相变温度,致使钢板内应力较大,虽然钢板通过矫直后其板形能够满足要求,但是矫直后的钢板在切割或者折弯成形时,仍容易二次变形(大部分为残余应力导致),致使下游用户在使用过程需要后续火校等工序来满足装备制造要求。

针对600～900 薄规格高强度结构钢板存在内应力过大的问题,东北大学与华菱涟钢合作,并协同中联重科、三一重工等企业,展开了低内应力高强度结构钢的设计与研发,通过对钢板加工后形变问题的研究分析,明确了60 \~90 MPa薄规格高强度结构钢板低残余内应力的控制方法,通过合金优化设计,并考虑钢板轧制及轧后冷却和热处理过程应力状态,调整钢板上下表面冷却水量、采用间断式冷却模式、进行堆垛缓冷和中高温回火热处理等工序,大幅度提高了钢板热处理过程中表面温度均匀性,显著降低了高强钢钢板的残余应力,最终实现了 薄规格高强度结构钢板低残余内应力控制,将吊臂折弯成形时一次合格率由传统钢板不到45%提高到95%以上[93],解决了高强度结构钢成型难度大的难题,被大量应用于中联重科、三一重工、徐工集团等大型工程机械的吊臂、拉板、臂架等关键受力结构部件制造,为下游用户大幅降低了生产成本。

# 6.1.3 工程自卸车用薄规格耐磨钢板协同研制开发与应用

耐磨钢板是大型工程机械、矿山机械、冶金机械和水泥装备关键部件制造的重要原材料,钢板的耐磨性能直接决定着制造装备的使用寿命。传统耐磨钢板存在合金含量高、焊接性能差、不可折弯成型和耐磨性能差等局限,严重制约了我国装备制造业的发展。耐磨钢板的强度和硬度极高,为了保证耐磨性能,通常需要添加较多的碳元素和合金,致使碳当量高,焊接成型困难。超高的强度和硬度使得钢板的韧塑性极低,无法折弯成型。在装备制造过程中,部分要求良好低温韧性、焊接性能和折弯成型性的零部件,不得不采用性能更低的低合金高强度钢板甚至普通碳锰钢板来替代,致使零件寿命大幅度降低、失效加速,导致维修和更换频繁,设备工作效率降低,消耗了大量的能源和材料。采用在普碳钢零部件表面强化热处理或者堆焊硬质合金的方法,可以有效提高耐磨性能,但是该类方法工序复杂、制造成本高,且在部分超大型复杂零部件上无法实现。为此,亟需进行新型耐磨钢板的研发,以满足大型装备制造用材的需求。

针对传统耐磨钢板合金含量高、耐磨性差、焊接性能差和无法折弯成型难题,东北大学与华菱涟钢、南京钢铁及新宏昌、十堰驰田、河南骏通等企业协同合作,充分利用微合金及铁碳化合物析出强化多重复合作用,降低碳含量和合金元素,减少脆性相孪晶马氏体组织,提出硬度、韧性和超硬析出物协同控制增强耐磨性的方法,实现新型超高强韧耐磨钢板在低温韧性、焊接性、折弯成型性和耐磨性等多个方面的突破;基于此,开发成功系列新型超高强韧耐磨钢产品和关键制备技术,满足了下游装备制造业用材亟需。研发的自卸车车厢用极限薄规格耐磨钢板最薄达2 mm,具有良好的折弯成型能力,同时兼具高强度、高硬度,能够实现自卸车型车厢直接折弯成型,获中钢协2018 年市场开拓奖。经新宏昌、十堰驰田、河南骏通等装备制造企业实际应用验证,采用 NM40/NM450/NM50 加工的 型矿用自卸车与原车型相比,不但能够显著提高车辆使用寿命(车身寿命提高50%\~30 %),而且还可以使车厢重量显著降低(在传统使用普碳钢或者高强钢的基础上,车厢减重可达 50% 左右[94-97])。

# 6.1.4 大型压路机振轮用超高强韧耐磨钢板协同研制开发与应用

压路机振轮的选材通常为低合金钢Q35 ,其良好的塑性和加工性能满足了压路机振轮辊压圈圆、焊接成型的工艺要求。但 Q35 振轮在长期的使用中,存在着强度不足的问题,容易发生变形,无法应对砾石路面的平整工作,且硬度不足,耐磨性较差,振轮磨损严重导致压路机整体寿命较短。为解决压路机振轮强度、硬度较低的问题,工程机械制造商提出采用低合金耐磨钢制造压路机振轮。为满足压路机振轮使用条件,选用的低合金耐磨钢不仅需要高强度及高硬度,同时还要兼具良好的冷弯性能、焊接性能及良好的韧性。

为此,东北大学、河钢集团邯钢公司、无锡大明及徐工集团等企业协同合作,开展了压路机振轮用超高强韧耐磨钢板的研制开发。在低合金耐磨钢基础上进行化学成分调整,通过微合金化和 Cr、、 等元素合金化协同设计,结合马氏体亚结构组织调控,开发出具有高强度、高硬度、优异焊接性能和良好低温冲击韧性的低合金高强度耐磨钢板[98-99]。该类钢板突破了传统耐磨钢板无法大角度折弯成型、成型后焊接接头高强韧匹配、焊接接头在圈圆和回圆过程中不开裂、焊缝在大载荷疲劳振动磨损不开裂和失效等多项难题,研发的超高强韧耐磨钢经徐工集团在严酷环境下近两年的实际应用验证,满足了大型压路机在苛刻工况环境应用的需求,显著提高了振轮耐磨性及使用寿命[100-101]。

# 6.2 工程机械用钢全生命周期循环利用策略探讨

我国的工程机械用钢经过近年来的迅速发展,无论是从产品级别还是规格、种类等方面,均满足了国内工程机械制造企业的需求,且我国工程机械产业相对比较集中,工程机械制造所用的钢铁材料大部分属于高洁净度和高附加值的产品,具有极高的回收和循环利用优势。在 全球工程机械制造商50强榜单中,中国企业占据13家,成为入选企业最多的国家,徐工集团、三一重工、中联重科则连续多年占据全球榜单10强位置。因此,只要抓住龙头企业,建立回收利用规范和标准,就可以较好地实现全产业链的循环利用。目前,国内还未见专门针对工程机械行业的拆解回收利用的企业,大部分情况是将工程机械归类为汽车行业的拆解和回收,未能有效地实现工程机械用钢的全生命周期循环。

工程机械用钢的强度相对较高,且品种种类相对较少,大部分均是高洁净度和高合金产品,分类回收相对较为容易,在工程机械的零部件制造中,大部分依靠折弯成型,并进行焊接或铆接连接,可拆解,比较易于循环和回收利用。在未来,建议进行工程机械用钢全生命周期循环利用策略的考虑,一方面,在产品研发和生产时,采用钢中合并归一化的合金成分设计,通过不同的工艺实现一钢多级或一钢多能[102],从而实现工程机械所需的性能的同时,大幅减少工程机械用钢的种类,有利于在回收利用时钢铁材料合金的利用和统一;另一方面,在生产和使用过程中,建立工程机械用钢专门的全流程全生命周期的数字化归类和标识,并在后续回收过程中,利用大数据和智能拆解利用装备的优势,进行工程机械用钢的分类回收和有效利用。通过上述方法,最终建立工程机械特有的钢铁材料全生命周期循环利用流程,支撑我国工程机械和钢铁工业高质量的发展。

# 7 结语

在国家“十四五”发展规划布局中,制造业转型升级对钢材性能提出了前所未有的严苛要求,推动着我国热轧钢材质量向更高层次发展。近年来,我国对制造业数字化转型的战略需求使得钢铁行业对产品高质化、工艺绿色化和装备智能化的发展有了更深层次的认识和目标。我国钢铁行业经过多年的努力,目前大多数钢种已经实现了自主保障,有些钢种甚至达到了国际领先水平,在钢铁材料生产和性能控制方面,也已经积累了大量理论和实验数据并对钢铁材料的强韧化机理有了深刻认识。因此,基于智能制造的数字化转型,自主研发并突破关键核心生产技术以及重大装备,以更好满足我国重大工程建设领域的需求,是非常必要的,也是完全可行的。
