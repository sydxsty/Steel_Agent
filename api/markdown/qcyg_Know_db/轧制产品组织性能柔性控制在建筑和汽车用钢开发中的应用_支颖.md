# 1.3 超细晶粒钢组织性能柔性控制的作用和应用实例

超细晶粒钢是通过提高钢的洁净度、细晶化和均匀性,使普通结构钢在保证其他性能要求的前提下,大幅度提高强度,从而提高性能。超细晶粒钢的出现使我国建筑结构钢质量大幅度提升,实现了钢材性能的升级换代。

将细晶强化和相变强化相结合,是大幅度提高钢材性能的有效措施。组织性能柔性控制在超细晶粒棒线材、超细晶粒中厚板及超细晶粒热轧带钢的开发中起到了关键作用。按照 公式,要使屈服强度提高到 MPa级以上,如果单纯依靠晶粒细化手段,铁素体晶粒应该细化至1\~2 m,这对于当时生产条件来说难度很大;另外,当晶粒细化到2μm 时,材料加工硬化能力变差,从而导致屈强比升高,使材料在应用上受到限制[3,6]。对于50 MPa级超细晶粒钢,需要采取其他强化手段,例如复合强化,即一方面要利用细晶强化,另一方面希望得到一定量的贝氏体组织,起到相变强化作用,因此需要对轧后冷却过程的中温转变进行更为精细的控制[6]。

在本世纪初,东北大学和宝钢、本钢、鞍钢等合作开发了性能达到 500 级超细晶粒热轧带钢[10-11]。下面以 级超细晶粒钢为例,介绍其组织性能柔性控制的具体做法[11]。
