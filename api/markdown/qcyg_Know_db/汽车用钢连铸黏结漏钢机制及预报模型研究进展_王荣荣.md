随着汽车需求的增加，钢材作为汽车生产的重要原料之一，备受企业和社会的关注，连铸作为钢材冶炼过程的重要工序，其生产过程中的黏结漏钢事故影响因素众多且较为复杂。随着冶金技术的发展，国内外越来越多的学者开始关注连铸的高效与安全生产。漏钢是连铸工序中经常发生的安全生产事故［1］，其中，黏结漏钢约占连铸漏钢事故的70％［2－4］。钢液的泄漏会引起灼烫、火灾等安全事故，并且发生漏钢后，钢液会从结晶器流入二冷区，在二冷区的喷淋装置作用下，高温钢液与冷却水直接接触发生爆炸［5］。漏钢事故的发生会影响铸坯质量、造成巨大的经济损失以及人员的伤亡［6－7］。

黏结漏钢的影响因素较多，并且各个因素之间存在一定的关联性，它们之间通过一定的耦合产生连锁反应，最终引发了黏结漏钢事故［8］。通过对黏结漏钢的形成机制进行研究，有助于更深入直观地了解事故发生的本质，为黏结漏钢预报模型的建立提供基础。黏结漏钢征兆的检测方法有许多，包括结晶器热交换分析法、热电偶检测法、摩擦力检测法、振动波型分析法等［9］。但是，热电偶检测法因具备实时监测、实时报警、准确性较高等特点在国内外得到广泛应用。近年来，伴随着机器学习的快速发展，越来越多的学者利用其鲁棒性、容错性以及较强的自适应能力等优点，开发了基于机器学习的漏钢预报模型［10－11］。该方法有效地解决了复杂的非线性问题，为提高黏结漏钢预报模型的准确率做出了贡献，未来漏钢预报模型将不断向智能化、高端化的方向发展。

为从源头上降低和消除连铸生产过程中黏结漏钢事故的发生，本文对连铸黏结漏钢的形成机制、影响因素、漏钢预报模型进行了分析和总结，旨在从源头上降低和消除连铸生产过程中黏结漏钢事故的发生。

# cd: 结晶器黏结漏钢形成机制的研究进展

杨俊锋等［12］认为黏结漏钢的形成机制是由于受到拉速的快速变化、结晶器液面异常波动等各种因素的影响，导致保护渣液渣向结晶器与坯壳之间的流入受阻，坯壳润滑发生变化，钢液直接与结晶器铜板接触并快速形成热点，从而产生黏结。胡志刚等［13］认为黏结漏钢的形成是由于弯月面受损，从而形成夹渣、黏结，具体原因分为内因和外因，外因是由于拉速过快或变化过大引起液面波动，导致弯月面出现破损；内因是由于钢液表面张力降低、弯月面强度下降，产生破损。吕爱强等［14］认为影响黏结漏钢的因素主要为保护渣性能、振动方式、铸坯无鼓肚、工艺操作水平。周青峰等［15］通过观察高碳钢漏钢坯壳组织形貌，分析其在结晶器中运动规律，发现坯壳厚度沿拉坯方向逐渐减小，漏钢坯壳振痕紊乱呈倒 V型，为典型的黏结漏钢。黏结漏钢是连铸生产中的重大恶性事故，20世纪90年代以来，国内外大量学者针对连铸黏结的形成、扩散行为以及形成机制等进行了大量研究［16－17］，普遍认为导致黏结漏钢的因素有很多，但其根本原因是由于钢水和连铸结晶器内壁直接接触，在弯月面处形成黏结点，此时在连铸结晶器振动和拉坯机拉力的共同作用下引发黏结性漏钢事故［18－19］。

图1所示为连铸黏结性漏钢的形成过程［20］。如图1（a）所示，由于某种原因导致保护渣与结晶器直接接触并在弯月面附近形成了黏结点。此时厚度不均匀的初生坯壳在结晶器的振动和拉坯机的拉力作用下，由于不能承受拉力和钢水静压力的共同作用，新凝固铸坯的最薄弱处发生断裂。如图1（b）所示，在结晶器的振动作用下钢水重新流入断裂坯壳间隙，此时钢水在冷却作用下会使断裂坯壳重新凝固形成新的薄坯壳。如图1（c）、（d）所示，此时结晶器继续向上、下振动，新凝固的薄坯壳的强度仍无法承受拉力作用，愈合部位会再次发生开裂。所以在结晶器振动和钢水凝固作用下，坯壳在被拉出结晶器之前一直重复着凝固和愈合的过程，并且坯壳与结晶器发生相对运动。如图1（e）所示，薄坯壳相对于结晶器来说发生着向下的相对运动，当坯壳被拉出结晶器后，会在断裂处引发黏结性漏钢事故。图2所示为发生黏结时铸坯表面的宏观形貌，可以看出铸坯表面有明显的 V型扩展裂纹。

黏结漏钢机制的研究为连铸的安全生产奠定了基础，结合黏结漏钢的发生机制，需要对其影响因素进行深入分析，如保护渣的优化，选择合理的保护渣充分保证其流动性并且控制好结晶器中钢液的液位以及稳定性，使足够多的保护渣流入结晶器和铸坯之间的空隙，以发挥其润滑作用，防止钢水在弯月面处发生黏结。以及根据不同的钢种和连铸机设备选择最优的结晶器振动参数和拉速，保证铸坯厚度均匀，在拉出时不存在应力集中点，在保障铸坯质量的同时减少黏结漏钢事故。在明确黏结漏钢的形成机制后，本文将对其影响因素进行详细的分析，全面剖析各个因素对黏结漏钢的影响，将影响因素与漏钢机制相结合，构建一套全方位的漏钢预报系统是连铸安全防控的发展方向。

# 2 结晶器黏结漏钢影响因素剖析

黏结漏钢的形成原因具有多样性，其影响因素有多种，具体可从结晶器参数、保护渣性能、钢液条件以及人员操作等方面分析。如图3所示，可分为这几个方面：保护渣的性能、钢的过热度和钢水成分、结晶器的振动频率和振幅等参数、人员操作等。这些因素的变化和不合理控制会直接或间接影响到初生坯壳厚度的均匀性、结晶器的传热性和结晶器内液面的稳定性，造成初生铸坯厚度的不均匀，导致钢水和结晶器内壁直接接触发生黏结漏钢事故。

# 2．1 保护渣的性能

保护渣在连铸生产中具有重要作用，主要表现在具有一定的绝热保温、防止二次氧化、吸收夹杂物的作用，并且可以起到润滑坯壳与结晶器铜管从而减少摩擦力，防止黏结漏钢事故的产生［21－23］。冉辉等［24］认为弯月面附近的熔渣厚度、温度、黏度以及流速的不均匀会引起渣膜厚度、温度的不均匀，进而造成局部应力产生裂纹源，发生漏钢事故。如图4所示，宋佳友等［25］针对SPA－H钢种使用的 A、B型2种保护渣性能对黏结漏钢率的影响进行了研究，认为当保护渣的碱度、黏度、熔点和熔速不合理时会阻碍保护渣发挥作用。如表1所示，C渣是优化后的保护渣，在保证铸坯质量的前提下，降低了碱度、熔 点、黏 度，提 高 了 熔 速，此 时 渣 耗 量 由0．4kg／t提高至 0．43kg／t。如表 2 所示，李 继等［26］通过提高碱度、降低黏度，在保证足够液渣层厚度的前提下降低配碳，得到优化后的保护渣效果见表3，经现场使用后优化方案2的液渣层和耗渣量均符合现场要求，解决了原保护渣消耗量低、易变性的问题。崔拓［27］通过调整保护渣碱度、黏度以及熔速等参数使其满足了生产要求，见表4，优化前3种保护渣均无法满足本厂S40 钢浇注使用。如表5所示，通过调整保护渣成分、熔点、熔速以及黏度，得到优化后的 XX－3D保护渣在生产过程中，坯壳在结晶器内的传热以及润滑得到了有效改善，渣耗稳定、热流稳定，窄宽比为0．9，渣膜厚度均匀，且黏结漏钢事故明显下降。KAJITANI等［28］研究了结晶器保护渣中羟基离子对结晶器传热和润滑的影响，发现大气中的水蒸气以羟基离子的形式被结晶器内钢液所吸收，羟基离子难以被还原并在保护渣内形成 H2O气体微孔。根据新机制研制了SiO2活性较低的保护渣，在应用之后成功降低了黏结漏钢事故的发生。

# 2．2 钢液条件

钢液的洁净度、过热度以及钢液中气体含量的多少等都会对连铸生产的顺利进行产生一定的影响［29－30］。王红军等［31］发现钢液洁净度会直接影响保护渣的润滑效果，当钢液中含有夹杂物，特别是含有B类夹杂物时，大量氧化铝不能及时充分上浮，使钢液黏度增大、流动性变差最终导致黏结漏钢。宋佳友等［25］发现钢水过热度的高低会影响保护渣的熔化效果，如图5所示，研究发现SPA－H 钢种在生产时黏结率随着过热度的升高而逐渐降低，过热度大于30℃时，SPA－H 钢种在浇注时的黏结率有轻微升高趋势。钢液中的气体控制也很关键，王伟宏等［32］发现钢水过热度提高10℃时，坯壳厚度会降低约2mm，并且即使炉后脱氧大大降低了钢液中的C－O反应，但当钢液后吹严重并且脱氧不良时，结晶器内会发生大量的 C－O反应，此时钢液中会产生 CO气体。这些气体严重降低了润滑条件、破坏了渣膜，从而使初生坯壳与结晶器铜壁接触面积增大，坯壳强度难以承受摩擦力的增加，最终导致黏结漏钢。因此，钢液过热度要控制在合理范围，同时去除钢液中的夹杂物，特别是B类夹杂物，以保证钢液洁净度，钢液过热度较低时，结晶器内的钢液温度也会随之降低，此时保护渣的熔化效果不佳、液渣层变薄，粉渣层变厚，当拉速到达一定临界值时，保护渣无法有效地发挥作用，同时夹杂物过多时，大量氧化铝不能及时充分上浮，使钢液黏度增大、流动性变差，极易发生黏结漏钢。

# 2．3 结晶器参数

结晶器振动装置的主要功能是在设定的振幅、频率和波形弧线条件下，使结晶器按照合理的参数进行振动，进而保证连铸生产的安全进行［33－34］。当结晶器的振动频率、振幅参数选择不合理时，结晶器无负滑脱或负滑脱小会造成漏钢［35－37］。结晶器振动参数不合理、钢液面波动较大，具体体现为振痕的深浅和间距。铸坯表面振痕紊乱，薄厚不均匀会影响铸坯质量，使坯壳的有效受力面积减少、受力不均匀，在拉坯拉力和钢水静压力作用下发生黏结漏钢事故［38］。

铸坯在被拉出结晶器之前，伴随着拉坯机拉力和结晶器振动的影响，一直与结晶器发生相对运动，在结晶器的一个振动周期内相对运动可分为正滑脱和负滑脱2个阶段，而相对运动的速度和渣膜厚度直接影响着结晶器内部铸坯与铜板之间的摩

擦力。

孙华平等［39］分析了结晶器振幅对振痕深度的影响，振痕的深浅会影响到铸坯的脱膜，振痕越浅越不利于脱膜，易诱发坯壳黏结。如图6和表6所示，在其他条件不变的情况下，模拟计算了5．8、5．2、4．8mm的3个振幅h下的渣道和弯月面所受压力以及负滑脱时间、负滑脱率大小。发现随着振幅的减小，渣道与弯月面所受的正负压力、负滑脱时间和负滑脱率均减小，振痕深度将随之减小。李继等［26］通过将振幅由±2．5mm提高到±3．5mm，同时降低频率，实现了正滑脱时间的提高保证了铸坯的脱膜。宋佳友等［25］发现结晶器窄面锥度的大小会影响保护渣流入的均匀性，进而影响保护渣的润滑效果，增大黏结漏钢概率，如图7所示，探究了在相同断面、不同锥度下SPA－H 黏结概率的大小，发现黏结率随着锥度的增大而升高。席常锁和吕晓军等［40］研究认为结晶器振动机械装置的好坏是预防黏结漏钢的关键，并根据结晶器振动频率、振幅、偏摆及轨迹等参数开发设计了一种便携式板坯连铸结晶振动检测装置，在国内某厂应用之后实现了黏结漏钢从6次／月的频率降低到0～1 次／月。因此，结晶器采用合理的锥度角和振动参数，针对不同成分的钢种选择合理的结晶器振动参数，并且结晶器振动参数要与拉坯速度等其他参数进行合理的匹配，通过优化工艺来达到稳定振痕深度、减少结晶器摩擦阻力，能够降低连铸的黏结漏钢次数，实现连铸的安全高效化生产。

# 2．4 人员操作

现场工作人员的规范操作对结晶器漏钢事故的预防起到很关键的作用。工作人员要按照设备安全运行参数进行巡查和及时纠错，不及时发现并纠正问题和异常就会造成不同程度的事故［40］。例如结晶器水口不对中、钢液位波动过高、拉坯速度不稳定、渣圈打捞不及时、水口堵塞或者机械折断等问题，不能得到及时解决时，轻则影响铸坯质量，重则造成漏钢事故导致生产中断和人员伤亡［41］。

孙华平等［39］分析了拉速对振痕深度的影响，如图6和表6所示，在其他条件不变的情况下，模拟计算了1．4、1．6、1．8m／min的3个拉坯速度下的渣道和弯月面所受压力以及负滑脱时间、负滑脱率大小。随拉坯速度增大，最大正压力减小，而最大负压力增大，负滑脱时间和负滑脱率变小，振痕深度将随之减小。李继等［26］通过采取液面控制系统，将液面波动值由±10 mm降至±5 mm，同时优化升降拉速制度，将升降拉速0．05m／min变动时间由不小于30s调整为不小于45s，以确保液面的稳定性，降低了黏结漏钢事故的发生。孟阳［42］发现水口的对中情况会影响到保护渣的润滑效果，当水口不对中时会导致结晶器内钢水活跃性不一致，造成保护渣熔化和流入不均匀进而造成黏结，并且水口插入深浅也会影响到液渣的流入情况，一般规定水口插入深度要控制在30～90 mm。

当结晶器水口不对中时，会发生铸坯壳薄厚不均匀，这是由于结晶器中的钢液冷却不均所致，在受到一定外力作用和钢水静压力下产生漏钢。钢液位波动过高时，为了保证铸坯质量和生产稳定性，要控制拉坯机以固定的速度稳定运行，当拉坯速度不稳定，会使钢水产生剧烈的波动，此时保护渣的正常三层结构和液渣层的均匀性会因为钢液面波动而破坏，从而导致熔渣的不均匀，使钢液与结晶器内壁直接接触发生黏结漏钢。并且结晶器中钢液面波动过于剧烈时易产生卷渣现象，导致未融化的保护渣进入坯壳和结晶器间隙中进而阻碍液渣的流入、堵塞液渣的通道，影响保护渣发挥作用，发生黏结漏钢事故。因此需要合理控制拉坯的速度，拉速的不稳定会直接影响到液面的大幅度波动，要保证拉速、液面等维持在一个稳定状态，液面过高时要适当的降低拉速，并且及时打捞渣圈、定期检查水口是否对中，以保证生产的安全进行。

# 3 结晶器黏结漏钢预报模型及应用

# 3．1 黏结漏钢征兆的检测方法

自20世纪70年代起，国外已有专家对漏钢预报做出了初步研究，对漏钢征兆的检测方法有了初步认识，如热交换分析法、热电偶检测法、振动波型分析法、超声波探测法等［43－44］。对这几种检测方法进行了详细的总结见表7。

以上各检测方法中，热电偶检测法在国内外应用最为广泛，该方法具备实时监测、实时报警、维护方便、准确性较高等特点。目前热电偶检测法的判别原理基本可以概括为以下3种：使用统计分析方法进行温度模式识别；使用逻辑分析方法进行温度模式识别；以及使用神经网络模式识别功能进行温度波动特征识别。

# 3．2 基于热电偶的漏钢预报模型

20世纪80年代，基于热电偶的漏钢预报技术在全球各大板坯连铸机上被广泛应用。该技术就是基于热电偶检测法来实现的，通过埋设多个热电偶，实时监测铜板表面温度变化，从而判别是否满足漏钢特征，通过对漏钢机理进行分析和数据的定量、定性分析进而形成逻辑条件来判别漏钢。如图8所示，产生黏结点之后，在拉坯力的作用下坯壳断裂处逐渐向下运动，对应位置的热电偶温度也会相应升高，热电偶的漏钢预报模型原理既根据结晶器上安装的热电偶所测得的温度变化情况来检测是否存在漏钢的可能性。

# 3．2．1 逻辑判断漏钢预报模型

早期以逻辑判断为基础的预报系统有新日铁Otia工厂、住友金属、英国钢铁、SolacFos等，漏钢预报系统基本都是基于纵向传播检测为主。通过对热电偶测温法的研究发现，当钢水中存在破裂时，破裂线在横向传播方向上的速度比在纵向上快。因此，人们开发了以横向传播检测为主的漏钢预报系统。基于该理论日本川崎钢铁公司千叶工厂开发了漏钢检测技术，在其3号板坯连铸机上成功应用并取得了很好的效果。如图9所示，逻辑判断模型分为点、线、面判断模型，根据热电偶的温度来计算相应的温度变化速率和传播时间等参数信息，最后计算出阈值，当热电偶所测温度的变化超过设定阈值后，模型就会发生报警。逻辑判断模型多是基于黏结机制、连铸设备工艺参数、工艺流程和操作等不同情况建立的预报模型，并且各个参数没有统一的标准，设定的最佳值需要根据工作经验进行现场调试，这就导致逻辑判断模型的准确性不高，所受影响因素过多，容易产生误报现象。

Md　OBAIDUL AH 等［50］研究了基于逻辑的新型漏钢预测系统（BOPS），不仅可以识别黏结漏钢，还可以检测由于拉速变化、液位波动和锥度等问题而发生的漏钢，该系统还可以找到黏结的确切位置，降低误报率。刘怡等［51］利用黏结裂口的扩展方式并结合热电偶温度的变化趋势，通过大量数据来进行人工计算相应的参数和阈值，建立逻辑判断漏钢预报系统。HE等［52］开发了一种新型逻辑判断漏钢预报模型，该模型通过布置多排热电偶利用相邻热电偶温度的变化率和时间滞后性以及水平和垂直检测来实现预报，结果表明能够达到较好的预报效果。高宇等［53］开发了一种基于逻辑判断的漏钢预报模型，该模型利用黏结点面传播的规律来实现模型的判别和预报。并开发了相应的预报系统，经实际生产验证，该专家系统对黏结漏钢的报出率为10 ％，预报准确率为818％。逻辑判断漏钢预报模型是由专业人员根据现场的工艺参数和设备条件来进行模型的调整和设定，该过程具有较强的主观性，并且模型需要根据实际生产条件的不同进行相应的调整。

# 3．2．2 基于机器学习的漏钢预报模型

20 世纪90年代起，人工神经网络技术因为其鲁棒性、容错性以及自适应能力逐渐引入到漏钢预报系统，采用人工神经网络技术建立的漏钢预报模型［41，54］，通过对连铸生产数据进行归一化处理，并将数据随机分为训练数据和测试数据2大类，并完成神经网络的误差优化和训练学习，BP神经网络是一种通过不断调整网络参数、优化误差来训练模型的机器学习算法。在训练过程中，通过反向传播算法来计算网络误差，并根据误差大小来更新网络中的权重和偏置等参数，以提高模型的准确性。最终，在完成训练后，使用测试数据来检验模型的准确性，图10所示为BP神经网络算法的整个流程，包括数据输入、误差计算、参数更新等步骤。

如图1 所示，基于机器学习的漏钢预报模型中采用不同的算法来达到机器学习的目地，机器学习对于逻辑判断来说可以处理复杂的非线性问题［55］，利用单偶时序网络和组偶空间网络来对温度曲线进行识别，当预测到漏钢征兆的波形时，通过算法的学习，系统会自动发出警报信息。是对热电偶所测的温度曲线变化特征进行判断，即对动态波形的模型进行识别的过程。基于机器学习的漏钢预报模型通过选取实际的连铸生产数据进行模型的训练和测试，根据热电偶温度幅度的变化，将数据分为正常数据、报警数据和不良数据3类，然后剔除不良数据。将保留的数据随机分为训练数据和测试数据，并设定报警阈值，当超出设定阈值时，模型将会报警。

# 4 结论及展望

1）连铸正常生产过程中会引发黏结漏钢事故，造成钢液的泄漏，当铸坯在弯月面附近与结晶器铜板直接接触时，会产生黏结点。在拉坯力和结晶器的振动条件下，坯壳不断重复着开裂与愈合的过程，当坯壳被拉出结晶器之前，开裂处未完全愈合或厚度无法满足钢水静压力和拉力的作用时，钢水会从坯壳中流出，造成黏结漏钢事故。结晶器是一个涉及多元多相反应的“黑匣子”，连铸黏结漏钢是多种因素互相作用的结果，目前虽有对连铸黏结漏钢形成机理的研究，但是想要从根本上解决漏钢问题还需要继续深入研究形成机制，并与漏钢预报模型相结合来达到更好的预防效果。

2）保护渣性能、钢液条件、结晶器参数以及人员操作等都会对连铸黏结漏钢事故产生一定程度的影响。保护渣性能不合理时会影响铸坯与结晶器之间的润滑效果；钢液条件不好会导致钢液黏度增大、流动性变差；结晶器参数设定以及人员操作不合理会造成液面波动不稳定、新生坯壳的厚度不均匀甚至影响保护渣发挥作用，这些因素之间也相互影响，最终导致黏结漏钢事故。因此，全面剖析各个因素对黏结漏钢的影响程度，将工艺制度、人员操作、钢液条件与漏钢预报模型相结合，构建一套全方位的漏钢预报系统是连铸安全防控的发展方向。

3）针对漏钢征兆的检测方法有许多，目前在国内外用于预测黏结漏钢的主要方法是热电偶测温法，包括逻辑判断漏钢预报模型和基于机器学习的漏钢预报模型。其中逻辑判断漏钢预报模型是由专业人员根据现场的工艺参数和设备条件来进行模型的调整和设定，该过程具有较强的主观性，并且模型需要根据实际生产条件的不同进行相应的调整。基于机器学习的漏钢预报模型主要是利用人工神经网络等算法来实现黏结漏钢预报，通过现场实际运行数据实现对网络模型的训练和调整，避免了主观干扰，但是，该模型对样本数据的要求也较高，需要大量的训练数据来确保模型的准确性，同时需要筛除部分错误数据和误差数据来保证网络的判断准确性，常采用多种算法结合的方式来实现神经网络权值和阈值的优化，进而提高漏钢预报模型的准确性。目前，普遍将逻辑判断与机器学习两种方法相结合来建立漏钢预报系统，该系统最大程度上发挥了两者的优点、提高了系统的准确率，未来漏钢预报系统将不断向多元化、智能化的方向发展。

# 《钢铁研究学报》征稿启事

《钢铁研究学报》是由中国钢铁工业协会主管，中国钢研科技集团有限公司主办的冶金类学术期刊刊物（CN　1－213／TF；IS N　101－0963），是中国冶金界很有影响力的学术性刊物之一。自1981年创刊以来，先后多次在全国和冶金科技期刊评比中获奖。连续多年入选中文核心期刊和中国科技论文统计源期刊，被国内许多著名检索刊物及数据库收录。 现任主编为干勇院士，殷瑞钰院士为名誉主编。

# 征稿对象

在科研单位、大专院校、生产企业、技术监督、质检商检等部门从事钢铁材料研究、生产、加工和使用的专家、学者、工程技术人员、研究生、管理人员等。

# 2 征稿范围

# （1）冶金与金属加工

冶金工业节能环保、冶金资源综合利用、炼铁、炼钢、连铸、铸造、凝固、锻压、轧制及后续热处理、冶金物理化学、钢铁冶金新工艺等。

# （2）材料科学与技术

金属基材料，涵盖但不限于：先进钢铁材料、高品质特殊钢、高温合金、新一代金属间化合物、金属功能材料、粉末冶金材料、结构用钛合金、功能与结构复合型材料、非晶与高熵合金、金属纳米材料等的基础研究，腐蚀、焊接、摩擦磨损、疲劳断裂等性能研究。
