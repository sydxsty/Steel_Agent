# EH420 海工钢低温 J 积分断裂韧性

叶其斌1，曲锦波1

（1. 江苏省(沙钢)钢铁研究院, 江苏张家港 215625）

摘 要：深海导管架海洋油气开采平台发展， 提出了对大厚度 EH420 高强度海工钢的新需求。 采用更高强度钢增加了结构断裂风险， 需要研究清楚升级材料断裂行为。在现行海工钢标准规范中考核低温断裂韧性，除了常规小尺寸夏比冲击外，还需要进行大尺寸试样的裂纹尖端张开位移 （CTOD） 评价。与 CTOD 相比， J 积分断裂韧性更适合评估高塑性变形与非线性断裂行为， 但却很少用于大厚度高强高韧海工钢。

本文以 80mm 厚度EH420 海工钢为研究对象， 分析了强塑性、动态夏比冲击韧性和弹塑性断裂韧性 （KJic），并重点分析了低温下动态冲击载荷和准静态载荷下裂纹扩展机制。采用 ISO 12135 准静态断裂韧性实验方法，从钢板心部取纵向试样， 加工 30×50×270mm 的 SENB 试样， 初始缺口深度 27mm， 采用疲劳预制尖锐裂纹 8 mm， 分别在室温、-20°C 和-40°C 条件下用三点弯曲循环压载荷， 获得不同温度的 J-R 曲线。 主要研究结果有： （1） EH420 海工钢显微组织类型由多边形铁素体、针状铁素体、贝氏体以及M/A 岛组成， EBSD 和TEM 结果显示基体具有较高的晶界密度和纳米级(Nb,Ti)(C,N)的析出。（2）准静态单轴拉伸结果表明， 实验钢室温屈服强度为 462 MPa、抗拉强度 587，断后伸长率 28.5%， 具有较好的强塑性匹配。动态夏比冲击试验结果表明， 实验钢-40 ℃冲击功达到 433J、 358J 和 335 J。（3）基于弹塑性断裂力学 J-R 曲线分析结果表明， EH420 海工钢在尖锐疲劳裂纹和低温条件下仍然具有优异的止裂性能。所有温度实验过程压力载荷均无明显下降，其中-40℃的 JIC=1253 kJ/m1/2、 KJIC=533MPa.m1/2， 断裂韧性仅比室温下降 9.8%。断裂韧性随温度下降主要是因为基体位错的移动能力下降。（4）实验钢微观组织中恰当的复相配比和弥散分布的球状 M-A 是其低温下仍具有高抗裂韧性的主要原因。其中， 贝氏体和铁素体的复相组织在保证了实验钢具有较好的强塑性匹配。 而贝氏体板条状的形态使得裂纹在穿过不同取向的板条时会发生偏折，提高了裂纹扩展路径； 铁素体良好的加工硬化能力可以钝化裂纹尖端。此外，球状和点状的 M/A 岛周围较高的位错密度可以有效提供位错源， 促进材料的塑性变形， 同时能阻碍裂纹扩展。

以上研究结果表明， 沙钢生产 EH420 海工钢具有优异的低温断裂韧性， 可满足大型海洋平 关键结构的可靠性和安全性要求。而相关机理分析表明， 进一步优化贝氏体铁素体比例以及 M/A 岛形态是优化大厚度海工钢低温断裂韧性的有效手段。
