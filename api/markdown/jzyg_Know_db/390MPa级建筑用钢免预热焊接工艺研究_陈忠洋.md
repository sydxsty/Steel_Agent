# 摘要

焊接是建筑结构用钢连接的主要方式，免预热焊接是绿色节能、提高生产效率、保证焊接接头性能的有效措施。本文主要采用热模拟和实焊验证的方法，研究了不同碳含量（0.15%和0.07%，质量百分数）的390MPa级建筑用钢在不同焊接模拟工艺下的组织性能演变规律，重点探讨了预热、层间温度对热影响区 (Heat AffectedZone，简称HAZ) 的淬硬倾向、软化、冲击韧性等影响规律，最终确定两种实验钢的最佳焊接工艺及预热温度，主要成果如下：

（1）通过焊接热影响区连续冷却转变实验测定了两种钢的SH-CCT (SimulatedHAZ Continuous Cooling Transformation）曲线，结果表明：0.07%C实验钢降低了马氏体组织生成的趋势，不同1815条件下主要生成贝氏体和铁素体组织，减小了冷裂倾向。HAZ细晶区 (Fine Grained HAZ, 简称FGHAZ）的晶粒尺寸明显小于粗晶区(Coarse Grained HAZ, 简称CGHAZ) 晶粒尺寸，开始相变温度要高于粗晶区，趋向于高温转变。两种钢无论是粗晶区还是细晶区，随着t815时间的延长硬度均呈下降趋势，0.15%C实验钢在t8/s低于20s（对应热输入为16kJ/cm）时硬度大于350HV，存在明显的组织硬化现象， 而 0.07%℃ 实验钢热影响区最高硬度不超过350HV，淬硬倾向降低。

（2）采用热模拟的方法进行了不同热输入对焊接热影响区组织与性能影响的实验， 0.15%C 实验钢在线能量小于20kJ/cm时容易生成淬硬马氏体，0.07%C实验钢在低于40kJ/cm的线能量下为贝氏体组织，大于40kJ/cm时两种钢均出现包围晶粒的先共析铁素体组织，0.07%C实验钢粗晶区冲击性能要优于0.15%C实验钢。两种钢细晶区组织均较细小，以贝氏体和铁素体为主，冲击性能均高于150J，0.07%C实验钢冲击性能相对较好。

（3）通过理论计算预热温度和热模拟实验验证不同预热温度对热影响区组织性能影响，得出预热可以改善0.15%C实验钢产生淬硬马氏体的倾向，对提高0.15%C实验钢细晶区冲击性能效果明显。预热能够增加大角度晶界比例，提高冲击性能，但对晶粒尺寸较大的粗晶区没有明显的改善效果。 0.07%℃ 实验钢不同预热温度下冲击性能均大于47J， 明显优于0.15%C实验钢。

（4）利用热力模拟实验机进行了二次热循环实验，研究了不同碳含量钢二次峰值温度对粗晶区组织性能的影响。结果表明：二次峰值温度为1350C时，组织与一次热循环下的粗晶区组织相同， 为焊接接头薄弱区。二次峰值温度为 700°℃时

0.15%C 实验钢生成沿晶界呈链状分布的珠光体组织，恶化了焊接热影响区性能。而  
0.07%℃ 实验钢由于碳当量低，不易生成链状组织，性能显著提升。

（5）通过模拟不同一次预热温度和层间温度对二次热循环组织演变规律发现，一次预热温度能够改善粗晶区组织构成，有缓解淬硬倾向的作用。随着层间温度的增加，临界粗晶区 （Inter Critically Reheated Coarse Grained HAZ, 简称ICCGHAZ)中碳元素富集倾向增加，形成了较大的珠光体或碳化物的块状或团状组织， 分布于晶界和晶内。 0.07%C实验钢碳富集现象不明显， 减少了硬相组织的生成。

关键词： 建筑用钢； 焊接性能； 碳当量； 淬硬倾向； 预热温度； 热循环

# 第1章绪论

# 1.1 焊接的重要性

国民经济的快速增长，农村城镇化进程加快，带动了建筑结构用钢的迅猛发展。钢结构以其绿色环保、可循环回收、结构轻、土地利用率高、可工业化生产以及生产工期短等一系列优点，被称为“绿色建筑”的主要代表。国外在建筑用钢方面发展较早，二十世纪50年代欧洲开始兴起钢结构建筑I川1，因其优越的综合性能，在国内外迅速发展。纵观国内外著名的地震灾害事件，无疑传统房屋建设（特别是混凝土石砖、土木结构的建筑）造成了重大的人员伤害以及财产损失。1923年日本关东大地震给日本造成了颠覆性的遭难，日本也由此诞生了世界上最早的建筑抗震标准。1995年日本兵库县阪神大地震带给我们启示12.31，钢结构以其良好的抗震性能避免了直接的人员伤亡和经济损失，日本也更加提升力度发展结构钢，开发高性能特种建筑用钢。1976 年唐山大地震以及2008年汶川大地震是我国两次重大的地震伤亡事件，震后带来了不可挽回的重创。研究表明，钢结构建筑较土木结构和砖混结构住房具有良好的抗震性。 因此， 建筑用钢结构更新换代是大势所趋。

随着结构钢的稳健发展，钢结构建筑不断向高层化、大跨度、高强度级别发展。据统计，英国、芬兰等发达国家，建筑结构中的钢结构占比均超40%，日本、美国甚至达到50%以上，并且形成了较为健全的体系。反观中国钢结构用钢占比仍不足10%。日本由于地震频繁，对建筑用钢方面的经验充足，标准体系也较为健全。大体可以分三个层次共8个标准，包括一般结构用钢中的《JISG 3101—2010 普通结构用轧制钢材》、建筑结构专用钢材中的《JISG3138—2005 建筑结构用轧制钢材》、特殊性能建筑结构用钢中的《JISG 3199—2010 厚度方向性能钢板》[41等等。在产品系列以及性能上面要求也较为严格，例如具有低屈强比抗震性能优良的SN系列I5]，要求其屈强比不大于0.80， 屈服强度波动范围小于120MPa。由此可以看出日本在钢结构建筑上的重视与发展。相对日本的系列标准，我国在近些年也不断发展并加强了对高性能建筑用钢的要求。在GB/T 19879—2015 《建筑结构用钢板》中，强度级别最高增加到了Q690GJ，Q345GJ、 Q390GJ、 Q420GJ和Q460GJ屈强比分别由不大于0.83、0.85、0.85、0.85调整为0.80、 0.83、 0.83、0.83，对板厚以及质量等级也都做了相应的调整。由此可见， 我国在建筑结构用钢方面逐步向高强度级别以及高性能方向发展[6]。

钢材的发展必定会带动焊接工程的发展，在建筑工程中， 钢结构最主要的连接方式就是通过焊接来完成的。焊接作为建筑用钢施工的重要环节，焊接接头质量严重影响着钢结构今后的应用与发展。阪神大地震中结构钢建筑失效主要是由于焊接接头不合格而造成的[2.3]。随着建筑结构用钢的强度等级不断上升，焊接接头的问题也逐步显现。焊接接头硬化、脆化、焊接冷裂纹（氢致裂纹）、再热裂纹，焊接接头软化等焊接问题制约着高性能建筑用钢的应用。建筑用钢的焊接行为研究往往滞后于高强钢的开发[7]， 这就造成了特殊用高强结构钢在建筑设计中无法应用。

国外对高强度结构钢早已开始应用并形成系列化， 德国柏林 Sony Center 大楼使用了S460和S690钢材，日本横滨 LandmarkTower大厦应用 600MPa级钢材。我国钢结构的“十三五”规划目标，钢结构用钢材从目前的“Q235+Q345”为主，过渡到以“Q345+Q390”为主。天津津塔以及广州新电视塔等工程就选用了大量Q390GJ钢，中国尊为国内高强度钢材（主要是Q390GJ）用量最大、比例最高的建筑，国家体育场“鸟巢”更是首次应用了110mm厚的Q460EZ35系列钢材。新的高强结构钢焊接问题对我们来说是进步更是一次考验，值得一提的是，鸟巢的施工对焊接工程是前所未有的挑战更是划时代的机遇。鸟巢不仅使用了高强度钢种，而且整个钢结构为100%全焊接结构，不存在一个铆钉和螺钉，焊缝承载着所有的作用力并决定着整个结构的成败，由此焊接技术在钢结构中的重要性可见一斑。焊接免预热可以减少焊接工时，提高生产效率；高效环保，节约能源；简化生产条件，保证焊接接头性能稳定。因此，焊接免预热工艺研究，对指导焊接生产、促进焊接理论认知与发展有着重要的意义。

# 1.2 焊接热影响区的分类

# 1.2.1 一次热循环的 HAZ分类

焊接热影响区 （Heat Affected Zone, 简称HAZ）主要指熔化焊时，焊缝附近的母材在焊接过程中未熔化， 但是却受到了焊接热影响的部分。焊接时由于热影响区各位置与焊缝距离不同，各点经历的热循环也不同，主要是HAZ峰值温度（Tp）的不同，不同峰值温度区间形成不同的组织，这对HAZ的性能产生重要的影响。按照HAZ峰值温度范围通常将HAZ分为四个区域：熔合区、过热区、正火区、部分相变区。低碳钢经历不同热循环的 HAZ如图1.1所示。

熔合区 (Fusion Zone) 是距离焊缝最近的区域，熔合区的晶粒部分发生融化，焊缝金属凝固时在剩下的部分晶粒上形核长大。这个区域的母材由于温度接近熔化温度，晶粒发生严重长大。

过热区(Coarse Grained HAZ, 简称 CGHAZ）又称粗晶热影响区（简称粗晶区），峰值温度区间约为固相线以下至1100℃，粗晶区由于峰值温度高并且高温停留时间较长，奥氏体晶粒严重长大且晶粒尺寸大小不一。冷却时极容易生成淬硬组织（如马氏体、贝氏体以及魏氏组织等脆性组织）或产生微裂纹，从而成为焊接接头性能最薄弱的位置。

正火区 (Fine Grained HAZ, 简称FGHAZ）又称细晶热影响区（简称细晶区），峰值温度区间大约在Ac3\~1100°℃。 这部分组织由于峰值温度区间比粗晶区较低，母材组织发生完全重结晶（即基体组织全部发生奥氏体化），但是由于温度相对较低而来不及发生长大。所以细晶区的组织比较细小，冷却后一般会形成较为细小分布的等轴晶，相当于对母材进行了正火处理。因此拥有良好的塑性和韧性，是HAZ中性能最好的部位。

部分相变区 (Inter Critical HAZ, 简称ICHAZ）又称临界转变晶区，峰值温度区间为Ac1\~Ac3。由于这部分母材被加热至“α+γ”两相区，只有部分基体奥氏体化，故部分相变区又称不完全重结晶区。富碳的奥氏体在冷却过程中或者发生相变分解形成“细铁素体+珠光体+未转变铁素体”，或者由于奥氏体稳定性提高而推迟相变过程，最终形成M-A岛。 ICHAZ的组织大小不均，力学性能各异，同样容易成为焊接接头较为薄弱的部位。

# 1.3 HAZ 目前存在的主要问题

焊接热影响区（HAZ） 作为焊接接头最为薄弱的环节，一直是国内外研究者致力于研究的重要对象。由于生产工艺、母材的原始组织、母材强度、合金元素的添加以及热输入等因素的影响，HAZ较容易出现的问题主要有焊接热影响区脆化、硬化、软化、焊接冷裂纹以及焊接再热裂纹等问题。

# 1.3.1 HAZ脆化

HAZ脆化问题是焊接接头常见的问题，也是严重影响焊接接头质量的一类问题一般在低合金高强钢中较容易出现。HAZ脆化是指焊接热影响区由于焊接过程导致HAZ组织韧性急剧下降，容易发生脆性断裂及冷裂纹等问题。HAZ脆化一般伴随着硬化，HAZ硬化是指经过焊接热循环后，焊接热影响区组织硬度严重高于母材硬度的现象。为了避免焊接接头硬化、脆化，甚至冷裂纹的产生，一般（API5L-1997）规定焊接热影响区硬度不大于350HV10。HAZ脆化主要发生在CGHAZ位置，与母材强度、合金元素以及热输入等都有很大关系。母材强度越高、合金元素含量越多、热输入过大都容易造成HAZ的脆化问题。CGHAZ由于峰值温度高且高温停留时间长，奥氏体晶粒严重粗化，在焊接后的冷却过程中易生成大块状的铁素体或者魏氏组织和M-A组元， 导致HAZ的韧性下降I，从而引起焊接接头脆化。CGHAZ晶粒长大是导致焊接接头脆化的主要原因，为此发展了通过控制高温下奥氏体晶粒长大的技术来减小CGHAZ脆化。 日本新日铁应用CLC工艺， JFE应用JFEEWEL技术，均成功生产出了超低碳及低焊接裂纹敏感系数的具有优良HAZ韧性的钢种。神户制钢也通过KST技术，控制奥氏体晶粒粗化，减少M-A岛硬化组织，细化奥氏体晶粒内相变组织，改进了HAZ韧性[4]。通过AI元素以及微量合金元素的添加控制韧性组织的形成已经有较多的研究I121，日本最先通过氧化物治金技术实现了对焊接热影响区韧性的控制[13-15]，主要目标就是抑制奥氏体的异常长大，国内对氧化物冶金技术控制 HAZ韧性的研究116-19]也有了长足的研究进展。

# 1.3.2 HAZ冷裂纹

HAZ冷裂纹常常伴随着脆化共同出现，冷裂纹的产生同样易出现在焊接粗晶区。淬硬组织的产生，焊接残余应力以及扩散氢的控制等三方面因素严重影响冷裂纹的产生。由于焊接热影响区不同位置热履历不同因此其组织差别较大。在热应力和组织应力的综合影响下，HAZ易产生三向拉应力，特别是马氏体将大幅增加三向拉应力。当母材中含碳量与合金含量较大，淬硬倾向大，则易产生马氏体硬相组织，急剧降低焊接接头韧性。而且在CGHAZ的晶界容易产生M-A组元，这些较硬的M-A组元容易成为焊接冷裂纹形核扩展的裂纹源，严重影响HAZ性能。在高温条件下，扩散氢的扩散速度较快，所以焊缝中扩散氢容易向母材方向扩散。但是在HAZ中，越远离焊缝区域扩散氢就越不容易扩散，导致扩散氢在熔合线以及CGHAZ位置聚集。聚集的扩散氢容易结合成氢气从而产生某点位置的压力，促进焊接冷裂纹的形成。曹兴华[20]在对Q390低合金高强钢焊接性研究中发现，在未采取预热、层间温度、焊后热处理措施的情况下，焊后容易出现冷裂纹。分析其原因是晶粒长大、产生淬硬组织、热影响区组织不均匀造成的。

# 1.3.3 HAZ软化

HAZ软化问题同样是比较严重的问题，但有关这方面的研究较少，随着近些年钢铁制造技术和焊接技术的发展，特别是西气东输工程的应用[21,22]，HAZ软化问题凸显并逐渐受到了重视。HAZ软化同HAZ硬化相反，是指焊接过程焊缝两端的热影响区由于受到热循环的影响而产生硬度低于母材初始硬度的现象，宏观即表现为材料变软。而且母材强度越高， 软化问题就越明显。

相对于传统的调质 （淬火+回火） 工艺， TMCP工艺下的HAZ 软化行为备受关注[23-25]。 重结晶软化和母材回火软化是影响焊接接头软化的主要因素。

重结晶软化是指发生在焊接峰值温度在Ac1\~Ac3范围内的部分相变区，调质态和TMCP态钢在两相区温度范围内组织均会发生部分奥氏体逆相变，在此过程中将会发生元素（特别是碳元素）的扩散与重新分配，如果在焊接后的冷却过程中冷速较慢，逆相变奥氏体则会产生高温铁素体等软相组织，随后晶粒严重粗化，最终导致整体强硬度的下降。

碳含量和合金元素的减少会减小钢的淬透性，焊接过程中更易得到粗大铁素体组织而引起接头软化。陈小伟等人[261通过热模拟手段研究了Ceq对X80级管线钢焊接接头拉伸性能的影响，实验结果（如图1.4所示）表明，碳含量和合金含量的降低容易造成软化。宗彬[271研究发现，不完全重结晶会使基体以铁素体为主的组织中的碳化物体积分数下降，降低了析出强化效果，从而导致接头软化。另一方面，对同一种母材，焊接热输入越高，HAZ高温停留时间增长，奥氏体尺寸粗化严重，t8/5时间长，易得到粗大铁素体晶粒而产生软化现象。杨喜胜[281通过对调质30MnCrNiMoB 钢焊接接头软化行为的研究发现，母材的软化程度随热输入呈现基本线性关系。

母材回火软化主要发生在峰值温度处于Aci以下的温度区间，这时HAZ虽然没有发生相变但会发生晶格畸变减小（如固溶在马氏体中的碳原子以碳化物形式析出）或亚结构变化等行为，同样会发生HAZ软化。贾璐[29]结合TEM和 EBSD 等手段研究了X80级抗大变形管线钢的焊接软化行为， 实验表明，对于以贝氏体+铁素体为基体的X80级管线钢，高温回火区 （600\~700C），生成了大块状的铁素体和回火贝氏体而导致HAZ软化。高温回火温度加快了回复过程，组织亚结构减少而且位错密度显著降低，这些变化都导致了组织硬度的降低。有研究人员[21.30]设计了通过加速冷却的方法来改善HAZ组织性能， 从而避免焊接软化行为，但却容易出现HAZ硬化问题。

# 1.4 预热的目的与作用

在钢结构焊接过程中，焊前预热是常见工序。预热是指焊接前对被焊件进行加热升温至室温以上的工艺手段，分为局部预热与整体预热两种方式。整体预热适用于特厚或形状复杂，可将焊件整体放在加热炉内进行加热的焊件，一般采用炉内整体加热的方式；局部预热应用范围较广，主要有火焰加热、工频感应加热以及远红外电加热等加热方式。每种预热方式都有各自的特点及作用，不同的预热方式应根据实际情况而定。对于焊接强度级别较高、有淬硬倾向、导热性能特别良好或厚度较大的焊件，以及当焊接区域周围环境温度太低时，焊前往往需要对焊件进行预热以达到良好的焊接质量。

预热的主要目的是降低焊接接头的冷却速度[31。众所周知，为满足现代化建筑需求，钢材强度级别提高、合金元素含量增加以及焊接结构拘束度的复杂化已经成为趋势。这就意味着钢材焊接淬硬倾向的明显增大，焊接冷裂纹不可避免的成为影响低合金高强钢焊接质量的主要问题之一。焊接冷裂纹的主要影响因素包括以下三方面：被焊母材的淬硬倾向，焊接接头的扩散氢含量以及焊接接头的应力状态（即拘束应力）。要想控制冷裂纹的产生，得到好的焊接接头质量，就必须从影响焊接冷裂纹的三因素着手。 而预热则可以很好地解决这些问题， 为防止焊接接头冷裂纹提供有效手段。

预热的作用主要有以下三个方面：

（1）预热增加焊件的温度能够减缓热影响区在降温过程中的冷却速度，特别是在约540C左右时的瞬时冷速，或者增加焊件从800℃至 500°℃的冷却时间t815。这是由于800\~500°C为奥氏体不稳定相变温度区间，控制t8/5可以防止钢材淬硬组织的产生以及焊缝和热影响区延展性的降低[32]。

（2）在200°C温度区间减缓冷却速度，使扩散氢有更多时间从焊接接头及相邻母材逸出， 以减少焊接接头含氢量[33,34]， 从而避免焊接冷裂纹的产生。

（3）预热可以减小焊接接头和母材之间的温差，对缓解焊接接头收缩应力[35]，减小峰值应力值起着至关重要的作用。

# 1.5 焊接免预热钢板开发

# 1.5.1 焊接免预热钢板的开发思路

预热为低合金高强钢以及厚板防止裂纹的产生起到了举足轻重的作用，是缓解淬硬倾向、去氢、消应力的有效措施，成为焊接工程中的一道重要工序。但选取合理预热温度、层间温度以及实际预热温度控制都需认真计算并且经过试验验证。这不仅使焊接生产工艺复杂、提高施工难度、延长焊接工时，而且增加焊接成本，有损经济效益和社会效益。过高或过低的预热温度还会损害焊接接头的性能[36]。所以，开发焊接免预热建筑用钢势在必行。

焊接免预热就是在不预热的条件下实施焊接，也可以理解为降低预热温度至不高于室温甚至低于室温。所以控制住预热温度To就可以做到焊接免预热，于是焊接免预热的设计准则便集中在确定预热温度To的影响因素，即To的计算公式上，这为我们开发焊接免预热建筑用钢提供了思路。

# 1.5.2 焊接预热温度的确定

为了找到焊接免预热的途径，首先要确定最佳的预热温度方法。随着焊接应用与理论的不断发展与完善，纷纷涌现出了不同估算焊接预热温度的方法，如通过最高硬度、临界冷却时间、碳当量法以及裂纹敏感性法等。下面我们主要介绍碳当量法和裂纹敏感性法确定焊接预热温度[37-39]。

# 1.5.3 焊接免预热钢板开发思路

# 1.5.3.1 合理的成分设计

出于对提高焊接性设计考虑，Q390GJ采用低碳的成分设计。从碳当量和裂纹敏感性指数计算公式可以看出，碳元素对Ceq值和Pcm值影响最为显著，所以低碳可以明显降低碳当量和裂纹敏感指数，从而降低预热温度。但是，碳含量的降低必定会造成钢材整体强度的降低，所以适当的微合金元素可以保证钢材的强度不受影响。考虑到生产的低成本、经济型与环保型，选用合适的微合金元素至关重要。钢材中常见的各种元素作用如下：

碳：C是保证钢强度性能所需的重要元素，C在钢中的强化方式主要是通过固溶在奥氏体或铁素体基体形成间隙固溶体，使基体的晶格发生畸变，位错运动阻力增加，滑移难以进行，最终导致钢的强度和硬度提高。由Fe-Fe3C 相图可知，随碳含量的增加， Fe3C含量随之增加，与基体铁素体相比Fe3C的硬度高，因此能够增加钢的强度。 同时，C含量增加，可显著提高钢的淬透性，焊接后冷却过程中易得到马氏体等硬相组织，易产生冷裂纹。所以在碳当量和冷裂纹敏感指数的计算公式中，C的权重最大，是影响Ceg的主要元素，C含量往往在提高钢的强度、硬度的同时削弱HAZ韧性、塑性，对钢的焊接性产生不利影响。因此在焊接结构钢制备过程中，低碳含量和低碳当量成分设计是一种必然的趋势。

锰：Mn是治炼钢水的脱氧剂，同时也是重要的强韧化元素之一。Mn以固溶态溶解于铁素体基体中产生固溶强化，适当的Mn在不降低钢塑韧性的同时提高钢的强度和硬度。Mn易于与钢中的S结合，生成MnS，可避免S引起的热脆、焊接热裂纹以及焊接时产生SO₂导致的气孔和缩松。Mn作为奥氏体稳定元素，可降低Ae3温度，使先共析铁素体在更低的温度形核长大，从而细化晶粒。同时Mn可增加过冷奥氏体的稳定性，抑制碳化物在其晶界上析出，保证了钢较高的塑性。Mn的添加能弥补低碳钢由于C含量降低而造成的强度损失，但Mn的添加亦会增加碳当量，因此从抑制焊缝韧性的角度，通常要求Mn含量在2.0%以下。

硅：Si是治炼钢水必备的脱氧剂，是非碳化物形成元素，主要是以固溶态溶解在铁素体基体中来提高钢的强度。Si含量低，则钢中氧含量一般较高；Si含量过高，容易在HAZ区域形成发达的铁素体和M-A岛组织，严重影响HAZ韧性。同时，过量的Si，容易使钢锭表面出现起皮、开裂等缺陷， 影响钢表面质量。

钛：T是铁素体稳定化元素，能够封闭奥氏体相区，有限扩大铁素体相区。同时Ti是强碳化物、氮化物形成元素。通常Ti分别以固溶强化和析出强化的方式对钢的强度产生影响，但Ti的细化晶粒作用不大。适当的Ti含量能够在HAZ中形成第二相质点，一定数量、分布、形态的Ti氧化物、氮化物夹杂[50.511能有效抑制HAZ奥氏体晶粒长大，并且在冷却过程中促进针状铁素体的形成，改善HAZ的焊接性能和低温韧性，这一特点在大线能量焊接中广泛被应用。

铌：Nb是铁素体稳定化元素，缩小奥氏体相区，使A3温度上升，A4温度下降。Nb也是一种强碳化物、氮化物形成元素，但NbC的熔点要比TiN低。Nb在钢中以固溶强化或以化合物析出的形式对钢产生强化作用[52]。Nb的固溶强化能力很强，能提高钢的淬透性，提高强度。另外Nb强烈推迟奥氏体再结晶温度，这主要是因为Nb与C、N结合生成碳、氮化物或复合化物，析出并聚集在晶体缺陷处。这一方面能够抑制形变奥氏体的再结晶，另一方面能够控制奥氏体的长大行为，从而起到细化晶粒的效果153-581。

铝：AI是钢中重要的脱氧剂，适量的AI添加能够改善HAZ的低温韧性。当A1与Ti配合是能够减少钢中M-A岛的数量，增加M-A岛中奥氏体含量，有利于提高韧性。AI能固定N原子，当AI与N作用形成细小弥散的AIN时，能够细化晶粒从而提高钢的强度。 AIN 熔点较高， 对HAZ韧性也起着复杂的作用。

硫磷：S、P元素一般认为是对钢性能有害的元素。S的危害是在钢中形成（Fe+FeS）低熔点共晶物，能够引起钢产生热脆，通常加入Mn形成MnS以降低S的危害。粗大的MnS夹杂还会成为裂纹形核、扩展的起裂源，显著增加HAZ的裂纹敏感性。但是由于MnS熔点（1600°C）较高，适当的MnS夹杂能在HAZ作为形核中心，促进针状铁素体的形成，对HAZ的韧性有利。另外，MnS严重降低钢板厚度方向性能，对有厚度方向性能要求[59]的一般严格要求S含量(S≤0.010%）。P的固溶强化作用极强，使钢的强度、硬度增加，剧烈降低塑韧性引起冷脆。严重影响HAZ的低温韧性和延伸率，在冶炼中应予以控制。

# 1.5.3.2 合理的工艺设计

TMCP是提高材料强韧性的重要技术，基本原理是“低温”、“大压下”、“快速冷却”160]。在奥氏体未再结晶区施以大压下变形，一方面抑制奥氏体再结晶，另一方面通过应变诱导微合金元素析出阻止奥氏体晶粒长大， 使钢加工硬化积累变形能[611。轧后快速冷却，促进铁素体形核相变最终获得细小的晶粒组织。采用控制轧制和控制冷却（TMCP）工艺可以弥补降低碳含量而造成的钢材强度上的损失，对组织控制也相对灵活和精准。TMCP工艺的强化机理I162-641主要有细晶强化、析出强化以及相变强化等。

细晶强化机理：细晶强化是能够同时提高材料强度与韧性，根据Hall-Petch 公式|651：σs=σ+kyd-1/2（其中σs为屈服强度；σ为位错在晶粒内运动克服内摩擦力所需要的应力，也称派纳力；ky为与材料有关的常数；d为有效晶粒尺寸），晶粒越细小，材料的强度越高。图1.6为纯铁中屈服强度与抗拉强度随晶粒尺寸的变化示意图， 与Hall-Petch 公式相符合。

析出强化机理：析出强化主要是由于微合金元素在轧制及冷却过程中生成的碳氮化物等第二相粒子对基体产生强化。高温过程中的析出可以钉扎在奥氏体晶界阻止奥氏体粗化；轧制过程中的析出可以抑制奥氏体再结晶和奥氏体晶粒长大，特别是Nb元素有强烈推迟奥氏体再结晶的功效，为高温轧制、减轻轧机负荷提供可能；实验证明1601超快冷工艺可以大幅度的推迟第二相粒子的析出温度，使析出物在铁素体区大量析出以钉扎晶界、亚晶界以及位错等，而且增加析出量并细化析出物尺寸使其弥散分布，这大大提高了析出强化的效果。根据 Orowan强化机制I67-691，位错以绕过第二相的方式运动并留下位错环，如图1.7所示，析出相粒子越多越弥散则留下的位错环数量就多，材料被强化的效果就越剧烈。特别是Nb元素在铁素体区析出产生的析出强化[70.71效果不可小觑。

相变强化机理：相变强化是通过获得不同最终组织来提升材料的强度，相比于传统的调质钢，TMCP能够更加精确的控制轧制与冷却过程，大大增强了轧后冷却能力并得到优良组织配比。不同控轧控冷条件下的相变组织有着不同的性能，通过软硬相结合的方式， 精细化的控制两相尺寸、分布、相比例能充分提升强化效果。

# 1.6 本文研究意义与内容

# 1.6.1 研究意义

在节能环保、绿色建筑的发展背景下，焊接免预热不仅能够改善焊接环境，减少焊接工时，提高生产效率，更能节约能源，有利于可持续发展。随着建筑用钢逐渐向大厚度、高强度、良好的可焊性方向发展，焊接预热通常是保证大厚度高强钢具有良好焊接接头的重要措施，但是在高层建筑建设中焊前预热通常不易完成，而且预热温度难以保证，焊接免预热的研究则可以很好的解决这些问题。但是国内关于焊接不预热的研究，特别是高性能建筑用钢的焊接免预热研究并不是很多，焊接工艺的制定有待进一步探讨。高强度建筑用钢焊接免预热性能的研究对免预热钢板开发与设计具有较高的理论意义，对建筑用钢免去焊前预热，提高焊接效率有重要的实际意义。

# 1.6.2 研究內容

本文以中信-CBMM铌钢研发与开发某项目为背景，以唐山钢铁集团有限责任公司试制钢板为研究对象，依托于东北大学RAL（轧制技术及连轧自动化国家重点实验室）自研的MMS-300热力模拟试验机、德国KB3000BVRZ-SA万能硬度计、德国ULTRA-55场发射扫描电子显微镜等实验及检测设备对Q390GJ建筑用钢焊接性进行了较为系统的研究。主要进行了0.15%碳含量Q390GJ建筑用钢和0.07%碳含量Q390GJ建筑用钢焊接SH-CCT曲线、焊接热输入、二次热循环、预热温度等对焊接热影响区组织性能的影响进行了对比研究。研究内容主要分为以下几方面：

（1)焊接热影响区连续冷却转变曲线的研究。采用连续冷却实验测定并绘制了0.15%碳含量和0.07%碳含量建筑用钢粗晶热影响区和细晶热影响区的SH-CCT曲线，对比并分析了其组织随t8/5冷却时间的变化规律及淬硬倾向，并间接评定实验钢的焊接性。 为设计焊接参数、焊接预热温度提供了基础依据。

的预热需求。

（3）两种试验用钢焊接冷裂纹敏感性的理论预测。采用碳当量法和裂纹敏感性指数法对比了不同试验钢的冷裂纹倾向，并根据预热温度的经验计算法对两种钢进行了最低预热温度的理论估算。

（4）预热温度对一次热循环下焊接粗晶区、细晶区以及临界转变晶区组织性能的影响。基于Rykalin模型，通过不同预热温度下焊接粗晶区、细晶区和临界转变晶区模拟实验，研究预热温度对不同热影响区组织性能的影响规律，对比分析0.07%碳含量实验钢在免预热焊接条件下的可行性与优势，提出两种钢在一次热循环下的最佳预热温度。

(5)二次峰值温度对二次热循环热影响区的组织性能影响规律。采用MMS-300热力模拟试验机，研究多层多道焊接对焊接接头的组织性能的影响规律，分析二次热循环下预热温度和层间温度对组织演变规律，对比分析两种试验用钢二次热循环的组织差异，分析临界粗晶区组织恶化的影响因素，确定试验用钢的预热和层间温度控制范围。

# 第2章 焊接热影响区连续冷却转变研究

焊接过程具有连续动态的降温过程，与等温相变过程相比存在截然不同的规律。钢铁材料在焊接过程具有升温速度快、保温时间短且冷却速度快等特点，因此与一般相变过程中的连续冷却过程也不尽相同。因此研究焊接热影响区域的组织连续转变行为具有重要作用，将为实际研究焊接工艺提供重要参考。焊接热影响区连续转变图简称为SH-CCT (Simulated HAZ Continuous Cooing Transformation），图中常包含热影响区不同部分在连续冷却条件下的相变开始温度、终止温度、相变时间以及相变的最终组织、硬度与不同冷速之间关系的信息，是表征焊接热影响区在连续冷却条件下动力学关系的曲线图[8.751，对指导焊接工艺设计、焊接参数调整以及预测焊接接头质量具有重要的指导意义。

在实际熔化焊过程中，垂直于焊接移动的方向上温度梯度大， 距熔合线不同位置的热影响区有着不同的热履历，即经历不同的焊接热循环[76]。距离熔合线越近其峰值温度越高，高温停留时间越长，升温速度与冷却速率越快。这些因素导致热影响区的不同分区在实际焊接中所占宽度极窄，组织变化差异大。因此通过“物理模拟”[771的方法放大所要研究的分区，研究各分区的组织及性能随不同冷却路径的演变规律，为我们控制焊接质量，提高焊接可靠性提供了有利保障。本章着重研究了0.15%C 和0.07%C 的Q390GJ实验钢以及对比焊接粗晶区 (CGHAZ) 和细晶区（FGHAZ) 在不同t8/5（温度从800°℃冷却到500°C所用的时间）时间下的SH-CCT曲线，为进一步研究打下基础。

# 2.3 实验结果对比与讨论

# 2.3.1 免预热设计的组织依据

结合1.4及1.5节所述，预热的主要目的是减缓冷却过程中的冷却速度，避免生成淬硬倾向的组织； 保证扩散氢有较充足的时间扩散出去，减少钢中氢含量；以及缓解焊接接头以及热影响区的组织应力。焊接免预热钢板的开发也是仅仅围绕以上三点进行了化学成分以及组织控制来提高可焊性。Arafinl80]等通过对X80和X100的氢脆组织敏感性发现，硬脆脆性组织例如贝氏体和马氏体相较于铁素体更容易发生氢脆以及裂纹形成与扩展。微观组织中的非金属夹杂物以及第二相粒子、偏析等均会促进裂纹的产生；夹杂物数量、形态、尺寸以及分布直接决定了界面应力以及残余应力的分布，对钢的裂纹敏感性起较大的影响；条状的MnS夹杂、M-A岛、晶界、析出相、位错等同样可以通过氢陷阱成为裂纹的起裂点[81]。

焊接热影响区是焊接裂纹作用的重要部位，对HAZ 的组织演变进行研究有利于免预热研究。铁素体具有较好的塑性和韧性，不易产生应力集中以及能够很好的缓解残余应力。而韧性较好的贝氏体或针状铁素体组织由于组织中位错结构较为复杂，并且产生“互锁”效应，能够提高韧性，降低裂纹敏感性。因此，韧性较好的贝氏体以及细晶铁素体组织能够有效的防止冷裂纹的产生，实现焊接免预热目标。

从组织变化可以看出 0.07%C钢避免了淬硬马氏体的生成。0.07%C钢无论是粗晶区还是细晶区硬度均大幅度降低。常规用钢快冷速下最高硬度超过350HV，而0.07%C 钢仅320HV左右，这反映出试验钢焊接硬化程度降低即裂纹倾向降低。但同时也发现 0.07%℃ 钢细晶区t8/5超过 600s时出现了软化现象，将影响热影响区整体的强度、 硬度和使用性能。°℃

# 2.4 本章小结

（1）通过对比0.15%C 钢和0.07%C 钢的 SH-CCT得到： 两种钢细晶区相对于粗晶区均具有更高的相变温度，不易形成马氏体。0.07%C 钢无论是粗晶区还是细晶区，快冷速下相变开始温度点高于相应的0.15%C钢，中间冷速相变开始温度点低于0.15%C钢，而慢冷速条件下相变开始温度点又高于0.15%C钢，这样减小了淬硬倾向而增大了贝氏体相变区间。0.07%C 钢与0.15%C钢开始相变点差值小于终止相变点差值， 故而0.07%C钢具有更小的相变温度区间。

（2）0.07%C钢在快冷速条件下淬硬马氏体生成量减少，获得板条状贝氏体或粒状贝氏体组织。组织转变向高温相变推进，并且增大了贝氏体和铁素体的冷却区间，进而减少了裂纹敏感性。随着冷速的降低，0.07%C钢细晶区并未像0.15%C钢一样生成先共析铁素体，而是发生了了贝氏体组织退化现象，而后生成铁素体+珠光体复相组织。

(3） 0.07%℃ 钢无论是粗晶区还是细晶区，在18/5为5s的条件下硬度均不超过350HV, 焊接硬化现象有所改善。但是0.07%C 钢细晶区在18/s大于300s后出现明显的软化现象， 应予以注意。

综上可知，随焊接热输入的增大，晶粒尺寸增大。组织由马氏体/贝氏体组织向全贝氏体再到贝氏体/铁素体组织过渡。当t815为10s时，组织中存在贝氏体和极少量马氏体。当t8/5为40s时，组织为板条贝氏体和粒状贝氏体等多种贝氏体的组合，原奥氏体晶界清晰可见，贝氏体板条束将一个原奥氏体晶粒分割。而当t8/5继续增加到120s时，原奥氏体晶界则变得不明显，无法区分晶粒之间的分界线，组织也变得相对复杂。其中一些板条状组织有明显的增大增宽趋势。当热输入继续增加，板条组织变得更加粗大，碳化物呈现点、块状在铁素体包围的晶内分布。当t8/5增加到400s左右，能看到明显的铁素体呈长条或呈块分布，碳化物发生了聚集长大，分布变得更加“团聚”。

# 3.4 实验分析与讨论

# 3.4.1 组织对比与分析

通过对比图3.2和图3.10， 0.15%C钢在18/5为10s和40s的工艺下有马氏体组织产生， 而相同工艺下 0.07%C 钢则主要以板条细密的贝氏体组织为主，这说明0.15%C钢的淬硬倾向更大。0.15%C钢在t8/s为120s时，开始生成贝氏体组织，随着t8/s时间的增长，沿原奥氏体晶界形成了包围晶粒的先共析铁素体和部分珠光体，并且有增多增大的趋势，这种组织的形成破坏了原组织的连续性， 原奧氏体晶粒內的板条状组织则增大变宽，板条平均宽度在 5μm左右，最大尺寸达到10μm。0.07%C钢在t8/5为120s 时生成沿晶界生成的块状铁素体组织，随着18/s时间的延长板条宽度和块状铁素体均有长大趋势。晶粒内的贝氏体组织形态发生变化，从电子探针形貌发现M-A岛状组织和碳化物不断聚集长大，并且由小圆点状逐渐变得有棱角。

贝氏体中的M-A岛或碳化物多以粒状、点状、条状和尖角状存在于贝氏体基体中，通常认为，M-A岛或碳化物尺寸小、分布均匀、数量少并且多以球状存在更有利。M-A 岛的存在一方面可以起到强化作用，但同时也破坏了基体的连续性。因为M-A岛或大的碳化物的存在必定引起周围晶格产生畸变从而引起应力集中，这对材料的塑性、韧性以及断裂行为都产生了重要的影响。相比于均匀分布的球状M-A岛，尖角状和长条状更容易引起应力集中，成为起裂源并且有利于裂纹的萌生和扩展，成为裂纹的低能量扩展通道182.83]。所以贝氏体中的M-A岛或碳化物形态对钢的性能有着严重的制约。另外M-A组元分布均匀和形态变化、晶界渗碳体量以及粒状贝

氏体晶粒取向影响 了大角度晶界。

# 3.5 小结

（1）细晶区由于峰值温度低，原奥氏体晶粒长大倾向不明显，经过不同热输入条件下的细晶区晶粒尺寸要明显低于粗晶区。晶界增多使细晶区形核能力增强，减小了在快速冷却条件下生成淬硬马氏体组织的倾向。在-20℃冲击时细晶区断口各分区明显，多为具有韧窝形貌的塑性断裂， 而粗晶区则以脆性断裂为主。

(2) 在热输入超过 40kJ/cm 时， 0.15%C 和 0.07%℃ 钢粗晶区均形成沿晶界生长的铁素体，破坏了原组织的连续性，并且原奥氏体内组织板条发生粗化，M-A岛或碳化物形态发生聚集长大且有棱角，严重影响了钢的冲击韧性。这说明无论是0.15%C还是0.07%C钢，均不适宜大线能量焊接。

（3）在热输入低于20kJ/cm时， 0.15%C 钢粗晶区容易产生具有淬硬倾向的马氏体组织， 而低碳钢则以贝氏体组织为主，降低了钢的裂纹敏感倾向。低碳钢粗晶区在低于20kJ/cm的热输入下，冲击吸收功大于47J，满足建筑用钢的韧性需求。所以， 0.15%C 钢在热输入低于20kJ/cm的情况下需要预热。

# 第4章 预热温度对 HAZ 的影响

第三章中我们重点讨论了不同焊接热输入对 HAZ 组织和性能的影响，研究表明0.15%C钢由于碳当量相对较高，HAZ在焊接快冷阶段容易产生具有淬硬倾向的马氏体组织，强烈影响粗晶区的韧性。在生成的贝氏体组织中，由于粒状贝氏体基体上M-A岛大量密集、呈具有一定棱角状形态分布，导致应力集中，同样对HAZ韧性产生不利影响。而0.07%C钢在快冷速下由于得到的贝氏体而非淬硬马氏体组织，韧性有了一定的改善。那么得到期望组织以及减少M-A岛（或碳化物）形态、分布引起的应力集中，才是改善韧性的主要手段。预热最主要的作用就是减小焊接冷却速度，改善焊接接头的组织状态与应力状态，从而减小脆性开裂倾向。本章节则主要研究不同预热温度对0.15%C钢和0.07%C钢的组织性能影响规律，为了避免热输入对实验结果带来的影响，参考第三章中的实验结果，选取热输入为20kJ/cm作为定值。在此热输入的基础上，通过施加不同预热温度的热模拟实验进行HAZ免预热工艺的研究。分析预热温度对其组织性能的影响，间接讨论预热对改善HAZ焊接开裂的作用， 验证0.07%C钢对预热温度的敏感性以及进一步讨论免预热机理。

# 4.2.2 预热温度对 CGHAZ力学性能的影响

对0.15%C钢和0.07%C钢的力学性能进行检验，将焊接粗晶区硬度及-20C冲击吸收功数据绘制成图4.4。实验结果发现， 0.07%℃ 钢的硬度均大于0.15%C钢，这主要受组织的影响。0.07%C钢由于Nb元素的添加较多，贝氏体形成温度区域扩大，在不同预热条件下均生成形态各异的贝氏体组织，贝氏体板条宽度均明显小于0.15%C钢。在预热温度较高时，0.15%C钢还生成沿原奥氏体晶界分布的铁素体组织，晶内板条严重粗化，这使0.15%C钢的硬度偏低。

# 4.5 小结

（i）随着预热温度的提高，CGHAZ组织类型变化最为明显，高预热温度促进0.15%C钢粗晶区沿原奥氏体晶界生成大块状铁素体，而0.07%C钢则主要产生贝氏体组织形态的变化，板条增宽、板条界不明显、贝氏体特征退化。预热温度对FGHAZ组织影响较小，0.15%C钢在高温预热时生成尺寸较小的铁素体，0.07%C钢贝氏体板条增宽。 ICHAZ 以回复和部分重结晶为主，仅发生位错密度减少以及一定程度上的晶粒长大。

（2） 预热对 0.15%C 钢 CGHAZ和 ICHAZ的硬度性能影响较大，大大改善了0.15%C钢 CGHAZ 的硬度值， 但同样使其 ICHAZ产生一定软化现象，这主要是通过改善 CGHAZ 淬硬组织和加速 ICHAZ 回复过程以及促进晶粒长大引起的，而对0.07%℃ 钢硬度变化影响较小。

（3）预热能够明显改善0.15%C钢细晶区冲击韧性，但对粗晶区韧性改善效果不明显。这主要是由于适当预热可以缓解细晶区粒状贝氏体中M-A岛或碳化物对韧性的影响， 而且可以促进细晶区生成细小的铁素体组织，使组织细化。另一方面，预热可以增加FGHAZ的大角度晶界比例，阻碍裂纹扩展，提高材料韧性。粗晶区晶粒尺寸严重长大，预热又使其产生沿原奥氏体晶界生成的大块铁素体组织，破坏了连续性。高预热温度还会使贝氏体基体上的M-A岛或碳化物聚集长大，或生成有棱角的珠光体组织， 均恶化了材料的韧性。

（4）结合不同预热温度下的组织和性能分析， 0.15%C钢和0.07%C 钢均不适宜大线能量焊接。在20kJ/cm 的热输入条件下，0.15%℃ 钢最佳预热温度为150°℃，但不超过250℃，其对应的t815为68\~149s。0.07%C钢在不同预热条件下的力学性能均满足建筑用钢焊接性能需求，满足不预热焊接使用要求，最佳预热温度为50℃，对应t815为37s。

# 第5章 预热对二次热循环 HAZ 的影响

第二、三章的研究内容表明，一次热循环造成0.015%C钢焊接热影响区冲击韧性恶化的一个主要原因是粗晶区晶粒的异常长大以及淬硬组织的产生。第四章揭示了0.15%C钢在预热的条件下，可以改善CGHAZ的冲击韧性，而0.07%C钢不需预热即可获得较好的冲击性能，初步验证了 0.07%C钢的免预热焊接性能良好。但在建筑用钢的实际焊接过程中，通常不是一道次即可完成焊接过程，而需要进行多层多道焊，这就造成前一道次焊接对后一道次焊接有预热效果，后一道次焊接热循环会对前一道次的组织性能造成影响。有研究表明[8-10]，二次热循环中临界粗晶区产生的链状组织同样是影响HAZ性能恶化的另一个重要原因。因此，对临界粗晶区的组织进行研究同样具有重要的意义。本章通过热模拟实验的研究手段，对0.15%C钢和0.07%C钢的未转变粗晶区、过临界粗晶区、临界粗晶区的组织性能以及预热对临界粗晶区链状组织和性能的影响进行了研究。重点对临界粗晶区进行热模拟研究，通过改变一道次预热温度以及二道次预热温度（即层间温度），研究了0.15%C钢和0.07%C钢HAZ晶界及晶内组织的产生、大小以及分布状态的变化。

# 5.1 二次热循环对 HAZ组织性能的影响

# 5.1.3.1 粗晶脆化

图5.7为0.15%C钢IRCGHAZ经历不同二次峰值温度的EPMA形貌和TEM形貌。在二次热循环的峰值温度为800℃时，由于大部分晶粒发生了重结晶，原粗晶区的贝氏体晶粒边界及贝氏体组织形貌被大大弱化，碳化物或M-A组元散乱地分布在整个基体上，如图5.7（a）所示。当二次峰值温度为700℃时，经一次热循环的CGHAZ仅发生小部分重结晶，并不能产生细化晶粒的作用，部分区域的晶粒尺寸依然能够达到80μm左右，如图5.7（b）所示。这是由于晶界位置能量高，奥氏体转变优先在贝氏体晶界上进行，二次热循环在相变点以上停留时间短，奥氏体未等长大就经冷却而发生相变，所以原CGHAZ的晶粒尺寸被保留下来。

# 5.1.3.2 “退化珠光体”及 M-A 组元引起的脆化

# 5.4 本章小结

（1）不同二次峰值温度的研究表明，UACGHAZ由于二次峰值温度高，组织完全奥氏体化且晶粒严重长大，生成的的组织同 CGHAZ相同。SCCGHAZ虽然也完全奧氏体化， 但受一次热循环粗大贝氏体组织位向关系的影响，碳元素扩散具有一定的方向性， SCCGHAZ最终生成的组织也具有一定的方向性。并且CGHAZ的贝氏体组织使二次热循环形核质点增多，细化了 SCCGHAZ 的晶粒尺寸。

（2）0.15%C钢在二次峰值温度处于两相区内时，晶粒尺寸并没有因部分重结晶而得到细化。较高的二次峰值温度使碳化物在贝氏体晶界和晶内成不均匀分布，随着二次峰值温度降低到 700℃，生成了沿贝氏体晶界连续分布的链状退化珠光体组织， 晶粒粗化和链状珠光体共同作用降低了材料的冲击韧性。

（3）一次预热温度主要对CGHAZ的组织和形态产生影响，而二次预热温度则影响了材料的重结晶过程。随着一次预热温度和层间温度的增加，组织中的碳元素发生两次富集过程，预热温度越高，碳元素的富集程度越大。层间温度低则主要在晶界位置产生富碳并生成珠光体链状组织，层间温度高则晶内、晶界位置均发生碳元素的聚集长大。

（4）通过组织观察，为控制二次热循环链状退化珠光体的生成， 0.07%℃ 钢次预热温度不应超过200℃， 0.15%C 钢预热温度和层间温度均应在不产生淬硬组织的情况下控制在最低。

# 第6章结论

本文对两种390MPa级建筑用钢的焊接性进行对比，研究了预热对HAZ组织性能的影响规律以及实验钢免预热焊接的机制。通过热模拟试验方法，分别对两种钢的SH-CCT曲线进行了绘制与分析，并研究了不同热输入对HAZ组织性能的影响，从而确定了最佳的焊接工艺参数；在结合理论计算与热模拟实验基础上，研究了不同预热温度对一次热循环CGHAZ、FGHAZ、ICHAZ组织性能的影响，利用Thermo-Cak软件和EPMA实验分析了二次热循环下ICCGHAZ组织转变的机理，最后对二次热循环下，一次预热温度和层间温度对ICCGHAZ组织的影响做了分析。主要结论如下：

（1）通过热影响区连续冷却转变实验表明： 0.07%C钢大大降低了淬硬组织产生的倾向，扩大了贝氏体相变冷却区间， HAZ最高硬度不超过350HV：0.15%C实验钢快冷速容易生成马氏体，产生了明显的HAZ硬化现象；两种钢CGHAZ随t8/5增加均生成先共析铁素体，破坏了组织连续性， 对冲击性能产生不利作用。

（2）不同热输入下0.15%C 实验钢CGHAZ冲击韧性恶化的原因是淬硬组织的产生和晶粒粗大，而0.07%C钢性能整体较好。过大或过小的热输入均对组织产生恶化，综合两种钢组织和性能变化规律，提出了最佳的热输入范围为20kJ/cm左右，并且认为建筑用钢不适宜用大线能量焊接。

（3）FGHAZ晶粒尺寸远小于CGHAZ，所以各项性能均优于CGHAZ。 预热促进了HAZ高温转变生成铁素体并增大了晶粒长大倾向，但对 FGHAZ 和ICHAZ 区的冲击性能影响较小；预热虽然能改善CGHAZ的淬硬倾向， 然而由於CGHAZ 晶粒异常长大， 并不能提高CGHAZ的冲击性能。

（4）一次预热温度主要影响CGHAZ的组织类型，层间温度则改变碳元素的富集状态。随着一次预热温度和层间温度的提高，CGHAZ相变产物向高温组织转变，ICCGHAZ中碳元素沿晶界和晶内的富集倾向增大，形成具有一定棱角、块状或团状的“富碳体”无规则地分布于晶界和晶内。

(5）适当的预热温度能够改善0.15%C实验钢CGHAZ组织类型及碳化物分布，减小淬硬倾向。但较大的预热温度使0.15%C 实验钢 ICCGHAZ组织粗化，碳化物聚集长大并生成沿贝氏体晶界分布的链状珠光体组织，恶化了热影响区性能。低预热温度对 0.07%℃ 钢性能影响不大，但高温预热能够促进晶粒长大以及碳元素的富集，产生较大的珠光体或碳化物，对组织产生不利影响。

(6)结合预热温度的理论计算公式与不同预热温度下的热模拟实验得出，在热输入为20kJ/cm时，0.15%C实验钢一次预热温度应高于150℃，且不应超过250℃，层间温度不应超过200℃。 0.07%C 钢在不预热时即可满足建筑用钢使用要求，二次热循环下层间温度不应超过200℃。

其一，感谢恩师。人生路上多磨砺，感谢唐帅老师对我科研、生活上的谆谆教诲。没有老师的指导，我在撰写论文的道路上将无的放矢。祝唐老师科研顺利、学识精进、身体健康、全家幸福。RAL实验室给我提供了丰富的科研设施与师资力量，亦如恩师般有爱，在此感谢RAL实验室的款款恩情。

其二，感恩父母。亲情永远是未来道路上砥砺前行的力量源泉，感恩父母二十六年来的悉心教导与默默支持，让我在生活、学习、科研道路上披荆斩棘。您们身上的担子，希望能放心的交给我，儿子愿永远是你们的登天梯。

其三，感念好友。感谢沈鑫珺师兄的慷慨解惑，亦师亦友的情谊铭记于心。感谢同门同窗的相携进步，师弟师妹的无私帮助，活泼室友的宽容与关心，109全体办公室成员的理解与照顾。山河不足重，重在遇知已。东大生活交友颇多，此离别后虽相隔千里， 愿情仍在、意长存。

最后，感谢所有“旅途”中遇见的人。“琴”歌王子子荐，帅气男孩增辉，欢乐无敌的Ms Li Yang，温暖喜人的傅昊，没有上午的男人朱哥，暗黑系创意少女小黄，缘分相识的涛哥、文杰、丹妮，还有带给我心灵慰藉的“领导”，此生不相忘。数不完的你们铸就了如今的我，愿大家生命中迎来的都将是甘甜，愿每一次相遇便是一生的感怀。一首“不为谁而作的歌”送给我爱的你们，盼望下一次相遇。

此时窗外寒风呼啸，伴着我思绪交错的心情却显得十分应景儿。论文即将结尾，东大学生生涯也要画上句号。自强不息，知行合一的校训已经在我身上刻下了印记，我愿带着它， 以一个新学生的身份走进社会这所大学。
