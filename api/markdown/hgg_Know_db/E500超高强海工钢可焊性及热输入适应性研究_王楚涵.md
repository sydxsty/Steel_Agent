# E500 超高强海工钢可焊性及热输入适应性研究

王楚涵, 韦　 晨, 党丽华, 韩　 美, 马青军, 黄薪钢, 陈博文, 黄雅馨(天津市特种设备监督检验技术研究院, 天津 300192)

摘要: 通过焊接热模拟、 最高硬度、 斜 Y 型坡口试验及热输入适应性试验, 研究了 E500 超高强海工钢的可焊性及焊接工艺适应范围, 结果表明: 50 mm 厚 E500 海工钢焊接性良好, 淬硬倾向不明显, 室温≥6 ℃时可免预热焊接; 室温为-6 ℃时需预热≥50 ℃,以避免冷裂纹; 即使热输入达到 55 kJ∕cm, 焊接接头强韧性均能满足标准要求, 从保证足够韧性角度推荐最佳范围为 35\~40 kJ∕cm。

关键词: 海工钢; 焊接性; 热输入适应性; 冷裂纹; 淬硬性中图分类号: TG457. 1 文献标识码: ADOI:10.13846/j.cnki.cn12-1070/tg.2026.05.003

# 0 引言

海洋工程装备与资源开发设施是国家海洋战略实施的核心载体, 其服役环境极端苛刻, 长期承受高盐雾腐蚀、 风浪冲击、 低温疲劳及复杂应力载荷。随着深海油气勘探、 大型浮式平台、 超深水钻井船及跨海大桥等重大工程向深远海、 超深水及极寒区域拓展, 对关键结构材料的强度、 韧性、 耐腐蚀性及焊接可靠性提出了前所未有的要求[1-3]。 E500 级超高强度海洋工程用钢 (屈服强度≥500 MPa) 凭借其优异的综合力学性能、 良好的低温韧性和耐海水腐蚀能力, 正逐步成为大型海洋平台节点等关键承力构件的重要材料。 焊接作为海工结构制造的核心工艺, 其局部高温热循环会显著破坏母材原有的微观组织平衡, 引发热影响区 (HAZ) 软化、 脆化、 晶粒粗化、 韧性恶化、 氢致延迟裂纹 (冷裂纹) 及再热裂纹倾向加剧等问题[4-6]。 焊接工艺采取不当可能导致焊接接头强度显著低于母材, 成为整体结构的薄弱环节; 而焊接残余应力与复杂服役应力的叠加, 更易诱发疲劳裂纹萌生与扩展, 直接威胁结构在恶劣海况下的长期服役安全[7-8]。 本文聚焦E500 超高强海工钢的焊接性本质与焊接工艺适应性, 通过系统研究热输入参数对焊接接头微观组织、 力学性能及抗环境失效能力的影响规律, 旨在揭示焊接热过程-组织演变-性能退化之间的内在关联机制[9-10], 建立优化的焊接工艺规范, 为提升我国高端海工装备的自主设计与安全可靠制造能力提供理论支撑与技术保障, 对于 E500 工程化应用有着重要的指导意义。

# 3 结论

(1) 通过对 TMCP +回火工艺生产的 E500 海工钢焊接连续冷却转变曲线进行测定, 发现该钢在常规焊接热输入范围内粗晶区只发生贝氏体转变, 且焊接 SH-CCT 曲线中最高硬度低于 270HV10, 淬硬倾向不明显, 焊接性良好。

(2) 通过最高硬度试验及斜 Y 型坡口冷裂纹敏感性试验得到以下结论: E500 在温度为 6 ℃以上可实现不预热焊接; 温度在 0 \~ -6 ℃范围内, 需焊前

# 海洋石油工程高强钢焊接接头腐蚀疲劳行为研究

程晋宜, 张　 凯, 田　 雷, 张剑利, 王林昌(海洋石油工程 (青岛) 有限公司, 山东 青岛 266520)

摘要: 为探究海洋石油工程服役环境最为苛刻的飞溅区焊接接头腐蚀疲劳行为, 文中选用 TMCP 态的 API 2W Gr. 60 结构钢制备飞溅区典型焊接接头, 开展了干湿交替环境下的腐蚀疲劳试验和腐蚀试验。 结果表明, 干湿交替环境下腐蚀疲劳寿命随应力幅降低而增加, 腐蚀疲劳失效均发生在母材, 拟合获得了 50%存活率和 97. 7%存活率下的 S-N 曲线分别为 S11. 66N = 5. 34×1035, S10. 23N = 7. 96×1031; 干湿交替环境下焊接接头随着腐蚀时间延长, 腐蚀产物形态由黄褐色松散型逐渐转变为黑色致密型, 腐蚀形貌由局部点蚀向广泛面蚀转变, 其中母材和热影响区的腐蚀速率较焊缝更为显著, 热影响区腐蚀敏感度最高; 焊接接头随着腐蚀机制的演化分为初期快速腐蚀阶段、 中期稳定腐蚀阶段和长期加速腐蚀阶段, 当局部点蚀扩展为面蚀后, 腐蚀呈现加速腐蚀。
