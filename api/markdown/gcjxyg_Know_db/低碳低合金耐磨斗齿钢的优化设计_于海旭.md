摘　要：低合金钢的生产过程较为简单，成本不高，且其耐磨性和韧度较好，适用于挖掘机铲斗等机械工程领域。铲斗在进行挖掘作业时，斗齿与物料直接接触，会产生严重的磨损。为了提高铲斗的强度和耐磨性，研究对斗齿钢的化学成分进行改进，并对铸造系统的浇道和冒口进行了优化设计。试验结果显示，研究设计的新型斗齿高度方向的磨损量仅为YNM40 钢的5 ．0％、54．0％和57．1％，约为YNM40钢磨损量的1／2，耐磨性有明显提升，且测试过程中未发生脱焊及开裂等现象，符合可焊接性的标准。 利用这种新型钢，可以使挖掘机性能得到提升，对挖掘机行业的发展具有重要意义。

斗齿属于挖掘机上的重要安全零件，由于在进行挖掘作业时会与矿石、沙土和岩石等物料直接接触，产生冲击磨损，因此对其耐磨性能的要求也较高［1］。在较为复杂恶劣的挖掘环境中，斗齿的消耗磨损量非常大。这种消耗加剧了挖掘工程的难度，导致挖掘作业中需要停机以更换部件，不但增加了工程的成本，也降低了挖掘作业的效率［2］。目前的优化研究中，许多专家将计算机技术与铸造技术相结合，通过优化设计及仿真模拟完成对铸造过程的定性分析，并对铸造过程产生的误差进行精确分析定位，采取相应的措施，以此完成更加合理的设计，实现降本增效［3］。斗齿的铸造工艺也是不可忽视的优化目标，通过改善其铸造方式，可以减少挖掘作业中产生的磨损，进而提高工程作业的效率及经济性［4］。目前的斗齿铸件材料主要有准贝氏体钢、高锰钢等。准贝氏体钢的硬度大，但韧性不够，而高锰钢适用于较为复杂的挖掘环境，但其斗齿表面硬度较低，耐磨性较差［5］。对此，研究对铸件材料的化学成分及铸造系统进行改进，创新性地利用硌矿砂作为砂芯，用橄榄砂作为面砂，在铸件材料中少量添加贵重金属和铌、钛等元素，并选择添加铬和钼而去除镍［6］。旨在设计出一种同时具备高强度、高韧性、高

耐磨性的新型钢。

# 斗齿钢的优化设计

# 1．1 成分设计

斗齿在工作时，所处的环境较为复杂恶劣，且需要与外物持续接触，因此，其韧度、硬度和耐磨程度都需要达到较高的水平［7］。斗齿铸件的最大轮廓尺寸为1　340 mm×425mm×25 mm，属于大型铸件。其齿尖两侧所设的加强筋能够有效增加斗齿的承载力，减小壁厚，降低成本，同时能够改善铸造过程中由铸件厚度高而产生的表面气孔问题［8］。铸造用硅砂的组成部分三筛需要高于75％，而优质石英砂的二氧化硅含量要求高于90％。由于砂型被消耗，硅含量较低的石英砂的耐火度会不断降低，从而影响斗齿质量［9］。不同二氧化硅分级代号的背砂成分可见表1。

铸造砂材料的酸碱值作为反映铸造材料酸性的指标，可以在一定程度上衡量铸造材料的性能［10］。当酸耗值较大时，铸造砂中的酸性氧化物成分则越多，铸件表面的气孔问题能够得到改善，且铸件爆破发生率也可被降低，从而提高铸件的耐磨程度。硌矿砂的稳定性强，不易在高温条件反应。橄榄砂的主要作用成分为二氧化硅，其稳定性也较强，具有耐温和耐侵蚀的优点，且能避免铸件产生化学黏砂，从而增加铸件表面的光滑程度［11］。因此研究利用硌矿砂作为砂芯，用橄榄砂作为面砂，以提高铸件的质量。

在国家标准中，斗齿钢的碳含量不能高于0．3，铬含量不能高于1，钛含量不能高于0．05，硼含量需在0．00　5～0．0　6（质量分数，％），其余元素，如硅、锰、镍、磷、钼的最大含量标准分别为0．07、1．6、

0．7、0．025、0．5（质量分数，％）［12］。为了在所有含量均满足国家标准的基础上，提高斗齿钢的冲击韧性和耐磨性，研究对斗齿钢的成分含量进行了相应调整。由相关研究可知，国内外重点钢企业的耐磨钢含碳量均在0．15％～0．3％，并添加了总量为3％～4％的铬、钼、硅、硼等合金元素［13］。为了保证优化钢的耐磨性保持良好的焊接性能，将其碳当量保持在0．6之内，冷裂敏感指数不高于0．35，并去除国家标准成分中的镍以降低成本。同时，为了提高斗齿钢的淬透性和冲击韧性，严格把控磷和硫等杂质的含量。此外，铌和钛元素可以细化晶粒，提高合金的硬度和韧度。国家标准工业机械用强度耐磨钢板的成分与优化钢的成分如表2所示。

# 1．2 铸造系统优化

在制造铸型时，为了满足安放嵌件及排气等成型条件，根据塑件的结构，将直接成型塑件的那一部分模具分成若干部分的接触面，此结合面即为分型面。除熔模、实型等较为特殊铸造情况外，一般的铸造过程都需要选择分型面以保证铸造过程的精度［14］。分型面的选择依据主要分为两点，首先，为了确保铸件顺利取出，一般将分型面选取为铸件的最大截面，并使铸件的重要加工部分尽可能地留在动模或下模的一侧，以此来增加铸件尺寸和外观的精确度，尽可能减少铸造过程产生的误差［15］。其次，分型面的选择需要考虑排位、塑件的形状和精度、浇口位置、侧抽芯、加工设备、顶出位置等多种因素，避免成型后的铸件产生缺陷。考虑到斗齿结构与分型面的选择条件，研究将分型面选择为铲斗的对称面，具体结构可见图1。

通过图1的分型面结构，可以减少砂芯、活块的数量，缩减砂箱的尺寸，使下芯过程更加方便，简化铸造过程，提高生产效率。直浇道作为高温金属液最先接触到的部分，对金属液有着引导作用。在浇注过程中，直浇道的存在能使金属液顺利经由横浇道和内浇口流入铸件型腔。对直浇道的深度进行调整后，可以使金属液的压头更加适当，促进金属液在铸件型腔的充型［16］。充型过程中，铸件型腔会受到金属液的冲刷，直浇道底部受到的冲刷作用相对更强，这种剧烈的冲刷可能会使铸件过程产生夹渣类缺陷。因此，研究设置直角道窝以改善金属液在铸件型腔中的流动状态。直角道窝增加后，金属液在达到横浇道时能够迅速流入正常区。

通过直角道窝的作用，可以使金属液在充型阶段产生的局部紊流现象得到有效改善，受到的阻力也更小，减少能量损耗［17］。同时，可以使内浇道流量分布更加均匀，减小金属液对直浇道底部型砂的作用，增强铸型的排气效果。研究使用漏斗形浇口杯，直浇道采用没有斜度的Φ70mm圆管，在直浇道底部设计直角道窝。直浇道和内浇口通过横浇道相连接。通过直浇道的作用，金属液能够较为均匀平缓地流入内浇口。此外，浇注初期的沙粒、熔渣和涂料等废渣易被带入横浇道，横浇道的存在也能实现一部分挡渣效果，提高铸件质量。研究将横浇道直边角设为圆角以增加缓冲效果，圆角半径为6 mm，整体为矩形截面，尺寸为45mm×5 mm。 直角道窝作用示意图可见图2。

内浇道的主要作用是控制金属液的流向和速度，调控铸件的凝固顺序。内浇道的设计将直接影响到浇注系统的补缩效果。为了防止型砂发生局部过热现象，薄壁铸造过程多采用两个及以上内浇道设计，使金属液的充型更加均匀分散，减少晶粒粗大和粘砂等铸造缺点。内浇道的位置设置影响着金属液流入的方式及冲击情况，除对内表面要求高的铸件外，其余圆形铸件均采用切线浇口设置，防止金属液冲击砂芯及型壁，能够顺型壁均匀流入。研究将内浇道设计为45mm×45mm的矩形截面，直角边也设置为圆角。

金属液经过充型后，温度会逐渐下降并逐渐开始凝固。由于金属液的形态由液态转化为固态，导致其体积缩小，在铸件较为厚实的部分或难以散热的部分出现缩松和缩孔等铸造缺陷，严重影响铸件的可塑性。当铸件内部的缩松为1％～2％时，铸件的可塑性可降至0。因此，在斗齿的铸造过程中，设计保温冒口是必要的。冒口的增加使凝固速度较慢，体积较大的铸件在进行最后的凝固步骤时，凝固收缩的部分得到补偿。通过在冒口加入金属液，可以有效减少铸件的缩松和缩孔问题。为了使补偿效果达到最佳，冒口在凝固过程中需要充足的金属液以补偿铸件体积收缩，其位置和形状需要设置合理，尽可能减少消耗的金属液，且金属液需要足够的补缩压力和通道以成功流至目标区域，完成对铸件收缩的补偿。由于斗齿的中心结构较厚实，因此研究将冒口位置设于斗齿中心，内径为1　90 mm，冒口的顶部敞开，与大气相通，利用重力作用完成对铸件体积的补偿。

# 3 结论

为了减少斗齿钢磨损，提升挖掘机整体的生产效率和经济性，研究对挖掘机铲斗的铸件材料进行改进。在铸件中添加贵重金属和铌、钛等元素，并选择添加铬和钼，去除镍，以硌矿砂作为砂芯，用橄榄砂作为面砂。改变直浇道的深度，以确保金属液能够顺利完成对铸件型腔的充型。在斗齿中心部位设置明冒口，选用保温冒口顶部敞开和大气相通，利用重力作用能够有效地补缩铸件。经测试，得到铸件材料的液相线为1　390℃，固相线为1　259℃。斗齿钢在距离淬火端0～2 cm处力学性能较为稳定，在距离淬火端2～6cm处力学性能急剧降低，后续距离力学性能保持较为平稳状态。3个测试位置的新型斗 齿 钢 侧 板 高 度 磨 损 量 仅 为 YNM40 钢 的5 ．0％、54．0％和57．1％，约为 YNM40 钢磨损量的1／2，耐磨性有明显提升。研究得出的结论如下：

（1）经过成分调整后，斗齿钢的材质强度得到了有效强化。利用这种新型斗齿钢，可以有效提高铲斗的强度和韧性。

（2）铸造工艺优化后，投入生产可以得到表面质量较好的斗齿，利于挖掘机生产的效率和质量。

（3）研究优化主要针对铸造系统的浇道与冒口，未考虑对排气孔等浇注系统关联部件的改良。因

# 此，未来研究将对浇注系统进行更全面的优化提升，进一步改善铸件表面的质量。

# 乐山玉润年处理 600 t（REO）稀土材料再生资源利用项目启动

据CRE网站报道，2025年2月26日，四川五通桥经开区迎来了一个具有里程碑意义的时刻——乐山玉润年处理 600吨（REO）稀土材料再生资源利用项目正式启动。 该项目总投资高达5．69 亿元人民币，占地面积达到 10319．52平方米，是乐山玉润在稀土材料再生资源利用领域的一次重大布局。

该项目采用先进的工艺和技术，以全溶法处理稀土废磁材料，旨在实现资源的高效再生利用。 预计项目建成后，将形成年产600吨稀土氧化物的生产能力，这将极大地提升乐山玉润在稀土材料领域的产能和市场竞争力。

在启动仪式上，区委副书记、区政府区长魏阳东发表了重要讲话，并宣布项目正式启动。 他指出，该项目的实施不仅有助于推动地方经济的发展，更将为五通桥区的绿色发展和可持续发展注入新的活力。同时，区人大常委会主任王读红、区政协主席陶红等领导也一同出席了启动仪式，并对项目的顺利实施表示了热烈的祝贺和期待。

据预测，该项目建成后预计可实现年产值48亿元人民币，利税8亿元人民币，将为地方财政带来可观的收入。 同时，项目还将解决20 余人的就业问题，为当地居民提供更多的就业机会和收入来源。
