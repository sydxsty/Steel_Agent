# 回火温度对 X70Q 管线钢 DWT 性能的影响

赵荣贵， 镇　凡， 邵春娟， 曲锦波（江苏省（沙钢）钢铁研究院有限公司，江苏 张家港 215625）

摘　要：为研究回火温度对X70Q管线钢落锤撕裂试验（DWTT）性能的影响，采用金相、扫描、电子背散射衍射、JMatPro模拟计算、透射电镜等方法，研究了不同回火温度（30 ～60 ℃）对X70Q厚壁管线钢组织与力学性能、特别是DWTT性能的影响规律与作用机制。 研究表明，在30 ～40 ℃中低温回火区间，试验钢发生了位错回复与亚晶合并，导致大角度晶界比例显著增加（40 ℃时达68．3％），同时细小的 M3C碳化物析出起到强化作用，展现出最佳的强韧性匹配；50 ～60 ℃高温回火时，晶粒粗化、脆性相析出及马氏体／奥氏体（M／A）岛分解，使 DWTT性能显著降低。高温回火恶化DWTT性能主要归因于晶粒粗化与等轴化、脆性相沿晶界析出、细小 M／A岛分解3个关键因素。 晶粒粗化与等轴化是指具有较小断裂单元、取向差异大的针状铁素体，高温回火后向等轴化的多边形铁素体转变，导致有效晶粒尺寸增大，特别是｛01｝解理面晶粒异常长大，降低了裂纹扩展阻力。脆性相沿晶界析出是指高温回火后粗大的 M23C6 沿晶界析出，造成晶界附近贫铬，弱化了晶界结合强度。细小 M／A岛分解是指作为阻碍裂纹扩展的重要组织，细小 M／A岛在高温回火后基本完全分解，丧失其有益作用。研究结果为 X70Q热处理生产提供了参考。

全球油气资源开发正向极地、深海等极端环境延伸［1］，厚壁、高强度、高止裂性已成为管线钢的核心发展方向。然而，钢板厚度增加会导致其落锤撕裂试验（DWTT）性能显著衰减［2］，这一问题成为制约厚壁管线钢安全应用的瓶颈。X70级管线钢强韧性匹配优异，因此被广泛应用于长距离输送管道，但传统热机械轧制工艺（TMCP）难以解决钢板厚度方向的温度梯度与组织不均问题，而调质工艺（淬火＋回火）被证实是改善厚壁钢DWTT性能的有效途径［3］。

目前，关于回火温度对管线钢力学性能的研究多集中于薄规格钢板。针对50mm厚X70管线钢，回火过程中微观组织、析出物类型和尺寸、晶界特征的演变规律及其对 DWTT性能的影响机制尚不明确。现有研究尚未探明高温回火下 DWTT性能恶化的核心诱因，也缺乏对最佳回火温度区间的精准界定与机理阐释。

基于此，本文以工业化生产的50 mm 厚 X70Q管线钢为研究对象，系统研究了30 ～60 ℃回火温度对其微观组织、析出行为及力学性能（特别是－57℃DWTT性能）的影响规律，旨在阐明回火温度驱动下的组织演变与 DWTT 性能劣化机制，为开发高性能厚壁管线钢、预防管道灾难性断裂事故提供关键的理论依据与工艺指导。

# 1．2 试验方法

# 1．2．1 DWTT 试验

API　RP　5L3标准中规定，钢板厚度大于19．0mm时，可对DWTT试样进行减薄处理，试验温度相应降低；对于厚度大于39．7mm 的钢板，不要求进行DWTT试验。邵春娟等［4］研究发现，双面减薄对DWTT性能要求更高。本研究中，50．0 mm 厚X70QDWTT试样从钢板宽度1／4处取得，双面减薄至19 mm，压制 V 型缺口，在 Instron 8150 试验机上进行－57℃（降温17℃）DWTT 试验。

# 1．2．2 显微组织观察

金相试样经手工打磨抛光后用体积分数为4％的硝酸酒精腐蚀，在Carl Zeis　Axio Imager Alm 金相显微镜（OM）和 Zis Evo18扫描电镜（SEM）下观察试验钢微观组织。 试样经电解抛光后，采用 Ape－ro2S场发射扫描电镜进行电子背散射衍射（EBSD）分析。使用JMatPro软件模拟计算不同回火温度下析出物尺寸、数量。试样经抛光后用体积分数为4％的硝酸酒精腐蚀，通过碳膜萃取复型法将析出物复制下来，采用JEM－F20 场发射透射电镜（TEM）观察析出物类型、尺寸。

随着回火温度升高，X70Q 显微组织发生连续演变。主要体现在BF、M／A岛的形态、尺寸和分布的变化，以及基体组织的回复。30 ℃低温回火后，组织整体保留了淬火态特征，SEM 中仍可见 AF、QF、BF和 M／A岛等组织。但BF和 M／A 岛已开始分解，过饱和碳以细小的ε－碳化物形式析出［16］，内应力得到部分消除。

在30 ～40 ℃中低温回火时，M3C首先析出，并在该温度区间内保持稳定。随着保温时间延长，其数量（体积分数最高约0．05 ％）和尺寸（均不超过5nm）变化不大，为该阶段的主要析出相，不会恶化DWTT性能。

影响更为突出。

M（C，N）因热力学稳定性最高，难以溶解，是回火过程中实现长效强化的关键相。当温度升高至50 ℃以上时，元素扩散能力增强，M（C，N）开始大量析出并缓慢长大。在60 ℃保温60min 条件下，其尺寸仅增至12nm，远小于 M7C3 和 M23C6。

试验钢 DQ态及不同回火温度条件下，DWTT断口IPF 图和 SEM 图像分别如图8和图9所示。

DQ态具有晶粒细小、晶界密度高、晶粒取向差异大的微观结构特征。裂纹扩展时遇到高位错密度晶界、细小的碳化物或细小 M／A岛时，无法直线穿过，会被迫绕行，传播方向发生大角度偏转，增加了扩展的能量消耗。极高的裂纹扩展阻力在断口上表现为大量深而密集的韧窝，这是典型的微孔聚集型韧性断裂特征，表明材料在断裂前经历了充分的塑性变形，因此DWTT性能优异。

# 3 讨论

工业化生产的 X70Q 管线钢在DQ态拥有良好

的强韧性匹配，30 ～60 ℃回火后强度、伸长率、冲击功等性能仍良好，但 50 ～60 ℃高温回火后DWTT性能显著下降，对其影响机制进行分析。

# 3．1 回火温度对力学性能的影响机制

回火温度从30 ℃升高至60 ℃，试验钢屈服强度R 逐步升高，抗拉强度R 缓慢下降。这种强度指标的变化与回火过程中微观组织的演变密切相关［23］。在30 ～40 ℃中低温回火区间，屈服强度的升高主要归因于ε－碳化物的析出强化。根据JMatPro仿真结果，在此温度区间内，M3C型碳化物为主要析出相，其尺寸细小（≤5nm）、分布均匀，能有效阻碍位错运动，从而提升屈服强度。与此同时，抗拉强度缓慢下降，这与回火过程中内应力释放和位错密度降低直接相关。EBSD分析结果显示，30 ℃回火后 KAM 值从DQ态的1．14°显著降低，表明位错发生了显著回复，内应力得到有效消除。当回火温度升高至50 ～60 ℃高温区间时，屈服强度继续上升的现象与 M（C，N）型碳氮化物的沉淀强化效应有关。JMatPro模拟表明，在此温度区间，稳定性高的 Nb、V、Ti的碳氮化物开始大量析出，形成有效的沉淀强化效果。而抗拉强度的进一步降低则与晶粒粗化和组织等轴化相关［24］。SEM 组织分析显示，60 ℃回火后，针状铁素体特征基本消失，形成大量等轴状多边形铁素体，晶内位错密度显著降低，这导致材料加工硬化能力下降，从而抗拉强度降低。

试验钢在全部回火温度下均保持优良塑韧性（伸长率A ＞30％，－80℃冲击功KV＞230J），这源于X70Q 钢原始细小的复相组织。 OM 分析显示，试验钢晶粒度达1 级，且由 AF、QF、BF、GB组成的复相组织能有效协调变形［25－28］，保证了塑韧性。

材料断裂强度计算见式（1）［29］。 可见，影响试验钢DWTT断裂韧性的主要因素为晶粒尺寸和晶界强度。

DQ工艺下，快速冷却使奥氏体发生相变，形成细小的 AF、BF、M／A 岛组织，晶粒（含有效晶粒及亚结构）尺寸细小。同时，相变过程中产生的高应变与高密度位错，促使大角度晶界、亚晶界交织成细密的“阻碍网络”。当 DWTT 冲击引发裂纹扩展时，由于晶界处原子排列紊乱，裂纹无法直接贯通，裂纹发展以穿晶扩展为主要方式。由于细晶粒间晶体学取向差大，裂纹前端穿越不同晶粒时，需在大角度晶界处重新形核并发生大角度方向调整。这种“频繁的方向转移”使裂纹扩展路径高度曲折，大幅增加能量耗散［23］。

同时，细晶组织为位错运动、微孔形核提供了充足“位点”，冲击应力下，第二相粒子或晶界处大量形核的微孔在塑性变形中持续长大、聚合，最终形成SEM 下深且密集的韧窝形貌，这是“微孔聚集长大”型韧性断裂的典型特征，反映出塑性变形的充分性与高断裂阻力。

JMatPro模拟计算与TEM试验结果表明，60 ℃回火时 M23C6 型碳化物沿晶界析出，导致晶界附近出现局部Cr元素贫化，属于典型的脆性析出相，会显著降低晶界结合强度。SEM 观察也证实，60 ℃回火后，基体与BF内 M／A 岛基本分解，碳化物明显粗化且分布更均匀，这种组织变化虽然有利于均匀变形，但降低了裂纹扩展阻力。在断口形貌上，SEM 观察到韧窝数量锐减、深度显著变浅（微孔聚集长大的塑性变形被抑制），同时出现撕裂棱与准解理面特征，准解理面的存在，标志着断裂机制向“脆性解理＋少量塑性变形”转变。

有效晶粒尺寸变化是影响裂纹扩展路径的关键因素。 EBSD分析表明，DQ态试验钢平均晶粒尺寸最小，裂纹扩展时需要频繁穿越这些细小的晶粒，消耗大量能量。而60 ℃回火后，晶粒显著粗化、等轴化，裂纹可“长距离”沿晶或沿｛01｝解理面穿晶扩展，无需频繁跨越晶界消耗能量，扩展路径更“平直顺畅”，导致韧性下降。这与ZHAO　M　C等［30］的观点一致：针状铁素体组织具有较小的断裂单元（有效晶粒尺寸），而等轴化组织具有较大的断裂单元，前者韧性更优。

M／A岛的分解行为对 DWTT 性能有重要影响，SEM 分析显示，随回火温度升高，M／A 岛逐渐分解。30 ～40 ℃回火时，M／A 岛部分分解并细化，改善了其作为硬化相的有害作用；而60 ℃回火时，M／A岛基本完全分解，失去了对裂纹扩展的阻碍作用。研究表明［31－33］，适量、细小的 M／A岛能有效阻碍裂纹扩展，提高韧性，而过度分解的 M／A岛则对韧性不利。

# 3．3 组织演变规律与韧性机理

X70Q管线钢在回火过程中的组织演变遵循位错回复－相变－再结晶的规律，这一过程显著影响材料的韧性表现。在30 ～40 ℃回火区间，EBSD结果显示大角度晶界占比显著增加（40 ℃回火后达68．3％），KAM 值大幅降低。这表明在此温度区间发生了明显的位错回复和亚晶合并，低能垒的小角度晶界转变为能垒更高的大角度晶界。这种结构变化有利于提高裂纹扩展阻力，因为大角度晶界能更有效地阻碍裂纹扩展［34］。这解释了在此回火温度区间，试验钢同时保持了高强度和优良韧性的原因。在50 ～60 ℃高温回火区间，组织发生等轴化转变，针状铁素体特征逐渐消失，形成大量多边形铁素体。这种转变虽然有助于内应力的进一步释放，但导致有效晶粒尺寸增大，减少了裂纹扩展路径上的障碍物数量。这些因素共同导致高温回火后韧性下降，尤其是 DWTT性能显著恶化。析出物演变对韧性也有重要影响。JMatPro模拟显示，不同温度下主导的析出相类型不同，40 ℃以下以 M3C为主，50 ℃以上则出现 M7C3、M23C6 及 M（C，N），其中 M23C6 易沿晶界析出，造成局部Cr贫化，加剧晶界脆化。而稳定性高的 M（C，N）相虽然有助于强度提升，但过度粗化会降低其对裂纹扩展的阻碍作用。

# 4 结论

1）试验钢DQ态具有晶粒细小、晶界密度高、晶粒取向差异大的微观结构特征，组织中大角度晶界与亚晶界交织成细密的“阻碍网络”，使裂纹扩展路径曲折并引发微孔聚集型断裂，展现出良好的抗撕裂能力。

2）回火温度通过改变试验钢的晶粒尺寸和晶界强度，主导着 DWTT性能演变。随着回火温度的升高，BF、M／A岛逐渐分解，AF转变为等轴状PF，导致晶粒尺寸逐渐增大；析出物由细小的 M C转变为粗大的 M C ，弱化晶界强度。裂纹扩展阻力逐渐减弱，断裂机制由微孔聚集型向准解理断裂过度，造成DWTT性能随回火温度升高而逐步下降。

3）在30 ～40 ℃中低温回火区间，试验钢发生了位错回复与亚晶合并，大角度晶界比例显著提升（40 ℃时达68．3％），同时细小的 M C碳化物析出起到强化作用，展现出最佳的强韧性匹配。

4）在50 ～60 ℃高温回火区间，晶粒粗化（特别是｛01｝解理面晶粒异常长大）与等轴化，细小M／A岛分解，粗大的 M23C6 沿晶界析出，这些变化显著降低了裂纹扩展阻力，导致试验钢的 DWTT性能明显恶化。
