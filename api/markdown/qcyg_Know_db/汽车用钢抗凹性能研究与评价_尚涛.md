# 汽车用钢抗凹性能研究与评价

尚　涛1，张士杰1，刘石双1，聂强胜1，王宝川2，韩龙帅2（1．首钢京唐钢铁联合有限责任公司，河北 唐山 06320 ；2 ．首钢集团有限公司技术研究院，北京 10043）

摘　要：针对汽车轻量化需求，本文研究了汽车板抗凹性能的影响因素。 通过抗凹性能实验和有限元仿真的结合，研究了预应变、钢板厚度和零件曲率等因素对汽车板抗凹性能的影响。实验结果表明：当预应变小于15％时，钢板抗凹刚度随预应变的增加而升高，当预应变大于15％时，钢板抗凹刚度随预应变增加而降低，这是由于预应变过大导致钢板厚度减薄所致。对于厚度分别为0．65mm和0．70mm的钢板，当预应变小于3％时，钢板抗凹刚度差别不大且凹痕深度均大于2mm；当预应变大于3％时，0．70mm厚钢板抗凹刚度明显大于0．65mm厚钢板，且两者凹痕深度急剧减小，随着预应变进一步的增大，凹痕深度变化不明显，这是由于随着预应变的增大，钢板发生加工硬化，强度显著提高阶段，钢板厚度是决定凹痕抗力的重要因素之一烘烤硬化对钢板抗凹刚度影响不大，但凹痕深度较烘烤前明显降低，这是由于烘烤过程中发生应变时效导致钢板强度增加所致。 有限元模拟进一步验证了零件曲率也是抗凹性能关键影响因素之一，零件抗凹性能随着曲率减小而增强，但曲率并非越小越好，应控制在合理范围内。

汽车轻量化技术是在保证汽车整体性能、质量和安全不受影响的前提下，最大限度地减轻车身自重，追求高输出功率、低噪声、低振动和良好的操纵性，同时降低油耗，减少排放［1－7］。目前，国内外汽车轻量化技术发展迅速，采用轻质合金、较薄的高强钢等材料作为车身材料，能够有效降低零件重量，实现汽车轻量化，但材料减薄会导致零件的抗凹性能下降，带来车身“薄”、“软”、“不安全”等方面的市场质疑［8］。在汽车制造领域，汽车板在承受外部载荷时抵抗凹陷扭曲及局部凹痕变形、保持形状的能力称为抗凹性能，是评价和反映汽车板表面质量和使用性能的重要指标［9－11］。抗凹性能与零件自身的曲率、支撑情况，钢板厚度、性能，以及冲压工艺等因素相关［12］，这些因素会直接或间接影响汽车板表面质量和使用性能。鉴于此，汽车板抗凹性能的检验评估正日益成为汽车车身综合质量评估中不可或缺的一环。

国外汽车研发和制造商很早就已经意识到建立科学统一的汽车板抗凹性能评估体系对于保证汽车板抗凹性能研究具有重要意义［13］，如美国福特汽车公司、克莱斯特汽车公司和瑞典的沃尔沃（VOLVO）公司都进行了相关方面的尝试，他们从零件原料、零件设计及冲压工艺3个方面进行了系统的理论分析和实验研究，建立了静态与动态抗凹性能实验方法、实验标准和评估指标，推动了汽车板抗凹性能研究的发展，提高了汽车板的使用性能，缩短了新车型的开发研制周期。国内在汽车板抗凹性能的研究方面起步较晚，在抗凹性能理论分析、实验研究和数值仿真方面的积累不足。本文深入研究了汽车板抗凹性能的影响因素，特别是预应变、钢板厚度和曲率对汽车板抗凹性能的影响，对汽车用钢的生产具有指导意义。

# 2 汽车板抗凹性能评价指标

一般认为抗凹性能分为静态抗凹性能和动态抗凹性能，前者表征零件抵抗人为触摸按压、积雪覆盖等静载荷作用的性能，后者表征零件抵抗碎石冲击等动载荷作用的性能［14］。衡量抗凹性能的核心指标包括：抗凹初始刚度、抗凹稳定性及局部凹痕抗力，各指标示意图如图3所示。由于汽车板多为带曲率的薄板零件，与刚性球头胀形件具有相似性，且其成形过程可在一定程度上反映冲压变形特点，因此，基于刚性球头胀形件的抗凹实验是评定汽车板抗凹性能的基本实验方法之一。

# 5 结论

（1）当预应变小于15％时，钢板抗凹刚度随预应变增加而升高；当预应变大于15％时，钢板抗凹刚度随预应变增加而降低，这是由于预应变过大引起板材厚度过度减薄所致；当预应变小于3％时，试样凹痕深度均大于2mm；而预应变大于3％时，凹痕深度急剧下降，且后续变化不明显。钢板厚度是决定其局部凹痕抗力的关键因素，0．70 mm 厚钢板的静态局部凹痕抗力明显高于0．65mm 厚钢板。

（2）汽车板抗凹性能随着其曲率半径减小而增强，但曲率半径并非越小越好，应控制在合理范围内。
