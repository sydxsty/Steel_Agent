# 桥梁钢板 Q345q 的开发与工艺研究

吴建国1 于玮弘1 刘宝喜2 刘志勇2 尹绍江2( 1 唐钢中厚板材有限公司; 2 唐钢技术中心)

摘 要 根据新版桥梁钢标准的要求，合理设计 Q345q 钢的化学成分。 经过实验室试验、小批量试生产和大批量生产等过程，对成品的力学性能进行统计分析及金相组织研究， 制定合理的冶炼、连铸、加热及轧制工艺，最终稳定生产出质量优良的产品，满足了用户的技术和使用要求。

# 2 化学成分设计

根据 GB /T 714 － 2015 《桥梁用结构钢》标准对 Q345q 钢的成分要求，考虑碳对韧性及焊接性能的不利影响、Si 对于表面质量的负面作用、Mn的固溶强化作用及价格因素， 实行了低碳设计，适当降低Si 含量，将Mn 含量控制在较高水平; 为了改善焊接性能、提高再结晶温度、更好地实现控制轧制并保证冲击韧性，采取了微 Ti、Nb 微合金化措施，同时严格控制 S、P 含量。 化学成分设计见表3。

# 3 生产工艺流程与控制

转炉冶炼→钢包吹氩→LF 精炼→板坯连铸→板坯下线缓冷→表面检查/火焰清理→3 500mm 轧机轧制→钢板堆垛缓冷→检查→入库。

# 3． 1 冶炼工艺

为了取得提高钢水纯净度、控制夹杂物性质和形态的效果，严格控制脱氧、脱硫过程，减少钢中夹杂物，以获得较好的低温冲击性能。转炉冶炼严格控制终点 C 含量，防止钢水过氧化，严格规范下渣操作; LF 精炼实现充分快速脱硫，保证软吹时间，使钢中夹杂物充分上浮。

# 3． 2 连铸工艺

使用二冷区电磁搅拌，有效均衡钢液中的溶质，抑制柱状晶生长，减轻铸坯的中心缺陷，凝固末端采用20 ～30 mm 的动态重压下，突破传统轻压下单辊压下量 ＜5 mm、总压下量 ＜10 mm 的工艺准则，有效解决了连铸坯中心偏析、疏松及内裂纹缺陷严重的技术难题，改善连铸坯与轧材的致密度、均质化 ，偏析控制在 C 类0．5 级以下。硫印检查结果见图1。

# 3． 3 加热工艺

严格控制加热温度及加热时间 ，防止原始晶粒过度长大。加热温度以微合金碳氮化物的全固溶温度作为制定依据，对于含 Nb 量为 0． 03% 的Q345q 钢，通过固溶温度公式计算，确定碳氮化物的全固溶温度为 097 ℃ ，因此将加热温度确定为 1 200 ～ 1 250 ℃， 加热时间控制在 4 ～4． 5 h。

# 3． 4 轧制工艺

采用再结晶区和未再结晶区两阶段轧制工艺，使轧制在各区间低点完成，杜绝在部分再结晶区间内轧钢，以确保获得均匀的晶粒组织。粗轧阶段开轧温度≥l 050 ℃，单道次压下率控制在15% ～ 30% ，采用粗轧大压下量工艺，使奥氏体晶粒达到完全再结晶并充分细化; 精轧阶段累计变形量控制在 60% ～70% ， 增加晶粒间变形带的总面积，促进铁素体形核，并严格控制终轧温度，从而细化铁素体晶粒度。

为获得均匀、细小的铁素体 －珠光体组织，考虑到微合金析出成核率最大及最快的温度区间，兼顾矫直温度，轧后采用 ACC 冷却，严格执行控冷工艺，控制晶粒长大。

由表4、表5 和图2 检验结果可以看出，所生产的Q345q钢板全部满足新版标准的技术要求。

20 mm 和 40 mm 厚度钢板的力学性能均匀，横纵向差别较小 ，纵向性能略高于横向性能，其原因是钢板沿轧制方向存在一定的带状组织; 钢板的冲击韧性良好，－40 ℃冲击功最低值145 J，－60 ℃冲击功达到 69 J，其中纵向冲击功优于横向冲击功，冲击功值随厚度增加有所提高，这主要是由于40 mm 厚度钢板的冲击试样制取避开板材中心部位，减轻了中心偏析的不利影响。
