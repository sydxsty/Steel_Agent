# 厚板X80管线钢焊接残余应力场数值模拟研究

韩　磊

（中联重科股份有限责任公司，湖南长沙 410013）

［摘    要］为解决厚板 X80管线钢焊接残余应力导致的接头开裂、承载能力下降问题，文章通过高温拉伸试验获取其在20\~900℃的热物理与力学参数，基于 ABAQUS 建立考虑材料非线性、相变效应及双椭球移动热源的三维模型，结合生死单元实现多层多道焊仿真。结果表明：厚板X80管线钢焊接残余应力呈“双峰值”分布，焊缝中心及热影响区（HAZ）存在最大拉应力，峰值达580\~620MPa，超过材料屈服强度；板厚方向应力梯度显著，表层拉应力向心部逐渐过渡为压应力；当焊接热输入从1.2kJ/mm 增至1.8kJ/mm 时，残余拉应力峰值提升15%\~20%， 而预热温度从80℃升至150℃， 可使拉应力峰值降低12%\~15%。

［关键词］X80管线钢 ；焊接残余应力；有限元模拟 ［中图分类号］ TG404 ［文献标识码 ］A

# 0 引言

X80高钢级管线钢具有高强度和良好的抗延性断裂能力， 是目前国际上输气管道的主导钢材。随着管线钢强度级别的提高、板厚的加大，焊接接头在焊接过程中产生残余应力的倾向也随之增大。焊接残余应力是导致焊接氢致裂纹、脆性断裂、疲劳断裂、应力腐蚀裂纹等破坏损伤的主要因素之一 [1]。因此，精准掌握厚板 X80管线钢焊接残余应力的演化规律，明确工艺参数对残余应力的调控机制，对优化焊接工艺、提升接头可靠性具有重要工程意义。文章通过试验测试获取 X80钢高温性能参数，基于有限元方法建立考虑材料非线性、相变效应及双椭球移动热源的焊接仿真模型，系统分析残余应力分布特征及工艺参数影响规律，旨在为厚板 X80管线钢焊接质量控制提供理论支撑与技术参考。

# 试验材料和方法

试验以25mm 厚热轧 X80管线钢为研究对象，其主要化学成分为C （0.06wt%）、Si （0.25wt%）、 Mn （1.85wt%）、S （0.03wt%）、S （0.012wt%）， 室温力学性能参数为 ：屈服强度620MPa、抗拉强度710MPa、伸长率28%、断面收缩率65%。 焊接材料选用 E8018-G 低氢型焊条，直径4.0mm， 熔敷金属抗拉强度≥700MPa， 可满足厚板焊接的强韧性需求。为支撑有限元模拟的参数输入，采用Gleeble-3500热模拟试验机开展高温拉伸试验，测试温度区间20\~900℃，升温速率10℃ /s，保温5min 后拉伸，获取不同温度下的弹性模量、泊松比及屈服强度等热物理与力学参数。

焊接试验采用手工电弧焊进行对接焊，试板尺寸300mm×200mm×25mm， 坡口形式为 X 形对称坡口 [2]。焊接工艺参数按工序划分 ：打底焊电流140\~150A、电压22\~24V、焊接速度80\~90mm/min ；填充焊与盖面焊电流160\~180A、 电 压 24\~26V、 焊 接 速 度 70\~80mm/min ；全程控制层间温度150\~200℃， 预热温度100℃， 后热温度250℃并保温1h。

# 2 有限元模型建立

基于 ABAQUS 2022 软件， 结合 X80钢的热物理与力学参数， 采用“温度—应力” 间接耦合方法建立三维有限元模型， 流程如图 所示。

模型采用非均匀网格划分：焊缝及热影响区取2mm×2mm×2mm 细化网格，母材区取5mm×5mm×5mm粗化网格， 总 单 元 数 82650、 节 点 数 95320， 兼顾计算精度与效率。材料属性定义中，将高温拉伸试验获取的20\~900℃弹性模量、泊松比、 屈服强度按温度分段赋值，并引入相变体积膨胀系数（1.8×10-5/℃）， 以匹配实际焊接相变效应。

热源设置采用双椭球模型， 参数参考手工电弧焊热输入（1.2\~1.8kJ/mm）， 取热效率0.75、上下半球热流分配系数 0.6/0.4， 模拟电弧热输入特性 [3]。边界条件贴合试验约束状态：约束试板底部 Z 向位移、一端 X 向位移，另一端释放 X 向自由度 ；散热采用对流与辐射复合模型。温度场计算完成后，将结果作为载荷导入应力场模块，启用生死单元技术模拟多层多道焊过程，最终输出残余应力分布数据。

# 2.2 应力场控制

应力场控制以温度场计算结果为载荷输入，核心围绕X80钢高温弹塑性变形特性与焊接工艺约束状态构建分析体系，需精准耦合材料高温力学参数与约束条件，实现应力演化过程的动态模拟。

基于 X80钢在20\~900℃的力学性能数据，采用 J2流动理论 （vonMises 屈服准则）定义材料塑性流动行为，引入随动强化模型描述塑性变形中的应力硬化效应，同时修正热膨胀系数以纳入相变体积膨胀，确保本构关系与材料实际高温响应一致[4]。应力场计算遵循连续介质力学静力平衡原理， 其控制方程如式 （3） 所示。

# 2.3 结果及分析

# 2.3.1 残余应力的分布

残余应力呈现显著的区域化梯度分布特征， 见表1。由表1可知，焊缝中心与热影响区 HAZ（距熔合线2mm）为拉应力主导区，母材区则表现为压应力。 纵向残余应力峰值出现在焊缝中心表层， 达 615MPa， 接近 X80钢室温屈服强度（620MPa）；横向残余应力峰值位于 HAZ 表层，为 582MPa， 略低于纵向应力，这与焊接过程中纵向 （焊接方向）热变形约束更强的力学机制直接相关。从板厚方向看， 应力梯度差异明显 ：表层（距上表面2mm） 至心部（距上表面12.5mm）， 焊缝中心纵向应力从615MPa降 至 320MPa， 横向应力从 528MPa 降至 265MPa ；HAZ纵向应力从 592MPa 降至 295MPa， 横向应力从582MPa降至 285MPa， 纵向应力梯度 （19.6MPa/mm） 高于横向（15.8MPa/mm）。

该分布规律的核心成因在于厚板焊接的温度场非均匀性：表层受电弧直接加热， 高温区间 （＞1000℃） 范围大、热膨胀量显著，而心部温度低（＜300℃）、刚性约束强，表层热变形被抑制，冷却后形成高幅值拉应力；心部则因表层收缩产生挤压效应，形成压应力；母材区因远离热源，仅受间接热影响， 最终表现为低幅值压应力。

由表2可知， 热输入对残余应力的影响呈正相关：当预热温度固定为100℃时， 热输入从1.2kJ/mm 增至1.8kJ/mm，焊缝中心纵向拉应力峰值从520MPa 升至625MPa， 增幅达20.2% ；横向拉应力峰值从485MPa 升至590MPa， 增幅21.6%。这是因为热输入增大时，电弧加热范围扩展，焊缝及热影响区高温区宽度增加， 热膨胀量与后续冷却收缩量同步增大， 导致残余拉应力累积加剧。

预热温度对残余应力的影响呈负相关 ：当热输入固定为 1.5kJ/mm 时， 预热温度从80℃升至150℃， 焊缝中心纵向拉应力峰值从605MPa 降至520℃， 降幅14.0% ；横向拉应力峰值从575MPa 降至495MPa， 降幅13.9%。其核心机制在于预热温度升高可缩小焊接区与母材的温度梯度， 降低热变形差异， 从而缓解应力集中。

综合分析，将热输入控制在1.2\~1.5kJ/mm、 预热温 度 控 制 在 120\~150 ℃， 可使残余拉应力峰值稳定在520\~580MPa， 兼顾焊接效率与应力控制需求。

# 3 结论

文章建立的厚板 X80管线钢焊接有限元模型， 通过温度场与应力场试验验证，计算误差小于10%， 可精准预测残余应力分布。试验结果表明 ：①残余应力呈“双峰值 +梯度”特征，焊缝及热影响区纵向拉应力峰值达615MPa，板厚方向纵向应力梯度19.6MPa/mm， 母材区为压应力 ；②工艺参数中，热输入增至1.8kJ/mm 时拉应力峰值增幅超20%，预热温度升至150℃时降幅约14%， 最优区间为热输入1.2\~1.5kJ/mm、预热温度120\~150℃。研究成果为厚板 X80 钢焊接工艺优化及管道服役安全保障提供了理论支撑。
