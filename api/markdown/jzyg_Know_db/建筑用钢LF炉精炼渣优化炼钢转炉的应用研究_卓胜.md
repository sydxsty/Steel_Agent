# 建筑用钢 LF 炉精炼渣优化炼钢转炉的应用研究

卓 胜， 陈 涛

（攀枝花钢城集团有限公司， 四川 攀枝花 617000）

摘 要：采用 FACTSAGE 软件对某厂现有 LF 工序渣料熔点进行分析，表明炉渣组分处于 1 600 ℃以上高熔点区域，提出调整钢包渣成分、降低渣系熔点的技术方案，调整后 LF 精炼炉渣组成为 w（CaO）=50%\~55%、w（AlO）=10%\~15%、w（SiO2）=18%\~22%、w（MgO）=7%\~9%，渣系熔点降低，炉渣的流动性得到改善，使用效果及各项指标优于现有渣系，且取消萤石的使用，具有明显的社会经济效益。

关键词：无氟化渣剂 钢包渣 LF 精炼中图分类号：TF769.2文献标识码：A

# 引言

某厂在生产建筑用钢时，通过向料仓配加活性石灰和萤石来将其作为钢包精炼渣。该渣系存在的主要问题：LF 工序钢渣成分组成不合理，熔点高导致渣料铺展性能不好，熔化不均降低脱硫效率，现有脱硫率平均为 45.82%；萤石资源日益紧张，价格上涨导致冶炼成本上升，且不满足环保趋势。

近些年，国内钢厂及相关高校开发出以氧化铝为基础的 CaO-Al2O3 渣系，并在小范围内实现推广使用[1-2]，但其成本相对较高。本文结合现场生产实际和工艺需求，提出调整钢包渣成分、降低渣系熔点的技术方案，并组织工业试验，取得一定的效果。

# 1 现状调查

现有建筑用钢采用 LD+LF+CC 工艺生产，前期其渣料使用为出钢时每炉加入 300\~400 kg 活性石灰，到达 LF 工序时，根据成品 S 含量和钢包渣化渣情况补加活性石灰和萤石。

目前 LF 出站渣系情况如表 1 所示， 从整个渣系看，炉渣的碱度控制得较低，氧化性波动范围较大，氧化铝含量较低，整个渣系主要靠萤石提高炉渣流动性。

# 4 试验结果分析

# 4.1 脱硫情况和渣料加入对比

试验炉次与对比炉次工艺小平台的 S 含量基本相当。试验工艺小平台成品脱硫率为50.33%，对比工艺为 45.82%，试验工艺脱硫率比原工艺高 4.49%；试验工艺活性石灰和高碱度精炼渣之和较原工艺降低12 kg/ 炉，专用精炼渣平均 190 kg/ 炉，萤石平均为166 kg/ 炉，专用精炼渣用量较原有萤石增加24 kg/炉。

# 5 结论

1）试验精炼渣用于方坯建材钢 LF 工序技术可行，可完全替代萤石的使用，吨钢工序辅料成本降低。2）试验表明，在LF 出站S 含量相当的情况下，试验工艺 S 分配比为 96，而原工艺 S 分配比为 92，说明试验工艺的炉渣脱S 能力较原工艺更强。3）根据热力学软件分析，试验炉次炉渣熔点已经处于低熔点区域，表现为试验炉次炉渣均能充分熔化，现场跟踪未出现化渣不良的炉次。4）试验工艺取消萤石使用，在降低熔渣对钢包炉衬侵蚀的同时，有效避免萤石对人体及设备造成的伤害，具有较大的社会效益。

# Application of LF Refining Slag for Building Steel to Optimize Steelmaking Converter Zhuo Sheng, Chen Tao （Panzhihua Gangcheng Group Co., Ltd., Panzhihua Sichuan 617000）

Abstract: Using FACTSAGE software to analyze the slag melting point of the existing LF process in a factory, it is shown that the slag composition is in the high melting point area above 1 600 ℃, and the technical scheme of adjusting the ladle slag composition and reducing the melting point of the slag system is proposed. After adjustment, the LF refining slag composition is w (CaO)=50%\~55%, w(Al2O3)=10% \~15%, w (SiO2)=18%\~22%, w (MgO)=7%\~9%, the slag melting point is reduced, and the fluidity of the slag is improved. The use effect is better than the existing slag system, and the use of fluorite is canceled, which has obvious social and economic benefits.

Key words: fluoride-free slag agent; ladle slag; LF refining
