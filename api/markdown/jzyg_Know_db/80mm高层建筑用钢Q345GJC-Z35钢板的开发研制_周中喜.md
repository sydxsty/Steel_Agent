# 周中喜， 温志红

（宝武集团广东韶关钢铁有限公司，广东 韶关 512123)

摘要：采用 270 mm 连铸坯料， 在 3450 mm 中厚板轧机上针 对Q345GJC-Z35 钢种进行了 80 mm 厚规格钢板的工艺试验， 根据性能结果， 确定了相应的轧制及冷却工艺， 结果表明：采用碳的质量分数约为 0.16 %, 添加适量铌、钒、钛等微合金元素， 按照两阶段控制， 当轧到成品钢板厚度的 1.6\~1.7倍时开始待温，精轧开轧温度小于 900 ℃， 终轧温度为800\~850 ℃, 终冷温度为 680\~720 ℃， 生产的 Q345GJC-Z35高强度厚板的性能完全满足国家标准GB/T19879-2015要求，而且其钢板的平均断面收缩率都大于40%，远高于Z35钢板的技术要求。实现了钢板很好的强韧性匹配， 工艺上不用后续热处理， 仅采用两阶段轧制， 减少了工艺流程， 节约了成本。

关键词： Q345GJCZ35; 厚板； 控制控冷； 屈强比； Z向性能
