# 高强度桥梁钢防脆断设计方法研究

王晓光（山东通达路桥规划设计有限公司， 山东  烟台 264000）

摘要：为探究高强度桥梁钢的防脆断设计方法，以Q690qE 钢为研究对象，针对大型跨海桥梁进行分析。首先，通过全桥受力分析，识别关键杆件，并计算其最大拉应力；然后，基于设计要求，确定初步截面尺寸，并通过迭代核查流程，确保所有杆件满足防脆断标准；最后，采用ABAQUS 软件建立有限元模型，模拟实际工作条件下的受力情况。结果表明，上弦杆和斜腹杆承受的主要为拉伸应力，而箱梁节段和腹杆主要承受压缩应力；通过调整板材厚度，优化局部应力水平，可确保结构满足抗脆断设计要求；通过上弦杆和斜腹杆的板材厚度调整，能减少应力集中，提高结构的整体安全性。

关键词： 高强度桥梁钢； 防脆断； Q690qE 钢中图分类号： U442.5 文献标识码： BDOI:10.16248/j.cnki.11-3723/u.2024.29.035

# 0 引言

在现代交通基础设施建设中，桥梁作为连接城乡、促进区域经济发展的重要纽带，其安全性和耐久性受到了广泛关注。高强度桥梁钢作为桥梁结构的关键材料，其性能直接影响桥梁的承载能力和使用寿命。然而，在实际应用中，高强度钢材往往伴随着脆性增加的问题，从而影响桥梁的安全运营。如何平衡强度与韧性，防止脆断现象的发生，仍然是一个亟待解决的技术难题。特别是在极端气候条件、重载交通和地震等自然灾害的影响下，桥梁结构的脆断问题尤为突出。鉴于此，本文旨在探究高强度桥梁钢的防脆断设计方法，以提高高强度桥梁钢的使用安全性，从而为桥梁建设提供更为坚实的材料保障。

# 1  桥梁钢结构典型构造断裂分析

# 1.1 典型构造

钢结构桥梁根据其形式和功能， 可分为多种类型，如钢板梁桥、钢桁梁桥、钢桁拱桥，以及以钢桁梁或钢箱梁作为主梁的斜拉桥和悬索桥。其中，钢板梁桥因其I 形主梁与横联结构，提供了高度稳定性和良好的荷载分散能力，广泛应用于中小跨度桥梁；钢桁梁桥由弦杆、腹杆和节点构成的主桁架，具有卓越的抗扭矩和弯矩能力，结构刚度大，适合大跨径桥梁设计[1]。

# 1.2 裂纹形式

裂纹通常源于焊接接头的缺陷，如焊缝内部的裂纹、夹渣和气孔等。裂纹缺陷在循环应力作用下会逐渐发展成宏观裂纹，最终导致疲劳断裂。疲劳裂纹大部分在焊缝根部开始发展，呈椭圆形扩散，其扩展方向主要沿着板材的宽度和厚度。在T 形结构中，裂纹通常出现在水平板的横向对接焊缝处，与杆件的拉力方向垂直，且在竖板上均匀分布；在棱角构造中，裂纹主要出现在横向对接焊缝处，垂直于拉力方向，并沿棱角线均匀扩展。

# 2 桥梁钢结构防脆断设计研究

# 2.1 工程概况

以某大型跨海桥梁Q690qE 高强度桥梁钢为研究对象，该跨海大桥作为城市快速通道，总长度为3.085 km，由主桥和海上入口的多个桥梁组合而成。主体桥梁由两段分别为202.5 m 和280 m 的下承式钢桁梁桥组成，桥面宽度为48.4 m，设计为双向8 车道，包括一个中心电动车道。钢桁梁的构造采用双主桁三角桁架设计，主桁在桥面位置的中心横向距离约10 m，设计内倾角为8°；桁架的纵向设计呈现高度变化，边缘支点和主跨跨中的桁高约为6.91 m， 而中间支撑处桁高达15.76 m。

在该桥桁架设计中，结合8°内倾角和纵向变化的高度，主桁下端节点采取整体焊接，顶部某些节点设置箱形横向连接。需要注意的是，在部分荷载条件下，由于采用了边跨和主跨连续的大型钢桁梁，中支点附近会承受较大的负弯矩。

# 2.2 防脆断设计流程

桥梁钢结构的设计为迭代循环过程，首先，通过全桥受力分析，识别可能发生断裂的关键杆件；

其次，计算关键杆件可能承受的最大拉应力。若满足设计要求，则确定初步截面大小；否则，需根据核查结果进行调整，并继续迭代核查，直到满足所有要求。

脆断性能核查的主要步骤：①基于对整个桥梁的力学分析，确定可能出现断裂失效的关键杆件；②根据完整桥梁的力学分析，计算关键杆件可能承受的最大拉力；③考虑到工程设计的温度、关键杆件能够承受的最大拉力，以及杆件的内部结构类别，通过参考选材表确定杆件可使用的钢板最大厚度Bmax；④对比允许使用的最大厚度Bmax和推荐的最大厚度B0，如果B0不超过Bmax，表明杆件满足防脆断设计要求，如果B0超过Bmax，则表明无法满足防脆断设计需求，需要调整杆件的截面尺寸，并重新进行核查流程，直至满足所有设计标准[3]。

# 2.3 计算模型

在连续钢桁梁结构的主桥部分，特定荷载工况下，中支点附近的梁体可能承受显著负弯矩，导致部分杆件承受高拉力，增加脆性断裂风险。本研究选取了中支点附近受力最不利的节段，包括节点S13、S14、S15 和节点 X13、X14、X15 及其相连的上弦杆、箱梁和腹杆，如图1所示。

![](images/0f063e10e73015327e7ec2756da49e799c9d656185890a4f7761698e7d7d5000.jpg)  
图1 节段模型在桥梁中位置

该跨海大桥位于东南沿海，该区域具有气候温暖、湿度高、多雨和高温的特点。根据桥位处的年平均气温和极端最低气温，桥梁设计温度为-5 ℃。根据设计图纸和材料性能表，初步拟定上弦杆、斜腹杆和中间竖杆的板厚，以确保结构的强度、刚度和稳定性。

利用ABAQUS 软件建立有限元模型，采用S4R壳单元进行模拟。模型中，节点附近的单元尺寸较小，而远离节点的区域单元尺寸较大，总计约有57万个单元。模型中钢材密度为7 850 kg/m3，弹性模量为 210 000 MPa， 泊松比为0.3。

结合 MIDAS Civil 全桥模型最不利荷载组合，计算S14 和X14 截面最大负弯矩时各杆件的轴力和弯矩。将荷载信息施加到ABAQUS模型中，并对特定杆件施加相应的位移约束，模拟实际工作条件[4]。

# 2.4 防脆断设计

有限元分析中，上弦杆和斜腹杆主要承受拉伸应力，而箱梁节段和腹杆则主要承受压缩应力，模型最大和最小主应力如图2 所示。上弦杆的最大主应力从顶部向下逐渐减小，呈现出层状分布，应力在220\~320 MPa。在节点板与上弦杆顶板焊接处，存在应力集中现象，最大集中应力达到399.7 MPa，上弦杆最大主应力见图3。对于倾斜支撑，其最大主应力为203.3 MPa，斜腹杆最大主应力如图4所示。

顶部连杆的最高主应力为 320 MPa，约为Q690qE钢屈服强度的46.4%，位于应力强度等级Ⅱ与Ⅲ之间；而倾斜支撑的最高主应力为203.3 MPa，约占Q690qE 钢屈服强度的29.5%，略低于应力强度等级Ⅰ，因此按照应力强度等级Ⅰ核查[5]。

在-5 ℃环境温度下，顶部连杆的T形和棱角构造允许的最大板厚分别为58 mm 和46 mm。 取较小值，即顶部连杆的最大允许板厚为46 mm。与初始设计相比，超过允许值，因此不符合抗脆断要求。在-5 ℃和应力等级I 条件下使用的倾斜支撑，其内部棱角结构的最大允许使用板厚为57 mm。考虑到倾斜支撑初始的水平和竖直板材厚度为44 mm，加劲板厚度为36 mm，使用的板材厚度均低于最大允许值，符合抗脆断设计标准。

为确保抗脆断安全，顶部连杆的板材厚度需要适当调整，以满足最大允许使用板厚46 mm 的要求。调整后，顶部连杆的顶板和底板厚度应调整为44 mm。 仅对顶部连杆的板材厚度进行轻微调整，因此对桥梁截面的整体承载能力及弯曲性能的影响较小，主要优化了局部应力水平[6]。

调整后上弦杆和斜腹杆的最大主应力云图见图5，弦杆的最大主应力降低，约在 200\~310 MPa，应力集中点的最大主应力为375.3 MPa。

上 弦 杆 的 最 大 主 应 力 为 310 MPa， 约 为Q690qE 钢的屈服强度的0.449 倍，应力强度为等级Ⅱ\~Ⅲ。考虑到-5 ℃的温度，最大允许使用板厚度分别为 59 mm （T 形结构） 和 47 mm （棱角结构），取最小值，因此SJ14 弦杆最大允许使用板厚度47 mm。比较弦杆使用的钢板厚度，经过厚度调整后，上弦杆满足防脆断设计要求。斜腹杆的最大主应力为 203.6 MPa，约为 Q690qE 钢的屈服强度的0.295 倍，低于应力强度等级Ⅰ，按应力强度等级Ⅰ进行核验。斜腹杆内棱角结构的最大允许使用板厚度为57 mm，所以斜腹杆仍然满足防脆断设计要求。

# 3 结束语

桥梁上弦杆和斜腹杆主要承受拉伸应力，而箱梁节段和腹杆则主要承受压缩应力。为确保抗脆断安全，仅对顶部连杆的板材厚度进行轻微调整，优化了局部应力水平，提高结构的整体安全性，以期为高强度桥梁防脆断设计方法提供参考。
